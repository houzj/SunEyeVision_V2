# 方案设计模板

## 方案输出格式

```markdown
## 问题分析
- 用户意图：[理解用户的真实需求]
- 涉及的代码：[文件和方法]
- 相关规则检查：[列出相关 rule-XXX]

## 解决方案
### 方案概述
[简要描述]

### 技术方案
1. [步骤1]：描述 + 遵循的规则
2. [步骤2]：描述 + 遵循的规则

### 实施步骤
1. [步骤1]
2. [步骤2]

### 验证清单
- [ ] 遵循 rule-XXX: [规则名]
- [ ] 遵循 rule-XXX: [规则名]

### 风险控制
- 风险：[描述] → 缓解：[措施]
```

## 方案设计原则

1. 全局视角：分析完整上下文（涉及模块、依赖、影响范围），禁止点对点修复
2. 复用优先：使用项目现有框架和模式，禁止重复造轮子
3. 风险控制：识别风险、提供缓解措施和回退方案
4. 上下文发现：动态搜索和分析现有代码，不硬编码假设
