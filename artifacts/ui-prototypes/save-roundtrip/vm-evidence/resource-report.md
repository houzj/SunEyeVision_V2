## 给 VM-PERSIST-14 的有限结论

“引用路径”并非统一的方案资源策略：图像列表有受控样本的归档附件恢复；订阅文件夹仍依赖文件夹；匹配模型的 UI 导入路径进入模块模型字节和 UserData，但容器层未证；标定读取工具的 `FileData` 受显式开关控制。自研实现若要比较等价，应按**资源种类 × 模式 × 保存开关 × 源文件是否仍在**分别列路径、字节所有权、失败返回、重开结果。此矩阵是证据驱动的比较建议，非原版全域行为结论。相对路径基准、跨目录/机器搬迁、VM 方案总体保存异常和各模型 native 容器写入链仍未知，交由对应目标继续补证；本局部任务不扩到完整方案解析。
