# 文档维护源码与本地证据输入

本目录中已纳入版本控制的生成器、导航脚本和规范页面快照用于维护主文档，不是产品运行代码。规范页面快照与可浏览页面成对保存；不要将它们和CAS准备副本、截图、日志混为一类。

交付状态生成器 `tool-framework-contract/build-live-implementation-status.cjs` 使用本地冻结的 `live-implementation-status.json` 及其逐SHA引用的取证输入；交付总览生成器 `build-delivery-home-overview.cjs` 还需要 `final-review-scope.json`、交付账本、角色登记和首页维护内容。这些运行取证数据不随本次未提交文件整理批量上传，也不重新生成测试结果。

新检出没有本地取证输入时：

- 保留已提交HTML，直接阅读其中明确区分的历史结果、未验证项和暂停状态。
- 主文档总生成入口仅在本地状态输入存在时调用交付状态生成器；总览发布入口缺输入时返回 `SKIPPED_LOCAL_EVIDENCE_UNAVAILABLE`，不以空数据覆盖页面。
- 不要将缺少输入解释为产品验收失败或通过。需要重建该部分时，应由交付经理按原证据索引恢复输入并核对SHA，不以新日志冒充旧结果。

本轮只核对语法、JSON及页面静态结构，不运行全站再生成、浏览器视觉验收、产品构建或独立验收。用户主动暂停的优化收口继续保持暂停。
