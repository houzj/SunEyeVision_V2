步骤交付路线具体改法验收（尚未执行）依赖/门槛
F0冻结事实与合同保留整改标现有类型/调用者/所有者；统一身份与质量状态表，列每种资源借用/保留/复制政策。先覆盖根运行、两子调用和相机；不以编出新接口当实现完成。无先决，但需产品确认失败/容错与逐帧政策
F1修执行终态与共享资源必须整改扩展Session/Scope与执行器收尾：跟踪所有Task及回调，应用级设备仲裁，超时隔离。取消不响应工具、并行子任务异常、停止异常下lease不早释，非取消异常不漏。F0；先有正确退役再做共享结果生命周期
F2字段与值访问适配层借鉴VM重做公共层ToolResults→FieldDescriptor/ValueRecord适配；绑定经统一门读取；根/子全局快照同版。动态字段迁移、数组形状错、缺变量、无效生产者、两Scope同NodeId均可定位。F0，资源载体需要F1语义；先适配2种工具再扩
F3批次发布与投影分离借鉴VM＋自研融合集中Outcome提交/字段重置/循环采用；所有显示和通信读版本化批次，按通道背压。普通/调试/相机/失败/切节点同合同；订阅者抛错不破坏执行结局，历史不串帧。F1/F2；保留旧入口适配，逐个切换
F4分层、兼容与退役收口保留整改＋按需拆分执行公共合同脱离WPF扩展；插件/方案版本映射；控件、分析及工具会话统一关闭。旧插件与方案、资源URI、设计器、干净机部署、资源曲线/长稳分别验收。F1-F3；按仓库规则实施时另做全量Release与运行，本轮不执行
F5测量后决定性能路线暂缓选型统计端到端延迟、分配、峰值内存、队列、丢弃/退役时长，再评估零拷贝和调度后端。输入/硬件/质量门槛一致，保留失败与缺测；无性能数据不宣称优于VM。正确性门禁通过，原厂性能对照需合法可用环境与另行授权
