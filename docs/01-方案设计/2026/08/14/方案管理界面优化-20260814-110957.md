## 一、改前 → 改后 → 依据

**改前（你现在看到的）**：程序主界面已支持亮/暗主题，但点"解决方案配置"弹出的这个窗口——白花花一片（全硬编码颜色）、系统灰条标题栏、emoji 按钮、假搜索框、卡片干巴巴、底部一行"跳过"按钮和复选框（且与标题栏未来方案重复）。暗色主题下特别突兀。

**改后（优化后你看到的）**：这个窗口和主界面同一套设计语言——VM 风格深色自绘标题栏（矢量 Logo + 双行标题 + 版本号 + 极简控件）、亮暗主题完全跟随、左侧"最近打开"列表 + 右侧工程化文字按钮卡片区、搜索真能过滤、无"跳过"入口（不选方案进不了空主界面）。

**依据**：标题栏照搬 VisionMaster（用户提供的参考图：深底 + 矢量 Logo + 版本号 + 右上"不再显示"）；主题化照抄项目里已完成的 `GlobalVariableManagerDialog`/`CommunicationManagerDialog`；最近打开数据 `SolutionRegistry.GetRecent()` 底层早已具备，只差界面接线。

## 四、解决方案（6 个改动模块）

### 模块 ① 无边框自绘标题栏（VM 风格）
- `SolutionConfigurationDialog` 改 `WindowStyle="None"` + 静态 `WindowChrome`（仿 MainWindow，CaptionHeight 覆盖标题栏，`UseAeroCaptionButtons=false`，保留可缩放）。
- 标题栏内容：**深色背景**（不随主题，VM/VS 惯例）+ 顶部 1px 强调色细线 + 左侧**矢量 Logo**（Path 绘制，不直接用模糊 ico）+ 双行文字（"太阳眼视觉"粗体 / "SunEyeVision"细体）+ 版本号（程序集读取）+ 右上 `□ 启动时跳过` + `✕`。
- 标题栏可拖动，控件 `WindowChrome.IsHitTestVisibleInChrome=True`。

### 模块 ② 整体主题化
- 全部硬编码颜色（约 30 处）替换为 `ThemeKeys` 语义色板：窗口 `PanelBackgroundBrush`、卡片 `TableRowBackgroundBrush`/`BorderBrush`、文字 `TextPrimary/TextSecondaryBrush`、选中态 `AccentBrush`、输入框 `InputBackground/InputBorder`、滚动条主题键。
- 按钮样式照抄 `GlobalVariableManagerDialog` 的 `PrimaryButtonStyle`/`SecondaryButtonStyle`。

### 模块 ③ 左侧"最近打开"列表
- VM 新增 `RecentSolutions`（`SolutionRegistry.GetRecent(6)`），布局改左右两栏（左约 240px）。
- 每行：图标 + 名称 + 相对时间（今天显示时分 / 昨天 / 3天前 / 上周）；单击/双击启动；底部固定"⚙ 全部解决方案 (n)"。
- 空记录显示"暂无最近打开的方案"引导文案。

### 模块 ④ 右侧卡片区 + 搜索 + 工程化按钮
- 工具栏改**纯文字按钮**（`[ 新建 ] [ 载入 ] [ 另存 ] [ 复制 ] [ 删除 ]`，去 emoji，扁平小圆角主题色），"设为默认"同款放右侧。
- 搜索框接真实过滤：VM 加 `SearchText` 属性 + `FilteredMetadatas` 集合（按名称/描述/路径，**只过滤右侧全部列表，左侧不动**）。
- 卡片视觉升级：品牌色图标占位（不加载缩略图）、选中/悬停态、圆角轻阴影，信息保留现有字段。

### 模块 ⑤ 跳过配置去重 + 启动交互调整
- **删除底部整行**（复选框 + "跳过配置"按钮 + "启动解决方案"按钮全部移除）。
- "启动时跳过配置"**上移到标题栏右上**（VM"不再显示"同款位置），勾选仍走 `SkipStartupConfig` 持久化。
- 启动方式改为：**双击卡片 / 选中后回车**（保留现有 `LaunchCommand`，新增回车 KeyBinding）。
- ✕ 行为按场景区分（调用方决定）：
  - **启动场景**（`App.xaml.cs`）：result==false → `Application.Current.Shutdown()` 退出程序（不提供空主界面入口）；
  - **菜单场景**（`MainWindowViewModel`）：result==false → 仅关闭对话框，回主窗口。

### 模块 ⑥ 连带子对话框主题化
- `NewSolutionDialog.xaml` / `EditSolutionDialog.xaml`：硬编码颜色替换为 `ThemeKeys`（仅主题化，**保留系统标题栏**，KISS）。

## 六、防御机制

| 机制 | 说明 |
|------|------|
| 主题 Key 契约 | 只使用 `ThemeKeys` 中已定义 Key，不新增硬编码；构建后目视验证亮/暗两套 |
| 启动流程回归 | 修改 App.xaml.cs 后验证"启动→选方案→进主界面"与"启动→✕→退出"两条路径 |
| 事件驱动不变 | 最近打开/全部列表均走现有 `SolutionAdded/Removed/Renamed/Updated/MetadataRefreshed` 事件，不破坏增量更新 |
| 报错优先 | 搜索/最近打开逻辑无兜底默认值，数据异常直接记录日志 |
