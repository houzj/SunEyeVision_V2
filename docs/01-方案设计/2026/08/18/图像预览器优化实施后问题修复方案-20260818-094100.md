# 图像预览器优化实施后问题修复方案

## 🔄 改前 → 改后 → 依据（写在最前面）

### 改前（用户视角）
方案 C（纯 WPF 重建）实施后，用户实测暴露两个问题：
1. **保存方案再打开**：之前在图像预览器里加过的图片，重开后缩略图全部消失，得重新加一遍。
2. **滚动缩略图**：拖得快、连续翻页时会卡顿，单次翻页也稍慢。

同时代码里还躺着一整套 10 个文件的"自研缩略图调度/缓存/解码体系"，但全代码库搜不到一次实例化（纯死代码），白白占着维护成本；实际显示却走一个每次绑定都新建对象的转换器，性能反而最差。

### 改后（用户视角）
1. **重开方案**：之前加过的图片缩略图原样恢复，不用重新加。
2. **滚动缩略图**：拖动、翻页顺畅跟手；已看过的图从缓存秒出，新图后台加载不卡界面。
3. **代码层面**：死代码全部清掉（-10 文件），图像预览器只剩一条简洁的"后台解码 + 缓存 + 绑定 Thumbnail"链路，和一个被测试用例锁住的持久化链路。

### 依据（业界参考）
| 参考 | 做法 | 借鉴点 |
|------|------|--------|
| 微软官方 WPF-Samples PhotoViewerDemo | `BitmapImage` + `DecodePixelWidth` 解码时缩小 + `Freeze` 跨线程；列表 `VirtualizationMode.Recycling` | 缩略图用 WIC 正确用法 |

## 一、问题现状复盘（两个用户反馈问题）

### 问题 1：保存重开缩略图不显示
**已确证**：用户保存的方案文件（`C:\Users\houzhongjie\Desktop\122333333.solution`）图像节点 JSON **没有 `ImageSourceConfig` 字段**（只有 `Parameters`/`ParamSettings`/`SelectedDisplaySource`）。
静态链路排查确认无断点：
- 保存侧 `MainWindowViewModel.SaveSolutionData` 遍历 `rootWorkflow.Nodes`，判断 `node is WorkflowNode && wfNode.InputSource is ImageInputSource`
- UI 层创建节点是 `WorkflowNode`（`src/UI/Services/Workflow/WorkflowNodeFactory.cs`），确实加入引擎工作流
- `WorkflowJsonConverter.Write` 用编译期 `WorkflowNodeBase` 序列化，`ImageSourceConfig` 在基类上会被写入
- 加载侧 `WorkflowJsonConverter.Read` → `TypeConverter` → `FromBase` 恢复 `ImageInputSource`

**结论**：问题在运行时实例状态，必须用**日志 + 测试**定位（用户要求的方式）。

### 问题 2：滚动/翻页卡顿
**已确证根因**：XAML 缩略图绑定 `FilePath` + `FilePathToImageSourceConverter`，每次虚拟化容器回收重绑定时 `new BitmapImage()`（无缓存、不解冻），UI 线程反复排队 WIC 解码。
而 `ImageInfo.Thumbnail` 属性和缓存基础设施**已存在但被架空**（方案 C 重写时退回转换器写法）。

## 四、修复问题 2（缩略图渲染架构）

### 4a. 新增静态缩略图缓存
```csharp
private static readonly ConcurrentDictionary<string, BitmapSource> s_thumbnailCache = new();
```
同路径滚回秒出，不重复解码；上限 30 张（复用现有 ImageCache 的 LRU 思路）。

### 4b. `ImageInfo.EnsureThumbnail()`（后台线程解码 + Freeze + 回 UI 更新）
```csharp
public void EnsureThumbnail()
{
    if (Thumbnail != null || _thumbnailRequested) return;
    _thumbnailRequested = true;
    Task.Run(() =>
    {
        var thumb = s_thumbnailCache.GetOrAdd(FilePath, DecodeThumbnail); // WIC+DecodePixelWidth=100+Freeze
        Dispatcher.InvokeAsync(() => { Thumbnail = thumb; });             // 触发 PropertyChanged
    });
}
```

### 4c. XAML 改绑定
```xaml
<Image Source="{Binding Thumbnail}" Width="60" Height="60"
       Stretch="Uniform" RenderOptions.BitmapScalingMode="LowQuality"/>
```
删 `FilePathToImageSourceConverter` 引用（保留转换器文件或一并清理，看 ImageInfo 是否还需要）。

### 4d. 加载时机
`AppendFiles`/`LoadFromConfig` 时对可见项调 `EnsureThumbnail()`；虚拟化 + `IsVisibleChanged` 懒加载。
