# 图像预览器缩略图渲染治本方案

## 🔄 改前 → 改后 → 依据（写在最前面）

### 改前（用户视角）
历经多轮修复后，当前状态：
- **加载成功率高**（原图点击都能显示，缩略图元数据齐全）
- **但拖动滚动条**：视口内缩略图不能即时显示，等待时间不确定
- **部分缩略图空白**：看不出是"还在解码"还是"解码失败"
- **加缓存后反而变灾难**：之前无缓存时加载快只是滚动卡，现在有了缓存连基本显示都受影响

### 改后（用户视角）
- 滚动到哪，视口内缩略图**即时**显示（缓存命中秒出，未命中后台并行解码）
- **有状态反馈**：加载中（占位）、成功（图）、失败（占位+日志），不再是"空白猜谜"
- 快速拖动/连续翻页**流畅**，所见即所得

- **现状**：已加诊断日志 + 5 个序列化契约测试（全过），确认序列化层无 bug。根因在保存侧运行时判断，待日志确认。

### 问题2：连续滚动卡顿 → 已演变为"灾难"

| # | 层 | 根因 | 状态 |

## 二、最终优化方案（3 阶段）

### Phase A：修复并发模型（治本，灾难根因）

**目标**：解码并行，锁只保护缓存字典。

**改 `LoadThumbnail`**（ImagePreviewControl.xaml.cs:357-383）—— 把解码移出锁：

```csharp
internal static BitmapImage? LoadThumbnail(string filePath)
{
    if (string.IsNullOrEmpty(filePath) || !File.Exists(filePath))
        return null;

    // 快路径：锁内只查缓存（微秒级）
    lock (s_thumbnailLock)
    {
        var cached = s_thumbnailCache.Get(filePath);
        if (cached != null) return cached as BitmapImage;
    }

    // 慢路径：锁外并行解码（I/O + CPU，互不阻塞）
    BitmapImage? bitmap;
    try
    {
        bitmap = DecodeThumbnailCore(filePath);   // WIC 解码 + Freeze
    }
    catch (Exception ex)
    {
        VisionLogger.Instance.Log(LogLevel.Warning,
            $"缩略图解码失败 | {filePath} | {ex.GetType().Name}: {ex.Message}",
            "ImagePreviewControl");
        return null;
    }

    // 写缓存：锁内极短
    lock (s_thumbnailLock)
    {
        s_thumbnailCache.Set(filePath, bitmap);
    }
    return bitmap;
}
```

**改 `ImageCache`**（xaml.cs:190-249）—— 加线程安全的 `Get`/`Set`：

```csharp
public BitmapSource? Get(string filePath)
{
    if (_cacheMap.TryGetValue(filePath, out var node))
    {
        _lruList.Remove(node);
        _lruList.AddFirst(node);
        return node.Value.Bitmap;
    }
    return null;
}

public void Set(string filePath, BitmapSource? bitmap)
{
    if (bitmap == null) return;
    if (_cacheMap.ContainsKey(filePath)) return;   // 已有则不动
    var entry = new CacheEntry(filePath, bitmap);
    _cacheMap[filePath] = _lruList.AddFirst(entry);
    if (_lruList.Count > _maxCacheSize)
    {
        var lastNode = _lruList.Last;
        if (lastNode != null)
        {
            _cacheMap.Remove(lastNode.Value.FilePath);
            _lruList.RemoveLast();
        }
    }
}
```

（删掉 `GetOrAdd` 或保留仅内部使用；`LoadImageOptimized` 也改走 Get/Set）

**效果**：8 张视口图并行解码（8 线程同时工作），总耗时从"8×单张串行"降为"单张耗时"，滚动即时显示。

### Phase B：失败可见 + 可重试（rule-015）

**改 `EnsureThumbnail`**（xaml.cs:135-152）—— 失败重置标志 + 状态机：

```csharp
public void EnsureThumbnail()
{
    if (Thumbnail != null || _thumbnailRequested) return;
    _thumbnailRequested = true;

    var path = FilePath;
    var dispatcher = System.Windows.Application.Current?.Dispatcher;
    if (dispatcher == null) return;

    System.Threading.Tasks.Task.Run(() =>
    {
        var thumbnail = ImagePreviewControl.LoadThumbnail(path);
        dispatcher.InvokeAsync(() =>
        {
            if (thumbnail != null)
            {
                Thumbnail = thumbnail;         // 成功
            }
            else
            {
                _thumbnailRequested = false;   // 失败重置，允许滚动回来重试
            }
        });
    });
}
```

**加状态枚举 + 属性**（ImageInfo）：

```csharp
public enum ThumbnailState { Pending, Loading, Loaded, Failed }

private ThumbnailState _thumbnailState;
public ThumbnailState ThumbnailState
{
    get => _thumbnailState;
    private set { _thumbnailState = value; OnPropertyChanged(nameof(ThumbnailState)); }
}
```

- `EnsureThumbnail` 入口：`Pending → Loading`
- 成功：`Loading → Loaded`
- 失败：`Loading → Failed`（显示占位）

### Phase C：XAML 状态反馈

**DataTemplate 改三态**（ImagePreviewControl.xaml:413-419）：

```xaml
<Grid Width="60" Height="60">
```
