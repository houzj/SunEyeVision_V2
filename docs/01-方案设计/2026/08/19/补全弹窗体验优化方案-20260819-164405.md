# 补全弹窗体验优化方案（主题化 + 图标 + 描述 + 签名帮助）

> 2026-08-19。脚本工具补全弹窗体验专项方案。
> 前置依赖：脚本编辑器流畅性根治（增量通道 + 滚动按行索引）已完成（be38606）。
> 本方案解决补全弹窗的 4 个体验差距：不受主题管控、无类型图标、无签名/文档描述、方法参数不补全。

## 🔄 改前 → 改后 → 依据

### 改前（用户视角）
1. 补全弹窗是白底，切到暗色主题时刺眼，跟周围深色界面不协调（不受主题管控）
2. 补全项只有文字，没有图标，分不清哪个是类、哪个是方法、哪个是属性
3. 鼠标悬停补全项没有签名/文档说明，只能靠名字猜
4. 方法名能补全，但输入 `(` 后不显示参数提示，不知道方法要传几个参数、每个参数是什么

### 改后（用户视角）
1. 弹窗背景、文字、选中高亮跟随主题（亮色白底、暗色深灰底），与界面统一
2. 补全项带完整类型图标（类/方法/属性/字段/枚举各有图标），一眼区分
3. 悬停补全项显示签名/文档描述
4. 输入 `(` 弹出参数提示浮窗（OverloadInsightWindow），重载可切换、当前参数高亮

## 问题分析（Phase 0）

### 需求拆解
- **表面需求**：补全弹窗更好看、更专业、能提示参数
- **根本问题**：补全弹窗只是 AvalonEdit 默认弹窗（无主题/图标/描述），且缺 Roslyn 的 SignatureHelp 参数提示服务
- **问题分类**：功能缺失（SignatureHelp 完全缺失）+ 实现粗糙（弹窗无主题/图标/描述）

### 方法对比（SignatureHelp 服务端）

| 维度 | 方案 A：SignatureHelpService.GetService（推荐） | 方案 B：MEF ISignatureHelpProvider | 方案 C：不用 Roslyn 服务，自解析 |
|------|--------------|--------------|--------------|
| 实现方式 | Roslyn 官方 `SignatureHelpService.GetService(doc)` | RoslynPad 的 MEF `ISignatureHelpProvider` 聚合 | 手动解析方法签名 |
| 架构一致性 | ✅ 官方 API，无 MEF 依赖 | ⚠️ 需 RoslynHost MEF 支持 | ❌ 重复造轮子 |
| 复杂度 | 低（一个调用） | 中（需 MEF 容器） | 高（重载/泛型/可选参数难处理） |
| 维护成本 | 低 | 中 | 高 |
| 长期 ROI | 最高 | 中 | 低 |

## 解决方案

### 方案概述
给补全弹窗加主题化、完整类型图标、延迟描述加载；新增 SignatureHelp 参数提示（用 Roslyn 官方 `SignatureHelpService` + AvalonEdit `OverloadInsightWindow`）。全部对齐 RoslynPad。

### 技术方案

**改动 1：弹窗主题化（ShowCompletionWindow）**
```csharp
var window = new CompletionWindow(CodeEditor.TextArea)
{
    StartOffset = startOffset,
    EndOffset = endOffset,
    Background = GetThemeBrush(SdkThemeKeys.PanelBackgroundBrush),
    Foreground = GetThemeBrush(SdkThemeKeys.TextPrimaryBrush),
};
```

**改动 2：完整类型图标（RoslynCompletionData）**
```csharp
private System.Windows.Media.ImageSource? _image;
public System.Windows.Media.ImageSource? Image => _image ??= CreateImage();

private System.Windows.Media.ImageSource? CreateImage()
{
    var kind = GetCompletionKind(item.Tags);   // type/method/property/field/...
    return kind == null ? null : ThemeGlyphProvider.Get(kind);
}

private static string? GetCompletionKind(ImmutableArray<string> tags)
{
    if (tags.Contains("class") || tags.Contains("struct") || tags.Contains("interface")
        || tags.Contains("enum") || tags.Contains("record")) return "type";
    if (tags.Contains("delegate")) return "delegate";
    if (tags.Contains("method")) return "method";
    if (tags.Contains("property")) return "property";
    if (tags.Contains("field")) return "field";
    if (tags.Contains("event")) return "event";
    if (tags.Contains("namespace")) return "namespace";
    if (tags.Contains("keyword")) return "keyword";
    if (tags.Contains("local")) return "variable";
    return null;
}
```
图标资源：Light/Dark 主题字典各加一组 `Glyph*` Path 几何矢量图标（双主题配色），`ThemeGlyphProvider` 按 key 从 `Application.Current.Resources` 取。

**改动 3：延迟描述加载（RoslynCompletionData）**
前置：`PopulateData` 的 `new RoslynCompletionData(item, null)`（1122行）改传 `doc`：
```csharp
var doc = _workspace.CurrentSolution.GetDocument(_userDocumentId);
data.Add(new RoslynCompletionData(item, doc));
```
`RoslynCompletionData` 加：
```csharp
private object? _description;
private bool _loadingDescription;

public object? Description
{
    get
    {
        if (!_loadingDescription)
        {
            _loadingDescription = true;
            _ = LoadDescriptionAsync();
        }
        return _description ?? item.InlineDescription;
    }
}

private async Task LoadDescriptionAsync()
{
    if (document == null) return;
    try
    {
        var description = await CompletionService.GetService(document)
            .GetDescriptionAsync(document, item).ConfigureAwait(true);
        _description = string.Join(" ", description.TaggedParts.Select(p => p.Text));
    }
    catch { /* 描述加载失败保持 InlineDescription（UI 提示降级） */ }
}
```

**改动 4：SignatureHelp 参数提示（新增）**
触发：`TextArea_TextEntered` 输入 `(` 或 `,` 时调 `ShowSignatureHelpAsync`：
```csharp
if (e.Text == "(")
{
    await ShowSignatureHelpAsync(caretOffset, token);
    return;
}
```
服务端（用 Roslyn 官方 API）：
```csharp
private async Task ShowSignatureHelpAsync(int position, CancellationToken token)
{
    var doc = _workspace.CurrentSolution.GetDocument(_userDocumentId);
    if (doc == null) return;
    var service = SignatureHelpService.GetService(doc);
    var items = await service.GetSignatureHelpAsync(doc, position,
        new SignatureHelpTriggerInfo(SignatureHelpTriggerReason.TypeCharCommand, '('), token);
    if (token.IsCancellationRequested || items == null) return;

    if (_insightWindow == null)
        _insightWindow = new OverloadInsightWindow(CodeEditor.TextArea)
        { Background = GetThemeBrush(SdkThemeKeys.PanelBackgroundBrush) };
    _insightWindow.Provider = new RoslynSignatureHelpProviderAdapter(items);
    _insightWindow.Show();
}
```
`OverloadInsightWindow` 是 AvalonEdit 自带控件，需 `IOverloadProvider` 适配器（实现 `CurrentIndex`、`CurrentHeader`、`CurrentContent`），参照 RoslynPad `RoslynOverloadProvider`。
