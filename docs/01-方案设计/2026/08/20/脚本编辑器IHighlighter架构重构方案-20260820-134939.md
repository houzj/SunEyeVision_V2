## 一、为什么必须重构（不再打补丁）

当前语义着色用 `DocumentColorizingTransformer`（LineTransformer），每次渲染行都重调 `ColorizeLine`。
AvalonEdit 对 LineTransformer 的行**不缓存颜色对象**——打字/重绘必然重算，异步分析延迟就是闪烁。
**这是架构性缺陷，任何补丁都绕不过**（已多轮打补丁：按需渲染、防闪烁、死循环修复，均未根治）。

RoslynPad 用 `IHighlighter`：AvalonEdit 对每行缓存 `HighlightedLine`（含 `Sections`），行不变不重调；
后台只改 `line.Sections` + `HighlightingStateChanged` 局部重绘。打字时旧色保留（旧 sections + offsetShift 平移），
新色算完覆盖，无空档 → **打字/Enter/删除不闪烁**。

## 四、重构步骤

### 阶段 A：语义着色换 `IHighlighter` 架构（核心，解决闪烁）

**A1. 新建 `RoslynSemanticHighlighter : IHighlighter`**（对齐参考同名类）
- 实现 `IHighlighter`：`HighlightLine(int lineNumber)` 同步返回 `HighlightedLine`
- 核心 `DoHighlightLine`：命中行缓存 → **复用旧 sections + offsetShift 平移**上色 → 入队异步重算覆盖
- 单 worker 队列（`ConcurrentQueue` + `SemaphoreSlim`）
- 行缓存：`CachedLine`（含 `DocumentLine`+`OldVersion`），用文档版本 `CompareAge==0` 按行判断失效
- 分析：`Classifier.GetClassifiedSpansAsync(doc, TextSpan(行))` 按行

**A2. 新建 `RoslynHighlightingColorizer : HighlightingColorizer`**（对齐参考同名类）
- `CreateHighlighter` 返回 `RoslynSemanticHighlighter`
- 接入：`LineTransformers.Insert(0, new RoslynHighlightingColorizer(...))` 替代现有 `SemanticColorizer`

**A3. 删除**现有 `SemanticColorizer`、`ClassifyLineOnDemandAsync`、`ScheduleSemanticAsync`、`SemanticBrushes`

**防闪烁效果**：
```
打字 → AvalonEdit 调 HighlightLine(行)
  → DoHighlightLine：命中旧缓存 → 旧 sections 平移对准 → 立即返回带色行（无空档）
  → 入队 worker 重算 → UpdateHighlightingSections 改 line.Sections → HighlightingStateChanged 局部重绘
  → 新色覆盖，全程不闪烁
```

### 阶段 B：诊断改事件驱动 + TextSegmentCollection

**B1. 事件驱动诊断**（对齐 `RoslynCodeEditor.ProcessDiagnostics`）
- `ScriptWorkspace` 重写诊断更新钩子（Roslyn 诊断事件）
- 或退而求其次：保留轮询但**增量 diff**——`_lastDiagnostics` 与新的按 Id/位置比对，只更新变化 marker
- **移除每次诊断的全量 `Redraw()`**（改为只更新变化的 TextMarker）

**B2. `TextSegmentCollection<TextMarker>` 锚定**（对齐 `TextMarkerService`）
- 诊断 span 用 `TextMarker : TextSegment` 存进 `TextSegmentCollection`，offset 自动锚定
- `ErrorMarkerColorizer` 改为 `DocumentColorizingTransformer + IBackgroundRenderer + ITextViewConnect` 组合

**B3. ToolTipRequest 事件**（对齐 `TextMarkerToolTipProvider`）
- 移除 `TextArea_MouseMove` 手动命中，改用 `ToolTipRequest` 事件 + `args.SetToolTip`

### 阶段 C：补全统一 + 软选择

**C1. 统一 `GetCompletionData`**（对齐 `RoslynCodeEditorCompletionProvider`）
- 一个方法同时处理签名帮助 + 补全，返回 `CompletionResult(data, overloadProvider, useHardSelection)`

**C2. `CustomCompletionWindow` 软选择**（对齐 `CodeTextEditor`）
- 用 `UseHardSelection = data.SuggestionModeItem == null`，suggestion 模式不硬选中当前项
