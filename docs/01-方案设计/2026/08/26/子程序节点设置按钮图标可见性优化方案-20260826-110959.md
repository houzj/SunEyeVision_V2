# 子程序节点设置按钮（齿轮）可见性与交互优化方案

> 类型：01-方案设计 | 日期：2026-08-26 | 状态：待实施

## 一、问题背景与完整排查时间线

子程序节点设置按钮（齿轮图标）历经多轮修改，始终未能同时满足"可见性 + 协调性 + 按钮语义"：

| 阶段 | 方案 | 遗留问题 |
|---|---|---|
| 1 | emoji 🔁 U+1F501 | `Foreground` 主题色对 emoji 无效，暗色主题下不可见 |
| 2 | ⚙ U+2699 + `IconFontFamily`，硬编码字号 24 | 字号比普通类型图标（`NodeIconFontSize`=18）大，不协调 |
| 3 | 字号改 `NodeIconFontSize`(18) | 悬停出现系统默认按钮背景块（偏大、不贴合） |
| 4 | 自定义模板、透明背景 | 悬停背景变橙色（半透明蓝叠加状态色块混色） |
| 5 | 纯 `ContentPresenter` + 24×24 热区 | **暗色主题下齿轮不可见** |
| 6 | 前景色改主题资源 `TitleBarIconBrush` | **依然不可见**，触发日志级深度排查 |

## 二、根因分析（诊断日志决定性证据）

程序内置埋点 `LogGearDiagnosis` 输出亮/暗主题完整链路，对比：

```
亮色: 齿轮Foreground=#FF333333(深灰), 节点背景=#FFE8EAF6(浅), 实际对比度=10.55 ✓
暗色: 齿轮Foreground=#FFC0C0C0(浅灰), 节点背景=#FFE8EAF6(浅!), 实际对比度=1.52 ✗
```

两个关键事实：

1. **节点卡片背景永远是浅色**：`CachedNodeBackgroundConverter`（`CachedNodeConverters.cs:104`）通过 `NodeDisplayAdapterFactory.GetAdapter(ToolType).GetBackgroundColor(node)` 取色，各适配器返回**写死浅色**（`#E6F2FF`/`#E8EAF6` 等），**完全不随主题变化**。
2. **主题前景色在暗色下变浅**：`TitleBarIconBrush` 暗色 = `#C0C0C0`（浅灰）→ **浅灰 on 浅底 → 对比度 1.52 不可辨识**。

**核心矛盾**：节点卡片背景不随主题（永远浅色），所以齿轮前景**不能用主题前景色**，必须用**固定深色**——这正是 `NodeIconStatusForegroundConverter`（`NodeIconStatusConverters.cs:62`）对"待运行"状态的既有处理（写死 `#333333`，注释记录用户 2026-08-17 决策"节点视觉冻结亮色主题"）。

## 三、最终优化方案

### 设计原则

- 齿轮是**按钮**（可点击），普通类型图标只是**展示**——两者语义不同。
- **基础色跟随节点运行状态**：与普通类型图标完全一致（复用同一转换器 `NodeIconStatusForegroundConverter`）。
- **悬停变色提示可点**：按钮语义，变主题蓝 `AccentBrush`。
- **背景恒透明**：不出现任何背景色块（避免与状态色块混色出杂色）。
- **字号 18 + 热区 24×24**：与普通图标协调且易点击。

### 完整 XAML（替换 `WorkflowCanvasControl.xaml` 287-323 行按钮）

```xml
<Button Background="Transparent"
        BorderThickness="0"
        Padding="0"
        Width="24" Height="24"
        Cursor="Hand"
        ToolTip="子程序参数设置"
        Click="SubroutineNodeSettings_Click"
        Loaded="SubroutineNodeSettings_Loaded"
        HorizontalAlignment="Center" VerticalAlignment="Center"
        Panel.ZIndex="10">
    <Button.Template>
        <ControlTemplate TargetType="Button">
            <!-- 背景恒透明：悬停/按下不出现背景色块，避免与状态色块混色出杂色 -->
            <ContentPresenter HorizontalAlignment="Center" VerticalAlignment="Center"/>
        </ControlTemplate>
    </Button.Template>
    <!-- 齿轮无局部 Foreground，继承按钮的：基础色=状态转换器，悬停=触发器覆盖 -->
    <TextBlock Text="&#x2699;"
               FontFamily="{StaticResource IconFontFamily}"
               FontSize="{DynamicResource NodeIconFontSize}" FontWeight="Bold"
               HorizontalAlignment="Center" VerticalAlignment="Center"/>
    <Button.Style>
        <Style TargetType="Button">
            <Setter Property="Visibility" Value="Collapsed"/>
            <!-- ★ 基础色与普通类型图标行为一致（同一转换器）：
                 待运行→深灰#333(on浅卡片)；运行中/成功/失败/跳过→白色(on实色色块)。
                 放 Style Setter 而非 TextBlock 局部值：Style Trigger 优先级 > Style Setter，
                 保证悬停触发器能覆盖。勿用主题前景色(暗色下浅灰on浅底不可见)。 -->
            <Setter Property="Foreground"
                    Value="{Binding Status, Converter={StaticResource NodeIconStatusForegroundConverter}}"/>
            <Style.Triggers>
                <DataTrigger Binding="{Binding ToolType}" Value="Subroutine">
                    <Setter Property="Visibility" Value="Visible"/>
                </DataTrigger>
                <!-- 悬停变主题蓝提示可点（按钮语义，待运行浅底时清晰可见） -->
                <Trigger Property="IsMouseOver" Value="True">
                    <Setter Property="Foreground"
                            Value="{DynamicResource {x:Static base:ThemeKeys.AccentBrush}}"/>
                </Trigger>
            </Style.Triggers>
        </Style>
    </Button.Style>
</Button>
```

### 关键实现细节

- **依赖属性优先级**：`Foreground` 绑定放在 **Style Setter**（而非 TextBlock 局部值）。WPF 优先级：`Style Trigger(8) > Local Value(6) > Style Setter`。因此 `IsMouseOver` 触发器（Style Trigger）优先级高于基础 Foreground 绑定（Style Setter）→ 悬停变色必然生效；若放 TextBlock 局部值则触发器无法覆盖（局部值优先）。
- **继承链**：TextBlock 不设局部 Foreground → 继承按钮 `Foreground` → 随状态绑定 / 悬停触发器自动联动。
- **资源存在性**：`NodeIconStatusForegroundConverter`（x:Key 已在 `WorkflowCanvasControl.xaml:49` 定义）、`base:ThemeKeys.AccentBrush`（`ThemeKeys.cs:62`）均已存在。

### 效果矩阵

| 运行状态 | 状态色块 | 齿轮基础色 | 悬停 |
|---|---|---|---|
| 待运行 | 透明 | 深灰 `#333`（任何主题可见） | 主题蓝 |
| 运行中 | 蓝 `#2196F3` | 白 | 主题蓝 |
| 成功 / OK | 绿 `#4CAF50` | 白 | 主题蓝 |
| 失败 / NG | 红 `#F44336` | 白 | 主题蓝 |
| 跳过 | 灰 `#9E9E9E` | 白 | 主题蓝 |

## 五、验收标准

1. 亮色主题：待运行深灰齿轮可见。
2. 暗色主题：待运行深灰齿轮可见（消除对比度 1.5 问题）。
3. 运行中 / 成功 / 失败 / 跳过：齿轮白色反白（与普通类型图标行为一致）。
4. 悬停：齿轮变主题蓝，无背景色块。
5. 节点运行状态变化时齿轮颜色实时联动。
