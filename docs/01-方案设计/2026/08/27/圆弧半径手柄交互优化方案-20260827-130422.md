# 圆弧半径手柄交互优化方案

> 整合完整对话上下文：半径手柄交互反着 → 中间点语义辨析 → 圆心派生性确认 → 增量法收敛
> 日期: 2026-08-27

---

## 一、改前 / 改后 / 依据（用户视角）

| | 改前 | 改后 |
|---|------|------|
| **拖圆弧中间点（半径手柄）** | 半径变化方向和鼠标移动**反着/错乱**——用"鼠标到弦中点投影"算半径，与手柄位置脱节 | 半径**精确跟随鼠标沿径向的位移**：拖离圆心 → 半径大，拖向圆心 → 半径小，变化量 = 鼠标真实移动量 |
| **参数变化** | 半径变化是"三点重算"的副产物，不是真实移动量 | **只有半径参数变**（两端点 P1/P2 不动），变化量 = 鼠标径向位移 |
| **圆心** | 隐式参与计算导致漂移 | 圆心是**派生值非卡尺参数**，随半径重算自动滑动 |

**依据**：用户多轮讨论收敛的核心结论——卡尺参数只有「起点/终点/半径」，圆心是派生值；拖半径手柄应**只有半径变**且变化量=鼠标真实位移（增量法）。

## 二、问题分析（含来源标注）

**当前实现** [来源] `MeasureEditorControl.xaml.cs:571-590`：
```csharp
var normal = ...;  // 从弦中点指向圆心
double h = Vector.Multiply(current - mid, normal);  // 鼠标到弦中点法线投影
double newRadius = Math.Sqrt(h * h + halfLen * halfLen);
```

**三个缺陷**：
1. **几何脱节**：`h` 是"鼠标到**弦中点**的法线投影"，但半径手柄在**弧顶**——手柄位置与公式的参考点（弦中点）不对应，算出的半径与手柄到圆心实际距离脱节 → "反着"
2. **漂移**：`UpdateArcRadius` 重算圆心，下一帧 `current - center` 又变 → 半径不稳定
3. **语义错位**：实际效果等价于"用 P1+P2+鼠标点三点重算圆"，半径变化不是真实鼠标移动量（用户精确指出的问题）

**正确模型**：
- 卡尺参数 = `ArcPoint1`（起点）+ `ArcPoint2`（终点）+ `ArcRadius`（半径）[来源] `MeasureInteractionModel.cs`
- 圆心 = `FromEndpointsAndRadius` 派生（非参数）[来源] `Arc2d.cs:68-99`

## 三、Bug 模式分析

**当前 bug**：半径手柄交互反着/错乱。

**真因分类**：**实现偏差**——用"到弦中点投影"（错误参考系）而非"鼠标位移增量"（正确参考系）。

**同类潜伏点**：
- [来源] `MeasureEditorControl.xaml.cs:571-590` — 半径手柄（本次）
- Circle 半径手柄用 `(current - center).Length` 但圆心固定（圆无此问题）[来源] `:553-561` — 不需要改

**治本点**：半径手柄改用**增量法**——记录拖动初始（圆心、半径、中间点位置），用"鼠标沿径向位移"驱动半径，圆心派生。

## 五、方案对比

| 维度 | **A（推荐）** 增量法 | B：鼠标到当前圆心距离 | C：三点重算 |
|------|------|------|------|
| 实现 | 记录初始，径向位移驱动 | `current - center` 每次算 | P1+P2+鼠标三点定圆 |
| 稳定性 | ✅ 用初始圆心算方向，不漂移 | ❌ 圆心滑动导致漂移 | ⚠️ 圆心/半径都变 |
| 变化量=移动量 | ✅ 精确 | ❌ 否 | ❌ 否 |
| 只有半径变 | ✅ | ✅ | ❌（圆心也变）|
| 复杂度 | 中（记录 3 字段）| 低 | 低 |
| 长期 ROI | **高** | 低 | 中 |

**推荐 A**：增量法，符合"只有半径变 + 变化量=真实移动量"。

## 六、修改清单

| # | 文件 | 变更 | 核心 |
|---|------|------|------|
| 1 | `MeasureEditorControl.xaml.cs` | 修改 | ①字段：`_dragCenter`/`_dragStartRadius`/`_dragRadialDir`；②`BeginHandleDrag` 记录初始状态；③`HandleShapeEdit` Arc Right 分支改增量法；④删除原 h/normal/mid 计算 |

**核心代码**：
```csharp
// BeginHandleDrag 中（Right 手柄）：
if (handleType == HandleType.Right && _model.EditingArc.HasValue && !_model.EditingArc.Value.IsEmpty)
{
    var a = _model.EditingArc.Value;
    _dragCenter = a.Center;
    _dragStartRadius = a.Radius;
    var hPos = a.GetPointOnArc(a.StartAngle + a.AngularSpan / 2);  // 中间点位置
    var radial = hPos - a.Center;
    radial.Normalize();
    _dragRadialDir = radial;
}

// HandleShapeEdit 中（Arc Right）：
var delta = Vector.Multiply(current - (_dragCenter + _dragRadialDir * _dragStartRadius), _dragRadialDir);
double newRadius = Math.Max(_dragStartRadius + delta, 1.0);
changed = _model.UpdateArcRadius(newRadius);
```

**说明**：`_dragCenter + _dragRadialDir * _dragStartRadius` = 拖动开始时中间点位置；`current - 初始中间点` 在径向方向的投影 = 鼠标沿径向位移量；`newRadius = 初始半径 + 位移量`。拖远→+，拖近→−，精确对应。
