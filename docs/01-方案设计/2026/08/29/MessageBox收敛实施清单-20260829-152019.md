# MessageBox 收敛实施清单

> 目标：将项目内散落的系统原生 `MessageBox.Show` 全部收敛为项目自研主题化 `ThemeMessageDialog.Show`，统一弹窗风格（深色背景 + 主题化按钮 + 悬停高亮 + 适配亮/暗主题）。
>
> 创建时间：2026-08-29 15:20:19

## 一、背景与根因

- `App.xaml` 已全局合并 `CommonStyleResources.xaml`，提供主题化 `PrimaryButtonStyle` / `SecondaryButtonStyle` / `ToolButtonStyle` / `DangerButtonStyle`。
- `AppResources.xaml` 提供全局隐式 `Button` 样式与 `PrimaryButton` / `SecondaryButton` 形态族。
- 但业务代码中仍有 **60+ 处** `System.Windows.MessageBox.Show`（系统原生弹窗），不跟随项目主题，与整体 UI 风格脱节。
- `ThemeMessageDialog`（`src/UI/Features/Dialogs/ThemeMessageDialog.xaml`）已具备主题化弹窗能力，替代系统 MessageBox。

## 二、处理策略（分层）

| 优先级 | 类别 | 说明 |
|--------|------|------|
| **P0** | YesNo / 确认类 | 涉及用户决策（删除/覆盖/关闭等），必须主题化 |
| **P1** | 普通提示 / 错误 OK 类 | 绝大多数业务提示，顺带收敛 |
| **保留** | 全局未处理异常兜底 | `App.xaml.cs` 的全局异常（UI 崩溃时不应依赖 UI 组件），**不换** |

> ⚠️ 全量替换前需逐处确认调用签名兼容（`ThemeMessageDialog.Show` 与 `MessageBox.Show` 参数顺序不同）。

## 三、调用签名对照

```csharp
// 系统原生
System.Windows.MessageBox.Show(string text, string caption,
    MessageBoxButton button, MessageBoxImage icon);
// 返回 System.Windows.MessageBoxResult

// 项目自研（参数顺序不同）
ThemeMessageDialog.Show(string message, string title,
    MessageBoxButton button = MessageBoxButton.OK,
    ThemeMessageDialog.MessageIcon icon = ThemeMessageDialog.MessageIcon.Info,
    Window? owner = null);
// 返回 System.Windows.MessageBoxResult（兼容）
```

**映射规则：**
- `MessageBoxImage.Question` → `ThemeMessageDialog.MessageIcon.Question`
- `MessageBoxImage.Information` → `ThemeMessageDialog.MessageIcon.Info`
- `MessageBoxImage.Warning` → `ThemeMessageDialog.MessageIcon.Warning`
- `MessageBoxImage.Error` → `ThemeMessageDialog.MessageIcon.Error`
- `MessageBoxButton.YesNo` → 原样传 `MessageBoxButton.YesNo`

**注意：**
- 文件需先 `using SunEyeVision.UI.Features.Dialogs;`
- 窗口关闭流程（`OnClosing`）中传入正在关闭的窗口作 owner 会导致弹窗静默不显示，此时必须传 `owner: null`。
