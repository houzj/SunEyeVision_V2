## 🔄 改前 → 改后 → 依据

### 问题一：测量工具栏类型过滤（✅ 已完成，已提交 cb7c1c9）

**改前**：圆查找、直线查找、边缘检测三个工具共用同一测量工具栏，打开任意工具都显示直线/圆/圆弧三种卡尺按钮，用户需手动挑选。

**改后**：打开圆查找 → 工具栏只有"圆卡尺 + 圆弧卡尺"；打开直线查找 → 只有"直线卡尺"；边缘检测保持三种全显示。

**依据**：对齐 Roi 编辑器"锁定形状类型"模式，复用 `ToolItem.IsVisible` 已有机制。

**状态**：已实施 + 提交 `cb7c1c9` + 已推送 Gitee。

---

### 问题二：关闭调试窗口后主图像残留"不可编辑的图形"（⏳ 待实施）

**改前**：关闭圆/直线/边缘检测的调试窗口后，主界面图像上仍残留引导几何（白线/白圆）和卡尺测量带（蓝带/橙主卡尺）。图形看得见摸不着（`OverlayHitTestVisible=false`），再次打开窗口时新旧图形叠加、渲染错乱。

**根因**：图像控件有两层叠加——`ResultRenderLayer`（算法结果层）和 `InteractionOverlayCanvas`（ROI 交互层）。测量引导几何/卡尺画在交互层，清理入口是 `MeasurementEditorManagerControl.ClearMainOverlay()`（清空画布 + 解订阅事件）。但三个工具的调试控件都没有挂接"窗口关闭 → Cleanup"链路，关闭窗口时清理逻辑从未执行。

**对比**：Threshold/Blob/ShapeMatch 等工具都有 `Loaded → window.Closing → Cleanup() → regionManager.ClearMainOverlay()`，测量工具三个控件缺失。

**改后**：关闭调试窗口时交互层完整清理，主图像只剩该节点执行结果（结果层，设计上应保留），再打开窗口从干净状态开始。

**依据**：`RoiEditorManagerControl.ClearMainOverlay` 既有范式 + Threshold 工具控件挂接范式。

---

### 问题三：测量工具栏颜色与 Blob 检测区域统一（⏳ 待实施）

**改前**：引导几何白色、普通卡尺蓝填充+钢蓝描边、主卡尺橙色高亮（透明度/粗细区分）、方向箭头绿色——五种颜色混杂。

**改后**（用户已确认）：
- 引导线、所有卡尺、方向箭头全部使用检测蓝 `#4488FF`（与 Blob 检测区域完全一致的语义色）
- 卡尺无填充（只有描边轮廓）
- 主卡尺与普通卡尺无任何区分（无透明度差、无粗细差）

**依据**：`ColorConstants.InspectionBlue`（`#4488FF`，Blob 检测区域同源色）。

## 实施步骤（待实施部分）

### 步骤 1：调试窗口关闭清理（3 个工具控件）

CircleDetect / LineDetect / EdgeDetect 三个调试控件各加两段：

```csharp
// 构造函数内
Loaded += (s, e) => {
    var window = Window.GetWindow(this);
    if (window != null) window.Closing += OnWindowClosing;
};

// 新增清理区域
public void Cleanup() => MeasurementManager?.ClearMainOverlay();
private void OnWindowClosing(object? sender, CancelEventArgs e) => Cleanup();
```

### 步骤 2：测量工具栏颜色统一（MeasureBandOverlay.cs）

- 删除 `BandFillColor` / `MainBandFillColor` / `MainBandStrokeColor` / `DirectionColor`，统一为 `StrokeColor = ColorConstants.InspectionBlue`
- 引导线 `Colors.White` → 检测蓝
- 3 处 `AddQuad` 调用改为 `AddQuad(p1,p2,p3,p4, Colors.Transparent, StrokeColor, 1.0, 1.0)`（无填充、粗细/透明度统一）
- 方向箭头改为检测蓝
