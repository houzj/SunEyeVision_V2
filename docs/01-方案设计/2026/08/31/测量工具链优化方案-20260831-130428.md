# 测量工具链优化方案

> 创建时间：2026-08-31 13:04:28（已更新至最终整合版，含实施状态标注）
>
> 关联背景：远程提交 `9f152b1` 引入 rms 获取错误（HALCON #1303），官方 `measure_stamping_part` demo 参考，"只支持数量主导卡尺"的产品决策，以及渲染卡尺与算法卡尺对应关系的排查。

## 一、背景与根因

### 1. 运行时报错

```
HALCON error #1303: Wrong value of control parameter 3 in operator get_metrology_object_param
```

- 来源：远程提交 `9f152b1` 把 `rms` 的获取从 `get_metrology_object_result` 改成 `get_metrology_object_param`
- 根因链：
  - 原代码 `get_metrology_object_result(idx, "all", "result_type", "rms")` → **#1305**（rms 不是 result_type）
  - `9f152b1` 改为 `get_metrology_object_param(idx, "rms")` → **#1303**（rms 不是 GenParamName）
  - **结论：HALCON 两个结果算子都不支持 `rms` 直读**

### 2. HALCON 24.05 官方文档确认

**`get_metrology_object_param` 的 GenParamName 完整合法值：**
```
'column', 'column_begin', 'column_end', 'distance_threshold', 'end_phi',
'instances_outside_measure_regions', 'length1', 'length2', 'max_num_iterations',
'measure_distance_min', 'measure_distance_max', 'measure_interpolation',
'measure_length1', 'measure_length2', 'measure_select', 'measure_sigma',
'measure_threshold', 'measure_transition', 'min_score', 'num_instances',
'num_measures', 'object_params', 'object_type', 'phi', 'point_order',
'radius', 'radius1', 'radius2', 'rand_seed', 'row', 'row_begin', 'row_end',
'start_phi', 'x', 'x_begin', 'x_end', 'y', 'y_begin', 'y_end'
```

- **没有 `'rms'`** → 传 `"rms"` 必然报 **#1303**
- **`'num_measures'` 合法** → 返回测量带数量（9f152b1 对 num_measures 的修改正确，保留）

### 3. 官方 demo（measure_stamping_part）参考结论

| 用途 | 正确算子 | 当前实现 |
|---|---|---|
| 拟合几何参数 | `get_metrology_object_result(idx, "all", "result_type", "all_param"/"radius"/"x"/"y")` | ✅ all_param 用法对 |
| 测量带数量 | `get_metrology_object_param(idx, "num_measures")` | ✅ 9f152b1 改对了 |
| **拟合误差 RMSE** | **不存在直读算子 → 用 `used_edges` 取点自算** | ❌ 两处都错 |
| 参与拟合的点 | `get_metrology_object_result(idx, "all", "used_edges", "row"/"column")` | ❌ 用的是 `get_metrology_object_measures`（口径不同） |

### 4. 位置修正架构（确立不动）

- demo 的 `reference_system` + `align_metrology_model(row,col,angle)` 是**刚体对齐**（不支持缩放）
- 当前实现基于工程内统一的 `AffineMatrix` 契约（ShapeMatch 产出，支持**缩放**），适合工具链架构
- 纯平移旋转场景两者等价，含缩放场景当前实现更通用 → **不改**

### 5. 卡尺分布与方向语义（最终确认）

**测量带几何语义**（官方文档）："The centers of the measure regions lie on the boundary of the object."（测量带中心落在对象边界上）——即测量带跨边界对称，中心在边界线上。

**分布相位**（已确认）：Halcon 圆/弧测量带**从 `start_phi`（0°）开始**，第一条卡尺中心在 `start_phi` 位置，无半格偏移：
```
θ_i = start_phi + i × (2π/N)
```

**方向/极性语义**（已确认）：
- `measure_transition` 只有 **`'positive'`=暗→亮 / `'negative'`=亮→暗** 的绝对灰度极性，**无空间方向概念**（没有"从内到外/从外到内"）
- Halcon 测量带对称双向，扫描方向由测量带几何内部确定，用户无需指定方向
- UI 上的方向箭头是**纯视觉装饰、无算法对应**，会误导用户 → 应移除

## 二、产品决策：只支持数量主导

**决策**：测量带生成只支持 `num_measures`（数量主导），废弃 `measure_distance`（间距主导）模式。

依据 `add_metrology_object_generic` 官方文档，两种模式互斥：

| 模式 | 参数 | 语义 |
|---|---|---|
| 数量主导 | `num_measures` | 指定数量，Halcon 自动算间距 |
| 间距主导 | `measure_distance` | 指定间距，Halcon 自动算数量 |

**收益**：
1. 消灭 #1210 类型 bug 根源（不再有 int→double 类型切换）
2. 参数模型更简单（少 1 个字段）
3. UI 少一个控件，语义清晰（只调数量）

**旧工程文件兼容**：JSON 反序列化默认忽略未知字段，直接删 `MeasureDistance` 字段不破坏已保存工程。

**新增辅助方法（三个工具各自实现）：**
```
ComputeRmsFromUsedEdges(model, index, allParam):
  usedRow = model.GetMetrologyObjectResult(index, "all", "used_edges", "row")
  usedCol = model.GetMetrologyObjectResult(index, "all", "used_edges", "column")
  // 圆/弧：dist = |点到圆心| - 半径
  // 直线：dist = |Nr·(r−Row1) + Nc·(c−Col1)|
  rms = sqrt(Σdist² / n)
```

| 文件 | 改动 |

**根因**：`GetOutputVariables()` 对 `GetPropertyMap()` 声明的属性做类型词汇表映射（rule-015 无兜底直接抛异常），`CenterPoint` 为 WPF `Point` 不在 `SdkTypeVocabulary` 支持列表（只支持几何模型 `Point2d[]`）。
**处理**：`CenterPoint` 仅用于显示文本（`GeometryDescription`/`FillDisplay`），不作为输出变量；圆心已在 `Circle`/`Arc` 几何内，中点可由 `Line` 端点计算。属性保留、契约移除。

### ⏳ P2 待实施：拟合点来源改 `used_edges`（解决"点不在卡尺里"）

**现状**：`ExtractMeasurementPoints` 用 `get_metrology_object_measures` 的 Row/Column
- 官方文档：该算子的 Row/Column **顺序未定义、无法归属到具体测量带**
- demo 白色 X 拟合点实际用 `get_metrology_object_result(..., "used_edges", "row"/"column")`（每测量带一个）

**改动**（3 工具，与 `ComputeRmsFromUsedEdges` 同源）：
```csharp
private Point2d[] ExtractMeasurementPoints(HTuple objectIndex, HMetrologyModel metrologyModel)
{
    try
    {
        // ★ 与 demo 一致：取实际参与拟合的点（每测量带一个）
        var usedRow = metrologyModel.GetMetrologyObjectResult(objectIndex, "all", "used_edges", "row");
        var usedCol = metrologyModel.GetMetrologyObjectResult(objectIndex, "all", "used_edges", "column");
        if (usedRow.Length == 0) return Array.Empty<Point2d>();
        var pts = new Point2d[usedRow.Length];
        for (int i = 0; i < usedRow.Length; i++)
            pts[i] = new Point2d(usedCol[i].D, usedRow[i].D);
        return pts;
    }
    catch { return Array.Empty<Point2d>(); }
}
```
文件：`CircleDetectTool.cs`、`LineDetectTool.cs`、`EdgeDetectTool.cs`

### ⏳ P3 待实施：start_phi 相位对齐（渲染 vs 算法错位根因）

**已确认**：Halcon 圆测量带**从 start_phi（0°）开始**，无偏移。

**现状不一致**：
| 位置 | 代码 | 分布 |
|---|---|---|
| 算法 | `CircleDetectTool` `BuildGenParamName` 传 `"start_phi"`+`parameters.StartAngle` | 从 **StartAngle** 起 |
| UI `RenderCircle` | `angle = i * stepAngle` | 从 **0°** 起（忽略 StartAngle） |
| UI `RenderArc` | `arc.StartAngle + (i+0.5)*stepAngle` | 从 StartAngle+**半格** 起 |
| UI `RenderLine` | `(i+0.5)*step` | 半格偏移 |

**问题**：整圆（StartAngle=0）无影响；**弧模式/自定义起始角时 UI 与算法错位旋转** → 拟合点不在渲染卡尺内。

**改动**：
1. `RenderCircle` 改用 `StartAngle + i*stepAngle`（需把 startAngle 传入 overlay）
2. `RenderArc` 去掉半格偏移 → `StartAngle + i*stepAngle`（与 Halcon 一致）
3. `RenderLine` 待验证 Halcon 直线分布相位后对齐

### ⏳ P4 待实施：去掉卡尺方向箭头（消除误导）

**改动**：`MeasureBandOverlay.cs` 移除 `AddDirectionArrow` 调用（Line/Circle/Arc 三处）+ 相关方法；卡尺只表达"位置+尺寸+数量"

### ⏳ P5 待实施：极性语义确认（参数面板文案）

## 四、两个查找工具完整实现逻辑

### 圆查找（CircleDetect）

```
输入层: 参数(引导圆/弧、测量带Length1/2、Sigma/Threshold、NumMeasures、
        transition/select、start/end_phi、位置修正源、判定配置) + 输入图像
  ↓
1. 参数校验 Fail-Fast: GuideCircle==null? Radius<=0? → LogError + SetError
  ↓
2. 获取图像: parameters.GetHalconImage() → 失败/空则 SetError
  ↓
3. 创建计量模型: CreateMetrologyModel + SetMetrologyModelImageSize
  ↓
4. 位置修正: IsPositionCorrectionEnabled && AffineMatrix?
    → 圆心: matrix.TransformWpfPoint(center)
    → 半径: radius * matrix.ScaleFactor()
  ↓
5. AddMetrologyObjectCircleMeasure(圆心Y,X, 半径, L1, L2, Sigma, Threshold,
    GenParamName, GenParamValue)
    → GenParam: [num_measures, measure_transition, measure_select, start_phi, end_phi]
    → Halcon 自动生成测量带阵列（中心落在边界上，从 start_phi 起）
  ↓
6. ApplyMetrologyModel(hImage) → 逐测量带 1D 边缘检测 + 拟合圆
  ↓
7. 结果获取:
    ├─ GetMetrologyObjectResult(idx,'all','result_type','all_param') → [Row,Col,Radius]
    ├─ GetMetrologyObjectParam(idx,'num_measures') ✅ 合法 → 测量带数量
    └─ GetMetrologyObjectResult(idx,'all','used_edges','row'/'column')
       → ComputeRmsFromUsedEdges: Σ(|点到圆心|−半径)²/n 开方 → RMSE
       → ExtractMeasurementPoints: used_edges 每测量带一个拟合点
  ↓
8. FillResult: 拟合圆Circle/弧Arc、CenterPoint、MeasurementPoints、RMSE、EdgePointCount
  ↓
9. EvaluateResult: 半径/中心X/中心Y/RMSE/点数 判定 → IsPass
  ↓
10. FillDisplay: 轮廓点 + 拟合圆 + 圆心文本 叠加图像
  ↓
输出: CircleDetectResults
```

### 直线查找（LineDetect）

```
输入层: 参数(引导直线两点、测量带Length1/2、Sigma/Threshold、NumMeasures、
        transition/select、位置修正源、判定配置) + 输入图像
  ↓
1. 参数校验 Fail-Fast: 线段长度<1e-6? → LogError + SetError
  ↓
2. 获取图像: parameters.GetHalconImage() → 失败/空则 SetError
  ↓
3. 创建计量模型: CreateMetrologyModel + SetMetrologyModelImageSize
  ↓
4. 位置修正: IsPositionCorrectionEnabled && AffineMatrix?
    → startP/endP: matrix.TransformWpfPoint()
  ↓
5. AddMetrologyObjectLineMeasure(start.Y,X, end.Y,X, L1, L2, Sigma, Threshold,
    GenParamName, GenParamValue)
    → GenParam: [num_measures, measure_transition, measure_select]
    → Halcon 自动生成测量带阵列
  ↓
6. ApplyMetrologyModel(hImage) → 逐测量带 1D 边缘检测 + 拟合直线
  ↓
7. 结果获取:
    ├─ GetMetrologyObjectResult(idx,'all','result_type','all_param')
    │  → [Row1,Col1, Row2,Col2, Nr,Nc, Dist]
    ├─ GetMetrologyObjectParam(idx,'num_measures') ✅ 合法 → 测量带数量
    └─ GetMetrologyObjectResult(idx,'all','used_edges','row'/'column')
       → ComputeRmsFromUsedEdges: |Nr·(r−Row1)+Nc·(c−Col1)| 均方根 → RMSE
       → ExtractMeasurementPoints: used_edges 每测量带一个拟合点
  ↓
8. FillResult: 拟合直线Line2d、LineStartPoint/EndPoint/CenterPoint、
    MeasurementPoints、RMSE、EdgePointCount
  ↓
9. EvaluateResult: 点数/角度/RMSE 判定 → IsPass
  ↓
10. FillDisplay: 轮廓点 + 拟合直线 + 中心文本 叠加图像
  ↓
输出: LineDetectResults
```

### UI 联动（两工具共用）

```
MeasureEditorControl.SetCaliberParams(Width,Length,Count)
  → MeasureBandOverlay 渲染卡尺（预览，无方向箭头）

```

### 两图差异对照

| 环节 | 圆查找 | 直线查找 |
|---|---|---|
| 引导几何 | 圆心+半径（可选弧：起止角/大弧/方向） | 两点 |
| 位置修正 | 圆心变换 + 半径×缩放因子 | 两端点变换（长度隐含缩放） |
| all_param | `[Row, Col, Radius]` | `[Row1,Col1, Row2,Col2, Nr,Nc, Dist]` |
| RMSE 自算 | `|点到圆心| − 半径` | `|Nr·Δr + Nc·Δc|`（点到直线） |
| 结果几何 | Circle / Arc | Line2d |
| 判定项 | 半径/中心X/中心Y/RMSE/点数 | 点数/角度/RMSE |
| 卡尺分布 | 从 start_phi 起（P3 对齐 UI） | 待验证相位（P3） |
| 拟合点 | used_edges 每测量带一个（P2） | used_edges 每测量带一个（P2） |
