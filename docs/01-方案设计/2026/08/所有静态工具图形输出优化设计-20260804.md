# 所有静态工具图形输出优化设计

## 🔄 改前 → 改后 → 依据

### 改前（用户视角）

- 各工具"输出变量"下拉里**只有图像和数值**。比如 Blob 分析有"Blob数量、总面积、中心X数组"，但**看不到** Blob 的轮廓、外接矩形、区域本身。
- 下游节点想绑定上游的"图形"（把阈值分割出的区域作为掩码、或绑定"找到的那个圆"来读半径），**没有入口**。
- 每个工具调试窗口里其实都能看到图形（轮廓、矩形、十字都画在图像上了），但**只在窗口里看，传不出去**。
- 用户自己绘制的检测区/屏蔽区（圆/矩形/多边形），**也无法作为数据供下游绑定使用**。

### 改后（用户视角）

- 每个工具的输出分成"输入区域组 + 图像组 + 数值组 + 算法产物组"四组，结构清晰。
- **检测区/屏蔽区几何**成为可绑定输出：下游可以整体绑定、按形状分组绑定、绑单个图形、绑图形属性（如"第 1 个圆的半径"）。
- **算法产物几何**（Blob 外接矩形、质心、匹配框、匹配中心）成为可绑定输出，可逐个下钻属性。
- **算法处理后的像素区域/轮廓**（二值区域、连通域、外轮廓）输出到结果树/图像上**显示**，但不作为下游绑定源（当前阶段）。
- 几百上千个图形**不炸树**：字段聚合显示（30 预览 + 100 封顶）+ 按类型分组。

### 依据（业界参考）

| 框架/产品 | 关键做法 | 借鉴点 |
|-----------|---------|--------|
| MVTec HALCON | Region/图像是第一类 iconic 数据，直接作为算子输入输出传递（`reduce_domain`/`connection`）；拟合几何是 control 参数走另一条通道 | 区域走"数据通道"、几何走"参数通道"，双通道分离 |
| 海康 VisionMaster | 上游工具输出引脚拖线到下游输入引脚建立数据通道；图像/区域/数值三类引脚；"输出掩膜"把绘制 ROI 转成像素区域输出；ROI 支持"独立绘制"和"继承上游模块"两种来源 | 检测区/屏蔽区作为可输出数据、下游可继承 |
| Cognex VisionPro | 工具处理区域输入是几何对象（`CogCircle`/`CogRectangle`）；运行后像素区域是结果数据，图形标注进 `CogGraphicCollection` | 输入区域用几何定义、输出结果可显示 |

## 一、贯穿全部决策的主线

1. **进契约（可绑定）= 几何图形 + 数值 + 图像**；**不进契约（仅显示）= Region 像素区域 + 轮廓**（等需要再开放绑定）。
2. **检测区域不输出 Region 像素类型，只输出几何形态**；**只有算法处理后的区域才输出 Region（仅显示）**。
3. **检测区/屏蔽区也作为输出**（RoI 契约），支持**四级绑定**：整体 → 按形状分组 → 单项 → 属性。
4. **双绑定范式**：图形整体绑定 + 通过参数绑定（精确取数）。
5. **几百上千个图形不炸树**：字段聚合显示（30 预览 + 100 封顶）+ 按类型分组。
6. **RoI 分工**：检测区用 RoI 契约（天然多态混合）、算法产物用具体几何类型数组（利于强类型消费）。

## 二、通用框架（所有工具框架级获得，不逐个改）

每个工具的输出 = **输入区域组 + 图像组 + 数值组 + 算法产物组** 四组：

| 组 | 输出变量 | 类型 | 可绑定 | 来源 |
|----|---------|------|:---:|------|
| 输入区域组 | `InspectionGeometries` 检测区几何 | RoI（ShapeParameters[]） | ✅ 四级绑定 | 用户绘制/订阅/计算 |
| 输入区域组 | `MaskGeometries` 屏蔽区几何 | RoI（ShapeParameters[]） | ✅ 四级绑定 | 同上 |
| 图像组 | 各工具现有图像输出 | Image | ✅ | 保留 |
| 数值组 | 各工具现有数值统计 | Integer/Double/String/Boolean | ✅ | 保留 |
| 算法产物组 | 各工具特有几何（外接矩形/质心/匹配框/角度…） | RotatedRect2d[]/点[]/Double[] | ✅ | 本次新增 |
| 显示叠加 | 算法处理后的 Region/轮廓 | — | ❌ 仅显示 | 本次明确不绑定 |

**绑定四级**（对 RoI）：`整体` → `[Type=Circle]` 形状 → `[i]` 单项 → `[i].Geometry.半径` 属性。

**结果树全貌**（3 个 Blob + 检测区 1 圆）：

```
■ Blob分析
├── 图像组：灰度图像 / 二值掩码 / 合成显示图像  [Image]          [可绑 ✅]
├── 检测区图形 [RoI·1项] → 圆 → 圆心X/Y/半径                    [可绑 ✅]
├── 预处理：阈值/最大值/类型                                    [可绑 ✅]
├── 判断：判断通过                                              [可绑 ✅]
├── 统计：Blob数量/总面积/平均面积/平均圆度…                    [可绑 ✅]
├── Blob详细：面积/中心X/Y/圆度/矩形度/边框 数组                [可绑 ✅]
├── ★外接矩形 [RotatedRect[]·3] → [i] 中心/宽/高/角度           [可绑 ✅]
├── ★质心点 [Point[]·3] → [i] X/Y                              [可绑 ✅]
└── 显示叠加：区域轮廓/矩形框/质心十字                          [仅显示 👁]
```

几百个 Blob 时：`外接矩形` 字段聚合（中心X/中心Y/宽/高/角度 各一行），不炸树。

## 四、动态工具说明（本次范围外）

- **子程序（Subroutine）**：内部节点输出自动透传。契约开通几何类型后，内部 Blob/匹配的几何输出自动成为子程序输出，**零额外开发**。
- **脚本（Script）**：脚本可声明几何类型输出变量（进契约、可绑定）；区域/轮廓输出仅显示。

## 五、绑定能力（下游节点视角）

### 绑定下拉树（同一根检测区）

```
└── Blob分析
    └── 检测区图形 [6项]
        ├── ☑ 检测区图形（整个）              ← 层级1：整体绑定
        │                                     路径: InspectionGeometries
        ├── ☑ 圆 (3项)                        ← 层级2：按形状分组
        │                                     路径: InspectionGeometries[Type=Circle]
        │   ├── ☑ [0] 圆                      ← 层级3a：单个形状
        │   │   ├── ☑ 圆心X                   ← 层级3b：单个属性
        │   │   │                              路径: ...[Type=Circle][0].Geometry.Center.X
        │   │   ├── ☑ 圆心Y
        │   │   └── ☑ 半径
        │   ├── ☑ [1] 圆
        │   └── ☑ [2] 圆
        └── ☑ 旋转矩形 (2项)                  ← 层级2
            ├── ☑ [0] 旋转矩形                ← 层级3a
            │   ├── ☑ 中心X / 中心Y / 宽 / 高 / 角度   ← 层级3b
            └── ☑ [1] 旋转矩形
```

### 三个层级绑定能力对照

| 层级 | 绑什么 | 绑定路径示例 | 现状 |
|------|--------|-------------|:---:|
| **1 · 整体** | 整个检测区域（6 个全绑） | `InspectionGeometries` | ✅ 现成 |
| **2 · 形状** | 某一种形状（所有圆） | `InspectionGeometries[Type=Circle]` | ✅ 现成（`FilterByShapeType` + `BuildRoiBindingChildren`） |
| **3a · 单项** | 某个形状（第 2 个旋转矩形） | `...[Type=Circle][0]` | ✅ 现成（`[i]` 索引） |
| **3b · 属性** | 某个形状的属性（第 1 个圆的半径） | `...[Type=Circle][0].Geometry.Radius` | ⚠️ 要补：绑定树 `[i]` 下挂属性叶子，解析器透传 `.Geometry` 字段 |

## 六、几百上千图形防炸机制

| 场景 | 显示形态 | 防炸机制 |
|------|---------|---------|
| 500 个检测圆 | 圆心X/圆心Y/半径 **三个聚合节点**，各 500 值一行 | 30 项预览 + ToolTip 完整值 |
| 500 个 Blob 外接矩形 | 中心X/中心Y/宽/高/角度 **五个聚合节点** | 同上 |
| 500 个 Blob 质心 | X/Y 两个聚合节点 | 同上 |
| 需要精确定位单个 | 展开 `[i]` 或输入索引 | 100 项封顶 + 溢出引导 |

**显示聚合 vs 绑定逐项**：结果树用字段聚合（看整体分布）；绑定树仍然逐项（`[i]`）或整体绑。**不提供**"绑定所有圆的平均半径"这类聚合属性——那是统计工具的活，按 YAGNI 先不做。

## 七、混合形状的异质数组处理

图形编辑器画了多种形状（如 3 圆 + 2 旋转矩形 + 1 多边形）：

```
检测区域 [几何 · 6项]
├── 圆 (3项)
│   ├── 圆心X (3项): 10.2; 25.6; 40.1; …
│   ├── 圆心Y (3项): 5.5; 12.3; 20.8; …
│   └── 半径  (3项): 8.0; 12.5; 6.5; …
├── 旋转矩形 (2项)
│   ├── 中心X / 中心Y / 宽 / 高 / 角度 (各2项)
└── 多边形 (1项)
    └── 顶点 (1项): [[10,10],[20,10],[20,20],[10,20]]
```

**决策**：检测区/屏蔽区走 **RoI 契约**（`ShapeParameters[]`），因为 `ShapeParameters` 内部 `Geometry` 字段是多态（圆/矩形/多边形…），`BuildRoiBindingChildren` 已实现"按类型分组 + 逐项 + 类型过滤"完整链路；算法产物走具体几何类型数组（`RotatedRect2d[]`）。**不新建**"几何数组"新概念（避免 5 处逻辑重写）。

## 九、范围界定

### 进契约（可绑定）的只有几何图形

| 来源 | 输出变量 | 类型 | 可下钻属性 |
|------|---------|------|-----------|
| Blob 分析 | `BlobBoxes` | 旋转矩形[] | 中心/宽/高/角度 |
| Blob 分析 | `BlobCentroids` | 点[] | X/Y |
| 形态学 | `BlobBoxes` | 旋转矩形[] | 中心/宽/高 |
| 形状匹配 | `MatchBoxes` | 旋转矩形[] | 中心/宽/高/角度 |
| 形状匹配 | `MatchCenters` | 点[] | X/Y |
| 所有工具 | `InspectionGeometries`（检测区几何） | 圆/线/矩形…[] | 圆心/半径等 |
| 所有工具 | `MaskGeometries`（屏蔽区几何） | 圆/线/矩形…[] | 圆心/半径等 |

### 不进契约（仅显示）的像素数据

- 阈值/图像阈值/形态学的**二值区域** → 继续转 `BinaryMask` 图像 + 区域轮廓画在图上，**不进输出变量**；
- Blob 的**连通域、轮廓** → 画在图上显示，**不进输出变量**；
- 检测区/屏蔽区的**像素掩码** → 只在工具内部用于算法（`BuildHalconROI`），**不外发**；
- **检测区不输出 Region 类型**，只输出几何形态（`InspectionGeometries`）。

### 将来开放 Region 时的扩展点

1. `SdkTypeVocabulary` 注册 `Region`→`IVisionRegion[]`、`Contour`→`IVisionContour[]`；
2. 工具结果加区域输出容器（Clone 生命周期管理）；
3. 绑定树放开 Region 类型过滤 + `FixedRegion` 订阅像素区域；
4. 下游增加 `ResolvedInputRegions` 掩码通道（镜像图像源模式）。
