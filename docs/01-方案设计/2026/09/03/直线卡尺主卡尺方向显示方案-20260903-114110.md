# 直线卡尺主卡尺方向显示方案

> 创建：2026-09-03 11:41
> 模块：SunEyeVision SDK - Measure 编辑器 / LineDetect 工具
> 状态：方案（待 craft 实施）

## 1. 背景与需求

直线卡尺（LineDetect）的引导线定义了测量区域，但画布上缺少"测量方向"指示。
需求：在**主卡尺**（中间测量带）上显示 Halcon 实际参与计算的边缘检测方向，做到"所见即所得"。

需求迭代中澄清的关键点：
- 方向**不是**沿引导线（切向），而是**极性的检测方向**（垂直于引导线 = 测量带法向）。
- 方向必须与 **Halcon 实际计算方向**对齐（非 WPF 自造语义）。
- 最终显示形态：**两个纯三角形（无杆）**，分别位于主卡尺**左、右两条竖直边**（与引导线垂直的两条长边）上，尖端朝 `normal`，位置沿法向 **4/3 全长**处。

## 2. 方向语义定标（Halcon 实验）

用 Halcon 真值实验（左黑右白图像 + 引导线）：

| 引导线方向 | `positive` | `negative` |
|---|---|---|
| 竖线 上→下 | 0 边 | 6 边（col=49.5） |
| 竖线 下→上 | 6 边 | 0 边 |

**结论**：Halcon line measure 的测量扫描方向 = 引导线方向**顺时针转 90°**（屏幕坐标）。
在 WPF 中即 `normal = (-dir.Y, dir.X)`（`BuildLineBands` 已在用的 normal）。
`positive` = 沿该法向**暗→亮**；`negative` = 亮→暗。

传参链路：`LineDetectTool.cs` 中 `AddMetrologyObjectLineMeasure(startP.Y, startP.X, endP.Y, endP.X, ...)`，
WPF `start→end` 直接映射 Halcon `RowBegin→RowEnd`（仅轴交换，顺序语义不变），无角度适配层。

## 3. 几何模型

```
引导线 start → end = dir（单位向量）
normal = (-dir.Y, dir.X)      // 屏幕：dir 顺时针 90°（例：dir=(1,0) → normal=(0,1) 朝下）

主卡尺（中间测量带，mainIndex = measureCount/2）：
  长边 = 法向 = 与引导线垂直（bandWidth，半长 = MeasureLength1）
  短边 = 切向 = 沿引导线（bandLength，半长 = MeasureLength2）

左右两条竖直长边 = "与引导线垂直的两条边"（三角锚点所在边）
```

主卡尺中心 `center` 与 `MeasureBandOverlay.BuildLineBands` / `GetMainCaliberFrame` 同构：
`center = start + dir × (halfBand + mainIndex × step)`（N=1 取中点）。

## 4. 最终显示布局

ASCII（dir 向右 / normal 朝下）：

```
   start ●───────────● end       引导线（水平）
      ┌────────────────────┐
      │                    │
  左竖边│                    │右竖边
      │  （主卡尺带，法向高 = bandWidth）
      │                    │
      └────────────────────┘
    ▲三角L   ▲三角R        ← 左右竖直边下方外侧，尖端朝下(=normal)
   （参考位置沿法向距中心 = bandWidth × 4/3）
```

## 5. 几何实现

两个纯三角（`AddPolygon` / `GraphicsType.Polygon`），无杆：

```
参考位置 P_L = center − dir×(bandLength/2) + normal×(bandWidth×4/3)   // 左竖边对应 x
参考位置 P_R = center + dir×(bandLength/2) + normal×(bandWidth×4/3)   // 右竖边对应 x

三角 L（尖端朝 +normal）：
  尖端 tipL = P_L
  底边两端 = P_L − normal×triSize ∓ dir×halfBase
三角 R（尖端朝 +normal）：
  尖端 tipR = P_R
  底边两端 = P_R − normal×triSize ∓ dir×halfBase

triSize（三角高）≈ max(bandWidth × 0.1, 5)
halfBase ≈ triSize × 0.6
```

> 待确认：`4/3` 若按"法向全长 bandWidth"则落在带外较远处；若按"半长 MeasureLength1"
> 则 = 2/3×bandWidth（带底边外 1/6 bandWidth）。craft 落地跑一次看实际位置再定乘数基准。

## 7. 验收标准

1. 引导线水平向右 → 主卡尺左右竖边下方外侧各出现**纯三角**，尖端朝下（= normal）。
2. 引导线旋转任意角度 → 两个三角跟随主卡尺旋转，始终贴左右竖边、尖端朝 `normal`。
3. 反转方向（交换 start/end）→ 三角翻转 180°（normal 反向）。
4. 结果层运行后同几何显示。
5. 手柄位于"方向视角右上"，悬停光标箭头方向与手柄位置一致。
