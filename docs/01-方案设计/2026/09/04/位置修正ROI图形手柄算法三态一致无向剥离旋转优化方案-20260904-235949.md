## 1. 用户视角（改前 → 改后）

**改前**：给工具绑定 ShapeMatch 位置修正矩阵后，若匹配结果带旋转，图中出现：矩形/旋转矩形的**图形和编辑手柄分离**；圆不分离但**手柄被转斜**；界面看到的检测区域与算法实际处理的区域可能不是同一姿态。

**改后**：位置修正对区域/图形/手柄**一视同仁、所见即所得**，规则一句话——**"有方向的形状跟随旋转，没方向的形状只平移缩放"**：

- 轴对齐矩形、圆（无向）：只**平移 + 均匀缩放**，永远水平/垂直，手柄轴对齐（N/S/E/W），编辑直观；
- 旋转矩形、多边形、直线（有向）：**完整仿射**，跟随匹配旋转；
- 界面预览、运行算法处理的是同一姿态，不再分离。

**同类潜伏点**：

## 6. 架构决策

**决策 D1：形状有向性语义**（放 `Plugin.SDK`，全仓库唯一事实源）

- 无向：`Circle2d`、`System.Windows.Rect`（含派生轴对齐形状）；
- 有向：`RotatedRect2d`、`Polygon2d`、`Line2d`。

**决策 D2：矩阵选择辅助**（新增，SDK 静态类）

`ResolveMatrix(geometry, AffineMatrix? m)`：

- `m==null` → null；
- 无向几何 → `m.StripRotation()`；
- 有向几何 → `m`。

**决策 D3：`AffineMatrix` 新增**

- `StripRotation()`：返回 `(s,0,0,s,tx,ty)`，`s=ScaleFactor()`；
- `IsConformal()`（保形判定：`|M11−M22|≈0 ∧ |M12+M21|≈0`），非保形时旋转矩形按四边形降级提示。

**决策 D4：显示模型**

- 无向形状剥转后无旋转 → 渲染端 `Rectangle` 不需支持角度、`SnapshotsEqual` 不需改，交互命中/拖拽无需"圆显示系重构"（剥转后手柄恒水平/垂直且命中自洽）——大幅缩小改动面；
- 旋转矩形显示角 = `rr.Angle + Δθ`（在上下文构建处叠加）。

**决策 D5：编辑逻辑不动**：命中/拖拽继续参考系（相似变换下数学自洽）。

**编辑正确性论证**（矩形图形/手柄贴合变换后，编辑逻辑依然正确）：

- 编辑全部发生在参考系（存储不变式），手柄命中 = `M⁻¹(鼠标)` 对参考手柄，天然命中；
- 位置型编辑（角点/边/中心/多边形顶点/线端点）：参考位移 `Δref=M⁻¹Δd`，显示位移 = `M·Δref = Δd`，精确跟手；
- 角度型编辑（旋转手柄）：相似变换保持角度差，参考系角增量 = 显示角增量；
- 非保形/镜像矩阵会破坏上述保证 → 由 `IsConformal()` 降级兜底（多边形点级编辑在任意仿射下仍线性跟手）。

## 8. 防御机制

1. **契约测试**：`AffineMatrix.StripRotation/IsConformal` 与 `ResolveMatrix` 单测（含：纯平移矩阵、旋转+缩放矩阵、null、非保形矩阵 → 返回完整/降级）；断言无向几何结果无旋转角（`M12==0 ∧ M21==0`）。
2. **端到端冒烟**：ShapeMatch(θ≠0) → ROI 工具链路，校验 3 处（算法处理区 / 交互层图形 / 结果层轮廓）空间一致（用同一形状在不同层输出的角点比对）。
3. **Fail-Forward**：非保形矩阵输入 `ResolveMatrix` 打 Warning 并降级（旋转矩形 → 四边形点集渲染），不静默。
