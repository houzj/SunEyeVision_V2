# 图像处理工具区域管线重构优化方案（v1.4）

> 日期：2026-09-05　状态：待实施（已确认方案 2：纯 ROI 管线）
> 适用范围：5 个图像处理工具（Blob / 图像阈值化 / 图像滤波 / 图像二值化 / 形态学处理）+ HalAdapter 区域管线

---

## 一、背景与目标

本会话此前已完成：
- 区域语义统一（有区域即限制 / 无区域全图，去 `IsRegionEnabled` 开关）— `ae7b6075`
- 新增 `HalconImageOpPipeline.Prepare` 并接入 5 个图像工具（含 Blob `DetachWorkingImage`）— `92ba19fd` / `a735578d` / `a605869e`
- 图像 3 工具交互层位置修正矩阵同步对齐 Blob — `0f1587d9`
- 死属性 `IsRegionEnabled` 清理 — `571311a0`

**经架构评审确认的设计缺陷**：当前 `Prepare` 无条件对输入图执行 `ReduceDomain` 并托管图像对象，等于替工具算法做了"按域执行"的决策，且引入 `DetachWorkingImage` 所有权转移复杂度。用户裁决：统一管线只负责「区域 + 位置修正」，图像执行方式（全图 / 按域）是各工具算法自身的职责。

**本方案目标**：把区域管线收缩为**纯几何 ROI 服务**，图像域处理归还算法层，所有权模型回归朴素 `using`，`Detach` 问题域整体消除。

## 二、架构定论（v1.4 边界）

| 层 | 职责 | 产出 | 关键约束 |
|---|---|---|---|
| **区域管线（helper）** | 区域订阅解析 + 位置修正（按形状有向性）+ 检测−屏蔽差集 | 纯几何 `RoiScope`（region 对象 + 计时 + 尺寸） | 不接收、不生成、不托管任何图像对象；只依赖图像宽高 |
| **图像域工具库（新增）** | `HalImageDomain.Restrict(image, roi)`：显式把 ROI 落到图像 Domain | 受限定义域图（reduce 或全图 Clone） | 静态、无状态；由工具显式选择是否调用 |
| **工具算法层** | 决定全图跑 or 按域跑 → 执行自有算法 | 结果 | 每种工具自主决策，管线不预设 |

**关键推论**：
- `DetachWorkingImage`、`MaskedImage.WorkingImage`、所有权转移**全部删除**；
- 工具图生命周期回到标准 `using`（自己 reduce 的图自己释放）；
- 算法获得"全图预处理 / 域内预处理"的自由；
- helper 从签名上无法碰图（`Resolve` 不接收 `HImage`），职责越界从根上消除。

## 三、修改清单（逐文件）

### 1. `src/SunEyeVision.HalAdapter/HalconImageOpPipeline.cs`（重写）
- `Prepare(HImage grayImage, ...)` → `Resolve(int imgWidth, int imgHeight, regions..., nodeResults, correctionMatrix)`；
- `MaskedImage` → `RoiScope`：含 `RoiRegion`(差集) / `InspectionRegion` / `MaskRegion` / `Timings` / 尺寸；`Dispose` 释放 region（保留防重入）；删除图像托管与 `DetachWorkingImage`；
- 类型建议改名 `HalconRegionPipeline`（语义精确），静态 `Resolve`；
- 类注释固化边界："只做区域 + 位置修正，不接触图像；全图 / 按域由工具算法决策"。

### 2. `src/SunEyeVision.HalAdapter/HalImageDomain.cs`（新增）
- `public static HImage Restrict(HImage source, HRegion? roi)`：`roi != null` → `ReduceDomain` 新图；否则 `Clone`。注释强调由工具显式选择。

### 3. 五个工具 `Run` 区域段重写（Threshold / ImageFilter / ImageThreshold / Morphology / Blob）

公共新模式（以 Threshold 示意）：

```csharp
var scope = HalconRegionPipeline.Resolve(
    imgWidth, imgHeight, inspectionRegions, maskRegions,
    parameters.NodeResults, correctionMatrix);
stepTimings.AddRange(scope.Timings);
if (scope.RoiRegion != null) 参数.LogInfo(...) else 全图 info;

// ↓ 算法层显式决策：本工具按域执行
using (var reducedImage = HalImageDomain.Restrict(grayImage, scope.RoiRegion))
{
    result.ReducedImage = new HalImage(reducedImage.Clone());
    ... Step4..N 原核心算子不变（输入 reducedImage）...
}
finally scope.Dispose();   // 只释放 region
```

- Threshold/IF/IT/MO：核心算子输入改为 `Restrict` 产物（行为与重构前等价）；
- **Blob**：删 `DetachWorkingImage`，`Restrict` 产物为 `processingImage`；Step3.5 预处理就地替换逻辑保留（自管 `using`），管线不再参与图生命周期；
- 区域语义（有区域即限制 / 无区域全图）与日志文案保持。

### 4. 契约测试（新建 HalAdapter.Tests 或并入现有测试项目）
| 用例 | 断言 |
|---|---|
| 无区域 Resolve | `RoiRegion=null`、Timings 含 ROI构建、不接收图（编译级） |
| 有检测区 Resolve | `RoiRegion`≈检测区（AreaCenter） |
| 检测+屏蔽 | `RoiRegion`=差集（屏蔽剔除） |
| 位置修正（含旋转） | `RoiRegion` 随矩阵变换 |
| `RoiScope.Dispose` 幂等 | 两次释放无异常 |
| `HalImageDomain.Restrict` 全图/按域 | 尺寸不变、Domain 正确、无所有权转移 |

### 5. 配套
- 交互层矩阵同步（`0f1587d9`）与管线解耦，零改动；
- 更新管线注释 /「视觉工具构建」技能（新增工具：区域前置 = `Resolve`，执行方式工具自决）；

## 五、执行顺序（分批提交，每批可验证）

1. **B1 helper 重构**：`HalconRegionPipeline.Resolve` + `RoiScope` + `HalImageDomain.Restrict` → 编译 helper；
2. **B2 工具接入**：5 工具 Run 区域段按新模式重写，删 Detach → 全量构建 0 错误；
3. **B3 行为回归**：dotnet test 相关项目 + 宿主手动复测（MT-01~05，含 Blob 预处理连跑）→ 通过后提交；
4. **B4 契约测试**：落地用例跑绿；
5. **B5 收尾**：技能 / 注释 / 验证记忆更新，推送远程。

## 六、风险与边界

- **行为等价是硬指标**：重构只搬归属（reduce 从 helper 移到工具），不改变执行顺序与结果；Blob 预处理仍在按域图后进行（与现状一致），"全图预处理"能力作为后续算法自由，不在本次启用；
- 5 工具 reduce 模板虽归算法，但经 `HalImageDomain.Restrict` 单行调用，重复可控且不承载语义；
- 不做：交互层改动、参数改动、`ReplaceWorkingImage`、Metrology 工具接入（区域语义不同，维持原状）；
- 回退点：B1/B2 独立提交，任一步回归失败可单独 revert。
