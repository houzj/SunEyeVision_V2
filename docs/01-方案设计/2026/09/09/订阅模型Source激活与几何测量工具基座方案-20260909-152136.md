# 订阅模型 Source 激活与几何测量工具基座方案（v4·修订）

> 关联：v3《四概念边界与订阅单模型重构最终方案-20260907-103754.md》（留档）。
> v4 修订：① 订阅模型三态互斥 → `Roi.Source` 显式激活；② **测量工具基座由"Roi 元素槽"路线修订为"测量引导+卡尺参数组 + ParamValue 参数订阅"路线**（依据代码事实与用户裁决，2026-09-09）。

## A. 订阅模型最终语义（已落地，P2 基线不变）

- `Roi { Source ∈ Drawing|WholeRegionSub|GeometricSub }`：三种配置（LocalGeometry / Binding / ParameterBindings）并存保留，`Source` 唯一激活；运行时 `ResolveRuntime` 按 Source 三选一。来源 `src/Plugin.SDK/Execution/Parameters/RoiInput.cs:19-27,103-107`。
- 订阅面板子模式（区域订阅↔参数订阅）纯视图切换 + 激活 Source，不清数据；主模式 订阅→绘制 清空该几何输入全部订阅配置；绘制→订阅 重置为默认"区域订阅"并清空两子模式显示。
- P2 测量元素若复用 Roi 则天然获得此能力；但经复核，测量工具改用"测量引导参数组"路线（见 B）。

## B. 几何测量工具基座（修订版）

### B.1 核心概念（用户裁决 + 代码事实）

**测量元素** = "引导几何参数 + 卡尺参数"参数组；每个工具两个元素（Element1 / Element2）。
- **绘制路径**：在 WPF 画布给引导几何（`MeasureEditorControl`，只画所需形状），配卡尺参数 → 运行时沿引导做**像素测量**（引擎自选 Halcon/Cv）→ 亚像素拟合出**被测几何**。
- **订阅路径 = 参数订阅**（用户裁决）：引导几何参数与卡尺参数**逐字段** `ParamValue<T>` 绑定上游输出；运行仍做 measure（订阅供给的是"引导/卡尺数值"，不是跳过测量的成品几何）。
- **点元素**：`MeasureEditorControl` 不支持 Point 编辑（`MeasureGeometryType` 仅 Line/Circle/Arc，来源 `UI/Controls/Measure/Models/MeasureToolItem.cs:9-19`）→ 点**无绘制**，仅以可绑数值（X/Y `ParamValue<double>`）+ 订阅形式存在。

### B.3 工具架构模板（每工具：tools/SunEyeVision.Tool.<Name>/，首期统一引 HalAdapter）
```
Parameters (继承 RoiParameters? 或 ToolParameters+ImageSource 兼容——沿用 RoiParameters 复用输入图/位置修正/结果层通道，见 C)
├─ Element1Parameters / Element2Parameters  (引导几何参数 + 卡尺参数, 全部 ParamValue<T> 以支持参数订阅)
│   ├─ Line   : 引导 X1,Y1,X2,Y2  (ParamValue<double>)
│   ├─ Circle : 引导 CenterX, CenterY, Radius (ParamValue<double>)
│   ├─ Point  : X, Y (ParamValue<double>，无绘制，仅订阅/常量)
│   └─ Caliber: MeasureLength1/2, NumMeasures, Sigma, Threshold, Transition, Select, DistanceThreshold (ParamValue<…>)
├─ 判定规格: 每测量输出项 MeasureThreshold(Enabled/Min/Max/Unit)
DebugControl(3-Tab)
├─ Tab1 元素: MeasureElementsEditorControl (双 MeasureEditorControl 互斥并排，无屏蔽区，形状限定)
├─ Tab2 运行参数: 元素选择 + 引导/卡尺参数 ConfigSetting（绑定走 ParamBinding/ParamValue 两态）
└─ Tab3 结果显示: 判定(MeasureThreshold×N + Toggle+Range) + 图形(引导/拟合/被测几何) + 文本
Tool.Run
├─ ① ApplyBindings 已由执行器注入 ParamValue（参数字典自动）
├─ ② 每元素: 绘制或订阅后取引导/卡尺数值 → measure(引擎) → 拟合被测几何(线/圆)（点=订阅坐标直取）
├─ ③ 元素间几何量: 线线距/夹角、点线距、圆心距、点距…（SDK 几何）
└─ ④ MeasureThreshold 判定 → OK/NG → 结果 FillDisplay/可视化
```

### B.4 UI 形态（用户描述）
两个测量工具栏**放在一行**，每个工具栏只显示该元素所需图形（线/圆），一次只激活一个（互斥）；无屏蔽区域。点元素不占工具栏绘制（以订阅数值呈现）。

## D. 排期与任务（用户裁决：先全支持 → 半支持 → 纯订阅）
1. SDK 基座 C1（MeasureThreshold + 判定器）先落地；
2. **线-线**（两元素全支持：引导绘制+卡尺 measure+参数订阅）定范式与双工具栏 UI（C2+C3+C4 首落于此）；
3. 线-圆、圆-圆（全支持，套模板，圆/弧参数）；
4. 点-线、点-圆（点元素仅参数订阅，无绘制）；
5. 点-点（纯订阅双点）；
6. slnx 登记 → 全量验收（双来源、互斥、上下限、生命周期、引擎无关 csproj 检查）。

## E. 验收要点
- 元素双来源：绘制（本地引导+卡尺→measure）与 参数订阅（引导/卡尺字段绑上游）两路径 + 混合；
- 点元素无绘制交互、值来自订阅；
- 双工具栏并排互斥、只显示所需形状、无屏蔽；
- 每测量输出项上下限 OK/NG；
- 调试窗 打开→运行→关闭→重开 无残留叠加/重复订阅；
- 六工具 csproj 引擎引用的独立性与"仅引所需引擎"。
