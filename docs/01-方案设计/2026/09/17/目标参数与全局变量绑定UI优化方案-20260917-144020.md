## 6. 详细规格

### 6.1 P1 复选框交互规格（冻结）

**角色**：叶子 = 唯一真源；父节点 = 派生显示 + 批量入口。

| 点击对象 | 点击前 | 结果 |
|---|---|---|
| 叶子 | ☐ / ☑ | 翻转 → 绑定 / 解绑（右侧列表同步增删） |
| **父节点** | ☐（子树无勾选） | **全选**：其下所有叶子置 ☑ |
| **父节点** | ☑（**部分或全部**选中均显示 ☑） | **反全选**：其下所有叶子置 ☐ |
| 右侧 ✕ | — | 解绑并置树中该叶子 ☐ |

**传播**

```text
[向下] target = !(父当前为 ☑)，递归 SetChildrenSelected(target)
[向上] parent.isSelected = parent.children.Any(c => c.isSelected)   // ANY 聚合
```

**一致性**：叶子 ☑ ⇔ 右侧列表有且仅有一条。

**生命周期**：打开时已有绑定 → 叶子初始 ☑ → 一次性聚合；确定 → 生成 `ConsumerBindings`；取消 → 丢弃。

**边界**

| # | 场景 | 规格 |
|---|---|---|
| 1 | 无匹配参数的节点 | **不显示复选框** |
| 2 | 子程序嵌套 | 子程序调用节点 = 批量操作其展开子树 |
| 3 | 父节点部分选中 | ToolTip「已绑定 x / y 个参数」 |
| 4 | 同一子工作流被多处调用 | §13 待定项 1 |
| 5 | 参数已被别的变量绑定 | §13 待定项 2 |

**实现形态**（`IsSelected` 由 `bool?` → `bool`；`UpdateParentCheckState` 用 `Any`；删除 `SupportsTriState`/`SelectionActionText`/`ToggleSelectionCommand`/三态 `null` 分支）

```csharp
private bool _isSelected;

public bool IsSelected
{
    get => _isSelected;
    set
    {
        if (!SetProperty(ref _isSelected, value)) return;

        if (Children.Count > 0) SetChildrenSelected(value);        // 父：向下全量置位
        else OnLeafSelectionChanged?.Invoke(this);                 // 叶子：同步右侧列表

        Parent?.UpdateParentCheckState();                          // 向上 Any 聚合
    }
}

internal void UpdateParentCheckState()
{
    if (Parent == null) return;
    bool anySelected = Parent.Children.Any(c => c._isSelected);    // ANY 语义
    if (Parent._isSelected != anySelected)
    {
        Parent._isSelected = anySelected;
        Parent.OnPropertyChanged(nameof(IsSelected));
        Parent.Parent?.UpdateParentCheckState();
    }
}
```

XAML（树模板）：`CheckBox`（`IsChecked="{Binding IsSelected, Mode=TwoWay}"`，默认 `IsThreeState=False`）+ 名称 `TextBlock`（`VerticalAlignment="Center"`），**所有层级显示**、空节点隐藏。

### 6.2 P2 显示名规格
1. 解析顺序：**工具契约 / 参数声明优先**；缺失时**不得静默回退英文**（日志告警 + 守卫测试拦截）
2. 工具侧为可绑定输入参数补中文 `[DisplayName]`，**取该工具调试窗 XAML 已有中文标签**，保证全项目同名
3. 途径1（`ParamSettings`）与途径2（`ToolParameters`）**共用同一过滤函数**（排除 `[JsonIgnore]`、非可绑定项，按 `targetTypeName` 过滤）
4. 守卫测试：可绑定输入参数必须有中文显示名；两途径返回**同一集合**

### 6.4 P4 规格

### 6.6 P6 绑定显示文案规格（新增）

| 项 | 规格 |
|---|---|
| 文案格式 | **`全局.<变量名>`**（前缀统一为「全局」） |
| 唯一入口 | 新增格式化入口（建议 `ParamBinding` 或 SDK 内静态 Helper）：`GlobalVariableDisplay.Format(string name) => $"全局.{name}"`，并配套 `TryGetVariableName(string display)` 解析；**禁止**任何位置再出现 `"全局变量."` / `"全局."` 字面量拼接 |
| 调用点收敛 | ① `ParamBinding.CompleteGlobalVariableBinding`（原 `:1131`）② `ConfigSetting.OnGlobalVariableRenamed`（原 `:441-443` 的字面量判断 → 改用 Helper 解析/重拼）③ `GlobalVariableManagerViewModel` 写 `SourceNodeName`（原 `:846`，改为 `GlobalVariableDisplay.Prefix` 常量） |

| ToolTip | 显示 `变量名 / 分组 / 类型 / 当前值 / 注释`（与"输入来源/目标输出"悬停信息对称） |
| 解绑 | ✕ 保留，补 ToolTip「解除该参数的全局变量绑定」 |
| 变量名可读性 | 自动生成名（`var4134`）信息量低 ⇒ 创建变量时给建议名并提示重命名；chip 若有「注释」则以次要样式显示 |

## 9. 防御机制（5 项）

1. **契约守卫（单测）**：可绑定输入参数缺中文显示名 ⇒ 失败；两途径参数集合不一致 ⇒ 失败
2. **主题守卫（单测）**：`src/UI/**/*.xaml` 出现 `#RRGGBB` / `White` / `Black` 字面色 ⇒ 失败（白名单需注释理由）
3. **交互守卫（单测）**：① 勾任一叶子 ⇒ 所有祖先 ☑ ② 子树叶子全取消 ⇒ 祖先全 ☐ ③ 点父（☑）⇒ 子树叶子全 ☐ ④ 叶子与右侧列表 1:1
4. **文案守卫（单测）**：源码中禁止出现 `"全局变量."` / `"全局."` 字面量拼接（必须走 `GlobalVariableDisplay`）
5. **端到端冒烟（manual）**：目标参数勾选 → 确定 → 依赖图连边；模块结果绑定 → 变量侧「输入来源」显示同一绑定；目标变量删除 → 回显刷新为「目标变量已删除」
