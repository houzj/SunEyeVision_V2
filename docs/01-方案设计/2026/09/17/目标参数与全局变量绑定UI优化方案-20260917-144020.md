## 4. 可绑目标判据 v3（三层漏斗）

```
  节点参数类的全部 public 属性（如 ShapeMatchParameters 的 20+ 属性）
                 │
   ① 节点类别过滤 │  仅「算法节点」→ 排除 条件分支 / 脚本 / 子程序
                 ▼
   ② 参数类别过滤 │  仅「运行参数」→ 排除结构/引用/派生字段
                 │  （SubroutineId、ScriptCode、AssemblyReferenceDir、
                 │    PositionCorrectionBindingDisplayText …）
                 ▼
   ③ 数据类型过滤 │  仅 Integer(整数) / Double(浮点数) / String(字符串)
                 │  （SdkTypeVocabulary 词目白名单）
                 ▼
        最终列出的可绑参数（示例）
```

| 维度 | 规则 | 落地依据 |
|---|---|---|
| ① 节点类别 | 仅算法节点 | 需可判定来源（§13-3 待选甲/乙） |
| ② 参数类别 | 仅运行参数；排除 `[IgnoreBind]` / `[JsonIgnore]` / 非数据字段 | `ToolParameters.GetBindableInputProperties()` 已支持 `[IgnoreBind]` |
| ③ 数据类型 | `{Integer, Double, String}` | `SdkTypeVocabulary.ToTypeVocabulary()` |

**对当前方案的实例效果**

| 节点 | 现状列出的 | v3 之后 |
|---|---|---|
| 图像载入1 | `FilePath`（英文） | ✅ 保留 + 补中文名「图像文件路径」 |

| Script1 | `ScriptCode`、`AssemblyReferenceDir`、`input1` | ❌ 全不列 |

| 子程序1 | `SubroutineId`、`SubroutineName`、`input1` | ❌ 自身不列；展开出的算法子节点 ✅ 照常列 |

## 5. P1 复选框交互规格（冻结）

| 点击对象 | 点击前 | 结果 |
|---|---|---|
| 叶子 | ☐ / ☑ | 翻转 → 绑定 / 解绑（右侧列表同步增删） |
| **父节点** | ☐（子树无勾选） | **全选**：其下所有叶子置 ☑ |
| **父节点** | ☑（**部分或全部**选中均显示 ☑） | **反全选**：其下所有叶子置 ☐ |
| 右侧 ✕ | — | 解绑并置树中该叶子 ☐ |

```
☐ 工作流1                    ← 未勾选：子树无绑定
☑ 工作流1                    ← 勾选：子树「有」绑定（不代表全选）
   ▼ 轮廓匹配1
      ☑ 最小匹配分数          ← 已绑定（加入右侧）
      ☑ 匹配超时(毫秒)
      ☐ 最大匹配数量          ← 父节点仍为 ☑（ANY 语义）
点父节点(☑) ⇒ 其下叶子全变 ☐（反全选）
点父节点(☐) ⇒ 其下叶子全变 ☑（全选）
```

- 向上聚合：`parent.isSelected = children.Any(c => c.isSelected)`
- 一致性：叶子 ☑ ⇔ 右侧列表有且仅有一条
- 空节点（无参数、无子程序）⇒ 节点不出现（沿用现有规则）
- 实现：`IsSelected` `bool?`→`bool`；删 `SupportsTriState`/`SelectionActionText`/`ToggleSelectionCommand`/三态分支；XAML `Button`→`CheckBox`（`IsThreeState=False`），**所有层级显示**

## 14. 防御机制与验收

**防御机制（5 项）**：① 契约守卫（中文名 + 两途径一致）② 主题守卫（禁字面色）③ 交互守卫（勾叶子⇒祖先☑；点父⇒子树全☐；1:1）④ 文案守卫（禁 `"全局变量."` 字面量）⑤ 端到端冒烟（绑定⇒两端一致；解绑⇒回退当前值）

**验收标准（15 条，核心）**

| 组 | 条目 |
|---|---|
| 交互 | 复选框即时生效 / 无 ▣ / 父节点全选与反全选 / ANY 向上聚合 / 叶子与右侧列表 1:1 / 空节点不显示 |
| 判据 v3 | 仅算法节点列出 / 仅运行参数 / 仅整数·浮点数·字符串 / 中文名齐全 |
| 视觉 | 输入来源列居中 / 选择变量窗口明暗主题无亮色残留 / 解绑按钮无硬编码色 |
| 绑定 | 结果行 `全局.<名>`+ⓧ 与变量侧一致 / 解绑后回退「未绑定（使用初值）」/ 一个参数被另一个变量改绑时旧记录被清理 |
| 文案 | chip 为 `全局.<名>`（只读）/ 重命名同步 / 源码无 `"全局变量."` 字面量 |
