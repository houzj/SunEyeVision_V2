# 相机管理器与预览调参界面最终优化方案

日期：2026-09-23  
状态：方案确认，待实施

## 目标

在当前相机管理器布局上做收敛，不重新设计管理器。相机管理器负责选择设备和查看基本信息；预览窗口负责同时查看实时图像、调整相机参数并验证效果。

## 相机管理器

- 保留现有设备列表与详情区域结构。
- 详情区域只保留“基本信息”Tab，移除“参数设置”Tab。
- 基本信息展示名称、厂商、型号、IP、连接状态。
- 预览按钮继续放在当前基本信息区域，不移动到设备列表。
- 移除独立连接、断开和重复的编辑按钮；移除参数 Tab 后可适当收窄管理器，宽度以设备名称和基本信息不被截断为准。
- 点击“预览”时自动连接相机；成功后打开统一的相机设置窗口。连接失败时显示明确错误，不打开空白窗口。设备已连接时复用现有连接，不重复连接。

```text
┌────────────── 相机管理器（沿用当前布局）──────────────┐
│ 设备列表                       │ 基本信息             │
│                                │                      │
│ 相机 A                         │ 名称：相机 A         │
│ 相机 B                         │ 厂商：海康           │
│                                │ 型号：MV-xxxx        │
│                                │ IP：192.168.1.10     │
│                                │ 状态：未连接         │
│                                │                      │
│                                │              [预览]  │
└────────────────────────────────┴──────────────────────┘
```

## 相机设置窗口

预览与参数设置放在同一个独立窗口，二者共用同一相机连接和采集会话。左侧显示图像，右侧显示可搜索、分类折叠的相机参数；修改参数后无需切换窗口即可观察后续图像。

```text
┌────────────── 相机设置：相机 A ────────────────────────┐
│ 已连接 · 连续采集 · 触发关闭                    [关闭] │
├──────────────────────────────────┬─────────────────────┤
│                                  │ 参数设置            │
│                                  │ [搜索参数……]       │
│                                  │                     │
│          实时图像预览            │ ▾ 常用参数          │
│                                  │   曝光时间 [1000]   │
│                                  │   增益     [2.0]    │
│                                  │ ▸ 图像格式控制      │
│                                  │ ▸ 采集控制          │
│                                  │ ▸ 其他相机参数      │
├──────────────────────────────────┴─────────────────────┤
│ 参数应用结果 / 设备错误 / 等待新帧反馈                  │
└────────────────────────────────────────────────────────┘
```

## 行为约定

1. **预览只显示相机实际采集到的图像。** 不自行切换触发模式、不强制连续采集、不覆盖设备参数。
2. **参数控件由相机 SDK 能力决定。** 依据节点类型、枚举选项、读写权限生成；只读参数只展示，只有设备支持且可写的参数才允许修改。
3. **触发行为遵循设备当前配置。** 软件触发仅在当前配置允许时启用；其他触发模式按相机真实状态工作。
4. **反馈区分参数写入与图像变化。** 显示写入成功/失败、设备回读值、是否收到新帧，避免将“写入成功”误认为图像必然有明显变化。
5. **关闭窗口统一收尾。** 停止本窗口的预览采集并释放对应资源；连接生命周期由相机会话统一管理，避免后台采集或重复连接。

## 预期结果

- 管理器更紧凑，仍沿用用户熟悉的现有布局和入口位置。
- 用户从基本信息中的“预览”进入后，可以在同一窗口完成看图、调参和效果核验。
- 参数面板与预览不再各自管理相机状态，减少连接重复、触发配置不一致和关闭后残留采集的问题。

## 验收要点

- 管理器只保留基本信息 Tab，预览按钮仍位于基本信息区域。
- 未连接设备点击预览会自动连接；连接失败有明确提示；已连接设备不会重复连接。
- 统一设置窗口同时显示图像和参数，参数修改后可核对 SDK 回读和新帧状态。
- 连续、软触发、硬触发等行为遵循相机当前配置，预览不擅自改写配置。
- 关闭设置窗口后预览流停止，后台没有残留采集任务。
