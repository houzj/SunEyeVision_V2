# 协议组装工具方案与沟通基线

日期：2026-10-10  
状态：文本组装首版插件及配置编辑器已实现；宿主执行器、双输出和共用数据分析已验证，人工界面验收待完成。

协议组装把常量和绑定数据按列表顺序形成一段文本，供后续工具使用，不发送、不直接写变量、不触发工作流。本轮仅文本组装，用户明确脚本组装暂不实现，不借用全局脚本；二进制字段打包、校验和、补位也不自动纳入范围。

统一输出原则：只按配置的内容、顺序和分隔符形成组装结果，不猜测常量类型或把文本自动转为寄存器数值。首版固定提供文本与对应UTF-8字节双输出；实际字节与HEX显示严格区分，不进行设备发送。

配套方案：[接收数据](./接收数据工具方案与沟通基线-20261010.md)、[发送数据](./发送数据工具方案与沟通基线-20261010.md)、[协议解析](./协议解析工具方案与沟通基线-20261010.md)。通信项目负责工具链，主项目负责标定工具链，共享契约变更须评估双方影响。

## 当前来源与联合验证定稿

当前值接收、多行变量与生产者依赖已接通；TCP新报文及Modbus两次主动读取均通过正式接收→解析→组装引擎。组装依旧只消费本次成功上游结果、其变量参数快照或常量，不直接读设备、不改变已有双输出契约。证据见[实施交接](../../../collaboration/HANDOFF_RECEIVE_CURRENT_VALUE_IMPLEMENTATION_20261012.md)。

2026-10-12确认：组装列表每行是独立内容项，主要来源为本次已有成功结果的上游节点字段，不限于紧邻上一节点；也可绑定全局变量执行快照或手填字符串常量。每行通过绑定按钮明确指定来源，不自动收集所有上游数据，不固定读取全局触发out，不直接读取通信管理接收事件out或设备最新值。

| 来源 | 示例 | 规则 |
| --- | --- | --- |
| 上游节点业务输出 | 协议解析out、测量结果的数值字段 | 按稳定绑定键取得本次有效结果 |
| 全局变量快照 | 产品编号、设备编号 | 当前执行快照内存在且类型兼容 |
| 直接填写常量 | RESULT、固定命令头 | 始终按文字保留，不猜数字或HEX |

组装项支持String／Integer／Double单项值，数值用固定文化和明确格式转文字。Binary、Boolean、图像、几何对象和未选一项的多项集合不自动转文字；空字符串合法，缺值或错误类型整体失败。绑定候选必须过滤为这三种兼容类型，执行仍严格校验，不能出现下拉能选但工具不支持；当前候选已通过AllowedDataTypes过滤，该修正与接收插件同批交付，不改变其他算法参数规则。

```text
设备 --> 接收数据(Binary) --> 协议解析(类型化字段)
                                      |
          常量／全局变量快照 ----------+
                                      v
                        协议组装列表逐项绑定
                                      |
                        String + UTF-8 Binary结果
                                      |
                        模块结果／主界面数据分析
```

接收原始Binary不能直接进入当前文本组装项；先解析为string／int／float，或选择可直接使用的原生String／数值。全局触发可在明确的参数映射及执行接线完成后提供输入，但不是组装列表的固定来源，也不是本批链路前置；相关接线尚未完成，不以事件out冒充节点out。

联合实例：接收节点实际取得ABC,2或00 5C 41 44，经解析得到ABC和2或92和AD，再用常量RESULT组成RESULT,ABC,2或RESULT,92,AD。接收在节点执行时取得当前来源；后续解析、组装仅消费本次成功输出，不因触发值不同而替换、不重读设备。组装直接绑定全局变量仍使用其参数执行快照；需要节点执行时当前变量则先通过接收变量模式产生out。

开发优先级为接收无UI服务与真实插件、同批解析／组装绑定筛选、设备联合验收，再做宽度等UI微调。已有常量／变量与纯算法测试仍有效，但不能替代设备链；第一批终点为模块结果，不新增发送行为。组装、解析首版与重排修复已实现，接收设备／单项变量首版与新筛选已实施，队列等路径仍待完成，详见[实施计划](./通信工具链实施计划-20261010.md)和[统一优化基线](./通信接收与协议解析优化基线-20261012.md)。

## 首版实施规则与界面

2026-10-12 界面定稿：默认窗口与普通算法节点一致，为400×550 WPF逻辑单位。配置页只显示必要标签和操作控件，不常驻显示功能说明、结果查看提示；解释放到标题悬停提示及后续帮助文档中。列表按内容高度展开，长列表在表格内滚动；“＋”紧跟表格。行内↑／↓作用于点击项，首末边界禁用；×删除该项，新增后选中新项。重排保留项身份和绑定。行、单元格、绑定输入、下拉项与选中态统一适配深浅色主题。共用SDK局部样式；算法与输出契约不变。

本节是当前项目实现口径，优先于后续候选设计。按列表顺序连接字符串、整数和有限浮点数，数值格式不随系统地区变化。直接输入始终是字符串，例如0001生成字符0001，其UTF-8字节为30303031，不猜成数值1或字节0001。绑定空值、失败上游、非单项列表、Boolean或Binary载荷不自动转换，整体失败。空字符串合法；必须至少配置一项。暂不加入转义、补位、校验和、结束符或脚本组装。

```text
+------------------------------------------------------------------+
| 协议组装                                      [宿主关闭入口]       |
| 组装配置                                                         |
| 分隔符 [, v] [自定义] [自定义时显示输入框]                          |
| 组装列表                                                         |
| 序号  内容                                                 操作   |
| 1     [自定义文本或上游字段_____________________][绑定]     ↑ ↓ ×  |
| [＋]（紧跟表格）                                                 |
|                                     [宿主执行] [宿主确定]         |
+------------------------------------------------------------------+
```

固定输出为组装结果String和16进制组装结果Binary，两者使用稳定绑定键。第二项实际承载BinaryPayload，名称中的16进制指展示方式，不是HEX字符串。UTF-8编码失败或任何组装项无效，不发布部分结果。列表顺序、自定义分隔符和项身份可保存重载；配置编辑器不显示运行预览，执行和确定使用宿主已有入口。

目前只有文本组装，建议不显示单选组或脚本占位入口，组装方式只读说明即可。

```text
+--------------------------------------------------------------------+

+--------------------------------------------------------------------+
| 组装配置                                                           |
|                                                                    |
| 组装方式   文本组装                                                |
| 分隔符     [,                                            v]        |
|--------------------------------------------------------------------|
| 组装列表                                                           |
|                                                                    |
| 序号   内容                                  类型        操作      |
| 1      [RESULT                        ][绑定] string      [删除]   |
| 2      [检测工具.结果                  ][绑定] int         [删除]   |
| 3      [定位工具.X                     ][绑定] float       [删除]   |
|                                                                    |

```

类型、删除和排序为项目优化，内容为示例。配置窗口只定义规则和输入；类型或绑定失效等配置校验可就地提示，但不显示本次运行值、耗时、成功状态或组装结果。

### 分隔符

复用通讯管理器和协议解析统一的数据源，支持自定义多字符分隔符。无表示直接连接，不自动补空格。只插入相邻项之间，不默认添加首尾分隔符。

```text
列表：RESULT、1、12.5
分隔符 "," -> RESULT,1,12.5
分隔符 "|" -> RESULT|1|12.5
无分隔符   -> RESULT112.5
```

自定义文本中的反斜杠不自动解码：两个字符的 \r 与预设标签对应的真实回车不同。显示标签和实际值分别保存，避免字符串标签误作控制字符。

### 组装列表

每行支持常量或绑定，复用工具宿主输入选择机制。常量默认字符串，不把 "0012" 猜成整数。绑定显示来源及原生类型，类型只读，不为组装任意转换类型。

添加、删除、上移和下移调整列表；列表顺序就是组装顺序。每行保持稳定身份，移动不丢绑定；来源删除或类型变化明确失效，不按同名结果自动关联。图像、集合、结构体和字节首版不自动调用 ToString，必须有明确转换能力才能接入。

## 3 文本格式化建议

| 输入 | 首版建议 |
| --- | --- |
| string | 原样保留，不自动 Trim |
| 有限整数标量 | 固定文化格式十进制 |
| float 或 double | 固定文化格式，保证必要精度，拒绝 NaN 和 Infinity |
| 空字符串 | 合法项，保留位置 |
| null 或缺失绑定 | 失败，不替代为空字符串 |
| 字节、图像、数组和结构体 | 首版拒绝，不隐式格式化 |

具体整数承载遵循SDK Integer；浮点承载为Double，当前实现接受int／long及有限float／double，并使用固定文化可往返格式。Boolean当前不支持，若扩展需另行设计显式格式；固定小数位和任意整数类型不在首版范围，不能偷偷舍入或放宽类型。

```text
列表："A"、""、"B"；分隔符 ","
结果：A,,B

第二项绑定不存在 -> 失败
不能自动输出 A,B
```

### 内容中的分隔符

首版建议原样拼接、不自动转义；官方没有明确 CSV 引号规则。

```text
列表："A,B"、"C"；分隔符 ","
结果：A,B,C
该结果无法仅靠同一分隔符还原成原来的两项。
```

配置可提示已知常量冲突，动态值冲突策略仍需确认。若要求可逆，应对解析与组装同时设计转义协议，不能仅在组装端加引号。

## 4 业务输出与模块结果

共用[通信工具链模块结果与数据分析统一约定](./通信工具链模块结果与数据分析统一约定-20261010.md)。主界面数据分析按每项展示来源、原生类型、格式化片段、插入分隔符及输出位置；模块结果只发布最终文本和按已确认契约提供的字节。两者读取同一次执行结果，格式化诊断不作为新的业务字段，不在配置或调试窗口增加结果区。

输出定义和当前值统一由宿主模块结果提供，不在调试窗口复制结果。按用户截图保留组装结果和16进制组装结果的显示名称，字段实际类型必须明确；不因名称含16进制就把输出改成文本。

| 结果字段 | 实际类型或规则 |
| --- | --- |
| 耗时(ms) | 宿主统一计时字段 |
| 模块状态 | 宿主统一状态，展示不擅自改变 SDK 枚举或数值 |
| 组装结果 | string，最终文本 |
| 16进制组装结果 | BinaryPayload／Binary，同一文本严格UTF-8编码后的字节，HEX仅为当前值显示形式 |

```text
+--------------------------------------------------------------------------+
| [图像]  [模块结果]                                                        |
+--------------------------+------------------------------+----------------+
| 结果名称                 | 当前值                       | 变量管理       |
| v 协议组装1              |                              |                |
|   耗时(ms)               | 0.6                          | [绑定]         |
|   模块状态               | OK                           | [绑定]         |
|   组装结果               | RESULT,1,12.5                | [绑定]         |
|   16进制组装结果         | 52 45 53 55 4C 54 ...         | [绑定]         |
+--------------------------+------------------------------+----------------+
```

示例值不是 VM 默认值。点击工具组可展开或折叠，当前值只读；长文本或字节详情复用宿主结果查看能力，不新增工具自己的预览区。业务字段使用稳定结果身份供下游订阅，HEX展示不改变绑定类型。

变量管理链形入口用于配置模块结果到变量的绑定，按类型及项目唯一生产者规则校验。变量管理不是当前值编辑框；查看或刷新结果不会自动新增赋值行为。实际执行的变量发布仅按显式绑定和宿主生命周期处理，组装工具不另建变量写入通道。

UTF-8是项目已实现约定，不声称VM官方具有相同默认编码；首版固定提供String和对应Binary双输出及稳定绑定键，不再列为待确认。Binary承载真实字节，不是HEX字符串，也不是旧Byte数值标量。

```text
组装文本："0001"
UTF-8 字节：30 30 30 31
HEX 当前值显示：30 30 30 31
不是寄存器数值编码：00 01
```

因此字节结果是文本编码，不是二进制字段组装能力。

## 5 执行与失败

```text
配置及输入快照
       |
       v
解析绑定并校验类型
       |
       v
明确格式化 -> 列表顺序连接 -> 编码
       |
       v
原子发布结果 -> 宿主模块结果与下游结果契约
```

任一项失败则整次失败，不跳过项，不提供忽略错误开关，清除本次有效业务结果而不是显示上次成功值。状态、耗时与原因仍通过宿主结果或诊断更新；技术错误原因是否作为可绑定字段需另定，不能凭结果表空值隐藏失败。

取消不发布半成品。建议空列表失败，一个合法空字符串可以组装成功，发送工具仍独立判断能否发送空报文。

| 操作 | 行为 |
| --- | --- |
| 执行 | 用当前编辑配置和可用输入快照单步组装，结果进入本节点模块结果，不保存方案 |
| 确定 | 校验并提交工具节点配置，方案保存时统一持久化 |
| 查看模块结果 | 只读查看当前执行结果，不发设备、不触发流程、不新增变量赋值 |

不自动运行上游，不重新读取设备。单步与正式执行都走宿主统一结果通道，标识执行上下文，不能把草稿测试结果注入另一个正在运行的流程。显示结果不等于隐式运行消费者。若已有变量生产者绑定，发布行为服从宿主单步运行契约，不由配置窗口自行赋值。

## 6 与发送工具及事件衔接

```text
检测／计算 -> 协议组装最终文本 -> 发送数据单项绑定 -> 设备

检测／计算类型化参数 -> 发送数据事件参数绑定 -> 发送事件格式化 -> 设备
```

直接发送已组装文本时，不再按字段增加分隔符；结束符建议由发送工具追加一次，组装工具不设结束符、设备或地址。使用发送事件通常不需要协议组装，除非事件明确接收一个完整字符串参数，不能把完整报文误当多个业务字段。

Modbus 数值写入绑定原生数值，由发送端编码；组装文本仅适用于明确的字符串写入路径。OPC UA String节点可以接文本，数值节点不能接拼接文本。UTF-8字节不能当作寄存器整数编码，本轮没有二进制组装能力。

现有 [CommunicationSendEventFormatter](../../../../src/Workflow/CommunicationSendEventFormatter.cs) 包含纯格式化逻辑，可评估复用算法，但组装工具不能伪造事件配置或带入事件目标、结束符和发送行为。插件不得依赖 UI 宿主，抽取共享算法前评估事件及主项目影响。

## 7 四个工具统一结果约定

接收数据、发送数据、协议解析、协议组装的配置窗口不展示运行结果；执行按钮及宿主运行把输出发布到对应节点模块结果。配置校验提示不是执行值，可以保留。发送截图中的结果显示页签只能按宿主能力用于显示设置，不承载运行结果表或重复预览。

接收和解析的配置输出映射为模块结果字段；组装固定文本及对应UTF-8 Binary双输出；发送状态与提交信息作为对应模块结果或宿主诊断。查看结果不改变原生类型，失败清空有效值，变量绑定遵循统一生产者约束。配置窗口不增加结果区。
