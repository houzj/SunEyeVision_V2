## 当前取数与界面定稿

接收节点执行时获取所选来源的当前数据。触发事件只决定工作流何时启动，不为接收工具锁定输入；事件的显式参数赋值仍是独立路径。触发后设备值发生变化时，以接收节点实际读到的值为准，工程负责设备与流程时序。一次读取完成后，模块结果、数据分析与下游绑定使用这次固定输出，不再随设备变化。

| 来源 | 节点执行时取数 | 输出 |
| --- | --- | --- |
| Modbus | 复用现有连接向所选地址块发起一次读取，取得本次返回值；不要求地址开启轮询，不用轮询缓存补位 | 寄存器数据区Binary，不含协议帧头 |
| OPC UA | 复用会话读取所选数据点，检查本次质量与实际原生类型；不以订阅缓存替代本次读取 | 数据点支持的原生类型 |
| 全局变量 | 通过执行层服务读取节点执行时的当前变量；多行输出一次取得一份变量集合，再原子发布，不使用工作流启动时的旧值 | 变量实际类型 |
| TCP／UDP／串口 | 读取当前连接最近实际收到、按设备分帧规则形成的完整报文；不发送隐式请求、不等待下一条 | Binary |

TCP等的当前报文是本机最近收到的内容，不保证远端此刻仍保持该值。读取不清空设备当前报文，没有新报文时重复执行可得到相同内容；尚未收到报文或连接已失效时失败。需要查询远端当前值的工程，应按设备协议明确配置发送请求和接收应答；关联、等待与超时能力必须单独评估，不把未知请求协议自动加入接收工具。

接收配置不提供报文年龄参数，也不隐藏默认时间限制。断线、设备／方案切换和通信配置变化后旧连接数据失效；取消、读取超时、无数据、质量错误、类型不支持均失败并清空本次业务输出，不回退上一次成功结果。主动读取沿用通信层超时和取消规则，不新建连接或第二套轮询。

沿用通信管理的列表、item和深浅主题资源；窗口尽量窄而高，文字及控件完整可读，不为收窄强行压缩列。配置页不展示运行值或常驻说明，说明进入Tip／帮助；设备模式无＋，变量模式隐藏设备／地址／有效期。队列仍为后续能力，服务未实现前不显示可用入口。

解析继续接受String／Binary，文本Binary按编码解码后拆分，字节Binary直接按区间读取。组装绑定本次成功上游结果、变量执行快照或常量，不直接重读设备；接收变量模式的执行时读取不扩大为所有算法参数的实时变量读取。事件out与节点out身份独立，不自动复制。

本节是用户需求确定的项目契约，不宣称VM内部实现如此。官方接收帮助确认三类来源、设备一项／变量多项及PLC地址选择；官方PLC帮助确认轮询间隔和数据同步按钮可读当前寄存器，但没有明确接收节点每次执行的读取时机。参考[第一类PLC通信协议](</D:/Program Files/VisionMaster4.4.0/Applications/Help/CH/GUID-033CB164-4DC3-40C2-8DB9-CFE9F89D58E5.html>)。以下首版记录仅说明当前代码／Release，新契约实施前不能拿原344项专项当作新规则验收。

接收数据工具把指定来源的数据引入当前工作流，生成供后续工具绑定的输出，不负责协议解析，也不负责触发工作流。本轮通信工具链包括接收数据、发送数据、协议解析、协议组装，暂不包含相机 IO 通信；主程序项目继续开发标定工具链。

本方案保留三种来源的UI与交互约定。队列后续交付；设备执行期取数与变量多行映射按当前定稿实施，共享契约改动仍须先评估。

统一输出原则：按所选来源取得当前载荷，保留实际类型，不自动解析或猜测字段。框架承载由实施者负责；取数时机以当前定稿为准，队列消费按后续配套契约确定。

2026-10-12最终输出约定：TCP／UDP／串口业务报文及Modbus寄存器数据区的out统一为BinaryPayload／Binary，不自动追加String副本。TCP传字节，可以承载文本或二进制；HEX只是展示。Modbus保留寄存器顺序、高字节在前的数据区，不含帧头。业务报文完整性复用分帧规则，不能把TCP一次读取块当作报文。OPC UA及变量／队列保留实际类型，原生数值可直接绑定兼容下游，不强制转String或经过解析。

2026-10-12最新进度：执行期当前值、设备分层和变量多行已实施，绑定及正式联合链重新验收。下一步编码与宽度UI、发送、队列和完整收发；原始Binary仍先解析为标量才进入文本组装。

协议解析接收String／Binary两种输入；文本模式必须能看到并订阅接收节点的完整Binary out，执行时按编码解码，再按分隔符拆分；字节模式直接按位置读取。绑定一个Binary载荷是取得完整报文，不是取一个字节；多项载荷需选择其中一项，不能自动拼接。输出身份、实际值、接收时间和后续解析对应同次快照。接收设备／单项变量首版已接通，队列和多项变量仍待完成，详见[最终优化基线](./通信接收与协议解析优化基线-20261012.md)。

2026-10-10 用户确认：接收工具的执行值、耗时、状态统一输出到宿主模块结果；配置或调试窗口只负责选择来源、定义输出和校验配置，不新增预览、结果表或历史框。

## 3 通信设备界面与交互

通信设备模式始终只映射一份数据，不显示添加按钮。协议差异通过目标能力决定，不使用“所有 PLC 都转字节”的统一假设。

```text

|--------------------------------------------------------------|
| 输入数据                                                     |

|                                                              |

```

- 设备来自通讯管理器；工具不重复配置 IP、端口和连接参数。
- “数据”选择所选设备中已配置的地址块，地址范围和数量只读显示。
- 建议输出寄存器数据区字节，保持可追溯的协议字节顺序；整数、浮点和字符串解释交给协议解析工具。
- 工具不新建连接，不启动第二套轮询，不直接访问通讯管理器控件。
- 地址删除使绑定明确失效；重命名只改变显示，不按名称重新绑定。

Modbus主动读复用驱动串行锁与连接，单次FC03支持1～125个寄存器，不自动拆分超长地址块；读取中配置或会话变化拒绝发布，不新增第二套轮询。

## 5 公共交互与配置保存

1. 切换模式只显示对应配置。建议各模式保留编辑草稿，只有当前模式参与执行。
2. 输出名称非空、同工具内唯一，默认从 out0 递增。建议用稳定输出 ID 维护下游绑定，改名不破坏引用；具体实现须符合统一工具结果契约。
3. 更换来源后重新校验绑定，不静默改绑同名设备、地址、变量或队列列。
4. 来源类型变化时刷新输出类型并提示不兼容的下游绑定，不做隐式强制转换。
5. 复用项目主题和局部表格样式，名称、数据与操作内容水平和垂直居中。
6. 确定提交到工具节点配置并标记方案变更；保存解决方案时统一持久化，不设独立保存配置入口。
7. 测试使用工具宿主统一单步运行入口，不另建收发调试区。队列测试若消耗数据，必须按配套队列契约明确提示。

确定和关闭是否采用草稿提交，服从现有工具配置窗口的统一交互；不能为通信工具另起一套保存行为。删除输出的确认和下游引用处理也应复用工具宿主规则。

## 6 执行与数据一致性

### 节点执行期取数

```text
事件满足条件 -> 启动工作流
                      |
                      v
             接收节点开始执行
                      |
                      v
    按所选来源读取当前值／当前完整报文
                      |
                      v
    校验质量和类型 -> 原子发布本次out
                      |
                      v
           解析／组装读取本次结果
```

Modbus和OPC UA通过执行层服务复用连接主动读一次；变量模式读取当时的当前变量集合；TCP等读取当前连接最近完整报文且不消费清空。节点不会因为触发事件而改绑来源，也不会回退读取上一次成功结果。触发条件值1而节点读到2时，输出2；读取完成后再收到其他数据，不改变已发布输出。

主动读取必须串行协调同一连接的读写与后台轮询，避免响应串包、死锁和并发修改地址；完成前校验设备会话、目标ID和配置仍有效。变量当前值由无UI执行服务提供，不把宿主窗口或全局变量UI作为数据源。参数与配置仍按执行快照传递；新增实时取数能力是显式服务调用，不是全面放宽其他节点的快照边界。

### 队列原子出队建议

按选定列和行数统一校验取数，任一列不足则整次失败，不消耗部分列。成功后消费本次数据，多个工作流不能重复取到同一份待消费数据。本工具不承担队列触发调度，调度由执行服务负责。

行对齐、多个读取者竞争、工具成功但下游失败后是否返还，以及取消发生时的消费边界，属于配套队列方案待定契约，不能仅依据 VM 界面决定。

### 失败与取消

来源失效、没有样本、质量错误、队列不足、变量不存在或类型不支持时，工具返回失败和原因，本次输出清空，不沿用上次成功结果。多输出模式全部成功后统一发布，避免半成功数据流入下游。

日志包含工具、来源和目标路径，不重复堆积无意义日志。取消沿用执行层令牌及统一状态规则；工具不得为等待数据而阻塞 UI，不持有窗口控件用于执行。

## 7 工具输出与功能边界

### 模块结果字段与分析数据

共用[通信工具链模块结果与数据分析统一约定](./通信工具链模块结果与数据分析统一约定-20261010.md)。配置输出out0等为模块结果业务字段，通信设备只一项；保留实际类型，字节当前值可HEX展示。来源路径、样本时间、质量与实际取得数量作为接收分析数据，主界面数据分析与模块结果读取同一次结果快照，不再次读设备。原始数据仅在来源提供时记录，不对图像或原生数值伪造字节；失败和无样本更新状态，清除无效业务值，分析保留原因。

| 输出或结果信息 | 用途 |
| --- | --- |
| out0、out1 等 | 配置的业务输出，保留相应类型 |
| 状态、耗时、错误原因 | 工具宿主统一执行信息 |
| 来源时间、设备与目标、样本身份、质量 | 结果详情诊断信息，样本身份须使用已建立的契约 |
| HEX 展示 | 仅字节输出提供，不改变实际类型 |

不设置对所有来源通用的 16 进制组装结果。队列图像、全局数值、OPC UA 布尔不应为了接收工具而转为 HEX。

```text
+------------------------------------------------------------------+
| [图像]  [模块结果]                                                |
+--------------------------+----------------------+----------------+
| 结果名称                 | 当前值               | 变量管理       |
| v 接收数据1              |                      |                |
|   耗时(ms)               | 1.2                  | [绑定]         |
|   模块状态               | OK                   | [绑定]         |
|   out0                   | 00 5C                | [绑定]         |
|   out1                   | 按原生类型显示       | [绑定]         |
+--------------------------+----------------------+----------------+
```

字段数量和类型随当前来源配置生成，示例并不表示通信设备模式允许两项。Byte[] 当前值可以 HEX 展示，变量绑定仍使用实际类型。变量管理为结果生产者绑定入口，遵循类型和唯一生产者规则，不因查看结果自动写变量。失败更新模块状态并清除本次有效业务结果，来源质量和错误原因通过宿主诊断展示。

| 功能 | 职责 |
| --- | --- |
| 通讯管理器 | 设备连接、目标配置、轮询和订阅、运行时收发 |
| 接收事件 | 后台解析或比较设备数据，产生事件结果 |
| 触发配置 | 根据事件或数据条件提交工作流执行 |
| 接收数据工具 | 在工作流中引入所选来源数据 |
| 协议解析工具 | 将引入的文本或字节按规则解析为字段 |

接收工具不要求先配置接收事件；事件决定启动时机，工具决定所选来源的执行期取数。两者可取到不同值，工程负责时序保证；结果查看不能再次读取设备。

工具插件不得依赖 UI 宿主程序集。来源解析通过执行层提供的服务或快照契约，不直接依赖通讯管理器 ViewModel。新增共享契约前须评估主程序标定工具链的影响，不能在通信分支擅自改动共享执行或 SDK 边界。

## 8 实施范围与验收建议

下一批优先接入执行期当前值读取、变量多行映射、设备与目标分层选择，并回归动态输出、绑定、方案保存和Release部署。队列服务具备后再开放对应模式。

验收覆盖模式切换、变量分组／搜索／多行及原子失败、输出改名／重排保持身份、目标删除／变化和会话隔离。Modbus轮询关闭仍可读、OPC UA非订阅读、触发后值改变取当前值、变量启动后变化取节点执行时值；TCP无报文失败、重复执行可读相同当前报文、断线后旧数据不可用。自动测试验证取消／超时／失败清空，UI验证主题、设计时、运行时、高DPI及可读宽度；实际设备验收独立记录。

## 9 待确认事项

| 事项 | 当前建议或边界 |
| --- | --- |
| 手动及触发运行取数 | 均按接收节点执行时当前来源读取，不以触发值代替读取结果；已定稿 |
| 数据队列交付范围 | 是否纳入本轮完整实施；当前尚无完整可复用队列服务 |
| TCP 服务端多客户端 | 是否选择具体客户端及如何隔离来源 |
| 会话与目标隔离 | 不设置报文年龄限制；连接／配置／方案变化使旧来源失效，按稳定设备及目标身份取数 |
| 队列消费边界 | 明确行对齐、取消、下游失败返还和并发读取契约 |
| 参数绑定及窗口提交 | 获取行数链形按钮的绑定能力、关闭是否丢弃草稿，按现有宿主契约定稿 |
