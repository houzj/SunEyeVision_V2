二、段 1：启动后台预热（消首次装载成本）

设计

项做法
挂点App.OnStartup 中 HandleStartupDecision returned 之后（日志 +2855ms 那个点），不 await、不进启动关键路径
线程Task.Factory.StartNew(..., TaskCreationOptions.LongRunning) + 线程优先级 BelowNormal，避免抢 UI/执行 CPU
预热内容① HOperatorSet.GetSystem("version")（触发 HALCON 平台装载，实测可覆盖）② 内存生成 8×8 灰度图 → HImage 构造 + 一个 Threshold 算子（覆盖 HImage 构造与算子注册）不读用户图像、不碰方案
幂等静态 Interlocked 标志，进程内只跑一次
失败语义失败只写一条 AddLog("HALCON 预热失败：…")，不弹窗、不重试、不影响首次执行（首次执行仍会正常装载）——属诊断日志，不是兜底
可观测成功记录 HALCON 预热完成 耗时=Nms（平台装载），用于后续验收对比
为什么有效：实测热态 platformInit=0-26ms、decode=4ms，证明装载成本只在首次；预热把这一次性成本挪到后台。
约束：不得在启动关键路径 await；不得占用执行租约；不得产生可见结果；不得写方案/日志刷屏（只 1-2 条）。

三、段 2：Blob 按需计算与算子合并

2.1 现状（实测 85ms 首次 / 33-38ms 非首次）

阶段耗时问题
入口准备（探针前）~24ms未拆分：参数 Freeze / ROI 栅格化 / 阈值准备，需先测
per-blob-measure23ms每 blob：SelectObj + CaptureRegion + ReadBoundary + ReadInnerRectangle + 无条件 ReadGrayStatistics（每 blob 一次 GrayHisto 256 桶）
region-snapshots10msSelectRegions×3 + CaptureRegion×3（final/ok/ng）全部无条件深拷贝

2.2 优化项（按风险从低到高）

#项做法预期风险
B1灰度统计按需ReadGrayStatistics(native,gray)（:179）改为按需求标志执行：仅当①结果显示需要灰度/对比度字段，或②判定组引用了灰度相关特征时计算。需求来源从 invocation.OutputRequests + 显示设置解析，写入 BlobOutputRequest 新标志-10~15ms中：需核对判定组字段消费
B2区域快照按需per-blob CaptureRegion 与 3 次批量 CaptureRegion 改为按输出端口/显示请求创建；未请求时输出 region 字段为 null（消费方需支持 null 语义）-6~8ms中高：涉及结果表/叠加/继承消费者
B3算子批量合并per-blob 的 connected.SelectObj(index) 合并为一次批量 SelectObj 取 region 数组；ReadInnerRectangle/ReadBoundary 仅在对应输出请求时执行（边界已按 requested 控制，保持）-3~5ms低
B4入口 24ms 定位在 ExecuteCore 开头到 execute-core-start 之间补细分探针（Freeze / ROI 栅格化 / 阈值准备），按结果决定是否优化待测低（只加探针）
实施顺序：B4（先测）→ B1（按需灰度，收益最大且独立）→ B3（批量合并）→ B2（区域按需，最后做，涉及面最广）。每步用探针 tool=blob stages=… 对比，不跑全量套件。

四、不做项（本轮明确排除）

项原因
执行引擎池化复用每批重建仅 ~1-2ms 级，收益小、状态残留风险高
启动依赖 SHA256 校验缓存属启动优化，与本次"执行耗时"目标不同，另立
ImageSource 解码优化非首次 3-5ms 已接近 VM 4.05ms，0.27MB JPG 解码无可省空间
ReadyToRun对 HALCON 原生装载无效，仅治 JIT（本轮非主因）

五、验收矩阵（探针对比 + 实机，不跑全量套件）

#验收项方法通过标准
1预热生效重启后首次执行，日志 image-read-decode≤10ms（此前 25-3134ms）；日志出现预热完成记录
2预热不阻塞启动对比启动日志 HandleStartupDecision returned 耗时与预热前持平（±0.2s）
3Blob 耗时下降探针 tool=blob stages=…非首次 ≤15ms（此前 33-38ms）
4结果语义不变实机对比：Blob 数量/面积/周长/质心/轮廓/结果表/图形叠加与优化前完全一致
5未请求特征的消费者结果表/属性树/继承链实机查看字段缺失时显示为空而非报错（按既有空值语义）
6ROI/结果显示零回归实机：绘制 ROI→运行→图形/文本/表/高亮与优化前一致

六、风险与回退

风险应对
预热拖慢启动或抢 CPUBelowNormal 优先级 + 只跑一次 + 失败不影响功能；实测对比启动日志
B2 区域按需导致结果表/叠加字段为空先确认消费者对 null 的处理语义；必要时保留"显示请求时必算"
B1 灰度按需遗漏判定组字段实施前逐项核对判定组引用的特征清单，不凭猜测跳过
性能优化引入语义偏差每段独立提交；探针保留期间可随时对比；实机确认后合入
