# DESIGN.md — 视觉软件 SunEyeVision 软件开发汇报（精简版）设计稿

> 通用设计路线（职场通用汇报场景，不命中学术/咨询/政务预设风格）。本文件是本项目的设计宪法，
> 4 页 slide 的全部视觉依据来自本文件。

## 1. 画布与母版（三区）

- 画布：**1280 × 720 px**（16:9）
- 页面 padding：**上 20 / 下 20 / 左右 60**
- 母版三区（内容页统一复用，页面内以固定结构呈现）：

| 母版区 | 垂直位置 | 高度 | 内容 |
| :--- | :--- | :--- | :--- |
| A · 标题块 | 20–120 | 100 | 页面主标题 34px bold + 左侧 6×34px 主色竖条 + 右上角步骤标签 |
| B · 内容区 | 120–660 | 540 | 卡片 / 时间轴 / 列表 |
| C · 页脚条 | 660–700 | 40 | 左：视觉软件 SunEyeVision · 软件开发汇报；右：`NN / 4`（13px 灰） |

- 封面与结束页采用自定义版式（封面省略 A/C 三区边框，结束页保留 C 页脚）。
- L3 角标：**全篇一次都不使用图片角标**，统一用文字水印「SunEyeVision V2」置于 C 区左侧，位置固定。

## 2. 颜色系统（4 hex + 2 中性灰）

| 角色 | hex | 用途 | 面积上限 |
| :--- | :--- | :--- | :--- |
| 主色（深蓝） | `#0B2A45` | 标题文字、左侧标题栏底色、结论条底色、封面背景 | ≤ 60% |
| 品牌色（亮蓝） | `#2196F3` | 已完成状态、进度条、竖条、图标、时间轴节点 | ≤ 30% |
| 强调色（橙） | `#E8930C` | 巨型锚点数字、进行中状态、"在建"标签 | ≤ 10%（Hero 页可至 18%） |
| 底色 | `#FFFFFF` | 页面底色 | 剩余 |
| 中性灰 A | `#5B6B7C` | 正文与注释文字 | — |
| 中性灰 B | `#E3E9EF` | 边框、分隔线、进度槽 | — |

- 渐变（仅封面与结论条使用）：`linear-gradient(135deg, #0B2A45 0%, #14456E 55%, #2196F3 160%)`
- 半透明：卡片浅底 `rgba(33,150,243,0.06)`；封面装饰块 `rgba(255,255,255,0.10)`
- 每页色彩分配（页面映射表内逐页声明），禁止全篇比例雷同：封面强调 15% / 产出页主色 45% / 计划页强调 16% / 结束页主色 50%。
- **浅色派生白名单**（不计入 4 hex 上限，仅作底/边框，面积合计 ≤ 页面 25%）：
  `rgba(33,150,243,0.06|0.08)` 主色浅底；`#F5F8FB` 中性浅底；`#FFF8EC` / `#FBE6C4` / `#8A5708` 强调色浅底与其深字；
  `#FDF3F3` / `#F7D9D9` / `#C0392B` 风险红（仅风险标识用，属语义色，单页面积 ≤ 6%）；
  `#14456E` / `#9FC3E0` / `#BBD6EC` / `#DCEAF6` / `#8FB4D1` 深蓝底上的浅色文字阶梯（仅用于深底之上）。
  说明：这些均为基准 3 色的明度/透明度派生（红为风险语义色），不引入新色相。

## 3. 字体系统

- 中文字体家族：**Microsoft YaHei（微软雅黑）**，西文回退 Segoe UI，全篇 1 套家族；
  巨型数字用同家族 **weight 800 + letterSpacing -1**（与正文 weight 400 形成字重差异）。

| 层级 | 字号 px | 字重 | 行高 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 78 | 800 | 1.15 | 仅封面 |
| 巨型锚点数字 | 84 | 800 | 1.0 | 封面 71% / 计划页 5/14 |
| 页面主标题（A 区） | 34 | 700 | 1.3 | 每页固定 |
| 卡片标题 / 条目名 | 21 | 700 | 1.35 | 产出块、时间轴段标题 |
| 正文 | 16 | 400 | 1.55 | 条目说明 |
| 注释 / 口径 | 13 | 400 | 1.45 | 引导句、脚注、页码 |

## 4. 信息密度门禁

- 常规内容页留白 **≤ 35%**（产出页 ≈18%、计划页 ≈26%、结束页 ≈22%）
- 卡片填充率 **≥ 85%**，条目尾部元素用 `marginTop: 'auto'` 或容器 `justifyContent: 'space-between'` 锚底
- 每页 ≥ 1 个视觉锚点：封面（84px 数字组）、产出页（底部在建进度条 + 19 个工具的超大数字）、计划页（84px「5/14」）、结束页（结论色块 + 状态图标）

## 5. 配图系统

- 本项目为**数据/文字型汇报**，全部视觉元素为**结构化元素（图标、进度条、色块、时间轴、大数字）**，
  不使用摄影/插画类配图，因此**不调用生图**（符合"允许 SVG/结构化元素承担叙事"的条件）。
- 图标统一使用 **FAIcon 实心风格**，同级尺寸统一（条目图标 26×26，状态图标 22×22，锚点图标 40×40）。
- L1 主视觉定义：封面为「渐变底 + 大数字组」（占 B 区 ≥ 40%）；计划页为「时间轴」（占左栏 60%）。

## 7. 全篇自检口径

- 内容页三区边界严格一致；页码格式 `NN / 4` 统一 13px 灰字。
- 页面高度合计：上 padding 20 + A 100 + gap 24 + B 496 + C 40 + 下 padding 20 = **700 ≤ 720**，安全余量 20px。
- 全篇只出现 4 种彩色 hex + 2 种中性灰，1 套字体家族。
- 不出现 Emoji；不使用 `display:grid` / `calc()`；不使用 `flex:1` 而不估算高度。
