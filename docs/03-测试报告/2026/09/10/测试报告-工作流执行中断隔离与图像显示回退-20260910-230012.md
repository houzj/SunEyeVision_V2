## 8. 手动验收步骤（L2 引导）

### MT-01 失败隔离与完整 run

1. 搭一条流程：`图像载入 → 灰度 → 脚本(强制抛异常) → 阈值`，并另加一条独立分支 `图像载入 → 边缘检测`
2. 运行
3. **预期**：脚本节点标红（失败）；阈值节点标"跳过"；边缘检测分支**照常有结果**；日志出现"组 N 存在失败节点，按隔离策略继续执行后续组"

### MT-02 调试可用性

1. 选中失败的脚本节点
2. **预期**：调试窗口能拿到上游（灰度）的输入图与数据源，参数可修改

### MT-03 显示回退（无输出节点）

1. 选中一个**没有图像输出**的节点（如下拉中无本节点项）
2. **预期**：图像区显示最近上游的图，且**下拉同步选中该项**

### MT-04 持久化源顺延

1. 选中某节点，把显示源手动切到"上游某节点结果"
2. 保存；重启后只执行**不产出该图**的部分，再次选中该节点
3. **预期**：图像区自动顺延到可用源（下拉跟随），不黑屏

### MT-05 整链无图

1. 清空/使整条链无任何可用图像
2. **预期**：图像区为空，无崩溃；日志"当前工作流无任何可用图像, 清空显示"
