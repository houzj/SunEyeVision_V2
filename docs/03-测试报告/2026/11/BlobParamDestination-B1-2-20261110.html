B1-1 判定

B1-1 无需增补字段。理由：BlobParameters.xml 已声明 105 项参数，BlobVmFindParameters 已承接原件 104 项（差集 0），BlobSettings 有 36 个宿主稳定字段并与闭包双向映射（FromSettings / ApplyTo）。计划里「41 vs 95 差集 54」的口径已被 B0-1 证伪。

真正待补的是 B0-3 查出的 6 项无算子承接参数，按用户决定归入 B3-1，不在 B1 重复处理。

参数去向规则（证明无静默省略）

去向类型含义判定依据
VM 闭包（bindingName）XML 参数通过 bindingName 映射到 VM 参数名，经 VmParameters 序列化XML 存在 bindingName 属性
宿主字段XML 参数 id 与 BlobSettings 公开字段同名，是宿主稳定字段合同id ∈ BlobSettings 字段集
VM 闭包（同名）XML 参数 id 直接等于 VM 参数名，经闭包序列化id ∈ BlobVmFindParameters 属性集
无去向既不在宿主字段也不在 VM 闭包三者皆不匹配，必须为零
