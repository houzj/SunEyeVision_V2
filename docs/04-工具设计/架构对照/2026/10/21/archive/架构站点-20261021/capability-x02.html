SUN EYE · 自研

自研当前实现

SDK同时装算法合同、参数结果类型、图像/ROI控件和调试窗口。插件不引用宿主UI，不代表它能脱离WPF运行。；工具带自己的依赖清单；宿主已有同名程序集时优先共用，因此不是每个插件都用自己的版本。；工具实例、后台任务、事件订阅、原生句柄和程序集是不同层；清掉工具列表不会自动销毁它们。；工具私有库随插件，大件平台由宿主供给；文件复制规则和运行依赖闭合是两件事。

完整缺陷与未闭合调用边

csproj实际UseWPF=true且有System.Drawing.Common；包描述“零依赖纯契约”不能作为架构事实。设计时资源字典依据设计环境加载Generic主题，运行时由宿主供给。；共享可避免跨边界类型身份分裂；但按simpleName和宿主文件存在回落，不等完整版本/公钥/API兼容验证。插件主程序集单独认本目录。；不可回收ALC是明确源码事实；UnloadPlugins没有调用逐实例Dispose或在途等待。不能据此断言一定泄漏，但不得把日志“卸载完成”解释为热更新/资源已全释放。；真实规则保留工具自身依赖，集中大件；宿主缺HALCON会构建报错。SuppressNativeRuntimesForToolPlugins按Link包含runtimes宽泛移除，未按私有原生依赖区分；不能保证新增插件私有native完整交付。

        protected override Assembly? Load(AssemblyName assemblyName)
        {
            var simpleName = assemblyName.Name;
            if (string.IsNullOrEmpty(simpleName))
                return null;

            // ① 插件主程序集：只认本插件目录内那一份 —— **绝不回落宿主**，
            //    避免 dev/Debug 根的历史残留同名 dll 被误用（方案 §十 清理清单第 5 条）。
            if (string.Equals(simpleName, _mainAssemblySimpleName, StringComparison.Ordinal))
            {
                var selfPath = Path.Combine(_pluginDirectory, _mainAssemblySimpleName + ".dll");
                return File.Exists(selfPath) ? LoadFromAssemblyPath(selfPath) : null;
            }

            // ② 契约与框架模块（SunEyeVision.*）→ 交回宿主，类型身份唯一
            if (PluginAssemblyPolicy.IsHostProvided(simpleName))
                return null;

            // ③ 宿主**已加载**的同名程序集 → 共用（跨边界类型必须同源）
            if (IsLoadedInHost(simpleName))
                return null;

        /// <summary>
        /// 获取所有插件
        /// </summary>
        /// <typeparam name="T">插件类型</typeparam>
        /// <returns>插件列表</returns>
        public List<T> GetPlugins<T>() where T : class
        {
            var pluginType = typeof(T);
            if (_plugins.TryGetValue(pluginType, out var pluginList))
            {
                return pluginList.OfType<T>().ToList();
            }
            return new List<T>();
        }
