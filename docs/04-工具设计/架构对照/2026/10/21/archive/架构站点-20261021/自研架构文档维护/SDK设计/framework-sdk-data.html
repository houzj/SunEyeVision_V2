读写数据：配置、输入、全局和结果分四种合同

数据类别公开结构/生效范围约束对应取舍
公开流程输入/输出FieldId + 名称别名 + ValueKind/Shape/Unit/CoordinateDomain + Required + schemaRevision默认客户只依赖流程公开schema，内部算法替换时保持schema即可；诊断/专家模块入口明确不稳定性。借鉴VM流程输出推荐，保留自研ParamSetting已有SourceFieldId，不能称完全无字段ID。
持久参数项目编辑事务提交并可保存；直接关系到方案修订编辑草稿不能被运行读取；执行参数覆盖只改当次请求，不修改持久化ToolParameters。保留ToolParameters及clone/metadata基础，切分UI通知与运行值。
当次输入每次Run单独请求，连续每轮由InputProvider提供或明确重复固定快照缺输入拒绝；不能沿用上一轮临时输入；坐标/图像格式与字节长度、stride、深度和色序校验。借鉴VM临时输入约定；自研给copy/retain明确选择，不暴露无寿命裸指针。
全局变量全局修订+根运行快照；子调用继承同一版本写入影响下一根Run，局部遮蔽明示；设备立即控制不走Globals.Update，结果回写须独立事务。自研新增保证，VM全局入口存在不等其快照政策相同。
结果ResultAddress含Run/Scope/Node/Iteration/Frame/schema；Quality区分Valid/Missing/Failed/Cancelled/StaleRead<T>不默认强制转换，数组不能自动截断/广播；TryRead返回结构化原因。结果只读，无WriteOutput绕过算法。VM typed读取可借鉴；不复制名哈希作为持久ID或缺失数据默认化。
资源图像/模型等返回显式lease，不把只读接口当不可变像素AcquireImage在父结果有效时获得独立子lease；子lease可按合同比父结果活得更久，但必须释放后项目才能完全关闭。现有IVisionImage只有Clone/Dispose，尚不等retain/refcount实现；原合同需适配。

稳定字段ID不是把所有业务都变成无类型object。工具内部保持强类型；外部读取用Field schema与Read<T>/TryRead，返回类型、形状、质量、版本错误。输入位置、输出点集、图像都带坐标域/单位，不按double[]长度猜类型。流程GetSchema同时列公开Inputs、Outputs及可覆盖的Parameters；WithParameterOverride只接受已公开参数FieldId，不能任意写内部工具字段。BeginEdit.SetParameter(nodeId,...)属于显式专家编辑接口，客户选择它就承担内部结构版本耦合。

别名与兼容：旧名称/属性路径由迁移适配映射到FieldId，找不到或歧义必须报错；只改显示名不变ID。定义修订和运行结果版本不同，GetLatest仅是显式便利接口，不能代替指定Run读取。
