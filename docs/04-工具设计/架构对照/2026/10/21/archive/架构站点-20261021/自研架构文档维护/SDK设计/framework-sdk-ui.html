二开 / 客户如何嵌入UI

UI控件库：可组合，不接管客户程序

组件绑定对象与职责不能做的事情/寿命规则
ImageViewer / ResultTree绑定IResultSource+FlowId/Run选择，默认流程公开显示合同不访问MainWindowViewModel/静态全局Context；不自行关闭ProjectSession
ParameterEditor绑定编辑事务+工具schema，草稿→校验→Commit/Cancel不把活跃参数对象直接给UI改；取消只丢草稿，模型训练/文件副作用需候选事务
ProcedureEditor可选绑定公开方案编辑接口/快照运行入口仍走Runtime.SDK，不在控件中调度；无此组件也能纯API运行
专业ROI/图形文字几何/坐标域/Frame与样式分离；输入结果只读坐标转换、DPI与帧失配拒收；保存渲染图不是保存原始像素
生命周期Attach → 订阅 → Dispatcher采用 → DetachAsync/Dispose迟到结果拒收；多Viewer各自lease，关闭一个不破坏另一个；切源归还旧lease

VM官方有WPF/WinForm及参数/流程/渲染等独立控件，并推荐绑定流程聚合显示。自研首期优先WPF，WinForms可通过单独宿主适配按需求增加，不自动承诺Qt或C++控件；C ABI/RPC属于未来独立边界。
