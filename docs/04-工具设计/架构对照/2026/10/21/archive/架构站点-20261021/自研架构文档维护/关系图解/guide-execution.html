执行关系：差异、影响与具体改法

分析点原版事实 / 证据边界自研当前链 / 覆盖边界取舍与验收动作
运行范围方案运行与所属流程运行是不同入口；运行流程不等于切换显示流程。UI侧装配请求，执行引擎按依赖就绪派发。将单流程、全部流程、子程序的范围逐项对照；不能仅因共享按钮或引擎而认定语义相同。
失败与完成托管调用入口已恢复；native 内部调度和完整异常排空仍未知。ReadyQueue / Tool.Execute / Context 是主链概览；局部固定包验证另列。分别核对依赖失败、跳过、异常传播和最终完成；局部 Engine 通过不能代表完整新执行合同。
停止与退役取消是否打断 native 调用、所有回调是否最终排空尚未闭合。停止请求、工具结束、结果持有与UI投影不是同一个观察点。用在途任务结束、临时资源释放和外部结果归还分别验收；等待被取消不等于实际执行停止。
