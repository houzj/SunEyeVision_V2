算法与输入前提

连通区先按面积/圆度/矩形度and筛选；计算几何统计，再排序和可选截断；按最终对象重建全部/OK/NG区域索引，轮廓仅按需生成。

核对项自研实际语义原版边界 / 差异与影响
Threshold / MaxValue此工具Threshold是灰度下限、MaxValue是灰度上限；不能与另一个Threshold工具的前景输出值同义原软阈值/ROI外政策另有字段，未建立公式一致性
预处理→阈值→形态→Connection顺序影响连通域；可选形态结果再交有效域原孔洞/轴比等声明不能由当前部分特征代替
SelectShape / 排序 / 截断面积/圆度/矩形度先and过滤；逐对象判断与过滤分开；排序和数量上限后重建区域索引原零Blob政策/更多筛选需按需求逐项，不默认新增全部
数值与区域输出FilteredBlobs各数组与BlobRegions/OK/NG对象应同序；Gray/Binary/轮廓按开关生成不能假设输出图像总存在；原输出列不证明数值一致

参数生效条件与单位

阈值/反色、可选滤波形态、面积/圆度/矩形度、排序/数量限制，以及灰度图/二值图/轮廓输出开关。筛选丢弃与OK/NG判定不同。

输出、排序与失败语义

数值列表、BlobRegions/OkBlobRegions/NgBlobRegions与显示对象分别输出；GrayImage和二值图受开关控制，不能假设总有图。

这个工具界面实际做什么？

实际四页：基本参数、预处理参数、Blob筛选、结果显示。不是统一阈值三页；数值分析与主图分开。

BlobAnalysisTool.Run → 灰度/ROI/Mask → 可选预处理 → 阈值/形态 → Connection → SelectShape → 统计/判定 → 排序/截断 → 重建区域索引

参数里存什么

阈值/反色、可选滤波形态、面积/圆度/矩形度、排序/数量限制，以及灰度图/二值图/轮廓输出开关。筛选丢弃与OK/NG判定不同。

实际算法/处理

连通区先按面积/圆度/矩形度and筛选；计算几何统计，再排序和可选截断；按最终对象重建全部/OK/NG区域索引，轮廓仅按需生成。

数据交给谁

数值列表、BlobRegions/OkBlobRegions/NgBlobRegions与显示对象分别输出；GrayImage和二值图受开关控制，不能假设总有图。

缓存在哪里

区域/统计属于本轮结果；可选截断降低输出量但不表示算法只发现这么多。没有跨轮Blob缓存证据。

失败、取消与释放

临时binaryRegion/scope局部finally释放；结果区域由宿主接收，整体最终回收未闭合。数量大时显示与下游可能同时保留。

具体缺点和VM差异

多个面积文字都使用同一style.PositionX/Y构造，可能叠在同处（是否预期需UI验收）；截断前后数量应可见，零Blob判定需明确。

VM原始资源能证明什么？

原声明软阈值、孔洞、轴比/偏差/直方图筛选、零Blob政策及更多几何/灰度输出。当前部分统计不等全部可配置筛选。
