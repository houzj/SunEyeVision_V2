算法与输入前提

输出中心距；交点按中心1→中心2轴投影t排序。两个正常相交圆交点轴投影相同，此键不能保证主次顺序。

核对项自研实际语义原版边界 / 差异与影响
Distance两圆中心距，不是圆周最短距离原C2CType、圆环/标定输出不能据字段名确定公式
交点定序当前沿中心连线投影t排序；对称交点投影相同，无法稳定打破并列具体改法：有符号叉积，再X/Y兜底，并定义换圆顺序
关系/判定存在“有交点?相交:相交”相同分支；按中文Name判定解析与native交点矛盾需诊断；判断用稳定Key

参数生效条件与单位

两圆参数及修正/测量配置；当前整圆、中心距语义。

输出、排序与失败语义

两圆/中心/半径、交点/重合/关系及内点诊断；不是圆周最小间距。

已识别差异

交点定序不能区分对称两点

问题与尚待核实的边界

除中文Name判定外，交点排序键数学上并列。DescribeRelation的有点/无点分支都返回相交，未暴露解析关系与原生交点矛盾。

这个工具界面实际做什么？

三页，两圆guide与两套检测参数；不是任意两个现成圆直接量测。

Run → guide修正 → 两圆取点/拟合 → DistancePp/IntersectionCircles → FillIntersections/Relation → 判定

参数里存什么

两圆参数及修正/测量配置；当前整圆、中心距语义。

实际算法/处理

输出中心距；交点按中心1→中心2轴投影t排序。两个正常相交圆交点轴投影相同，此键不能保证主次顺序。

数据交给谁

两圆/中心/半径、交点/重合/关系及内点诊断；不是圆周最小间距。

缓存在哪里

每次新建计量模型并using释放，未见工具级跨轮模型缓存；显示/历史另属宿主。

失败、取消与释放

    {
        RequireFinite(first, "点1");
