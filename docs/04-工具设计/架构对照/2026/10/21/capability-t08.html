自研当前实现

Closing可阻止关闭，Closed停止连续模式并解绑完成事件；阈值另清主图叠加。

完整缺陷与未闭合调用边

关闭→在途执行/失败回调最终接收；加载卸载→全部订阅配对；清叠加→图像最后读者仍是另一边 OnClosed逐个childWindow.Close，之后退订图像事件、发StopWorkflowCommand并Application.Shutdown。相机预览OnClosed为async void且await Host.DisposeAsync，主窗口没有汇总这些异步完成任务。不能从Close返回证明每个预览流已结束；具体异常/时序未运行。

VM可借鉴与不可推断：参考原版Window_Closed注销服务、AlgorithmTabRoot.Dispose/DoFinish的配对职责。

具体改法 / 成本：关闭请求先阻止新轮次，等待本会话终态再退订/释放；禁止先Dispose在用帧，成本为异步Closing与失败恢复。 建立可等待调试会话退役，回调先验证会话仍有效；清编辑/清显示/释放帧分开；当前Close被拒绝时不得先销毁资源。

验收：编辑中关闭/关闭被拒绝/重复Loaded/算法中关闭均无重复回调或残留叠加。 预览采集中退出、工具停止异常、子窗取消关闭、迟到帧回调分别验；关闭阶段故障可定位到具体Owner，未结局资源保留隔离。

    public static bool TryClose(FrameworkElement editor, Window owner, Func<string, bool>? confirmDiscard = null)
    {
        if (ToolEditorCommit.TryCommit(editor, out var error)) return true;
        var prompt = error + "\n\n是否关闭窗口并放弃尚未提交的控件编辑？\n已实时写入参数的修改会保留，不会回滚；无效配置仍不能执行。\n选择“否”返回继续修改。";
        var discard = confirmDiscard?.Invoke(prompt) ?? MessageBox.Show(owner, prompt, "配置未提交", MessageBoxButton.YesNo,
            MessageBoxImage.Warning, MessageBoxResult.No) == MessageBoxResult.Yes;
        if (!discard) return false;
        ToolEditorCommit.DiscardPendingEdits(editor);
        return true;
    }
}

        protected override void OnClosed(EventArgs e)
        {
            // 主窗口关闭时主动关闭仍存活的子窗口，避免预览窗口或对话框继续持有
            // Dispatcher、相机采集会话和 Debug 输出程序集，导致进程残留并锁定 DLL。
            var childWindows = Application.Current?.Windows
                .OfType<Window>()
                .Where(window => !ReferenceEquals(window, this))
                .ToArray();
            if (childWindows != null)
            {
                foreach (var childWindow in childWindows)
                {
                    try
                    {
                        childWindow.Close();
                    }
                    catch (Exception ex)
                    {
                        VisionLogger.Instance.Log(LogLevel.Warning,
                            $"关闭子窗口失败: {childWindow.GetType().Name}, {ex.Message}", "MainWindow");
                    }
                }
