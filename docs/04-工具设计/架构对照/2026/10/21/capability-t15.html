完整缺陷与未闭合调用边

编译/程序集载入→具体信任/取消/释放；输出修改→旧绑定失效；UI和后台脚本→真实副作用准入 当前同一try依次Init→Process→Release；Init或Process抛错就直接catch，Release跳过。输入反射失败先记errors，后续仍会尝试执行生命周期。 编译键是代码哈希、宿主名称版本指纹和勾选引用名指纹；引用名列表未包含文件内容/路径/版本。相同文件名替换内容时键仍相同，不能保证重新编译或加载。 MaxResident=16，超过上限按LastUsed淘汰并Dispose；GetOrCreate返回裸Sandbox，未记录在用计数，Invalidate/Clear也未等待在途。ConcurrentDictionary的工厂可能被并发调用多次，不能沿注释声称只创建一次。当前未找到外层对Clear/Invalidate的调用，最终进程回收不能代替逐会话合同。

        internal static string ComputeRefListFingerprint(IReadOnlyList<string>? assemblyNames)
        {
            if (assemblyNames == null || assemblyNames.Count == 0)
                return "none";
            var sb = new StringBuilder();
            foreach (var name in assemblyNames.OrderBy(n => n, StringComparer.OrdinalIgnoreCase))
                sb.Append($"{name}|");
            return Convert.ToHexString(SHA256.HashData(Encoding.UTF8.GetBytes(sb.ToString())))[..16];
        }
