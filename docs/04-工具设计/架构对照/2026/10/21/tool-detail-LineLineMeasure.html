算法与输入前提

锐角0–90°；主距是线1拟合中点到线2无限线。Min/Max为线1内点到线2的距离极值，不是两有限线段集合最短/最长距。

核对项自研实际语义原版边界 / 差异与影响
主距/极值距主距=line1中点到line2无限线；Min/Max是line1内点到line2距离极值不等两有限线段的集合最短/最长距
Angle / 方向结果为锐角0–90°；方向性与端点交换需独立说明原AngleRange选择不等当前固定锐角
判定Key当前用GetJudgment(key).Name中文名分派显示改名/本地化不应改变公式；改成稳定Key

参数生效条件与单位

两套引导线/卡尺与阈值；坐标与方向需要统一定义。

输出、排序与失败语义

两线、内点/RMSE、主/极值距离、交点和平行标志；交叉不等所有距离自动0。

已识别差异

中文Name判定；主距不是两线段最短距

问题与尚待核实的边界

判定按GetJudgment(key).Name中文展示名称分派，改名/本地化可失去数值；距离名称没有表达实际方向和采样范围。

    {
        RequireFinite(first, "点1");
        RequireFinite(second, "点2");
        var dx = RequireFinite(second.X - first.X, "ΔX");
        var dy = RequireFinite(second.Y - first.Y, "ΔY");
        // Hypot avoids overflowing the intermediate squares for representable distances.
        var distance = RequireFinite(double.Hypot(dx, dy), "点距");
        var angle = RequireFinite(Math.Atan2(dy, dx) * 180.0 / Math.PI, "连线角度");
        return (distance, dx, dy, angle);
    }
