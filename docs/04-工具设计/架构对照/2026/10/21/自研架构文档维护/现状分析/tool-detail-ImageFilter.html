算法与输入前提

Mean/Gaussian走HalconLinearFilters，MedianRect、中值；BilateralFilter仅Reflect边界且由sigma驱动；自定义核ApplyKernel。先在全域算邻域再限制输出有效域。

核对项自研实际语义原版边界 / 差异与影响
核尺寸 / SigmaX,Y均值/Gaussian用有限权重相关；Sigma=0为max(0.5,(size-1)/6)，非零直接进入高斯权重原Gaussian/Mean只有模式声明，不能推相同核/尾部
BorderTypeValue线性相关：0 mirrored、1 continued、2常数0、4 cyclic；不支持项显式拒绝原边界填充未核；相同编号不是兼容合同
Bilateral / Median双边Sigma控制邻域且只接收Reflect，结果核宽高0；MedianRect未传自定义Border参数不能把界面核直径或Border选项当作所有模式都生效
Filter2D / CustomKernelDivisor行优先系数直接相关，不翻核、不自动归一化；未启用自定义时为固定3×3锐化核VM Invert=4而自研Filter2D=4，同数字不同能力
像素类型与ROI转灰；real工作类型后恢复源类型，int4超过±16777216拒绝；全域邻域计算后限制结果域原InputMask不自动等同自研几何ROI，彩色/边界语义待证

参数生效条件与单位

核宽高、SigmaX/Y、SigmaColor/Space、自定义核文本/divisor和边界类型；不同方法支持范围不同。

输出、排序与失败语义

GrayImage和输出图像是克隆后的结果对象；几何域不是VM的InputMask图像端口，不能混为同一种输入。

已识别差异

当前强制灰度；不等于彩色滤波

问题与尚待核实的边界

输入始终转灰，彩色信息丢失；双边核尺寸不能被解释成实际算法参数。scope创建到Restrict异常的清理边界需收紧，不宣称已测到泄漏。

这个工具界面实际做什么？

三页：基本参数（图像源/ROI/修正）、运行参数（按五种方法显示设置）、结果显示配置；主图来自宿主注入。

调试ExecuteWithLiveContext → ToolExecutor → ImageFilterTool.Run → 灰度 → ROI/Mask域 → FullDomain邻域滤波 → ReduceDomain → 结果

参数里存什么

核宽高、SigmaX/Y、SigmaColor/Space、自定义核文本/divisor和边界类型；不同方法支持范围不同。

实际算法/处理

Mean/Gaussian走HalconLinearFilters，MedianRect、中值；BilateralFilter仅Reflect边界且由sigma驱动；自定义核ApplyKernel。先在全域算邻域再限制输出有效域。

数据交给谁

GrayImage和输出图像是克隆后的结果对象；几何域不是VM的InputMask图像端口，不能混为同一种输入。

缓存在哪里

本工具无跨轮滤波结果缓存；宿主位图复用不能被算作滤波性能优势。

失败、取消与释放

reducedImage/scope在finally释放；GetHalconImage在局部try前，跨后端转换返回值所有权没有由裸HImage类型说明。最终输出由谁回收仍待核。

具体缺点和VM差异

输入始终转灰，彩色信息丢失；双边核尺寸不能被解释成实际算法参数。scope创建到Restrict异常的清理边界需收紧，不宣称已测到泄漏。

VM原始资源能证明什么？

原声明InputMask/OutputMask、ROI/Annulus/Fixture等；枚举值和边界公式不能从XML推定数值等价。
