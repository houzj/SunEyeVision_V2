算法与输入前提

输入先转二值区域；结构元素含退化点/线分支；开闭按阶段/次数执行，最终Intersection有效域，防掩码外复活。

核对项自研实际语义原版边界 / 差异与影响
输入灰度 / 固定阈值先以128阈值转区域，再做区域运算；不是直接灰度形态学原算子枚举不能证明原版也先二值化
KernelShapeRect=0/Cross=1/Ellipse=2；Ellipse单轴退化为线/点VM声明Rectange=0/Ellipse=1/Crosss=2，必须按语义映射
Iterations / OperationOpen为N次腐蚀后N次膨胀，Close逆序；Gradient=Dilate−Erode，TopHat=Input−Open，BlackHat=Close−Input原迭代/锚点/边界内部未知，不能等同每轮Open重复N次
域与输出最终区域Intersection有效域，再RegionToBin；避免Mask外区域重新出现原mask/ROI边缘内部合同待证

参数生效条件与单位

腐蚀/膨胀/开闭/梯度/TopHat/BlackHat；Rect/Cross/Ellipse及宽高次数。固定阈值128没有作为运行参数暴露。

输出、排序与失败语义

GrayImage、OutputImage、BinaryMask分开；Output与Mask是独立图像对象。灰度127/128/129会先受阈值划分，不是直接灰度形态变化。

已识别差异

固定128区域形态学，不是灰度形态学

问题与尚待核实的边界

虽然声明是二值处理，实际仍接受非二值并隐式阈值128；用户很难从核参数理解这种转换，不能把它写成已配置的前处理。

取舍路线

必须整改语义＋按需新增

收益、代价与兼容取舍

明确二值合同改动较小但不提供灰度能力；独立灰度模式需要算子、参数和版本兼容，先暴露固定128转换。

这个工具界面实际做什么？

基本参数/运行参数/结果显示；核形、宽高、次数与操作配置；主图为宿主图像。

MorphologyTool.Run → 灰度 → ROI/Mask → 固定128阈值 → 区域形态学 → 与有效域相交 → RegionToBin → 结果

参数里存什么

腐蚀/膨胀/开闭/梯度/TopHat/BlackHat；Rect/Cross/Ellipse及宽高次数。固定阈值128没有作为运行参数暴露。

实际算法/处理

输入先转二值区域；结构元素含退化点/线分支；开闭按阶段/次数执行，最终Intersection有效域，防掩码外复活。

数据交给谁

GrayImage、OutputImage、BinaryMask分开；Output与Mask是独立图像对象。灰度127/128/129会先受阈值划分，不是直接灰度形态变化。

缓存在哪里

每轮构造结构元素/区域，未见模型或结果跨轮缓存。

失败、取消与释放

局部using/finally处理结构元素、区域和域；裸HImage输入有借用/跨后端转换所有权歧义，输出最终回收不由此证明。

具体缺点和VM差异

虽然声明是二值处理，实际仍接受非二值并隐式阈值128；用户很难从核参数理解这种转换，不能把它写成已配置的前处理。

VM原始资源能证明什么？

原声明形态类型/核形/次数/宽高及mask；是否灰度/二值分支、核锚点/边缘迭代的原实现仍缺。
