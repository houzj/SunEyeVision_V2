算法与输入前提

圆心距d；无符号圆周距abs(d-r)；最近点沿圆心到输入点方向。d<=1e-9抛异常，方向不唯一与距离有效性未拆开。

核对项自研实际语义原版边界 / 差异与影响
距离定义中心距d；圆周距abs(d−r)，无符号；最近点沿中心至点方向原closest/farthest/angle等多结果不等当前全覆盖
中心重合d<=1e-9当前整工具异常；距离仍可有定义而最近点方向不唯一拟议按字段有效性保留可用距离，而非伪造最近点
位置修正guide半径乘ScaleFactor，点只按其已声明坐标进入任意仿射不保持圆，不宣称已支持所有变换

参数生效条件与单位

单点输入、圆心/正半径和测量参数；仅guide修正，半径乘ScaleFactor，不能直接宣称任意非相似仿射仍为圆。

输出、排序与失败语义

点、拟合圆、中心/半径、最近点及两类距离；不含已证明等价的最远距/角度。

已识别差异

圆心重合整工具失败；缺部分结果合同

问题与尚待核实的边界

点在圆心时最近点方向不唯一，但距离仍可定义；当前整工具失败使有效结果也丢失。缺最远距/角度及坐标合同。

基本/运行/结果显示三页；点直接输入，圆是引导卡尺检测；非两者都检测。

Run → 单点解析 → guide圆修正 → 模型取点/圆拟合 → 圆心距/圆周最近点 → 结果

参数里存什么

单点输入、圆心/正半径和测量参数；仅guide修正，半径乘ScaleFactor，不能直接宣称任意非相似仿射仍为圆。

实际算法/处理

圆心距d；无符号圆周距abs(d-r)；最近点沿圆心到输入点方向。d<=1e-9抛异常，方向不唯一与距离有效性未拆开。

数据交给谁

点、拟合圆、中心/半径、最近点及两类距离；不含已证明等价的最远距/角度。

缓存在哪里

每次新建计量模型并using释放，未见工具级跨轮模型缓存；显示/历史另属宿主。

失败、取消与释放

模型与拟合助手有局部using；原生Apply同步，Run无内部取消检查。裸HImage借用/转换所有权及结果最后读者仍未闭合，不能假称全释放。

具体缺点和VM差异

点在圆心时最近点方向不唯一，但距离仍可定义；当前整工具失败使有效结果也丢失。缺最远距/角度及坐标合同。

VM原始资源能证明什么？

原声明center/closest/farthest距离、角度、圆环和CalibMatrix；原生圆弧/符号实现未核。
