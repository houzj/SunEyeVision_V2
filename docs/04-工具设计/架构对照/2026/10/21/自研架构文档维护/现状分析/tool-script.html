④ VM 原版 → 自研当前 → 目标：逐项借鉴与取舍

每轮运行与实例状态

VM 原版已证

活动COM链创建一个UserScript并Init，后续帧SetHandle/Clear/Process复用；编译缓存含moduleId。

自研当前实现

每次new实例/Init/Process/Release，编译键共用池；static不随new自动重置。

目标设计

保留逐次实例行为，编译字节可共享；运行ALC隔离域含方案会话+节点+编译代次，同节点同代次static可能常驻，须明示且串行准入。

借鉴：模块有独立运行身份、编译与运行Owner分开。自研：新实例合同、节点隔离域、运行租约和输入快照。不照搬：不直接改为VM常驻用户实例，避免悄悄改变字段持久性；不将moduleId缓存等同每次static重置。

停止

VM 原版已证

配置窗停止后续循环并等待本地Task；流程停止进入IMVS_StopExecute_V30并有停止回调，正在跑的脚本能否强制中断未知。

自研当前实现

工作流令牌已存在，脚本生命周期未消费；S2视图取消/编译等待是另一层。

目标设计

协作取消穿透到ScriptContext与边界检查；停止后排空运行/清理再释放租约。未响应保持“停止中/超时未结束”，拒绝旧代结果/受控写回，不虚报已停止。

借鉴：分开停止请求与停止完成回执。自研：真实运行台账/完成信号/来源一致的取消归因。不照搬：不采用方法名或回调出现就推断硬停，也不把Task取消或ALC.Unload当强制终止。

VM 原版已证

自研当前实现

目标设计

借鉴：区分用户Dispose、loader引用清除和程序集处理。自研：确定异常清理、取消与错误分型。不照搬：不照搬可见异常分支的清理缺口和失败后清dirty语义。
