### 1.1 调试控制面板结构

调试控制面板采用 **4 Tab 分页布局**，与 LineCaliper / ArcCaliper 完全一致：

```
                                                                     |
|  +-------------------------------------------------------------+   |
|  |                    当前选中 Tab 的内容区                      |   |
|  +-------------------------------------------------------------+   |
+---------------------------------------------------------------------+
```

**Tab 功能定位：**

| Tab | 名称 | 核心职责 | 与 ArcCaliper 差异 |
|-----|------|----------|--------------------|
| Tab1 | 基本参数 | 图像源、圆形ROI(圆心+半径)、位置补正 | **无起止角拖拽手柄**，圆心+半径即可 |
| Tab2 | **卡尺参数** | 径向采样配置、投影参数、边缘极性阈值 | **无起止角参数区块**，比ArcCaliper少5个参数 |
| Tab3 | **拟合筛选** | 圆拟合 + 离群过滤 + 半径容差验证 | 输出完整圆(圆心+半径)，无角度限制 |
| Tab4 | 结果显示 | Expander三分组(判断/图形/文本) | 图形元素适配完整圆可视化 |

### 1.2 CircleCaliper vs ArcCaliper 核心差异

**CircleCaliper 是 ArcCaliper 的简化特例（固定 360°，隐藏起止角参数）：**

```
ArcCaliper (弧形):                      CircleCaliper (圆环):
                                    
    ╭────╮                              ╭──────────╮
   ╱  ↗  ╲    ← 用户需设起止角         │   ↗↗↗↗   │   ← 固定360°
  │   ↗   │                             │   ↗↗↗↗   │
   ╲  ↗  ╱                              │   ↗↗↗↗   │
    ╰────╯                              ╰──────────╯
   "我要测这段圆弧"                     "我要测这个圆孔"
   
   参数: 圆心+半径+起止角               参数: 圆心+半径 (更少!)
   交互: 4个拖拽手柄                    交互: 2个拖拽手柄 (更简单!)
```

### 1.3 组件复用清单

与 LineCaliperTool 完全一致（详见 直线卡尺工具UI设计方案.md 第1.4节）。

### 2.2 CircleCaliper ROI 详细说明

CircleCaliper ROI 定义了一个**完整圆形(360°)测量区域**，是三者中最简单的 ROI：

```
+-- CircleCaliper ROI 结构详解 ----------------------------------------+

                 采样射线 (360° 均匀分布, 像时钟刻度)
                         ↑↑↑
                    ↗↗   ↑↑↑   ↗↗
                   ↗↗  ↗ ↑ ↑ ↗  ↗↗
                  ↗    ↗  ●  ↗    ↗    ← 圆心拖拽手柄
                   ↘↘  ↘ ↑ ↑ ↗  ↗↗
                    ↘↘   ↓↓↓   ↗↗
                         ↓↓↓       ← 半径调节手柄 ⇌
                     所有方向径向辐射

   可交互操作:
    |- 拖拽圆心 --> 移动整个测量区域
    |- 拖拽圆周边缘 --> 调整半径 (Radius)
    |- 双击圆心 --> 打开精确数值输入对话框

   内部几何属性:
    |- Center: 圆心坐标 (cx, cy)
    |- Radius: 圆半径 (R, 单位:像素)
    |- SampleCount: 采样射线数量 (显示用, 默认36条, 每10°一条)

   与 ArcCaliper ROI 的关键区别:
    |- ❌ 无起始角/结束角拖拽手柄 (固定360°)
    |- ❌ 无角度范围限制
    |- ✅ 更简洁的交互体验
    |- ✅ 采样射线显示整圈均匀分布

+----------------------------------------------------------------------+
```

### 2.3 采样射线可视化说明

**采样射线可视化是 CircleCaliper ROI 的重要交互标识：**

- 默认显示 36 条虚线射线（每 10° 一条），从圆心向外辐射
- 射线终点落在圆周上（半径为 R）
- 每条射线代表一个 1D 剖面采样方向
- 当 SampleCount 在 Tab2 调整时，射线密度同步更新
- 在 ROI 编辑器中，射线仅用于可视化预览，不参与拖拽交互

### 3.2 圆环卡尺工作原理

```
+-- 圆环卡尺(CircleCaliper)工作原理 ----------------------------------+

  Step 1: 定义测量区域
    根据 CircleCaliper ROI 确定: 圆心(Cx, Cy), 半径(R)

  Step 2: 在 360° 圆周上均匀生成 N 个采样射线 (N = SampleCount)
    θ_i = 360° * i / N, i = 0, 1, ..., N-1
    For each θ_i:
       射线方向 = 从圆心指向圆周的径向方向 (法线方向)

  Step 3: 对每个采样射线做1D剖面采样
    profile_i[x] = gray(C + unit(θ_i) * (R - ProjectLength/2 + x))
    x in [0, ProjectLength]
    剖面沿径向方向取灰度值 (内→外 或 外→内, 取决于极性)

  Step 4: 平滑 + 梯度计算 + 边缘检测
    同 LineCaliper (1D剖面梯度法)

  Step 5: 亚像素精化
    同 LineCaliper (抛物线插值)

  Step 6: 边缘点集合 --> 圆拟合
    所有有效边缘点 (N个, 可能部分被剔除) 参与圆拟合
    输出: 圆心(cx_fit, cy_fit) / 半径(R_fit) / RMSE

  输出: 边缘点集合 + 拟合圆 (cx, cy, R, RMSE)
+----------------------------------------------------------------------+
```

### 3.3 参数详解

#### 测量配置参数

| 参数 | 控件类型 | 默认值 | 范围 | 说明 |
|------|----------|--------|------|------|
| **圆心 X** | ConfigSetting | 来自ROI | 0~图像宽 | 测量圆心X, 与ROI双向同步 |
| **圆心 Y** | ConfigSetting | 来自ROI | 0~图像高 | 测量圆心Y, 与ROI双向同步 |
| **半径** | ConfigSetting | 来自ROI | 10~5000 | 测量圆周半径, 与ROI双向同步 |

> **注意：无起始角/结束角参数。** 与 ArcCaliper 的5个测量参数相比，CircleCaliper 只有3个。

#### 采样配置参数

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| **采样点数(SampleCount)** | **36** | 8~360 | 圆周上均匀分布的采样射线数量, 默认36(每10°一个) |
| **角度补偿(AngleOffset)** | **0.0°** | -180~180 | 采样射线的整体旋转偏移 |
| **采样间隔(SampleInterval)** | **1.0px** | 0.5~10.0 | 沿径向的采样点间距 |

#### 投影配置参数

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| **投影长度(ProjectLength)** | **20px** | 5~500 | 沿径向的1D剖面长度(法线两侧) |
| **投影宽度(ProjectWidth)** | **5px** | 1~100 | 垂直于径向方向的剖面宽度 |

#### 边缘检测/阈值/亚像素参数

与 LineCaliperTool / ArcCaliperTool 完全一致：

| 参数 | 默认值 |
|------|--------|
| 边缘极性 | LightToDark |
| 选取模式 | All |
| 对比度阈值 | 30 |
| 幅度阈值 | 10 |
| 平滑核 | 5 |
| 亚像素 | ON |
| 插值方法 | Parabolic |

## 六、三件套三维对比总表

### 6.1 何时用哪个工具——决策树

```
你想要测量什么？

┌── 直线边缘? 
│   └── LineCaliperTool (直线卡尺)
│
┌── 圆弧段? (非整圆)
│   └── ArcCaliperTool (弧形卡尺)
│
┌── 完整圆/圆孔/圆环?
│   └── CircleCaliperTool (圆环卡尺)
│
┌── 不规则轮廓匹配?
│   └── ShapeMatchTool (轮廓匹配)
```

### 6.2 三维对比总表

| 维度 | LineCaliper | ArcCaliper | **CircleCaliper** |
|------|------------|------------|-------------------|
| ROI形状 | 线段矩形 | 弧形段 | **圆形(固定360°)** |
| 交互手柄数 | 4(端点+旋转+宽度) | 4(圆心+半径+起止角x2) | **2(圆心+半径)** |
| 采样轨迹 | 直线等距 | 弧线等角 | **圆周等角** |
| 1D剖面方向 | 垂直Rake | 沿弧线法线 | **径向辐射** |
| 拟合目标 | 直线(ax+by+c=0) | 圆弧(圆心+半径+起止角) | **圆(cx,cy,R)** |
| Tab2参数数 | 13 | 12 | **10** |
| 起止角参数 | ❌ | ✅ 可调 | ❌ 固定360° |
| 用户需设 | 方向+长度+宽度 | 圆心+半径+起止角 | **只需圆心+半径** |
| 数据复杂度 | 中等 | 较高 | **最低(最简洁)** |
| 典型场景 | 边缘定位/宽度 | 部分圆弧/孔径 | **圆孔/圆度/同心度** |
| 对标Halcon | measure_pos | measure_arc | **measure_arc(360°) + fit_circle** |

## 九、设计约束

### 9.1 必须遵守的项目规范

同 LineCaliperTool / ArcCaliperTool。

### 9.2 不需要的功能

| 功能 | 决策 | 原因 |
|------|------|------|
| 起止角配置 | ❌ 不实现 | 固定360°，CircleCaliper 定位就是"整圆测量" |
| 内径/外径同时测量 | ❌ 不实现v1.0 | 可用两个 CircleCaliper ROI 组合实现 |
| 椭圆拟合 | ❌ 不实现 | 只做标准圆拟合，YAGNI |
| HoughCircle备选 | ❌ 不实现 | 使用卡尺1D剖面方式 |
| 扇形角度范围过滤 | ❌ 不实现 | 固定全圆，局部过滤由 ArcCaliper 承担 |

### 9.3 设计亮点

- **最简交互**：CircleCaliper 是三件套中交互最简单的——仅圆心+半径两个拖拽手柄
- **直观可视化**：采样射线像时钟刻度一样均匀显示在圆周上，用户一眼就能理解测量原理
- **参数最少**：比 ArcCaliper 少 3~5 个参数，用户配置更轻松
- **风格统一**：Tab 结构、控件类型、配色方案与 LineCaliper/ArcCaliper 完全一致
