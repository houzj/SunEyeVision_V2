## 一、整体架构概览

### 1.1 调试控制面板结构

调试控制面板采用 **4 Tab 分页布局**，完全对齐 BlobAnalysis / ShapeMatch 工具的实现风格：

```

|  +------+------+------+------+

|  | 基本 | 卡尺 | 筛选 | 结果 |
|  | 参数 | 参数 | 合并 | 显示 |
|  +------+------+------+
                                                                     |
|  +-------------------------------------------------------------+   |
|  |                    当前选中 Tab 的内容区                      |   |
|  +-------------------------------------------------------------+   |
+---------------------------------------------------------------------+
```

**Tab 功能定位：**

| Tab | 名称 | 核心职责 | 与 HoughLinesP 版本的差异 |
|-----|------|----------|---------------------------|
| Tab1 | 基本参数 | 图像源、搜索区域(支持LineCaliper ROI)、位置补正 | ROI 新增 LineCaliper 类型支持 |
| Tab2 | **卡尺参数** | 搜索方向、采样配置、边缘极性、选取模式、亚像素、过滤阈值 | **完全重写** - 从 Canny+Hough 参数改为卡尺专用参数集 |
| Tab3 | **筛选合并** | 多卡尺结果聚合 + 共线性检查 + 拟合方法(OLS/RANSAC/Theil-Sen) + 过滤 + 排序(9种) | 适配卡尺输出格式(边缘点->直线拟合) |

### 1.2 与 HoughLinesP 方案的本质区别

```
+=====================================================================+
|           HoughLinesP 方案 (v1.0, 已废弃) vs 卡尺方案 (v3.0)        |
+=====================================================================+

  HoughLinesP (全局盲搜)              卡尺Caliper (引导式搜索)

  +---------------------+            +---------------------+
  |                     |            |    +---+             |
  |   全图Canny边缘     |            |    |ROI |             |
  |   --> 霍夫空间投票    |            |    +-+-+             |
  |   --> 全局直线提取    |            |      v               |
  |   --> 输出线段集合    |            |   沿Rake方向采样     |
  |                     |            |   --> 边缘点检测      |
  +---------------------+            |   --> 亚像素精化      |
                                     |   --> 直线拟合输出    |
                                     +---------------------+

  关键差异:
  |- 先验需求: 无(全图搜索)     vs  需要(ROI位置+搜索方向)
  |- 输入数据: Canny二值边缘图   vs  原始灰度图(内部梯度)
  |- 边缘极性: 不支持           vs  支持(亮->暗/暗->亮/任意)
  |- 亚像素: 后处理可选         vs  内建核心能力(默认开启)
  |- 典型场景: PCB走线/划痕检测  vs  精密尺寸测量/间隙/定位
  |- 对标API: OpenCV HoughLinesP vs Halcon measure_pos / VP Caliper
```

### 1.3 三件套体系定位

**LineCaliperTool** 是卡尺工具三件套中的 **直线卡尺**, 与 ArcCaliperTool(弧形卡尺) 和 CircleCaliperTool(圆环卡尺) 共享统一的设计理念和技术架构:

```
+=====================================================================+
|                     Caliper 卡尺工具三件套体系                         |
+=====================================================================+

  +-------------------+  +-------------------+  +---------------------+
  |  LineCaliperTool  |  |  ArcCaliperTool   |  | CircleCaliperTool   |
  |     直线卡尺       |  |     弧形卡尺       |  |     圆环卡尺        |
  +-------------------+  +-------------------+  +---------------------+
  | 测量对象: 直线边缘  |  | 测量对象: 圆弧边缘  |  | 测量对象: 圆/圆环    |
  | ROI: 线段矩形      |  | ROI: 弧形区域      |  | ROI: 圆形/圆环      |
  | 搜索: 沿Rake方向   |  | 搜索: 沿弧线法线   |  | 搜索: 径向辐射      |
  | 输出: 边缘点集合   |  | 输出: 边缘点集合   |  | 输出: 边缘点集合    |
  | 拟合: 直线拟合     |  | 拟合: 弧线/圆拟合  |  | 拟合: 圆拟合       |
  |对标:Halcon measure |  |对标:Halcon measure |  |对标:Halcon measure  |
  |_pos               |  |_arc              |  |_circle             |
  +-------------------+  +-------------------+  +---------------------+

  三件套共享的核心能力:
  +------------------------------------------------------------------+
  | 1. 1D剖面灰度采样 + 一阶梯度边缘检测 (非2D Canny/Hough)          |
  | 2. 边缘极性过滤 (亮->暗 / 暗->亮 / 任意)                          |
  | 3. 亚像素插值精化 (抛物线/高斯/线性, 默认抛物线, 精度+/-0.05px)  |
  | 4. 多采样行聚合 + 鲁棒性检查                                      |
  | 5. OLS / RANSAC / Theil-Sen 三种拟合方法可选                       |
  | 6. ConfigSetting 双模式参数绑定 (常量/绑定)                        |
  | 7. Expander三分组结果显示: 判断(4项) / 图形(6项) / 文本(6项)      |
  +------------------------------------------------------------------+

  三件套核心差异:
  +------------------------------------------------------------------+
  | 差异维度        | LineCaliper    | ArcCaliper      | CircleCaliper  |
  |----------------|---------------|-----------------|----------------|
  | ROI几何类型    | 线段矩形       | 圆弧段           | 圆形/圆环       |
  | 采样轨迹       | 线性等距       | 角度等分         | 径向辐射       |
  | 1D剖面方向     | 垂直于Rake    | 沿弧线法线       | 沿半径方向     |
  | 聚合方式       | 共线性判定     | 共圆心判定       | 径向一致性     |
  | 拟合目标       | 直线(ax+by+c=0)| 圆弧(圆心+半径)  | 圆(cx,cy,R)    |
  | Tab2特有参数   | RakeAngle      | ArcStart/ArcEnd  | InnerR/OuterR  |
  | 适用场景       | 边缘定位/宽度  | 圆弧检测/孔径    | 圆度/同心度    |
```

### 2.2 LineCaliper ROI 详细说明

**LineCaliper（线卡尺）是卡尺工具的核心 ROI 类型**, 它定义了一个带方向的矩形测量区域:

```
+-- LineCaliper ROI 结构详解 ------------------------------------------+

                        搜索方向 (Rake Angle)
                             ^
                             |
   +-----------------------------------------+
   |                         | 采样宽度(SampleWidth)    |
   |    *<--------------------+-------------------->*      |
      |                  起点                    |
   |         (StartPoint)                    |
   |                                          |
   |  .... ..... ..... ..... ..... .....     |  <- 采样点行
   |  (沿Rake垂直方向排列的采样点)            |
   |  .... ..... ..... ..... ..... .....     |
    |         终点                              |
   *<----------------------------------------*
   |                         | MeasureLength
                           v (卡尺长度)

   可交互操作:
   |- 拖拽中心 --> 移动整个卡尺区域
   |- 拖拽端点 --> 调整卡尺长度(MeasureLength)
   |- 拖拽旋转手柄 --> 调整搜索方向角(RakeAngle)
   |- 拖拽侧边 --> 调整采样宽度(SampleWidth)
   |- 双击 --> 打开精确数值输入对话框

   内部几何属性:
   |- CenterPoint: 卡尺中心坐标 (cx, cy)
   |- RakeAngle: 搜索方向角 (theta, 单位:度, 0度=水平向右)
   |- MeasureLength: 卡尺长度 (L, 单位:像素)
   |- SampleWidth: 采样宽度 (W, 单位:像素, 垂直于Rake方向)
   |- StartPoint / EndPoint: 由以上4个参数计算

+----------------------------------------------------------------------+
```

**LineCaliper ROI 参数绑定到 Tab2:**

| ROI 属性 | 绑定到 Tab2 参数 | 说明 |
|----------|-----------------|------|
| CenterPoint | -- | 由用户在图像上拖拽设定 |
| RakeAngle | 搜索方向角度 | 双向同步 |
| MeasureLength | 卡尺长度 | 双向同步 |
| SampleWidth | 采样宽度 | 双向同步 |

同步策略: ROI 编辑器的修改自动同步到 Tab2; 用户在 Tab2 修改数值时 ROI 实时更新. 采用 TwoWay Binding.

### 2.3 ROI 形状选择与适用性说明

| ROI 形状 | 是否推荐 | 说明 |
|----------|---------|------|
| 矩形 | 可用但不推荐 | 需额外指定搜索方向; 适合"区域内多卡尺扫描"高级用法 |
| 旋转矩形 | 可用 | 同上 |
| **LineCaliper** | **强烈推荐** | 天然包含方向和长度信息, 最符合卡尺语义 |
| 圆形 | 不适用 | 无明确搜索方向 |
| 多边形 | 高级用法 | 复杂轮廓边缘跟踪 |
| Annulus | 不适用 | 用于圆/弧查找 |

### 3.2 卡尺工作原理总览

```
+-- 卡尺(Caliper)直线检测工作原理 --------------------------------------+

  Step 1: 定义测量区域
    根据 ROI (LineCaliper) 确定: 起点, 方向(theta), 长度(L), 宽度(W)

  Step 2: 沿 Rake 方向生成采样点
    P_0 -- P_1 -- P_2 -- ... -- P_n  (共 N = floor(L/SampleInterval)+1 个)

  Step 3: 对每个采样点做垂直于Rake方向的1D剖面采样
    profile[x] = gray(P_i + x*n_hat), x in [-W/2, W/2]

  Step 4: 对1D剖面做平滑处理 (高斯/均值核, 默认核大小=5)

  Step 5: 计算一阶导数(梯度), 寻找边缘候选点(梯度极值)

  Step 6: 极性过滤 + 幅度阈值过滤
    - Any:        保留所有极性
    - LightToDark: 只保留 gradient < 0
    - DarkToLight: 只保留 gradient > 0
    - |gradient| >= MinEdgeAmplitude

  Step 7: 亚像素精确定位
    抛物线插值: delta = g[i-1]/(2g[i-1]-4g[i]+2g[i+1])
    subpixel_pos = i + delta  (精度 +/- 0.05px)

  Step 8: 多行聚合 --> 直线拟合
    单行(SampleRows=1): 直接输出边缘点坐标
    多行(SampleRows>1): 按第几个边缘分组 -->每组最小二乘拟合

  Step 9: 选取模式过滤
    First / Strongest / All(默认) / Nth

  输出: 边缘点集合 或 拟合直线集合
+----------------------------------------------------------------------+
```

### 3.3 搜索方向配置参数

| 参数 | 控件类型 | 默认值 | 取值范围 | 算法属性 | 说明 |
|------|----------|--------|----------|----------|------|
| **搜索方向角度** | ConfigSetting | **0.0** | -180.0 ~ 180.0 | `RakeAngle` | 卡尺搜索方向. 水平右=0度, 逆时针为正. 与LineCaliper ROI双向同步 |

角度坐标系:
- 0度 = 从左向右搜索(检测垂直边缘)
- 90度 = 从下向上搜索(检测水平边缘)
- -90度 = 从上向下搜索(检测水平边缘)
- 注意: 角度含义是"扫描方向", 不是"被测直线角度". 被测直线约等于 RakeAngle +/- 90度

### 3.4 采样配置参数详解

| 参数 | 控件类型 | 默认值 | 取值范围 | 算法属性 | 说明 |
|------|----------|--------|----------|----------|------|
| **卡尺长度** | ConfigSetting | **100** | 10~2000 | `MeasureLength`=100px | 沿Rake方向的测量距离. 决定最大边缘跨度覆盖能力 |
| **采样宽度** | ConfigSetting | **20** | 3~500 | `SampleWidth`=20px | 垂直于Rake的采样带宽. 越宽抗噪越强但定位精度下降 |
| **采样间隔** | ConfigSetting | **1.0** | 0.5~10.0 | `SampleInterval`=1.0px | 相邻采样点间距. 越小越密但计算量大 |
| **采样行数** | ConfigSetting | **1** | 1~50 | `SampleRowCount`=1 | 采样宽度内平行排列的行数. 多行支持直线拟合 |

**MeasureLength 调参指南:**

| 场景 | 推荐 | 说明 |
|------|------|------|
| 窄间隙 | 30~80px | 测量微小间隙 |
| 边缘定位 | 100~200px | 找到边缘即可 |
| 宽幅扫描 | 200~1000px | 大面积寻边 |
| 通用 | **100px默认** | 多数工业场景 |

**SampleWidth 调参指南:**

| 图像质量 | 推荐 | 说明 |
|----------|------|------|
| 清晰锐利 | 5~10px | 高分辨率良好光照 |
| 一般工业 | **15~25px(默认20)** | 有一定噪声 |
| 高噪声 | 30~60px | 金属表面织物等 |

**SampleRowCount 含义:**
- 1(默认): 快速定位, 输出边缘点坐标
- 3~5: 一般直线检测, 输出拟合直线
- 5~15: 高可靠性, 输出高质量直线+置信度
- 15~50: 极低信噪比环境, 强鲁棒输出

### 3.5 边缘检测配置参数详解

#### 3.5.1 边缘极性 (EdgePolarity) -- 卡尺核心特性

| 枚举值 | 显示文本 | 条件 | 典型应用 |
|--------|---------|------|---------|
| `Any` | `任意` | 不过滤 | 极性不确定/需要全部边缘 |
| `LightToDark` | **从亮到暗(默认)** | gradient<0 | 黑背景亮物体(LCD边框等) |
| `DarkToLight` | `从暗到亮` | gradient>0 | 白背景暗物体(金属件轮廓等) |

选择指南: 先观察图像目标边缘是从亮区进暗区还是相反. **选错极性会完全找不到边缘!**

#### 3.5.2 选取模式 (SelectionMode)

| 枚举值 | 显示文本 | 输出规则 | 应用 |
|--------|---------|---------|------|
| `First` | `首边` | 第一个满足条件的 | 到达检测 |
| `Strongest` | `最强边` | 梯度最大的 | 高噪声可靠边缘 |
| `All` | **所有边(默认)** | 所有满足条件的 | 宽度测量/多边缘 |
| `Nth` | `第N个边` | 第N个(配合序号) | 固定序列精确选 |

**第N个边的序号:** 仅 Nth 模式有效, 默认=1, 范围1~100.

### 3.6 过滤阈值参数详解

| 参数 | 控件类型 | 默认值 | 范围 | 算法属性 | 说明 |
|------|----------|--------|------|----------|------|
| **最小对比度** | ConfigSetting | **30** | 1~255 | `MinContrast`=30 | 边缘两侧灰度差阈值. 低对比过渡被忽略 |
| **最小边缘幅度** | ConfigSetting | **10** | 1~255 | `MinEdgeAmplitude`=10 | 梯度绝对值阈值. 过滤噪声假边缘 |
| **平滑核大小** | ConfigSetting | **5** | 1/3/5/7/9 | `SmoothKernelSize`=5 | 1D剖面平滑核. 奇数越大越平滑 |

调参提示:
- MinContrast: 背光照明用50~100, 漫射光照用10~20, 默认30适用环形光
- MinEdgeAmplitude: 与MinContrast协同, 干净图像20~30, 有噪声15~40
- SmoothKernelSize: 应 <= SampleWidth/2, 默认5适用多数场景, 高噪声用7/9

### 3.7 高级设置详解

#### 亚像素精度

| 状态 | 精度 | 说明 |
|------|------|------|
| **ON(默认)** | +/-0.05~0.1px | 插值方法精确定位, **内建核心能力**, 非后处理 |
| OFF | +/-0.5px | 整数像素, 快速, 适用无需高精度场景 |

#### 插值方法

| 枚举值 | 显示文本 | 精度 | 速度 | 特点 |
|--------|---------|------|------|------|
| `Parabolic` | **二次抛物线(默认)** | 高(+/-0.05px) | **快** | 3点拟合, 最佳平衡 |
| `Gaussian` | 高斯插值 | 最高(+/-0.02px) | 较慢 | 高斯函数拟合, 最高精度 |
| `Linear` | 线性插值 | 一般(+/-0.2px) | 最快 | 两点线性, 不推荐 |

### 4.2 多卡尺合并详解

**与HoughLinesP"线段合并"的本质区别:**
- **HoughLinesP**: 同一物理直线被拆成多个线段 --> 合并为完整线段
- **Caliper**: 多个卡尺各找到一个边缘点 --> 这些点拟合成一条直线

**合并算法:** 按"第几个边缘"分组 --> 共线性判定(残差/角度/点数) --> 通过则最终直线拟合.

### 4.3 直线拟合参数

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 拟合方法 | **OLS(最小二乘)** | OLS/RANSAC/Theil-Sen | OLS最快但怕离群点, RANSAC抗少量异常, Theil-Sen最鲁棒(50%异常仍可用) |
| 最小拟合点数 | **2** | 2~100 | 少于此数的组直接丢弃 |
| 最大残差阈值 | **3.0px** | 0.5~50.0 | 超出的点被剔除(outlier rejection) |

### 4.4 过滤与排序

过滤参数: 最小直线长度(10px), 角度范围(0~180), 最大数量(50).

**排序选项完整清单 (9种):**

| 排序选项 | 显示文本 | 排序规则 | 典型场景 | 与其他卡尺一致性 |
|----------|----------|----------|----------|------------------|
| `None` | 无排序 | 保持引擎原始输出顺序 | 不关心顺序, 只需前N个 | 三件套统一 |
| `ConfidenceDescending` | **按置信度降序(默认)** | RMS残差越小越高 | 精密测量优先最高质量结果 | 三件套统一 |
| `ConfidenceAscending` | 按置信度升序 | RMS残差越大越高 | 调试分析时查看最差结果 | 三件套统一 |
| `LengthDescending` | 按直线长度降序 | 拟合直线越长越优先 | 长边缘优先(如长边定位) | LineCaliper特有 |
| `LengthAscending` | 按直线长度升序 | 拟合直线越短越优先 | 短边缘优先(如缺口检测) | LineCaliper特有 |
| `AngleDescending` | 按角度降序 | 直线角度从大到小 | 按角度归类查看 | LineCaliper特有 |
| `AngleAscending` | 按角度升序 | 直线角度从小到大 | 按角度顺序扫描 | LineCaliper特有 |
| `XAscending` | **按X坐标升序** | 边缘点/直线中心X从小到大 | 从左到右扫描工件 | 三件套统一 |
| `YAscending` | **按Y坐标升序** | 边缘点/直线中心Y从小到大 | 从上到下扫描工件 | 三件套统一 |

默认**按置信度降序**(残差越小越高). 这与HoughLinesP版默认"按长度降序"不同, 因为卡尺核心优势在于**测量精度和可靠性**.

## 六、交互流程图

### 6.1 完整操作流程

```
Phase 1: 准备 (Tab1)
  (1) 选图像源 --> (2) 绘制LineCaliper ROI (拖拽位置/长度/方向/宽度)
       --> (3) 配置位置补正(可选)

Phase 2: 卡尺参数配置 (Tab2)
  (4) 设搜索方向角 (与ROI同步或手动) --> (5) 设采样参数 (长度/宽度/间隔/行数)
       --> (6) 设边缘检测 (极性/选取模式) --> (7) 设过滤阈值 (对比度/幅度/平滑)
       --> (8) 设高级选项 (亚像素/插值方法)

Phase 3: 运行与调优循环
  (9) 运行检测 --> 查看结果
       满意? --> Phase 4
       不满意?
       - 找不到边缘? --> 降低MinContrast/MinAmplitude, 检查极性是否正确
       - 噪声假边缘? --> 提高MinContrast/MinAmplitude, 加大SmoothKernelSize
       - 位置不准? --> 开启亚像素, 改用Gauss插值, 减小SampleInterval
       - 只想要特定边缘? --> 改选取模式为First/Nth
       --> 回到(9)重新运行

Phase 4: 完成
  保存参数 --> 集成到工作流 --> 部署运行
```

### 6.2 问题诊断树

```
检测结果不理想?

|-- "找不到任何边缘"
|   (1) 检查边缘极性是否正确! 最常见错误!
|   (2) 降低 MinContrast (30-->10~20)
|   (3) 降低 MinEdgeAmplitude (10-->3~5)
|   (4) 检查ROI是否覆盖了目标边缘
|   (5) 增大 MeasureLength (确保覆盖边缘位置)
|
|-- "找到太多假边缘"
|   (1) 提高 MinContrast (30-->50~100)
|   (2) 提高 MinEdgeAmplitude (10-->20~30)
|   (3) 加大 SmoothKernelSize (5-->7或9)
|   (4) 收窄 SampleWidth (过宽会引入干扰)
|   (5) 使用选取模式=First或Strongest
|
|-- "边缘位置抖动/不稳定"
|   (1) 增加采样行数 (1-->5~10)
|   (2) 开启多卡尺合并, 拟合直线替代单点
|   (3) 加大 SampleWidth (提高单点稳定性)
|   (4) 改用 TheilSen 或 RANSAC 拟合(更鲁棒)
|
|-- "只需要特定位置的边缘"
|   (1) 设置选取模式=First(取第一条) 或 Nth(取第N条)
|   (2) 配合 MeasureLength 控制搜索范围
```

### 6.3 典型场景快速配置

#### 场景A: 零件边缘精密定位

目标: 高精度定位零件边缘位置(亚像素级)
特征: 边缘清晰、对比度高、已知大致方向

Tab1: 图像源选好, 用LineCaliper ROI覆盖边缘, RakeAngle设为垂直于边缘方向
Tab2: 长度=80, 宽度=15, 间隔=1.0, 行数=5, 极性=LightToDark, 选取=Strongest,
      对比度=50, 幅度=15, 平滑=5, 亚像素=ON, Gauss插值
Tab3: 合并=ON, 偏差<=2.0px, 角度偏差<=2度, 点数>=3, OLS拟合, RMS<=1.0
Tab4: 位置偏差判断 ON, 范围[-0.3, +0.3]px

#### 场景B: 零件宽度测量

目标: 测量零件两边缘之间的宽度
特征: 需要找到两条平行边缘

Tab1: LineCaliper ROI横跨零件两边
Tab2: 长度=150, 宽度=20, 行数=1, 极性=Any, 选取=All
      (选取All以获取首尾两个边缘, 计算距离即为宽度)
Tab3: 最小直线长度=5, 角度范围限制为边缘方向+/-5度
Tab4: 数量判断 ON, 范围[2, 2], 确保恰好找到两条边缘

#### 场景C: 胶路/间隙检测

目标: 检测两条边缘之间的间隙是否合格
特征: 两条边缘近似平行, 间隙较小

Tab1: LineCaliper ROI跨越间隙区域
Tab2: 长度=60, 宽度=30(较宽以提高稳定性), 行数=10(强鲁棒),
      极性根据实际情况选择, 选取=First+Last(通过后续计算获取间隙)
Tab3: 合并=ON, OLS拟合, 高置信度优先排序
Tab4: 位置偏差判断 ON, 结合公差范围判定OK/NG

#### 场景D: 到达/有无检测

目标: 判断某个位置是否存在边缘(二元判断)
特征: 只关心"有没有", 不关心精确位置

Tab1: ROI放在预期边缘出现的位置
Tab2: 选取模式=First, 其他参数宽松即可
Tab4: 数量判断 ON, 范围[1, +inf](有边缘=OK) 或 [0, 0](无边缘=OK, 反向逻辑)

## 八、设计约束与约定

### 8.1 必须遵守的项目规范

| 规范类别 | 要求 |
|----------|------|
| MVVM架构 | UI层不含业务逻辑, 所有逻辑在ViewModel |
| 属性通知 | 继承 ObservableObject/ViewModelBase, 使用 SetProperty() |
| 日志系统 | ViewModel用 LogInfo/LogError, Service用 _logger.Log() |
| 命名规范 | PascalCase(类/方法/属性), camelCase(变量), _camelCase(私有字段) |
| 序列化 | System.Text.Json, PascalCase, [JsonPolymorphic]+[JsonDerivedType] |
| KISS原则 | 选择最简单合理的实现方式 |
| YAGNI原则 | 只实现当前明确需要的功能 |
| 参数系统 | Dictionary<string, object> 存储 + ParametersTypeName 强类型恢复 |
| ConfigSetting双模式 | 每个参数支持常量/绑定两种输入模式 |

### 8.2 与HoughLinesP版(v1.0)的关键变更清单

| 变更项 | v1.0(HoughLinesP) | v3.0(Caliper) | 影响范围 |
|--------|--------------------|----------------|---------|
| **核心算法** | Canny + HoughLinesP | 1D剖面梯度 + 亚像素插值 | 全局重写 |
| **Tab2全部参数** | Canny(3) + HoughLinesP(5) | 搜索方向(1) + 采样(4) + 极性(1) + 选取(1+1) + 过滤(3) + 高级(2) | Tab2完全重写 |
| **输入图像要求** | 需要Canny预处理后的二值图 | 直接使用原始灰度图 | Service层 |
| **边缘极性** | 不支持 | 支持(3种) | 新增能力 |
| **亚像素** | FitLine后处理(可选) | 内建核心能力(默认开启) | 精度提升 |
| **ROI依赖** | 不需要先验位置/方向 | **必须**有ROI位置和方向 | UI交互改变 |
| **ROI类型** | 矩形等常规ROI即可 | **强烈推荐LineCaliper** | ROI编辑器扩展 |
| **输出格式** | 线段(x1,y1,x2,y2) | 边缘点(x,y) + 拟合直线(点+方向向量) | 数据模型变化 |
| **默认排序** | 按长度降序 | **按置信度降序** | 体现设计理念差异 |
| **典型场景** | PCB走线/标定板/划痕 | **精密测量/间隙/到达/宽度** | 定位转变 |
| **对标API** | OpenCV HoughLinesP | **Halcon measure_pos / VP Caliper** | 行业对标 |
