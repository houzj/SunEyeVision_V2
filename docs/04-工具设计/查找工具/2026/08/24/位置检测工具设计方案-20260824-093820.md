## 一、定位与职责

位置检测工具是测量工具链的**第一个环节（取点）**，在 ROI 内沿测量方向提取边缘点，作为后续边缘检测（拟合）和几何测量（计算）的数据来源。

```
图像源 → [① 位置检测] → 边缘点集合 → [② 边缘检测] → Line2d/Circle2d → [③ 几何测量] → 距离/角度
```

**对应 Halcon measure_pos**：沿测量矩形主轴的法线方向提取 1D 边缘点，输出边缘点坐标 + 幅度 + 极性。

## 三、方案设计

### 3.1 算法实现（Halcon 1D Metrology）

**直接调用 Halcon HOperatorSet，不新增 CvOp 自研代码**（rule-008 KISS / rule-014）：

```csharp
// 1. 生成测量矩形句柄（引导线 → 带方向的测量矩形）
HOperatorSet.GenMeasureRectangle2(
    row, col, phi,          // 引导线中心 + 方向角
    length1, length2,       // 测量矩形半长/半宽（垂直/沿向）
    width, height,          // 图像尺寸
    "nearest_neighbor", out var measureHandle);

try
{
    // 2. 执行 measure_pos：沿法线方向提取边缘点
    HOperatorSet.MeasurePos(
        hImage, measureHandle,
        sigma, threshold,           // 平滑 + 边缘阈值
        transition, select,         // 极性 + 选取模式
        out var rowEdge, out var colEdge,
        out var amplitude, out var distance);

    // 3. 输出：rowEdge/colEdge = 边缘点坐标（数组），amplitude = 幅度，distance = 相邻间距
}
finally
{
    HOperatorSet.CloseMeasure(measureHandle);  // 释放句柄
}
```

### 3.2 参数定义（对齐 Halcon measure_pos）

```csharp
public class PositionDetectParameters : RegionParameters
{
    public MeasurePosParams Measure;   // 卡尺参数（1D Metrology）
    public EdgeFilterParams Filter;    // 过滤（幅度/极性/数量）
    public PositionSource Source;      // 测量线方向源（直线/圆弧）
}

public record MeasurePosParams
{
    public double Length1 = 20;       // 测量矩形半长（垂直方向）
    public double Length2 = 5;        // 测量矩形半宽（沿方向）
    public double Sigma = 1.0;        // 高斯平滑（0.4~100）
    public double Threshold = 30.0;   // 边缘阈值（1~255）
    public EdgeTransition Transition; // 'all' / 'positive' / 'negative'
    public EdgeSelect Select;         // 'all' / 'first' / 'last'
    public bool SubPixel = true;      // 亚像素（Halcon 内建）
}
```

### 3.3 结果定义

## 五、防御机制

| # | 机制 | 说明 |
|---|------|------|
| 1 | **Fail-Fast 输入校验** | ROI 为空、图像未设置、measure 句柄生成失败 → `SetError`（rule-008） |
| 2 | **句柄释放** | `gen_measure_rectangle2` 生成的句柄必须在 finally 中 `close_measure`（防泄漏） |
| 3 | **算子调用规范** | 必须用 HOperatorSet 静态方法（rule-014），禁止实例方法封装 |
