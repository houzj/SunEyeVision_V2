## 一、定位与职责

边缘检测工具是测量工具链的**第二个环节（拟合）**，通过引导几何（直线/圆/圆弧）在图像中定位边缘，拟合出几何对象，供③几何测量绑定使用。

```
图像 + 引导几何(RoI) → [② 边缘检测]（Halcon 2D Metrology：测量带阵列 + 拟合）→ Line2d / Circle2d / Arc2d → ③ 几何测量
```

**独立可用**：内置卡尺取点 + 拟合，不依赖① 位置检测（方案 A，已确认）。

**合并依据**：直线/圆/圆弧查找共享 80% 逻辑（2D Metrology 框架完全一致），仅几何引导类型不同。

**算法本质（对齐 Halcon 2D Metrology）**：
- 用户绘制引导几何（线/圆/弧）→ 系统自动生成 N 条测量带（measure bands）→ 每条带内做 1D 边缘检测 → 多点收集 → 拟合
- 这不是 measure_pos（1D 单条测量），而是 2D 卡尺测量（自动测量带阵列 + 拟合）

## 三、算法实现（Halcon 2D Metrology）

**直接调用 Halcon HOperatorSet，不新增 CvOp 自研代码**（rule-008 KISS / rule-014）：

```csharp
public EdgeDetectResults Run(EdgeDetectParameters p)
{
    var hImage = p.GetHalconImage();              // HalconHelpers.cs:11
    HOperatorSet.CreateMetrologyModel(out var model);
    try
    {
        HOperatorSet.GetImageSize(hImage, out var w, out var h);
        HOperatorSet.SetMetrologyModelImageSize(model, w, h);

        HTuple index;
        switch (p.GeometryType)
        {
            case GeometryType.Line:
                // 引导直线 → 自动生成测量带阵列
                HOperatorSet.AddMetrologyObjectLineMeasure(
                    model, p.GuideLine.Start.Y, p.GuideLine.Start.X,
                    p.GuideLine.End.Y, p.GuideLine.End.X,
                    p.MeasureLength1, p.MeasureLength2, p.Sigma, p.Threshold,
                    new HTuple("measure_distance", "measure_transition", "measure_select"),
                    new HTuple(p.MeasureDistance, p.Transition, p.Select), out index);
                break;

            default: // Circle / Arc
                // 引导圆 → 环形测量带（Arc 用 start_phi/end_phi 限定角度）
                HOperatorSet.AddMetrologyObjectCircleMeasure(
                    model, p.GuideCircle.Center.Y, p.GuideCircle.Center.X, p.GuideCircle.Radius,
                    p.MeasureLength1, p.MeasureLength2, p.Sigma, p.Threshold,
                    new HTuple("measure_distance", "start_phi", "end_phi",
                               "measure_transition", "measure_select"),
                    new HTuple(p.MeasureDistance, p.StartAngle, p.EndAngle,
                               p.Transition, p.Select), out index);
                break;
        }

        HOperatorSet.ApplyMetrologyModel(hImage, model);   // 逐测量带取点 + 拟合

        // 几何参数：Line=[Row1,Col1,Row2,Col2,Nr,Nc,Dist] / Circle=[Row,Col,Radius]
        HOperatorSet.GetMetrologyObjectResult(model, index, "all", "result_type", "all_param", out var param);
        // 拟合残差
        HOperatorSet.GetMetrologyObjectResult(model, index, "all", "result_type", "rms", out var rms);
    }
    finally { HOperatorSet.CloseMetrologyModel(model); }   // 句柄释放
}
```

## 四、参数定义

```csharp
public class EdgeDetectParameters : RegionParameters
{
    public GeometryType GeometryType;       // Line / Circle / Arc

    // 引导几何（来自 RoI 绘制）
    public Line2d? GuideLine;               // Line 模式
    public Circle2d? GuideCircle;           // Circle/Arc 模式

    // 测量带参数（对齐 Halcon 2D Metrology）
    public double MeasureLength1 = 20;      // 单条测量带法线方向半长（宽度）
    public double MeasureLength2 = 5;       // 单条测量带切线方向半长（长度）
    public double MeasureDistance = 10;     // 测量带间距（与 num_measures 互斥）
    public double Sigma = 1.0;              // 高斯平滑（0.4~100）
    public double Threshold = 30.0;         // 边缘阈值（1~255）
    public EdgeTransition Transition;       // positive/negative/uniform
    public EdgeSelect Select;               // first/last/all
    public double StartAngle = 0;           // Arc 起止角（弧度）
    public double EndAngle = Math.PI * 2;
}

public enum GeometryType { Line, Circle, Arc }
```

**数量交互**：UI 主控"数量"（Slider，2~200），内部换算 `num_measures=N`（Halcon 均匀分布，最小约束：线≥2、圆≥3、弧≥4）。

## 七、测量带可视化与主卡尺交互

### 7.1 测量带渲染（核心）

引导几何绘制后自动生成测量带阵列并叠加渲染（VisionPro 风格每条单独画）：
- Line：N 条垂直测量带（沿引导线）
- Circle：N 条径向测量带（沿圆周）
- Arc：N 条径向测量带（限定起止角）

参数联动实时刷新：数量→条数增减；宽/长→尺寸变化。

### 7.2 主卡尺交互

N 条中选一条主卡尺（高亮），承载交互，其余半透明：
- Line：中间那条 / Circle：0°那条 / Arc：起止角中点那条

### 7.3 手柄：仅 2 个

```
┌────────────┐
│●      ↑    │ ← 宽度手柄(短边中点) + 方向箭头(卡尺内部)
│       ●    │ ← 长度手柄(长边中点)
└────────────┘
① 宽度手柄 → MeasureLength1（全同步）
② 长度手柄 → MeasureLength2（全同步）
```

**为什么 2 个**：所有测量带共享参数，每维度 1 个手柄即可。

### 7.4 方向箭头：卡尺内部 + 垂直引导线

```
positive → 单箭头 ↑ / negative → 单箭头 ↓ / all → 双箭头 ↕
```
箭头始终在主卡尺矩形内部，方向 = 法线方向（垂直引导线）。

## 十二、与①位置检测的边界

| 维度 | ① 位置检测 | ② 边缘检测（本方案） |
|------|-----------|-------------------|
| 算法 | Halcon 1D（measure_pos） | Halcon 2D Metrology |
| 引导 | 旋转矩形 ROI | Line/Circle/Arc ROI |
| 输出 | 边缘点集合 | 拟合几何对象 |
| 调试窗口 | 对齐 Threshold（3 Tab） | 对齐 Threshold/ImageFilter + BlobAnalysis 结果 |
| 独立 | ✅ | ✅ |
