## 输入与坐标语义

- `p=(u,v)`，u 是图像列/X，v 是图像行/Y，采用同一像素中心坐标域。
- `s=(Xs,Ys)` 是 R 轴轴心编码器绝对机台坐标，单位 mm，不是 Mark 或 TCP 坐标。
- `phi=signR*(Theta-Theta0)`，编码器角度以 deg 输入，三角函数前转 rad。
- `q=A*p+t=s+R(phi)*d`，q 是 Mark 绝对物理位置，d 是参考 R 角下轴心到 Mark 的偏心。
- 平移采样保持 Theta0；旋转采样保持轴心 XY。Mark 偏心与 TCP 偏置分开。

本实验只对数值点调用 `affine_trans_point_2d`，统一约定输入顺序为 `(u,v)`；没有图像、区域或 XLD 图像变换，不添加半像素偏移。另以交换矩阵列和点输入顺序的方式核对 `(row,column)` 适配，不能把本实验的矩阵未经适配直接用于 HALCON 图像变换。物理平面的圆拟合按 `(Row,Column)=(Y,X)` 传入，圆心转换回 `(X,Y)`。

## HALCON分阶段路线

九个平移点先以 `vector_to_hom_mat2d(u,v,Xs,Ys)` 得到辅助映射 H0。参考角下 q=s+d，因此：

```text
H0(p) = A*p+b = s
b = t-d
```

旋转样本转换到该辅助物理平面后：

```text
H0(p_i) = s + R(phi_i)*d-d
        = (s-d) + R(phi_i)*d
```

这时轨迹才是等尺度物理平面的圆。用 `gen_contour_polygon_xld` 和 `fit_circle_contour_xld('geometric',...)` 求辅助圆心 c，得到：

```text
c = s-d
d = s-c
t = b+d
最终 Mark 物理位置 q = H0(p)+d
```

辅助圆心 c 不是机构轴心绝对坐标，H0 也不是最终的 Mark 绝对坐标映射。忽略偏心修正会留下恒定的 d 偏差。

另做保留编码器角度的分阶段路线：九点映射 H0 不变，旋转点采用 `solve_matrix` 解两个偏心未知量：

```text
(R(phi_i)-I)*d = H0(p_i)-s_i
t = b+d
```

它仍是本项目对轴心 XYR 的建模组合，但各数值步骤由 HALCON 原生算子执行，且不靠三点曲率猜测偏心。

## 对照方法与复现

共 209 组数据，每组计算以下五条路线：

| 路线 | 实际执行内容 |
|---|---|
| HALCON 分阶段物理圆 | 九点原生仿射、辅助物理平面圆拟合、偏心修正、原生点变换 |
| HALCON 分阶段编码器角 | 九点原生仿射、已知角度的两参数原生最小二乘、偏心修正 |
| 当前联合 QR | 原样编译仓库 NPointCalibrationSolver.cs，调用其最小二乘 Fit |
| HALCON 联合线性最小二乘 | 相同 24×8 观测方程，CreateMatrix/SolveMatrix/GetFullMatrix，general、epsilon=1e-12 |
| 负对照 | 在原始图像中拟圆，再变换圆心，演示该捷径的坐标错误 |

当前 QR 对照使用隔离的数据类型替身，字段与求解器所消费的参数一致，不运行 WPF、工作流和文件发布。比较的是未修改的真实求解器源码，不是 Release 程序集或整个工具节点。此次没有验证 Huber/Tukey 迁移和权重参数等价性。

无噪声覆盖六组：既有测试模型参数、非等比缩放及斜切、镜像、R 反方向、非零参考角跨周、±10° 小弧。另做错误 R 符号、旋转轴心移动和零偏心三个边界组。

噪声覆盖宽角度 `0/90/180°` 和小角度 `-10/0/10°`，各 100 个固定随机种子。每个图像坐标独立加入均匀分布 ±0.05 px 噪声，编码器 XYR 保持无噪声。矩阵真值为 `[0.05,0.008,100;-0.003,0.07,50]`，偏心为 `(5,-3) mm`，Theta0=17°。不从拟合结果反推真值；生成与验证的真值坐标由独立的标量仿射公式计算。

每组用另外 30 个不参与拟合的无噪声观察检查 Mark 映射和轴心反算。后者使用 `s=q-R(phi)*d`，仅验证 Mark 模型的轴心反算，不代表已验证任意 TCP 的抓取补偿。

## 无噪声结果

六组无噪声数据的四条正向路线均通过 1e-7 mm 的坐标及偏心误差断言，观测到的最大误差为 `1.978e-11 mm`。非零参考角、镜像、负 R 正方向和跨周角度均能正确恢复。

模型示例：真实矩阵为 `[2,0.3,100;-0.2,3,50]`，d=(5,-3) mm。九点 H0 得到平移 `(95,53)`，并非 `(100,50)`；旋转轴心 s=(1375,1137) mm，辅助轨迹圆心 c=(1370,1140) mm，按 d=s-c 得回 `(5,-3)`，最终平移恢复为 `(100,50)`。

原始图像拟圆负对照在这组完全无噪声数据上仍出现偏心误差约 2.14 mm。错误不是定位噪声引起，而是把仿射成像下的图像轨迹当成物理圆。

在 207 组适合比较的案例中，当前 QR 与 HALCON 联合最小二乘的矩阵系数和偏心分量最大差为 `1.231e-11`。这一结论仅覆盖此次数据范围、最小二乘及同一观测模型，不等于任意病态数据上的逐位等价保证。

下表为 100 个随机种子中，每次 30 个独立点的最大 Mark 坐标误差再取均值，单位 mm，不是训练 RMS，也不是现场精度保证。所有路线均能完成数值计算，不表示均满足生产容差。

| 路线 | 宽角度均值 | 小角度均值 | 小角度最坏单组最大误差 |
|---|---:|---:|---:|
| HALCON 分阶段物理圆 | 0.004562 | 0.107483 | 0.315906 |
| HALCON 分阶段编码器角 | 0.003636 | 0.010723 | 0.025478 |
| 当前联合 QR | 0.003473 | 0.010717 | 0.025475 |
| HALCON 联合线性最小二乘 | 0.003473 | 0.010717 | 0.025475 |

本次小角度样本中，三点圆拟合明显放大了定位噪声；保留已知 R 角的两条 HALCON 路线更稳定。此结果不能推导为任意工位都应选哪一条路线，也不能把独立点数量扩大当作增加了训练旋转样本。

## 边界结果与必需的门槛

- 错误 R 符号：物理圆路线仍得到几乎零的径向误差 `6.175e-15 mm`，但完整 XYR 训练 RMS 为 `3.3665 mm`，独立轴心反算最大误差为 `11.6619 mm`。因此圆残差不能替代编码器方向、点角对应及完整模型残差检查。联合拟合也会数值返回，必须由质量门槛拒绝，不能把算子成功当成标定成功。
- 旋转轴心移动：分阶段路线及当前求解器按 0.01 mm 固定轴心门槛拒绝。HALCON 联合线性算子仍能求出真值，因为方程允许逐样本输入实际 s；它本身不负责本项目规定的采样轨迹验收。迁移后不能丢掉已有几何前置检查。
- 零偏心：三点轨迹退化，本次圆拟合报 HALCON 9201；已知角度分阶段和两条联合路线可数值恢复零偏心。这不等于现场允许发布零偏心的“旋转标定”，生产策略仍须定义可观测性门槛。
- 三点径向拟合缺少异常点识别冗余；小角度、错序、错误单位、XYR 不同步和系统性定位偏差不能靠更换原生算子自动解决。

## 后续路线建议

目前不支持直接把现有联合模型替换为“九点仿射加三点圆心”，也不支持认定当前数学模型错误。优先保留轴心 XYR 与 Mark 偏心定义，评估将底层线性求解移入 HalAdapter，采用 HALCON 原生矩阵求解，同时保留完整残差、采样几何和独立验证。

若产品明确要求分阶段展示，优先评估“原生九点映射加已知编码器角偏心求解”，将物理圆拟合作为有足够旋转覆盖时的交叉检查，而不是唯一生产依据。最终选择须补真实相机/机构数据、控制器 XY 的实际含义、编码器噪声、旋转行程和工艺阈值，再由用户确认。现有候选/正式文件分层、独立验证与发布边界不因底层算子更换而撤销。
