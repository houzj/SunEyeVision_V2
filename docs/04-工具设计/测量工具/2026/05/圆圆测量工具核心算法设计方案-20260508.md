# 圆圆测量工具 (CircleToCircle) 核心算法设计方案

> 版本: v1.0 | 日期: 2026-05-07 | 状态: 设计完成

---

## 一、算法概述

圆圆测量工具的算法核心是计算两个圆之间的几何距离关系。输入为两个圆信息（圆心坐标 + 半径），输出为根据用户选择的测量模式计算出的距离值，以及相关的判定结果。

算法整体流程:

```
输入: 圆1 (C1X, C1Y, R1), 圆2 (C2X, C2Y, R2)
                    |
                    v
           计算圆心欧氏距离
          centerDist = sqrt((C2X - C1X)^2 + (C2Y - C1Y)^2)
                    |
                    v
          根据测量模式计算目标距离
                    |
     +--------+-----+-----+--------+
     |        |           |        |
     v        v           v        v
   中心距    最小边距     最大边距   (选择其中一种)
                    |
                    v
          单位换算 (px -> mm)
                    |
                    v
          公差判定 (OK/NG)
                    |
                    v
  输出: CircleToCircleResults
```

## 二、三种测量模式

### 2.1 中心距 (CenterDistance)

**定义:** 两个圆心之间的欧氏距离。

**公式:**

```
centerDist = sqrt((C2X - C1X)^2 + (C2Y - C1Y)^2)
```

**几何含义:**

```
        C1 . ____  centerDist ____ . C2
           /                          |
          |    R1           R2        |
           \_________________________/
```

**适用场景:**
- 孔间距测量
- 位置度检测
- 轴心偏差检测

---

### 2.2 最小边距 (MinEdgeDistance)

**定义:** 两个圆在最近点的距离。

**公式:**

```
minEdgeDist = centerDist - R1 - R2
```

**几何含义:**

```
        C1 . _______ centerDist _______ . C2
           |    |                     |   |
           |  R1|                     |R2 |
           |    |<-- minEdgeDist -->  |   |
           |    |                     |   |
           |    |_____________________|   |
           |_____________________________|
```

**推导说明:**
- 两圆连线方向上，从 C1 出发向 C2 方向移动 R1 到达圆1的最近边缘点
- 从 C2 出发向 C1 方向移动 R2 到达圆2的最近边缘点
- 这两点之间的距离即为最小边距

**特殊情况:**
- 当 centerDist > R1 + R2 时: minEdgeDist > 0，两圆分离
- 当 centerDist == R1 + R2 时: minEdgeDist == 0，两圆外切
- 当 centerDist < R1 + R2 时: minEdgeDist < 0，两圆相交（负值表示重叠程度）
- 当 centerDist < |R1 - R2| 时: 一个圆完全包含另一个圆，minEdgeDist 为负值

**适用场景:**
- 间隙检测（测量两零件之间的间距）
- 壁厚测量
- 装配间隙验证

---

### 2.3 最大边距 (MaxEdgeDistance)

**定义:** 两个圆在最远点的距离。

**公式:**

```
maxEdgeDist = centerDist + R1 + R2
```

**几何含义:**

```
        . C1 _____ centerDist _____ C2 .
       /|    |                     |    |\
      | |  R1|                     |R2 | |
       \|    |                     |    |/
        .    |_____________________|    .
             |<---- maxEdgeDist ---->|
```

**推导说明:**
- 从 C1 出发向 C2 方向的反向移动 R1 到达圆1的最远边缘点
- 从 C2 出发向远离 C1 方向移动 R2 到达圆2的最远边缘点
- 这两点之间的距离即为最大边距
- 也可以理解为两个圆的外包络直径在圆心连线方向的投影

**适用场景:**
- 外径范围检测
- 整体尺寸验证
- 碰撞检测

## 三、核心算法实现

### 3.1 基本几何计算

**圆心距离计算:**

```
CenterDistance(C1, C2):
    dx = C2.X - C1.X
    dy = C2.Y - C1.Y
    return sqrt(dx * dx + dy * dy)
```

**各模式距离计算:**

```
switch (measureMode):
    case CenterDistance:
        return centerDist
    case MinEdgeDistance:
        return centerDist - R1 - R2
    case MaxEdgeDistance:
        return centerDist + R1 + R2
```

### 3.2 单位换算

当用户选择物理单位 (mm) 时:

```
distanceMM = distancePX * pixelCalibration
```

其中 pixelCalibration 为标定系数，表示每个像素对应的物理长度 (mm/pixel)。

如果选择像素单位 (px):

```
distancePX = centerDist (直接输出像素值，不换算)
```

### 3.3 数值精度控制

根据用户设定的小数位数对结果进行格式化:

```
round(distance, decimalPlaces)
round(centerX, decimalPlaces)
round(centerY, decimalPlaces)
```

## 四、公差判定逻辑

### 4.1 判定流程

```
if (isToleranceEnabled == false):
    isPass = true
    message = "OK (公差未启用)"
    return

if (distance >= toleranceLower && distance <= toleranceUpper):
    isPass = true
    message = "OK (测量值在公差范围内)"
else:
    isPass = false
    if (distance < toleranceLower):
        message = "NG (测量值低于下限: {distance} < {toleranceLower})"
    else:
        message = "NG (测量值超出上限: {distance} > {toleranceUpper})"
```

### 4.2 边界条件处理

| 条件 | 处理方式 |
|------|----------|
| toleranceLower > toleranceUpper | 自动交换上下限值 |
| toleranceLower == toleranceUpper | 允许，判定等价于 distance == toleranceLower |
| toleranceLower == toleranceUpper == 0 | 始终 NG（除非距离也为 0） |
| 公差未启用 | 跳过判定，始终 OK |

## 六、算法执行流程

### 6.1 Run 方法伪代码

```
Run(inputImage):
    // Step 1: 获取圆1 信息
    if (Circle1InputMode == LinkMode):
        // 从链接工具的 Results 中获取圆1
        var linkResults = GetLinkedToolResults(Circle1LinkTool)
        if (linkResults == null || linkResults.FilteredCircles.Count < Circle1LinkIndex):
            return Error("链接工具未找到圆1")
        circle1 = linkResults.FilteredCircles[Circle1LinkIndex - 1]
    else:
        // 使用手动输入的参数
        circle1 = (CenterX: Circle1ParamX, CenterY: Circle1ParamY, Radius: Circle1ParamR)

    // Step 2: 获取圆2 信息 (同上)
    if (Circle2InputMode == LinkMode):
        var linkResults = GetLinkedToolResults(Circle2LinkTool)
        if (linkResults == null || linkResults.FilteredCircles.Count < Circle2LinkIndex):
            return Error("链接工具未找到圆2")
        circle2 = linkResults.FilteredCircles[Circle2LinkIndex - 1]
    else:
        circle2 = (CenterX: Circle2ParamX, CenterY: Circle2ParamY, Radius: Circle2ParamR)

    // Step 3: 计算圆心距离
    centerDist = sqrt((circle2.CenterX - circle1.CenterX)^2
                    + (circle2.CenterY - circle1.CenterY)^2)

    // Step 4: 根据测量模式计算目标距离
    switch (MeasureMode):
        case CenterDistance:
            distancePixels = centerDist
        case MinEdgeDistance:
            distancePixels = centerDist - circle1.Radius - circle2.Radius
        case MaxEdgeDistance:
            distancePixels = centerDist + circle1.Radius + circle2.Radius

    // Step 5: 单位换算
    if (MeasureUnit == mm):
        distanceDisplay = distancePixels * PixelCalibration
    else:
        distanceDisplay = distancePixels

    // Step 6: 公差判定
    if (IsToleranceEnabled):
        isPass = (distanceDisplay >= ToleranceLower
               && distanceDisplay <= ToleranceUpper)
        message = BuildJudgmentMessage(isPass, distanceDisplay)
    else:
        isPass = true
        message = "OK (公差未启用)"

    // Step 7: 构建结果
    return CircleToCircleResults
    {
        Distance = round(distanceDisplay, DecimalPlaces),
        DistancePixels = distancePixels,
        MeasureMode = this.MeasureMode,
        Center1X = round(circle1.CenterX, DecimalPlaces),
        Center1Y = round(circle1.CenterY, DecimalPlaces),
        Radius1 = round(circle1.Radius, DecimalPlaces),
        Center2X = round(circle2.CenterX, DecimalPlaces),
        Center2Y = round(circle2.CenterY, DecimalPlaces),
        Radius2 = round(circle2.Radius, DecimalPlaces),
        CenterDistance = round(centerDist, DecimalPlaces),
        IsPass = isPass,
        Message = message
    }
```

## 八、边界情况处理

### 8.1 输入验证

| 验证项 | 条件 | 处理 |
|--------|------|------|
| 圆1圆心有效 | CenterX, CenterY 在图像范围内 | 超出返回 InvalidInput 错误 |
| 圆1半径有效 | Radius > 0 | 半径 <= 0 返回 InvalidInput 错误 |
| 圆2圆心有效 | CenterX, CenterY 在图像范围内 | 同上 |
| 圆2半径有效 | Radius > 0 | 同上 |
| 像素当量有效 | PixelCalibration > 0 | 为0时使用默认值 1.0 并发出警告 |

### 8.2 测量异常处理

| 场景 | 计算结果 | 说明 |
|------|----------|------|
| 两圆完全重合 | centerDist=0，minEdgeDist=-R1-R2，maxEdgeDist=R1+R2 | 各模式均有合理物理含义 |
| 两圆同心不同半径 | centerDist=0，minEdgeDist为负，maxEdgeDist=R1+R2 | 内圆完全包含于外圆 |
| 圆半径极大 | 距离可能溢出 double 精度范围 | 实际场景中罕见，不特殊处理 |
| 圆半径极小 | 最小边距趋近于 centerDist | 可忽略半径影响 |

### 8.3 数值稳定性

- 使用 double 类型进行计算，避免 float 精度损失
- 开方运算时处理 dx/dy 为0的退化情况:
  - 当 dx==0 && dy==0 时，centerDist = 0.0
  - 当 dx==0 时，centerDist = abs(dy)
  - 当 dy==0 时，centerDist = abs(dx)
- 公差判定使用 >= 和 <=，边界值判定为 OK

## 九、性能分析

### 9.1 计算复杂度

圆圆测量算法时间复杂度为 O(1)，常数时间:

```
计算量:
  - 加减法: 5 次 (dx，dy，centerDist，+/- R1/R2)
  - 乘法: 2 次 (dx*dx，dy*dy)
  - 开方: 1 次 (sqrt)
  - 比较: 2 次 (公差判定)
```

### 9.2 性能预估

| 操作 | 预估耗时 | 说明 |
|------|----------|------|
| 基础计算 | < 0.001ms | 纯算术运算 |
| 单位换算 | < 0.001ms | 一次乘法 |
| 公差判定 | < 0.001ms | 两次浮点比较 |
| 结果构建 | < 0.001ms | 赋值操作 |
| 合计 | < 0.01ms | 相较于图像处理可忽略 |

## 十一、与 Halcon 对标

| Halcon 概念 | 本方案对应 | 说明 |
|-------------|-----------|------|
| distance_pp() | CenterDistance 计算 | 两点距离 = 圆心距离 |
| distance_cc() | MinEdgeDistance | 两圆轮廓最近距离 |
| distance_cc() + 取负 | 两圆相交/包含检测 | 负值表示重叠 |
| select_shape_std() | 圆拾取链接 | 从已有检测结果选圆 |

圆圆测量工具本身不依赖复杂的图像处理算子，其核心计算为纯几何运算。精度完全取决于输入的圆检测质量。
