# 点点测量工具 (PointToPoint) UI 设计方案

> 版本: v1.0 | 日期: 2026-05-07 | 状态: 设计完成
> 适用范围: 点点测量工具 (PointToPoint) — 测量图像中两点间的欧氏距离
> 参考基准: 测量工具综合UI设计框架 / BlobAnalysisTool 实现风格

---

## 一、工具概述

### 1.1 功能定位

点点测量 (PointToPoint) 是测量工具集中最基础的测量工具，用于计算图像中两个点基元之间的欧氏距离。用户通过绑定上游节点输出的 Point2d 对象，或手动输入/点击图像获取点坐标，工具自动计算两点距离并输出测量结果。

### 1.2 整体架构

```
+-------------------------------------------------------------------+
|                   PointToPoint 测量工具调试面板                       |
+-------------------------------------------------------------------+
|                                                                     |
|   +--------+ +--------+ +--------+                                  |
|   | Tab1   | | Tab2   | | Tab3   |                                  |
|   | 基本参数 | | 测量参数 | | 结果显示 |                                  |
|   +--------+ +--------+ +--------+                                  |
|                                                                     |
|   +-------------------------------------------------------------+  |
|   |                                                             |  |
|   |                    当前选中 Tab 的内容区                      |  |
|   |                                                             |  |
|   +-------------------------------------------------------------+  |
|                                                                     |
+-------------------------------------------------------------------+
```

### 1.3 输入输出概要

| 项目 | 说明 |
|------|------|
| 输入基元 | Point2d (x, y) x 2个 |
| 测量算法 | 欧氏距离: sqrt((x1-x2)^2 + (y1-y2)^2) |
| 主要输出 | Distance (当前单位), DeltaX, DeltaY |
| 辅助输出 | DistancePixels, IsPass, Message |
| 显示形式 | 连接线标注 + 坐标文本 + 分量值 |

### 2.2 图像源选择 (ImageSourceSelector)

#### 2.2.1 控件结构

图像源选择器使用 SDK 内建的 `ImageSourceSelector` 控件封装在 `LabeledControl` 中，标签文本固定为 "输入图像"。

```
+-------------------------------------------------------------+
| LabeledControl: "输入图像"                                   |
| +-------------------------------------------------------+   |
| | 输入图像: [Image1(v)]    [_______________________]    |   |
| +-------------------------------------------------------+   |
|                                                             |
| (v) 展开后下拉列表内容:                                     |
| +-------------------------------------------------------+   |
| | Image1              (源图像, Mat)                      |   |
| | Image2              (源图像, Mat)                      |   |
| | circleFind1.GrayImage (灰度图像, Mat)                  |   |
| +-------------------------------------------------------+   |
+-------------------------------------------------------------+
```

#### 2.2.2 功能说明

| 功能 | 描述 |
|------|------|
| 下拉选择 | 列出工作流中所有可输出 Mat 类型图像的节点 |
| 自动过滤 | 仅显示图像类型输出（如 Mat、CvImage） |
| 默认值 | 无，默认显示 "请选择输入图像源" placeholder |
| 数据绑定 | 选择结果存储在 Parameters 中，供 Run() 方法读取 |

### 2.3 点输入 (基元1)

#### 2.3.1 输入方式选择

使用 RadioButton 组提供两种输入模式，默认选中 "按点"。

```
输入方式:
(O) 按点    ( ) 按坐标
```

**按点模式**：用户通过 ParamBinding 链接工作流中其他节点输出的 Point2d 对象。这是最常用的模式，适用于工作流中已有找点/找圆/找角点等工具的输出场景。

**按坐标模式**：用户手动输入 X 和 Y 浮点数值来指定点的位置。适用于已知固定坐标的场景，或调试阶段快速测试。

#### 2.3.2 按点模式下的控件

```
LabeledControl: "点1"
+----------------------------------------------------------------+
| 点1: [__________________________________] [链接]               |
+----------------------------------------------------------------+

TextBox 显示取到的绑定源名称
--- 示例 ---
| 点1: [circleFind1.FoundCircle.Center______________] [链接]    |
```

| 控件 | 类型 | 说明 |
|------|------|------|
| 文本框 | TextBox (只读) | 显示当前绑定的源名称，如 "circleFind1.FoundCircle.Center" |
| 链接按钮 | Button | 打开 ParamBinding 选择面板，仅显示 Point2d 类型输出 |

**ParamBinding 选择面板弹出效果:**

```
+-------------------------------------------------------------------+
| 选择绑定源                                                          |
| 类型过滤: Point2d                                                   |
|                                                                     |
| +---------------------------------------------------------------+  |
| | circleFind1.FoundCircle.Center         (圆心坐标)             |  |
| | blobAnalysis1.Centroid                 (质心坐标)             |  |
| | templateMatch1.MatchCenter             (匹配中心)             |  |
| | lineFinder1.StartPoint                 (线段起点)             |  |

| +---------------------------------------------------------------+  |
|                                                                     |

+-------------------------------------------------------------------+
```

#### 2.3.3 按坐标模式下的控件

当选中 "按坐标" 时，控件布局切换为坐标输入界面：

### 3.2 测量单位 (ComboBox)

| 属性 | 值 |
|------|-----|
| 控件类型 | ComboBox |
| 选项 | "px (像素)", "mm (毫米)" |
| 默认值 | "px (像素)" |
| 说明 | 选择测量结果的显示单位，影响测量值输出和公差值的单位 |

**单位切换逻辑：**

```
用户选择 "mm (毫米)"
    |
    +--> 检查像素当量是否 > 0
    |       |
    |       +--> 是: 显示像素当量输入框
    |       +--> 否: 显示提示 "请设置像素当量"
    |
    +--> 测量值 = DistancePixels * PixelCalibration
    +--> 公差值单位跟随切换

用户选择 "px (像素)"
    |
    +--> 隐藏像素当量输入框
    +--> 测量值 = DistancePixels (原始值)
```

### 3.5 公差设定

#### 3.5.1 启用公差判断 (ToggleSwitch)

| 属性 | 值 |
|------|-----|
| 控件类型 | ToggleSwitch |
| 默认值 | OFF |
| 说明 | 控制是否启用测量结果的 OK/NG 判断 |
| 关联行为 | 开启后显示公差上限/下限输入框，并影响 Tab3 中测量结果的判断逻辑 |

#### 3.5.2 公差上限 (ConfigSetting)

| 属性 | 值 |
|------|-----|
| 控件类型 | ConfigSetting |
| 标签 | "上限" |
| 默认值 | 100.0 |
| 范围 | 0 ~ 99999.0 |
| 单位 | 跟随测量单位 (px 或 mm) |
| 可见性 | 仅当启用公差判断 = ON 时显示 |

#### 3.5.3 公差下限 (ConfigSetting)

| 属性 | 值 |
|------|-----|
| 控件类型 | ConfigSetting |
| 标签 | "下限" |
| 默认值 | 0.0 |
| 范围 | 0 ~ 99999.0 |
| 单位 | 跟随测量单位 (px 或 mm) |
| 可见性 | 仅当启用公差判断 = ON 时显示 |

**判断逻辑：**

```
if (启用公差判断 == OFF)
    IsPass = true, Message = ""
else
    if (Distance >= 下限 && Distance <= 上限)
        IsPass = true, Message = "OK"
    else
        IsPass = false, Message = "NG: 距离超出公差范围"
```

## 八、执行流程

```
ExecuteTool() 调用链
    |
    +-- 第1步: 输入解析
    |       +-- 从 DataProvider 获取图像源 Mat (Tab1 的选择结果)
    |       +-- 解析点1: 按点模式从 ParamBinding 获取 Point2d 实例
    |       |           按坐标模式从 X/Y 输入创建 Point2d
    |       +-- 解析点2: 同上
    |       +-- 验证: 两个点都必须有效 (非 null, 坐标在有效范围内)
    |
    +-- 第2步: 计算测量值
    |       +-- DistancePixels = sqrt((x1-x2)^2 + (y1-y2)^2)
    |       +-- DeltaX = |x1 - x2|
    |       +-- DeltaY = |y1 - y2|
    |
    +-- 第3步: 单位转换
    |       +-- if (Unit == mm): Distance = DistancePixels * PixelCalibration
    |       +-- if (Unit == px): Distance = DistancePixels
    |
    +-- 第4步: 公差判断
    |       +-- if (IsToleranceEnabled == false): IsPass = true
    |       +-- else: IsPass = (Distance >= 下限 && Distance <= 上限)
    |
    +-- 第5步: 构建显示项
    |       +-- Clear() 清除上一帧显示
    |       +-- 添加两点连接线 (MeasureLineStyle)
    |       +-- 添加点1十字标记 (PrimitiveMarkerStyle)
    |       +-- 添加点2十字标记 (PrimitiveMarkerStyle)
    |       +-- 添加测量值文本 (MeasureValueStyle)
    |       +-- 添加点1坐标文本 (PrimitiveCoordTextStyle)
    |       +-- 添加点2坐标文本 (PrimitiveCoordTextStyle)
    |       +-- 添加 DX/DY 分量文本 (DeltaTextStyle)
    |
    +-- 第6步: 返回 MeasurementResults
            +-- Distance, DistancePixels, DeltaX, DeltaY
            +-- IsPass, Message
            +-- Point1, Point2
```

## 九、设计约束

### 9.1 必须遵守的规范

| 规范类别 | 要求 |
|----------|------|
| MVVM 架构 | UI 层不包含业务逻辑，所有执行逻辑在 Tool.Run() 中 |
| 属性通知 | 继承 ObservableObject/ViewModelBase，使用 SetProperty() |
| 日志系统 | ViewModel 用 LogInfo/LogError，Service 用 _logger.Log() |
| 命名规范 | PascalCase (类/方法/属性), camelCase (变量), _camelCase (私有字段) |
| 序列化 | System.Text.Json, PascalCase, [JsonPolymorphic] + [JsonDerivedType] |
| KISS 原则 | 选择最简单合理的实现方式 |

### 9.2 不需要的功能

| 功能 | 决策 | 原因 |
|------|------|------|
| ROI 区域设置 | 不实现 | 点点测量无需 ROI，基元来源已限定范围 |
| 多实例测量 | 不实现 | 只管一对点，不支持多对点批量测量 |
| 键盘快捷键 | 不实现 | 用户明确要求不支持 |
| 位置补正 | 不实现 | 测量工具非定位工具，应在工作流上层转换 |
| 角度输出 | 不实现 | 点点测量无角度概念（两点连线即是方向） |
