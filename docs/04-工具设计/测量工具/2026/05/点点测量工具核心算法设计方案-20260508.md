# 点点测量工具 (PointToPoint) 核心算法设计方案

> 版本: v1.0 | 日期: 2026-05-07 | 状态: 设计完成
> 工具类型: 测量工具
> 核心功能: 计算图像中两个点基元之间的欧氏距离，输出距离值和坐标分量

---

## 一、算法选型

### 1.1 候选方案对比

| 方案 | 计算公式 | 计算复杂度 | 实现难度 | 精度 | 适用场景 |
|------|----------|-----------|---------|------|---------|
| **A: 二维欧氏距离** | sqrt(dx^2 + dy^2) | O(1) | 低 | float64 | 标准图像坐标，最常用 |
| **B: 曼哈顿距离** | |dx| + |dy| | O(1) | 低 | float64 | 网格路径规划，不适用测量 |
| **C: 切比雪夫距离** | max(|dx|, |dy|) | O(1) | 低 | float64 | 棋盘距离，不适用测量 |
| **D: 三维欧氏距离** | sqrt(dx^2+dy^2+dz^2) | O(1) | 低 | float64 | 3D 测量场景，本项目不涉及 |

### 1.2 最终选择: 方案 A — 二维欧氏距离

```
Distance = sqrt((x1 - x2)^2 + (y1 - y2)^2)
```

**选择理由：**
1. **行业标准**: 欧氏距离是所有视觉测量软件（Halcon、VisionPro、VisionMaster）中点点测量的标准算法
2. **数学意义**: 对应两点之间的直线最短距离，物理意义明确直观
3. **计算高效**: O(1) 常数时间复杂度，仅需 1 次 sqrt + 2 次乘方 + 2 次减法
4. **扩展性强**: 结果可自然地转换为 DeltaX/DeltaY 分量输出
5. **对齐 Halcon 语义**: Halcon `distance_pp` 算子使用相同的欧氏距离公式

## 二、算法流程总览

```
+-------------------------------------------------------------------+
|              PointToPoint 核心算法执行流程                            |
+-------------------------------------------------------------------+
|                                                                     |
|   输入:                                                             |
|     Point2d P1 (x1, y1)   -- 来自绑定或手动输入的基元1             |
|     Point2d P2 (x2, y2)   -- 来自绑定或手动输入的基元2             |
|     MeasureConfig          -- 测量配置 (单位/像素当量/公差等)       |
|                                                                     |
|    +-- Step 1: 输入验证 -----------------------------------------+  |
|    |                                                               |  |
|    |   条件: P1 和 P2 都必须为非空, 坐标值必须在有效范围内          |  |
|    |   无效时: 返回 Distance=0, DeltaX=0, DeltaY=0,                |  |
|    |            IsPass=false, Message="无效的输入基元"               |  |
|    +---------------------------------------------------------------+  |
|                               |                                      |
|                               v                                      |
|    +-- Step 2: 计算 DeltaX / DeltaY ------------------------------+  |
|    |                                                               |  |
|    |   DeltaX = |x1 - x2|    (x方向分量的绝对值)                    |  |
|    |   DeltaY = |y1 - y2|    (y方向分量的绝对值)                    |  |
|    |                                                               |  |
|    +---------------------------------------------------------------+  |
|                               |                                      |
|                               v                                      |
|    +-- Step 3: 计算像素距离 -------------------------------------+  |
|    |                                                               |  |
|    |   DistancePixels = sqrt(DeltaX^2 + DeltaY^2)                  |  |
|    |                                                               |  |
|    |   注: 使用 Math.Sqrt(double) 计算,                              |  |
|    |   返回 float64 精度                                           |  |
|    +---------------------------------------------------------------+  |
|                               |                                      |
|                               v                                      |
|    +-- Step 4: 单位转换 -----------------------------------------+  |
|    |                                                               |  |
|    |   if (Unit == mm)                                             |  |
|    |       Distance = DistancePixels * PixelCalibration            |  |
|    |   else                                                        |  |
|    |       Distance = DistancePixels                               |  |
|    +---------------------------------------------------------------+  |
|                               |                                      |
|                               v                                      |
|    +-- Step 5: 数值舍入 -----------------------------------------+  |
|    |                                                               |  |
|    |   DecimalPlaces = 用户配置 (1~4)                               |  |
|    |   Distance = Math.Round(Distance, DecimalPlaces)              |  |
|    |   DeltaX = Math.Round(DeltaX, DecimalPlaces)                   |  |
|    |   DeltaY = Math.Round(DeltaY, DecimalPlaces)                   |  |
|    +---------------------------------------------------------------+  |
|                               |                                      |
|                               v                                      |
|    +-- Step 6: 公差判断 -----------------------------------------+  |
|    |                                                               |  |
|    |   if (IsToleranceEnabled == false)                            |  |
|    |       IsPass = true, Message = "OK"                           |  |
|    |   else                                                        |  |
|    |       if (Distance >= ToleranceLower &&                        |  |
|    |           Distance <= ToleranceUpper)                          |  |
|    |           IsPass = true, Message = "OK"                       |  |
|    |       else                                                    |  |
|    |           IsPass = false                                      |  |
|    |           Message = "NG: 距离值超出公差范围"                   |  |
|    +---------------------------------------------------------------+  |
|                               |                                      |
|                               v                                      |
|    +-- Step 7: 输出结果 -----------------------------------------+  |
|    |                                                               |  |
|    |   输出:                                                       |  |
|    |     Distance: double    (当前单位的测量值)                     |  |
|    |     DistancePixels: double (原始像素距离)                     |  |
|    |     DeltaX: double     (X方向分量)                            |  |
|    |     DeltaY: double     (Y方向分量)                            |  |
|    |     Point1: Point2d    (基元1原始坐标)                        |  |
|    |     Point2: Point2d    (基元2原始坐标)                        |  |
|    |     IsPass: bool       (判断结果)                             |  |
|    |     Message: string    (判断消息)                             |  |
|    +---------------------------------------------------------------+  |
|                                                                     |
+-------------------------------------------------------------------+
```

## 三、核心算法详解

### 3.1 输入验证

输入验证是算法的前置条件检查，确保后续计算使用的数据有效。

**验证规则：**

```
规则1: P1 != null && P2 != null
    +--> 失败: 返回 IsPass=false, Message="点基元为 null"

规则2: P1.X, P1.Y, P2.X, P2.Y 均为有效浮点数
      (!double.IsNaN && !double.IsInfinity)
    +--> 失败: 返回 IsPass=false, Message="点基元坐标无效"

规则3: 点1和点2非重合 (DistancePixels > 0)
    +--> 警告但不阻断: Distance=0 但视为有效结果
    +--> Message="警告: 两点坐标重合"
```

### 3.2 DeltaX / DeltaY 分量计算

DeltaX 和 DeltaY 是两个重要的辅助输出量，分别表示两点在 X 和 Y 方向上的距离分量。

**数学定义：**

```
DeltaX = |x1 - x2|    (取绝对值)
DeltaY = |y1 - y2|    (取绝对值)
```

**物理意义：**

```
                      DeltaX
              |<----------------->|
              |                   |
              |   P1 (x1, y1)     |
              |       +           |
              |        \          |
              |         \         | DeltaY
              |          \        |
              |           \       |
              |            +      |
              |        P2 (x2, y2)|
              |                   |
              +-------------------+

    DeltaX: 两点在 X 方向上的投影距离
    DeltaY: 两点在 Y 方向上的投影距离
    Distance: 两点之间的欧氏距离 (直线距离)
    
    三者关系: Distance^2 = DeltaX^2 + DeltaY^2
```

**特殊说明：**

- DeltaX 和 DeltaY 始终为正数（取绝对值），不携带方向信息
- 当两点在一条水平线上时: DeltaY = 0, Distance = DeltaX
- 当两点在一条垂直线上时: DeltaX = 0, Distance = DeltaY
- 当两点重合时: DeltaX = DeltaY = Distance = 0

### 3.3 欧氏距离计算

**标准公式：**

```
Step 1: dx = x1 - x2              (double 精度)
Step 2: dy = y1 - y2              (double 精度)
Step 3: dxSquared = dx * dx       (double 精度)
Step 4: dySquared = dy * dy       (double 精度)
Step 5: DistancePixels = Math.Sqrt(dxSquared + dySquared)
```

**数值稳定性考量：**

```
场景1: dx 和 dy 数量级差异很大
    例如: dx = 0.001, dy = 1000.0
    dx^2 = 1e-6, dy^2 = 1e6
    float32 精度无法区分 dx^2 的贡献 -> 需要 float64 (double)
    保障: C# Math.Sqrt 使用 float64, 精度足够

场景2: dx 和 dy 都非常大
    例如: dx = 50000, dy = 50000 (大分辨率图像)
    dx^2 + dy^2 = 5e9, 在 double 范围内安全
    保障: double 可安全表示 2^53 (~9e15) 以内的整数

场景3: dx 和 dy 都非常小
    例如: dx = 1e-10, dy = 1e-10 (亚像素精度)
    dx^2 = 1e-20, sqrt 结果 = ~1.414e-10
    保障: double 最小正数为 5e-324, 完全安全
```

**与 Halcon 对比：**

| 项 | Halcon distance_pp | 本方案 |
|----|-------------------|--------|
| 公式 | sqrt((row1-row2)^2 + (col1-col2)^2) | sqrt((x1-x2)^2 + (y1-y2)^2) |
| 坐标系 | 行列 (row, col) | 图像 (x, y) |
| 精度 | double | double (Math.Sqrt) |
| 返回值 | 距离值 | Distance + DeltaX + DeltaY |
| 单位 | 像素 | 像素 + 可选毫米转换 |

### 3.4 单位转换

**转换规则：**

```
if (Unit == MeasurementUnit.Millimeter)
{
    Distance = DistancePixels * PixelCalibration;
    // PixelCalibration 单位为 mm/px
    // 例如 PixelCalibration = 0.05, 即每像素对应 0.05mm
}
else // Unit == Pixel (默认)
{
    Distance = DistancePixels;
    // 直接使用像素值
}
```

**像素当量验证：**

```
输入: PixelCalibration (double)

验证:
    if (PixelCalibration <= 0)
    {
        记录警告 "像素当量必须大于 0, 当前值为 {PixelCalibration}"
        PixelCalibration = 1.0  // 回退到像素单位
    }

说明:
    PixelCalibration 的值通常通过标定流程获得:
    - 使用标定板拍摄已知物理尺寸的物体
    - 计算公式: 像素当量 = 实际物理尺寸(mm) / 像素尺寸(px)
    - 例如: 10mm 对应 200px -> 像素当量 = 10/200 = 0.05 mm/px
```

**转换精度说明：**

| 场景 | 像素当量值 | 影响 |
|------|-----------|------|
| 理想标定 | 0.05 (精确值) | 测量误差 0% |
| 标定误差 1% | 0.0505 (含 1% 误差) | 测量值偏差 1% |
| 像素当量由变量绑定 | 来自工作流变量 | 精度取决于上游标定工具的输出 |

### 3.5 数值舍入

舍入操作影响最终的显示和公差判断。

```
decimalPlaces = Math.Clamp(DecimalPlaces, 1, 4);

Distance = Math.Round(Distance, decimalPlaces, MidpointRounding.AwayFromZero);
DeltaX   = Math.Round(DeltaX,   decimalPlaces, MidpointRounding.AwayFromZero);
DeltaY   = Math.Round(DeltaY,   decimalPlaces, MidpointRounding.AwayFromZero);
DistancePixels = Math.Round(DistancePixels, decimalPlaces, MidpointRounding.AwayFromZero);
```

**舍入策略：**

| 项 | 选择 | 原因 |
|----|------|------|
| 舍入方式 | AwayFromZero | 四舍五入，符合视觉行业显示习惯 |
| 保留位数 | 1~4 (用户可配) | 默认 2 位小数 |
| 中间值 | 0.005 -> 0.01 | ToEven 会得到 0.00, AwayFromZero 得到 0.01 |

### 3.6 公差判断

```
+-- 公差判断详细逻辑 -------------------------------------------+
|                                                                 |
|  输入:                                                          |
|    Distance: double            (舍入后的最终距离值)              |
|    IsToleranceEnabled: bool    (公差判断开关)                    |
|    ToleranceLower: double      (公差下限, 含该值)               |
|    ToleranceUpper: double      (公差上限, 含该值)               |
|                                                                 |
|  伪代码:                                                        |
|  if (!IsToleranceEnabled)                                       |
|  {                                                              |
|      IsPass = true;                                             |
|      Message = "OK (未启用公差判断)";                           |
|      return;                                                    |
|  }                                                              |
|                                                                 |
|  if (ToleranceLower > ToleranceUpper)                           |
|  {                                                              |
|      // 配置错误, 交换上下限                                    |
|      Swap(ref ToleranceLower, ref ToleranceUpper);               |
|      Message = "警告: 下限大于上限, 已自动交换";                |
|  }                                                              |
|                                                                 |
|  if (Distance >= ToleranceLower && Distance <= ToleranceUpper)   |
|  {                                                              |
|      IsPass = true;                                             |
|      Message = "OK";                                            |
|  }                                                              |
|  else                                                           |
|  {                                                              |
|      IsPass = false;                                            |
|      if (Distance < ToleranceLower)                             |
|          Message = "NG: 距离 {Distance:F2} < 下限 {ToleranceLower:F2}"; |
|      else                                                       |
|          Message = "NG: 距离 {Distance:F2} > 上限 {ToleranceUpper:F2}"; |
|  }                                                              |
|                                                                 |
+-----------------------------------------------------------------+
```

**边界条件测试用例：**

| 距离值 | 下限 | 上限 | 预期结果 |
|--------|------|------|---------|
| 50.00 | 0.00 | 100.00 | OK |
| 0.00 | 0.00 | 100.00 | OK (边界值, 含下限) |
| 100.00 | 0.00 | 100.00 | OK (边界值, 含上限) |
| 100.01 | 0.00 | 100.00 | NG (超出上限) |
| -0.01 | 0.00 | 100.00 | NG (低于下限, 负距离理论上不发生) |

## 五、精度与边界分析

### 5.1 精度分析

| 阶段 | 数据类型 | 理论精度 | 实际影响 |
|------|---------|---------|---------|
| 原始输入 | double | ~15-17 位有效数字 | 取决于上游工具输出精度 |
| 减法 (x1-x2) | double | 可能发生 catastrophic cancellation | 当两点非常接近时精度下降 |
| 平方 (dx*dx) | double | ~15 位有效数字 | 安全 |
| 开方 (Math.Sqrt) | double | ~15 位有效数字, 1 ulp 精度 | IEEE 754 保证 |
| 舍入 | double -> double | 精确到指定小数位 | 用户可控 |

### 5.2 边界条件分析

```
场景 A: 两点完全重合
    输入: P1=(100,200), P2=(100,200)
    计算: dx=0, dy=0, Distance=0, DeltaX=0, DeltaY=0
    结果: 距离为 0, 提示警告

场景 B: 两点在水平线上
    输入: P1=(100,200), P2=(500,200)
    计算: dx=400, dy=0, Distance=400, DeltaX=400, DeltaY=0
    结果: Distance = DeltaX, DeltaY = 0

场景 C: 两点在垂直线上
    输入: P1=(100,200), P2=(100,600)
    计算: dx=0, dy=400, Distance=400, DeltaX=0, DeltaY=400
    结果: Distance = DeltaY, DeltaX = 0

场景 D: 两点非常接近 (微米级)
    输入: P1=(100.001, 200.002), P2=(100.003, 200.001)
    计算: dx=0.002, dy=0.001
          Distance = sqrt(4e-6 + 1e-6) = sqrt(5e-6) = 0.002236...
    结果: 亚像素距离, 精度保持

场景 E: 超大图像 (40K x 40K)
    输入: P1=(0, 0), P2=(40000, 40000)
    计算: dx=40000, dy=40000
          Distance = sqrt(1.6e9 + 1.6e9) = sqrt(3.2e9) = ~56568.5
    结果: double 可安全表示, 无溢出风险

场景 F: 像素当量转换
    输入: DistancePixels=56568.5, PixelCalibration=0.05
    计算: Distance = 56568.5 * 0.05 = 2828.425
    舍入: Distance = 2828.43 (小数位=2)
    结果: 约 2828.43 mm
```

## 六、性能预估

### 6.1 单次执行耗时

| 步骤 | 操作 | 预估耗时 |
|------|------|---------|
| 输入验证 | 4 次浮点判断 | < 0.001 us |
| DeltaX/DeltaY | 2 次减法 + 2 次 Abs | < 0.001 us |
| 欧氏距离 | 2 次乘法 + 1 次 Sqrt | < 0.01 us |
| 单位转换 | 1 次乘法 | < 0.001 us |
| 舍入 | 4 次 Round | < 0.01 us |
| 公差判断 | 2 次比较 | < 0.001 us |
| 合计 | | < 0.02 us |

### 6.2 性能特征

| 指标 | 值 |
|------|-----|
| 单次执行耗时 | < 0.02 us (微秒级) |
| 每秒可执行次数 | > 50,000,000 次 |
| 内存分配 | 无 (纯计算, 只使用栈内存) |
| 与图像分辨率关系 | 无关 (仅操作坐标值) |
| 与区域面积关系 | 无关 (仅操作坐标值) |

**结论：** 点点测量的算法计算开销可以忽略不计，整体工具执行性能主要取决于上游基元获取环节（如图像预处理、基元检测等）。

### 9.1 框架复用

点点测量的核心算法作为 `MeasureCalculator` 静态类中的方法实现，供所有测量工具调用：

```
|                                                                 |
|  ComputePointToPoint(Point2d p1, Point2d p2):                   |

|                    double upper): (bool, string)                |

+-----------------------------------------------------------------+
```

点点测量的计算结果统一包装为 `MeasurementResults`，与框架中其他测量工具共享同一输出类型。
