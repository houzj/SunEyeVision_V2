# 点线测量工具 UI 设计方案

## 1. 概述

点线测量工具用于计算二维平面上一个点到一条直线的垂直距离（或最小距离）。用户通过选择或定义点与线的输入方式，获取点与线之间的精确距离值，同时输出垂足坐标等辅助信息。该工具适用于定位精度检测、边缘对齐校验、装配间隙测量等视觉检测场景。

工具整体布局采用标准三选项卡结构，与 SunEyeVision 平台其他测量工具保持一致的交互范式。


## 2. 功能总览

工具包含三个选项卡，按操作流程从左至右排列：

+-----------------------------+-----------------------------+-----------------------------+
|   基本参数                   |   测量参数                   |   结果显示                   |
|  (Tab1 - 输入配置)          |  (Tab2 - 计算配置)          |  (Tab3 - 输出展示)          |
+-----------------------------+-----------------------------+-----------------------------+
| 输入图像源选择               | 方向类型                     | 结果判断（Pass/Fail）        |
| 点输入方式配置               | 测量单位                     | 图形叠加显示                 |
| 线输入方式配置               | 像素当量标定                 | 数值文本显示                 |
+-----------------------------+-----------------------------+-----------------------------+


## 3. Tab1 - 基本参数

基本参数选项卡是用户配置测量输入的首要步骤，包含图像源选择、点输入配置和线输入配置三个功能区域。

### 3.1 输入图像

使用 ImageSourceSelector 组件包裹在 LabeledControl 中用于选择输入图像源。LabeledControl 的标签文字为 "输入图像"。用户从下拉列表中选择当前工程中已有的图像源（如相机采集、图像文件加载或上游工具的输出图像）。

### 3.2 点输入

点输入区域通过 RadioButton 提供两种模式：

#### 模式一：按点

用户从下拉选择器中选择上游工具输出的点对象（如圆心点、角点、Blob 中心点等）。选择器右侧提供链接按钮，点击后进入 "点链接模式"——用户点击图像上的某个点对象，自动将对象 ID 回填到选择器中。这是推荐的默认输入方式，支持动态数据流传递。

#### 模式二：按坐标

用户直接输入 X 和 Y 坐标值（浮点数，单位像素）。坐标输入框支持正负数。可选 "从图像点选" 复选框，勾选后用户可在图像预览区域点击选取坐标，选取的坐标自动回填到 X/Y 输入框中。

### 3.3 线输入

线输入区域通过 RadioButton 提供两种模式：

#### 模式一：按线

用户从下拉选择器中选择上游工具输出的线对象（如直线拟合工具输出的线段、边缘检测提取的直线等）。选择器右侧提供链接按钮，功能与点输入的链接按钮类似，进入 "线链接模式"。

#### 模式二：按参数

用户直接输入直线方程 Ax + By + C = 0 的三个参数 A、B、C。其中 A 和 B 不能同时为零。输入框提供基本的输入校验。A 和 B 通常归一化处理，但用户也可以输入任意值，工具内部自动进行归一化计算。


## 4. Tab2 - 测量参数

测量参数选项卡配置距离计算的相关参数和输出显示格式。

Tab2 的布局结构如下：

+------------------------------------------------------------------+

|                                                                  |
|  ---------------------------------------------------------------- |

|  小数位数:                                                        |
|    [____]  范围: 0 ~ 6, 默认: 3                                  |

|    [O] 绝对值范围 (下限 <= 距离 <= 上限)                          |
|    [ ] 标称值+偏差 (标称值 +/- 偏差)                              |
|                                                                  |
+------------------------------------------------------------------+

### 4.1 方向类型

提供两种距离计算方式：

- **垂直距离（默认）**：计算点到直线的垂直距离，即点到直线的法线距离。使用公式 distance = |Ax0 + By0 + C| / sqrt(A^2 + B^2)。

- **最小距离**：如果线输入有端点限制（线段而非无限直线），则计算点到线段的最短距离。当垂足落在线段范围内时与垂直距离相同，否则取点到两个端点的距离中的较小值。

### 4.2 测量单位

- **像素（px）**：距离以图像像素为单位输出。
- **毫米（mm）**：距离以物理毫米为单位输出，需要配合像素当量进行换算。

### 4.3 像素当量

当测量单位选择 mm 时，像素当量输入框启用。用户可手动输入像素当量值（浮点数，单位 px/mm），或从标定文件加载标定数据。

距离换算公式：Distance_mm = Distance_px / CalibrationValue

### 4.4 小数位数

控制所有测量数值的显示精度，取值范围 0~6，默认值 3。该值影响测量值、坐标值等所有数值的输出格式。

### 4.5 公差判断

公差判断区域默认折叠，用户点击展开后配置：

- **启用公差**：复选框，默认关闭。开启后根据公差值判断测量结果是否合格。
- **上限**：距离允许的最大值（含边界）。
- **下限**：距离允许的最小值（含边界）。
- **公差类型**：
  - 绝对值范围：直接指定上下限，适用于有明确的合格区间要求的场景。
  - 标称值+偏差：输入标称值 N 和偏差 D，自动计算上限 N+D 和下限 N-D，适用于对标称位置有偏差容忍的场景。

判断规则：
  - 距离测量值在下限到上限范围内（含边界）时 IsPass = true
  - 超出范围时 IsPass = false
  - 未启用公差时 IsPass 始终为 true

### 5.1 结果判断区

在 Tab3 顶部以大号字体显示判断结果：

- **通过**：背景绿色，文字白色，同时显示测量值。
- **不通过**：背景红色，文字白色，同时显示测量值和超出公差的提示信息。

如果未启用公差，始终显示 "通过" 状态，测量值正常显示。

### 5.2 图形显示区

在图像预览区域上叠加绘制测量相关的图形元素。所有图形元素通过平台的 GraphicsLayer 机制绘制，支持缩放和平移联动。

| 输入点标记 | 黄色 (Yellow) | 实心圆 | 输入点位置以黄色实心圆点标记，直径 6-8 像素 |

## 6. 错误处理与边界情况

### 6.1 输入验证

工具在运行前执行以下输入验证：

- 图像源为空：提示 "请选择输入图像源"，中止测量。
- 点未定义：提示 "请输入或选择测量点"，中止测量。
- 线未定义：提示 "请输入或选择测量线"，中止测量。
- 直线参数无效：如果 A 和 B 同时为零，提示 "直线参数无效，A 和 B 不能同时为零"，中止测量。
- 像素当量为零或负值：提示 "像素当量必须为正数"，中止测量。

### 6.2 运行时异常

- 点坐标超出图像范围：发出警告但继续计算，以物理意义为准。
- 直线与图像不相交：不影响计算，直线在数学上无限延伸。
- 输入对象被删除或无效：提示 "输入对象不可用，请重新选择"，中止测量。


## 7. 参数序列化

参数以 Json 格式序列化保存到 Recipe 中。序列化字段清单：

字段路径：
  Params.InputImage          字符串  - 输入图像源 ID
  Params.PointMode           整数    - 0=按点, 1=按坐标
  Params.PointObjectID       字符串  - 点对象选择器中的对象 ID
  Params.PointX              浮点数  - 按坐标模式的 X 值
  Params.PointY              浮点数  - 按坐标模式的 Y 值
  Params.PointPickFromImage  布尔值  - 是否启用图像点选
  Params.LineMode            整数    - 0=按线, 1=按参数
  Params.LineObjectID        字符串  - 线对象选择器中的对象 ID
  Params.LineA               浮点数  - 按参数模式的 A 值
  Params.LineB               浮点数  - 按参数模式的 B 值
  Params.LineC               浮点数  - 按参数模式的 C 值
  Params.DirectionType       整数    - 0=垂直距离, 1=最小距离
  Params.Unit                整数    - 0=px, 1=mm
  Params.CalibrationValue    浮点数  - 像素当量值 (px/mm)
  Params.DecimalPlaces       整数    - 小数位数 0~6
  Params.ToleranceEnabled    布尔值  - 是否启用公差
  Params.ToleranceUpper      浮点数  - 公差上限
  Params.ToleranceLower      浮点数  - 公差下限
  Params.ToleranceType       整数    - 0=绝对范围, 1=标称值+偏差
  Params.ToleranceNominal    浮点数  - 标称值（公差类型=1 时有效）
  Params.ToleranceDeviation  浮点数  - 偏差值（公差类型=1 时有效）


## 8. 输出数据结构

工具输出数据对象 PointToLineResult 包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| Distance | double | 测量距离（以当前选定单位） |
| DistancePixels | double | 以像素为单位的距离值 |
| PointCoord | Point2d | 输入点的坐标 |
| FootCoord | Point2d | 垂足点坐标 |
| LineParams | Tuple(A,B,C) | 直线方程参数 |
| IsPass | bool | 测量是否合格 |
| Message | string | 测量状态消息 |


## 9. 与平台集成

- **数据流**：工具输入输出通过平台的数据流引擎与其他工具连接。点和线对象可以从上游工具获取。
- **可视化**：图形叠加通过平台的 GraphicsLayer API 实现，确保与图像缩放平移联动。
- **结果记录**：测量结果可通过平台的数据记录模块导出到文本文件或数据库。
- **校准管理**：像素当量可通过平台的校准管理器统一管理，支持全局标定和工具级局部标定。
