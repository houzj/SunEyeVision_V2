# 点线测量工具核心算法设计方案

## 1. 概述

点线测量工具的核心算法是计算二维平面上一个给定点到一条给定直线的垂直距离。该算法是计算机视觉和几何测量中最基础的操作之一，广泛应用于定位精度检测、边缘对齐校验、装配间隙测量等工业视觉场景。

本设计方案详细描述点到直线距离的数学原理、计算步骤、单位换算机制、公差判断逻辑以及程序实现细节。


## 2. 数学原理

### 2.1 直线的一般式方程

在二维平面中，直线使用一般式方程表示：

    Ax + By + C = 0

其中 A、B、C 为直线参数，A 和 B 不能同时为零。该表示方式能够描述平面上的任意直线（包括垂直和水平直线），且在距离计算中具有直接的代数便利性。

向量 (A, B) 是直线的法向量，其方向即为点到直线的最短距离方向。

### 2.2 点到直线的垂直距离公式

给定点 P(x0, y0) 和直线 L: Ax + By + C = 0，点 P 到直线 L 的垂直距离为：

    distance = |A * x0 + B * y0 + C| / sqrt(A ^ 2 + B ^ 2)

公式推导过程：

    1) 直线 Ax + By + C = 0 的法向量为 n = (A, B)
    2) 在直线上取一点 Q，向量 QP = (x0 - xq, y0 - yq)
    3) 点 P 到直线的距离 = |n . QP| / |n|
    4) 代入直线方程中点的关系，化简得到上述公式

其中分子 |A*x0 + B*y0 + C| 的几何意义是点 P 代入直线方程后的绝对值，分母 sqrt(A^2 + B^2) 是法向量的长度。

### 2.3 垂足坐标计算

垂足 F(xf, yf) 是从点 P 向直线 L 作垂线的垂足点，其计算公式为：

    t = -(A * x0 + B * y0 + C) / (A ^ 2 + B ^ 2)

    xf = x0 + A * t
    yf = y0 + B * t

推导过程：

    1) 垂线的方向向量与直线法向量 n = (A, B) 平行
    2) 垂线的参数方程: (x, y) = (x0, y0) + t * (A, B)
    3) 垂足在直线上，满足直线方程: A * xf + B * yf + C = 0
    4) 代入 xf, yf: A*(x0 + A*t) + B*(y0 + B*t) + C = 0
    5) 求解 t: t = -(A*x0 + B*y0 + C) / (A^2 + B^2)
    6) 回代得到垂足坐标

垂足坐标和距离的几何关系如下：

                P(x0, y0)          (输入点)
                  .
                   .
                    .  (垂线，与法向量方向平行)
                     .
                      .
    ---F(xf, yf)----.--------------------------- (直线 L: Ax+By+C=0)
         (垂足)

    距离 d 即为线段 PF 的长度。

### 2.4 线段最小距离

当输入直线实际为有限线段（起点 Ps, 终点 Pe）而非无限直线时，需要计算点到线段的最小距离：

    1) 计算点 P 到无限直线的垂足 F
    2) 判断垂足 F 是否在线段 PsPe 上（通过参数 t 判断）
    3) 如果 F 在线段上，最小距离 = 垂直距离
    4) 如果 F 不在线段上，最小距离 = min(distance(P, Ps), distance(P, Pe))

点到线段最小距离的几何意义：

    情况 A: 垂足在线段内
      P
       \
        \  (垂线)
         \
     Ps---F---Pe
      距离 = 垂直距离

    情况 B: 垂足在线段起点外侧
          P
         /
        /  (垂线延长线)
       /
    --F---Ps--------Pe
      距离 = distance(P, Ps)

    情况 C: 垂足在线段终点外侧
    Ps--------Pe---F
                   \
                    \  (垂线延长线)
                     \
                      P
      距离 = distance(P, Pe)


## 3. 算法实现步骤

算法的完整实现分为以下几个阶段：

### 3.1 输入阶段

接收来自工具配置的输入数据：

    输入:
      - 点 P: (PointCoord.X, PointCoord.Y)       -- 浮点数坐标
      - 直线参数: (LineA, LineB, LineC)           -- 直线方程 Ax+By+C=0
      - 输入类型: DirectionType (垂直距离/最小距离)
      - 测量单位: Unit (px/mm)
      - 像素当量: CalibrationValue (px/mm)
      - 小数位数: DecimalPlaces (0~6)
      - 公差配置: ToleranceEnabled, ToleranceUpper, ToleranceLower

### 3.2 计算阶段

#### Step 1: 归一化直线参数

为了计算的数值稳定性和后续处理便利性，首先对直线参数进行归一化：

    norm = sqrt(A ^ 2 + B ^ 2)

    如果 norm 接近零（小于 1e-10）:
        报告 "直线参数无效" 错误，终止计算

    A_norm = A / norm
    B_norm = B / norm
    C_norm = C / norm

归一化后的 (A_norm, B_norm) 是单位法向量，距离公式简化为：

    distance = |A_norm * x0 + B_norm * y0 + C_norm|

#### Step 2: 计算垂直距离

    numerator = A_norm * PointCoord.X + B_norm * PointCoord.Y + C_norm
    distancePixels = abs(numerator)

此时 distancePixels 的单位是像素，因为所有坐标值以像素为单位。

#### Step 3: 计算垂足坐标（使用归一化参数）

    t = -(A_norm * PointCoord.X + B_norm * PointCoord.Y + C_norm)

    footX = PointCoord.X + A_norm * t
    footY = PointCoord.Y + B_norm * t

注意：此处使用归一化参数后，公式中的分母为 1，因为 A_norm^2 + B_norm^2 = 1。

#### Step 4: 线段最小距离（可选）

    如果 DirectionType == 最小距离 且 线输入为线段:
        计算线段参数 t_line:
          t_line = ((footX - LineStart.X) * (LineEnd.X - LineStart.X)
                  + (footY - LineStart.Y) * (LineEnd.Y - LineStart.Y))
                 / LineLengthSquared

        如果 t_line < 0:  垂足在线段起点外侧
          距离 = math.sqrt((Px - Lsx)^2 + (Py - Lsy)^2)
        如果 t_line > 1:  垂足在线段终点外侧
          距离 = math.sqrt((Px - Lex)^2 + (Py - Ley)^2)
        如果 0 <= t_line <= 1: 垂足在线段上
          距离 = distancePixels (垂直距离)

### 3.3 单位转换阶段

根据用户配置的测量单位进行转换：

    如果 Unit == mm (毫米):
        distanceOutput = distancePixels / CalibrationValue
    否则 (像素):
        distanceOutput = distancePixels

    其中 CalibrationValue > 0，单位 px/mm。

### 3.4 精度控制阶段

对所有输出数值应用小数位数控制：

    formatValue(value, decimalPlaces) = round(value, decimalPlaces)

涉及的数值包括：距离值、点坐标、垂足坐标、直线参数。

### 3.5 公差判断阶段

    如果 ToleranceEnabled == false:
        IsPass = true
        Message = "测量完成（公差未启用）"

    否则:
        如果 ToleranceType == 绝对值范围:
            IsPass = (ToleranceLower <= distanceOutput <= ToleranceUpper)
        否则 (标称值+偏差):
            实际下限 = ToleranceNominal - abs(ToleranceDeviation)
            实际上限 = ToleranceNominal + abs(ToleranceDeviation)
            IsPass = (实际下限 <= distanceOutput <= 实际上限)

        如果 IsPass:
            Message = "测量完成，结果合格"
        否则:
            Message = "测量完成，结果超差"


## 4. 输出数据定义

### 4.1 输出结构

    class PointToLineResult:
        Distance:      double    # 测量距离（转换后单位）
        DistancePixels: double   # 像素距离值（始终以像素为单位）
        PointCoord:    Point2d   # 输入点坐标 (X, Y)
        FootCoord:     Point2d   # 垂足坐标 (X, Y)
        LineParams:    Line2d    # 直线参数 (A, B, C)
        IsPass:        bool      # 结果是否合格
        Message:       string    # 状态消息

### 4.2 输出值与来源映射

    +------------------+---------------------------------------------+
    | 输出字段          | 来源                                         |
    +------------------+---------------------------------------------+
    | Distance          | distanceOutput (经单位转换和小数控制)         |
    | DistancePixels    | distancePixels (原始像素距离，应用小数控制)   |
    | PointCoord        | 直接使用输入点坐标                           |
    | FootCoord         | 计算所得 (footX, footY)                      |
    | LineParams        | 输入的直线参数 (A, B, C)                     |
    | IsPass            | 公差判断结果                                 |
    | Message           | 状态描述字符串                               |
    +------------------+---------------------------------------------+


## 5. 边界情况与容错处理

### 5.1 输入验证矩阵

    +---------------------------+----------------------------------------------+
    | 输入条件                   | 处理方式                                      |
    +---------------------------+----------------------------------------------+
    | A 和 B 同时为零            | 直线无效，中止计算，返回错误消息                |
    | 点坐标包含 NaN/Infinity   | 中止计算，返回 "点坐标无效" 错误               |
    | 像素当量 <= 0             | 中止计算（mm 模式下），返回 "像素当量无效" 错误 |
    | 小数位数不在 0~6 范围     | 默认使用 3                                     |
    | 距离值极小（< 1e-10）     | 视作零距离，点恰好在直线上                      |
    | 公差上限 < 下限           | 自动交换上下限                                  |
    +---------------------------+----------------------------------------------+

### 5.2 数值稳定性

    1) 当直线参数 A 和 B 数值很大时，先归一化再计算，避免浮点溢出
    2) 使用 double 精度（64位浮点数），满足亚像素精度要求
    3) 比较操作使用 epsilon 容差：EqualEpsilon = 1e-10
    4) 圆整操作使用标准 Banker 舍入（MidpointRounding.ToEven）


## 6. 与 Line2d.DistanceToPoint 的关系

项目中 Line2d 类型已提供 DistanceToPoint() 方法，该方法实现了点到直线距离的基础计算。点线测量工具算法与此方法的关系如下：

### 6.1 直接复用

    算法核心距离计算直接调用 Line2d.DistanceToPoint():
        Line2d line = new Line2d(A, B, C)
        double distancePixels = line.DistanceToPoint(pointCoord)

    Line2d.DistanceToPoint() 内部实现应与本方案第 2 节描述的数学公式一致。

### 6.2 工具层扩展

    在 Line2d.DistanceToPoint() 基础之上，点线测量工具额外提供：

    1) 垂足坐标计算 (Line2d 可能尚未提供，需在工具层实现)
    2) 线段最小距离计算（扩展逻辑）
    3) 单位转换机制
    4) 公差判断逻辑
    5) 输出格式化和消息生成
    6) 图形叠加数据生成（用于 UI 显示）


## 7. 算法流程伪代码

    算法: PointToLineMeasure

    输入:
      pointCoord: Point2d
      lineParams: (A, B, C)
      config: MeasurementConfig

    输出:
      result: PointToLineResult

    步骤:
      1. 验证输入有效性
         if (lineParams.A == 0 AND lineParams.B == 0):
           返回错误 "无效直线参数"

         if (pointCoord 包含无效值):
           返回错误 "无效点坐标"

      2. 创建 Line2d 对象
         line = Line2d(lineParams.A, lineParams.B, lineParams.C)

      3. 计算距离（利用 Line2d.DistanceToPoint）
         distancePixels = line.DistanceToPoint(pointCoord)

      4. 计算垂足
         footCoord = ComputeFootPoint(pointCoord, line)

      5. 如需线段最小距离，重新计算
         if (config.directionType == MIN_DISTANCE AND line 存在端点):
           distancePixels = ComputeMinDistanceToSegment(
               pointCoord, lineStart, lineEnd)

      6. 单位转换
         if (config.unit == MM):
           distance = distancePixels / config.calibrationValue
         else:
           distance = distancePixels

      7. 舍入控制
         distance = Round(distance, config.decimalPlaces)
         distancePixels = Round(distancePixels, config.decimalPlaces)

      8. 公差判断
         isPass = CheckTolerance(distance, config)

      9. 构造输出
         result = PointToLineResult(
           Distance = distance,
           DistancePixels = distancePixels,
           PointCoord = pointCoord,
           FootCoord = footCoord,
           LineParams = lineParams,
           IsPass = isPass,
           Message = 根据 isPass 生成对应消息
         )

      10. 返回 result


## 8. 性能分析

### 8.1 计算复杂度

    点到直线距离计算的时间复杂度为 O(1)，仅涉及常数次数的浮点运算：
      - 归一化: 1 次开方, 3 次除法
      - 距离: 3 次乘法, 2 次加法, 1 次绝对值
      - 垂足: 2 次乘法, 2 次加法
      - 合计约 15~20 次浮点运算

### 8.2 内存消耗

    工具不涉及动态内存分配，所有计算基于栈上分配的结构体：
      - 输入结构: 约 40 字节
      - 临时变量: 约 40 字节
      - 输出结构: 约 48 字节

### 8.3 适用场景

    该算法适用于高速实时检测场景，单次测量可在微秒级完成。
    支持在 10000+ FPS 的帧率下进行逐帧点线测量。

### 9.3 输入点标记数据

    位置 = PointCoord
    形状 = 实心圆

### 9.4 直线绘制数据

    直线: Ax + By + C = 0
    颜色 = 青色 (Cyan)

## 10. 校准与标定

### 10.1 像素当量来源

    1) 手动输入: 用户直接输入已知的像素当量值
    2) 标定文件加载: 从平台的校准文件中加载标定数据
    3) 上游工具传递: 从上游标定工具的结果中获取当量值

### 10.2 校准精度要求

    像素当量的精度直接影响物理距离测量的准确性:
      - 推荐使用至少 4 位有效数字的标定值
      - 标定误差应控制在 1% 以内
      - 对高精度测量场景，建议使用 0.1% 精度的标定

      直线: 2x + 3y - 6 = 0
