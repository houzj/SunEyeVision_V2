> 版本: v1.0
> 日期: 2026-08-24
> 状态: 设计完成（作为测量工具链③ 沟通基线）
> 对标: Halcon distance_pp/pl/pc/ll/lc/cc / VisionPro CogDistancePointPointTool 家族
> 定位: 六个测量（P2P/P2L/P2C/L2L/L2C/C2C）合并为**一个**几何测量工具
> 依赖: ① 位置检测 + ② 边缘检测（提供几何对象）→ 本工具（计算）

---

## 一、定位与职责

几何测量工具是测量工具链的**第三个环节（计算）**，绑定上游① ② 提供的几何对象（Point2d/Line2d/Circle2d），计算两点/点线/点圆/线线/线圆/圆圆之间的距离或角度，输出测量值 + 公差判断。

```
① 位置检测 → ② 边缘检测 → Line2d/Circle2d → [③ 几何测量] → 距离/角度 + OK/NG
```

**一个工具，六种测量**：通过 `MeasureType` 枚举切换，避免六个独立工具（对齐项目"每工具一项目"但几何测量内部高度同构）。

### 3.2 共享测量基类（SDK 新增）

**位置**：`src/Plugin.SDK/Execution/Parameters/MeasurementParameters.cs`

```csharp
[JsonPolymorphic]
public abstract class MeasurementParameters : ToolParameters
{
    public MeasurementUnit Unit;        // Pixel / Mm
    public double CalibrationValue;     // 像素当量 px/mm
    public bool ToleranceEnabled;
    public double ToleranceUpper;
    public double ToleranceLower;
    public int DecimalPlaces = 3;

    public double ToDisplay(double pixelValue)
        => Unit == Mm ? pixelValue * CalibrationValue : pixelValue;
}
```

### 3.4 输入绑定设计（关键）

输入1/输入2 通过 `ParamValue<object>` 绑定几何对象。**按 MeasureType 动态确定 targetType**，数据源类型过滤由 `GetAvailableDataSources(nodeId, targetType)` 实现（`DataSourceQueryService.cs:248-271` 已验证）：

| MeasureType | Input1 类型 | Input2 类型 |
|-------------|------------|------------|
| P2P | Point2d | Point2d |
| P2L | Point2d | Line2d |
| P2C | Point2d | Circle2d |
| L2L | Line2d | Line2d |
| L2C | Line2d | Circle2d |
| C2C | Circle2d | Circle2d |

**绑定 UI**：输入1/输入2 各用绑定选择器（类似 ImageSourceSelector），按 `MeasureType` 传对应 `targetType` 过滤数据源。

### 3.5 六种测量公式（对齐 Halcon）

| 类型 | 公式 | Halcon 算子 |
|------|------|------------|
| P2P | `p1.DistanceTo(p2)` | `distance_pp` |
| P2L | `line.DistanceToPoint(p)` + 垂足 | `distance_pl` |
| P2C | `p.DistanceTo(c.Center) - c.Radius`（有符号：内负外正） | `distance_pc` |
| L2L | `l1.AngleTo(l2)` 夹角；平行时 `l1.DistanceToPoint(l2.StartPoint)` | `angle_ll` / `distance_ll` |
| L2C | `c.Center` 到 `l` 距离 - `c.Radius` | `distance_lc` |
| C2C | `c1.Center.DistanceTo(c2.Center)` | `distance_cc` |

### 3.6 核心执行逻辑

```csharp
public GeometryMeasureResults Run(GeometryMeasureParameters p)
{
    var result = new GeometryMeasureResults();

    // 解析输入几何对象（绑定或手动坐标）
    var input1 = ResolveInput(p.Input1, p.MeasureType, 1);
    var input2 = ResolveInput(p.Input2, p.MeasureType, 2);

    // 计算距离/角度（px）
    double pixel = p.MeasureType switch
    {
        MeasureType.P2P => ((Point2d)input1).DistanceTo((Point2d)input2),
        MeasureType.P2L => ((Line2d)input2).DistanceToPoint((Point2d)input1),
        // ... 其余类型同理
    };

    // 单位换算 + 公差判断
    result.DistancePixels = pixel;
    result.Distance = p.ToDisplay(pixel);
    result.IsPass = !p.ToleranceEnabled
        || (result.Distance >= p.ToleranceLower && result.Distance <= p.ToleranceUpper);
    result.Message = result.IsPass ? "OK" : "NG";

    result.SetSuccess();
    return result;
}
```
