# 几何测量工具集（6 独立工具）设计方案

> 版本: v1.0（收敛版）
> 日期: 2026-09-07
> 状态: 设计完成（历轮澄清收敛，待实施）
> 覆盖: 点-点 / 点-线 / 点-圆 / 线-线 / 线-圆 / 圆-圆 测量
> 定位: 工具栏"测量"分组 6 张工具卡，引擎无关，仅依赖 SDK
> 演进: 与 `2026-08-24` 单工具六测量合并方案的取向不同（本版为 6 独立工具，架构零新增）

## 一、用户功能性视角

### 改前用户看到什么
测量点距 / 点线距 / 线线夹角 / 圆心距等几何量，需要手写脚本或串多个检测工具再人工换算；无统一 UI、无 OK/NG 判定、无可视化，调机慢。

### 改后用户看到什么
工具栏新增 **"测量"** 分组，含 6 张工具卡。每张卡有 **固定 2 个几何输入**，支持 **订阅**（绑上游几何输出或按参数定义）与 **绘制**（图上手画）双模式；测量值配上下限出 OK/NG，并叠加辅助线 / 文本可视化。

### 解决了哪些功能性问题
1. 几何关系测量无需脚本，开箱即用
2. 几何输入既可从任意上游工具取，也可手动放置，覆盖全场景
3. 测量值直接参与流程判级（OK/NG），与现有工具判定一致
4. 纯像素输出，物理单位交给专用"坐标转换"工具，职责单一

### 依据（业界对标）
| 决策 | 依据 | 引用 |
|------|------|------|
| 6 独立测量工具卡形态 | VisionMaster "测量"分组（点线/线线/圆测量…） | 用户附图 + CSDN 线线测量实操 + Hikrobot VM 官网 |
| 距离/角度语义 | Halcon `distance_pp/pl/pc/ll/lc/cc`、`angle_ll` | VisionMaster 实操文档 |
| 引擎无关分层 | 对称架构：HalAdapter ↔ CvAdapter 成对实现区域栅格化 | `CvRegionBridge.cs` 与 `ToolRegionHelper.cs` 并存 |

## 二、需求决策锁定（历轮确认汇总）

| # | 决策点 | 最终结论 |
|---|---|---|
| D1 | 工具数量/形态 | 6 张**独立工具卡**，`Category="测量"`，各自独立 csproj |
| D2 | 几何输入结构 | 每工具**固定 2 个几何输入**（2 个"卡尺槽"） |
| D3 | 几何输入模式 | **订阅 / 绘制** 两种顶级模式（RadioButton 切换） |
| D4 | 订阅内部 | 二分：**按图形类型**（整体绑上游同类型几何输出）＋ **按图形参数**（逐参数定义，坐标只是参数的一部分） |
| D5 | 点输入约束 | **点一律只走绑定**（无绘制）——点来自各种上游输出，无固定卡尺可画 |
| D6 | 线/圆/弧输入 | 支持**订阅 + 绘制**（有几何形态，可在图上放置） |
| D7 | OK/NG 判定 | **需要**：测量值配上下限 → `IsPass`，沿用 `ResultConfig` 范式 |
| D8 | 输出单位 | **纯像素**；像素→物理由独立"坐标转换"工具负责 |
| D9 | 算法实现 | **纯 C# 几何运算**（SDK 几何类型自带方法），不调 Halcon/OpenCV 算子 |
| D10 | 代码组织 | 6 个**独立完整工程**（对齐现有 12 工具形态） |
| D11 | 共享层 | **不新建任何共享工程/不动 SDK/不动 adapter**——几何测量引擎无关，只依赖 SDK 已有能力 |
| D12 | 引擎解耦 | 区域栅格化类操作已由 HalAdapter / CvAdapter **成对隔离**（`ToolRegionHelper` ↔ `CvRegionBridge`），换 CV 后端只换 adapter 实现，工具零改动 |

## 三、架构结论（核心）

### 3.1 几何测量工具 = "SDK 纯几何层"工具

```
上游检测工具（任意引擎，Halcon 现在 / OpenCV 未来）
        │  输出同一套 SDK 几何契约
        ▼
Line2d[] / Circle2d[] / Point2d[]   ← SdkTypeVocabulary 词汇表已注册
        │  ParamBinding / OutputVariableResolver 寻址
        ▼
几何测量工具（引擎无关，纯数学）
        │
        ▼
double 测量值 + OK/NG + 可视化叠加
```

- 工具只引 `SunEyeVision.Plugin.SDK`（`<Private>false</Private>`），**不引 HalAdapter/CvAdapter/halcondotnetxl**
- 换 OpenCV 后端：测量工具**零改动**

### 3.2 平台共享能力映射（全部已有，零新增）

| 需要的共享能力 | 已有设施 | 来源 |
|---|---|---|
| 几何模型+数学运算 | `Models/Geometry/{Line2d,Circle2d,Point2d,Arc2d}.cs` | `Line2d.cs:135-199` |
| 绘制/订阅/参数化 双模式输入模型 | `RoiData` + `ShapeParameters`/`FixedRoi`/`ComputedRoi` | `RoiData.cs:215-274` |
| 订阅值寻址 | `OutputVariableResolver` / `ParameterSource` | `OutputVariableResolver.cs:24-140` |
| 几何参数解析（三种模式→数值） | `RoiResolver.Resolve` | `RoiResolver.cs:72-105` |
| 参数基类（图像源/位置修正/区域） | `RoiParameters` | `RoiParameters.cs:39-290` |
| 纯几何辅助 | `GeometryToolkit` | `GeometryToolkit.cs:13-73` |
| 显示收集器/可视化 | `DisplayCollector`（AddLine/Circle/Text） | `DisplayCollector.cs:44-151` |
| 结果基类+属性映射 | `ToolResults` + `GetPropertyMap()` | `ToolResults.cs:529` |
| 工具注册/序列化 | `[Tool]` + `[JsonDerivedType]` | `ToolAttribute.cs` |

### 3.3 区域类共享（像素域）为何不在本方案内

本工具**不做像素域处理**（无检测区栅格化需求），因此不依赖 `ToolRegionHelper` 的 `BuildROI`。若未来工具需要"区域内测量"，再以 RoiParameters 的 Inspection/Mask 接入——那时通过 SDK 契约解耦，Hal/Cv 各自适配。

## 五、几何输入数据模型（复用 RoiData，不新造）

### 5.1 每工具参数类

```csharp
[JsonDerivedType(typeof(PointLineMeasureParameters), "PointLineMeasure")]
public class PointLineMeasureParameters : RoiParameters   // 复用图像源/位置修正/序列化基座
{
    public RoiData GeometryA { get; set; }   // 点：仅订阅（FixedRoi/ComputedRoi）
    public RoiData GeometryB { get; set; }   // 线：订阅（FixedRoi/ComputedRoi）或绘制（ShapeParameters）
    public PointLineResultConfig ResultConfig { get; set; }   // 上下限 OK/NG
    public GeometryDisplayStyle GeometryAStyle { get; set; }  // 图形显示样式
    public GeometryDisplayStyle GeometryBStyle { get; set; }
    public TextStyle MeasureTextStyle { get; set; }           // 测量值文本样式
}
```

- **订阅-按图形类型** → `RoiData.Parameters = FixedRoi(sourceNodeId, outputName)`（绑上游 `Line`/`Circle`/`Point` 词目）
- **订阅-按图形参数** → `RoiData.Parameters = ComputedRoi` + `ParameterBindings`（每个参数绑上游标量或手输常量）；点几何的 X/Y、线几何的起止坐标、圆几何的圆心+半径均为"参数"
- **绘制** → `RoiData.Parameters = ShapeParameters`（Geometry=Line2d/Circle2d/Arc2d…）

### 5.2 运行解析（Run 内）

```csharp
var resolver = new RoiResolver(parameters.CreateParameterContext(nodeResults));
var geoA = resolver.Resolve(parameters.GeometryA);   // → ResolvedRegion（IsValid/CenterX.../StartX...）
var geoB = resolver.Resolve(parameters.GeometryB);
if (!geoA.IsValid) throw ...; if (!geoB.IsValid) throw ...;   // Fail-Fast (rule-015)
// 依据 ResolvedRegion.ShapeType + 数值字段组装 Point2d/Line2d/Circle2d
```

`ResolvedRegion` 已覆盖全部字段：CenterX/Y、Radius、StartX/Y、EndX/Y、Angle、Start/EndAngle、Points（`RoiResolver.cs:15-67`）。

### 5.3 UI 绑定参数行（按图形参数）用 SDK 控件

每参数行 = `手输常量 | 绑上游标量` 二选一。默认对齐 `ConfigSetting`/`ParamBinding` 的通用交互（数值框 + 数据源按钮）；第一版实现细节决策见 §十 开放点 #2。

## 七、算法方案（纯 C#，逐工具）

Run 统一模板（每工具独立实现，内容极薄）：

```csharp
public LineLineMeasureResults Run(LineLineMeasureParameters parameters)
{
    var result = new LineLineMeasureResults { ToolName=..., ToolId=..., Timestamp=... };
    var sw = Stopwatch.StartNew();
    try
    {
        // 1) 解析两几何（RoiResolver + 修正矩阵）
        // 2) 组装 Line2d/Line2d
        // 3) 按测量类型计算：
        //    夹角 = lineA.AngleTo(lineB)          [Line2d.cs:186-191]
        //    间距 = lineA.DistanceToPoint(起点投影) + 平行判定
        // 4) ResultConfig.IsInRange → IsPass
        // 5) FillDisplay：几何A/B + 角弧/间距标注 + 测量文本
        result.SetSuccess(sw.Elapsed.TotalMilliseconds);
    }
    catch (Exception ex) { result.SetError(ex.Message, ex); }
    return result;
}
```

关键点：**无图像依赖**——Run 不调用 `GetHalconImage()`/`GetCvImage()`，仅几何参数即可出值（这也是引擎无关的根源）。输入图像仅作为调试窗口背景叠加参考。

## 八、输出契约

```csharp
public class LineLineMeasureResults : ToolResults
{
    public double MeasurementValue { get; set; }   // 主测量值（像素/度）
    public double AuxValue { get; set; }           // 辅助量（如平行间距/圆周距）
    public bool IsPass { get; set; }               // OK/NG
    public Line2d GeometryA { get; set; }          // 回显（图形显示）
    public Line2d GeometryB { get; set; }
    public Point2d[] VisualPoints { get; set; }    // 辅助标注（垂足/角点等，可选）
    public override List<PropertyMapEntry> GetPropertyMap()
        => [ .. base.GetPropertyMap(),             // 必须合并基类"执行耗时"
             new("MeasurementValue", "测量值", "测量结果"),
             new("AuxValue", "辅助值", "测量结果"),
             new("IsPass", "判定结果", "测量结果"),
             new("GeometryA", "几何A", "输入几何"),
             new("GeometryB", "几何B", "输入几何") ];
}
```

`ToolResults` 输出变量契约自动派生，绑定树/条件工具可直接消费 `MeasurementValue`/`IsPass`（词汇表已有 `Double`/`Boolean`/`Line` 词目）。
