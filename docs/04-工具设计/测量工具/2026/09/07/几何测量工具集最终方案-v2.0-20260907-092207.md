## 0. 用户功能性视角

### 改前用户看到什么
测量点距 / 点线距 / 线线夹角 / 圆心距等几何量，需要手写脚本或串多个检测工具再人工换算；无统一 UI、无 OK/NG 判定、无可视化，调机慢。

### 改后用户看到什么
工具栏新增 **"测量"** 分组，含 6 张工具卡。每张卡**固定 2 个几何输入（卡尺1/卡尺2）**，**默认绘制模式**在图上直接画线/圆测量；也可订阅上游几何输出。测量值配上下限出 OK/NG，并叠加辅助线 / 文本可视化。

### 解决了哪些功能性问题
1. 几何关系测量无需脚本，开箱即用
2. 几何输入既可从任意上游工具取（订阅），也可手动放置（绘制），覆盖全场景
3. 测量值直接参与流程判级（OK/NG），与现有工具判定一致
4. 纯像素输出，物理单位交给专用"坐标转换"工具，职责单一

### 依据（业界对标）
| 决策 | 依据 | 引用 |
|------|------|------|
| 6 独立测量工具卡形态 | VisionMaster "测量"分组（点线/线线/圆测量…） | 用户附图 + CSDN 线线测量实操 + Hikrobot VM 官网 |
| 距离/角度语义 | Halcon `distance_pp/pl/pc/ll/lc/cc`、`angle_ll` | VisionMaster 实操文档 |
| 引擎无关分层 | 对称架构：HalAdapter ↔ CvAdapter 成对实现区域栅格化 | `CvRegionBridge.cs` 与 `ToolRegionHelper.cs` 并存 |

| D2 | 几何输入结构 | 每工具**固定 2 个卡尺**（几何槽），类型由工具决定 |

## 2. 架构结论

### 2.1 几何测量工具 = "SDK 纯几何层"工具

```
上游检测工具（任意引擎，Halcon 现在 / OpenCV 未来）
        │  输出同一套 SDK 几何契约
        ▼
Line2d[] / Circle2d[] / Point2d[]   ← SdkTypeVocabulary 词汇表已注册
        │  ParamBinding / OutputVariableResolver 寻址
        ▼
几何测量工具（引擎无关，纯数学）
        │
        ▼
double 测量值 + OK/NG + 可视化叠加
```

- 工具只引 `SunEyeVision.Plugin.SDK`（`<Private>false</Private>`），**不引 HalAdapter/CvAdapter/halcondotnetxl**
- 换 OpenCV 后端：测量工具**零改动**

### 2.3 工具层唯一新增件：双卡尺编辑器管理器

现有 `MeasurementEditorManagerControl` 只编排"1 引导 + 屏蔽"（`MeasurementEditorManagerControl.xaml.cs:19-26`），不支持双引导。因此工具层需新增轻量封装：

```
DoubleCaliperEditorManager（工具层薄封装，复用 MeasureEditorControl 无头 API）
├── Caliper1Editor : MeasureEditorControl   ← LockGeometryType(工具固定类型)
├── Caliper2Editor : MeasureEditorControl   ← LockGeometryType(工具固定类型)
├── 统一事件路由：同一时刻仅一个卡尺进入 Draw（互斥激活，防抢鼠标）

└── 复用无头 API：SetOverlayCanvas / ProcessMouseDown|Move|Up /
    RenderForManager / SetZoom / SetPositionCorrectionMatrix
```

> 放置策略：随首个含绘制工具（点-线测量）实现验证，供其余 5 工具复制（对齐现状：无共享库，生成期范式复制）。

## 3. 数据模型（每工具同构）

### 3.1 每工具参数类

```csharp
[JsonDerivedType(typeof(XxxMeasureParameters), "XxxMeasure")]
public class XxxMeasureParameters : RoiParameters   // 复用图像源/位置修正/序列化基座
{
    public RoiData GeometryA { get; set; }   // 卡尺1（类型固定：点/线/圆）
    public RoiData GeometryB { get; set; }   // 卡尺2
    public XxxMeasureResultConfig ResultConfig { get; set; }   // 上下限 OK/NG
    public GraphicsStyle GeometryAStyle { get; set; }  // 图形显示样式
    public GraphicsStyle GeometryBStyle { get; set; }
    public GraphicsStyle MeasureLineStyle { get; set; } // 辅助线样式
    public TextStyle MeasureTextStyle { get; set; }     // 测量值文本样式
}
```

- **订阅-按图形类型** → `RoiData.Parameters = FixedRoi(nodeId, outputName)`（绑上游 `Line`/`Circle`/`Point` 词目）
- **订阅-按图形参数** → `RoiData.Parameters = ComputedRoi` + `ParameterBindings`（逐参数绑上游标量或手输常量）；点=X/Y、线=起止坐标、圆=圆心+半径均为"参数"
- **绘制** → `RoiData.Parameters = ShapeParameters`（Geometry=Line2d/Circle2d/Arc2d…）

### 3.2 运行解析（Run 内）

```csharp
var resolver = new RoiResolver(parameters.CreateParameterContext(nodeResults));
var geoA = resolver.Resolve(parameters.GeometryA);   // → ResolvedRegion（IsValid/CenterX.../StartX...）
var geoB = resolver.Resolve(parameters.GeometryB);
if (!geoA.IsValid) throw ...; if (!geoB.IsValid) throw ...;   // Fail-Fast (rule-015)
// 依据 ResolvedRegion.ShapeType + 数值字段组装 Point2d/Line2d/Circle2d
```

`ResolvedRegion` 已覆盖全部字段：CenterX/Y、Radius、StartX/Y、EndX/Y、Angle、Start/EndAngle、Points（`RoiResolver.cs:15-67`）。

## 6. 算法方案（Run 模板）

```csharp
public XxxMeasureResults Run(XxxMeasureParameters p)
{
    var result = NewResult(p);
    try {
        var geoA = Resolve(p.GeometryA) ?? throw new InvalidOperationException("卡尺1 未配置或解析无效");
        var geoB = Resolve(p.GeometryB) ?? throw new InvalidOperationException("卡尺2 未配置或解析无效");
        var (value, aux) = ComputeMeasurement(geoA, geoB);   // 纯 SDK 几何方法
        result.MeasurementValue = value;
        result.AuxValue = aux;
        result.IsPass = p.ResultConfig.IsInRange(value);
        FillDisplay(result, p, geoA, geoB);   // 几何 + 辅助线 + 文本
        result.SetSuccess(durationMs);
    } catch (Exception ex) { result.SetError(ex.Message, ex); }
    return result;
}
```

关键点：**无图像依赖**——Run 不调用 `GetHalconImage()`/`GetCvImage()`，仅几何参数即可出值（引擎无关根源）。输入图像仅作调试窗口背景叠加参考。
