差异定性（三条）
① 设计差异（首次慢根因）：本方把算法库装载推迟到首次执行且无预热；VM 算法在 C++ Server 常驻、有 MVD 预热机制。
② 设计差异（每次成本）：本方每批 new 执行引擎 + 每节点 new 会话/快照；VM 模块常驻，运行只发请求。
③ 实现+栈差异（Blob 慢）：本方每 blob 多次 HALCON 算子往返、全部特征无条件计算、4 次区域深拷贝；VM C++ 一次遍历算完。

维度本方VM差异性质可优化性
启动：壳与重活分离壳先显示 + 遮罩 + 后台初始化启动画面线程 + BeforeStartPart 并行相当—
启动：依赖校验准入阶段对 275MB 依赖做 SHA256（含不装载的 HALCON）无此机制（原生链接）本方额外成本可做校验结果缓存
启动：算法库装载延迟到首次执行算法在 Server/C++ 常驻设计差异预热可解
启动：预热无（日志 Pre warm skipped）MVD 预热 + 加载后静默执行设计差异可补（后台预热）
启动：CPU/GC 策略无特殊处理CPU 亲和配置 + 周期 GC 定时器本方缺视需要
执行：引擎/对象生命周期每批 new 引擎、每节点 new 会话/快照模块常驻，运行只发请求设计差异可复用引擎

执行：结果发布每次重建 publication + 场景 + 表（同身份短路）回调 + 常驻渲染池实现差异部分可优化
