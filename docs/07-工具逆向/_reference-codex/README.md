## 二、关键警告：这些页面描述的不是我方状态

Codex 工具页里的「当前实现与差异」章节，描述的是 **VisionReplica** 项目的 JSON 目录与实现状态（例如「无当前 ModuleId 映射」「分析优先级 deferred」）。

**它与我方 SunEyeVision 的现状无关。** 直接拿这些页面向他人说明我们的进度会造成误导。

正确用法：

- ✅ 用它查「原件有什么、在哪、证据是什么」
- ✅ 用它的 `originalEvidence` 与 SHA-256 溯源到具体程序集与行号
- ❌ 不要引用它的「当前实现」章节当作我方现状
- ❌ 不要把它的页面链接放进我方主导航

我方自己的对照页在 `../pages/`，由 `scripts/tool-reverse/generate-pages.ps1` 从卡片数据生成，「当前实现」章节只写我方真实状态。

## 三、怎么打开

直接用浏览器打开 `site/index.html`，或从 `site/工具/` 里按工具名找页面。文件名格式 `<分类>-<模块名>-<hash>.html`。

页面之间的相对链接依赖本目录的完整结构，**不要单独移动某个页面**，否则链接与样式引用会断。

## 四、与我方卡片的关系

Codex 的 162 张工具卡（`../../tools/`）与这里的 163 个页面是同源的：卡片是数据，页面是渲染。

我方页面**不复用**这两者的「当前实现」内容，只复用「原件事实」部分。
