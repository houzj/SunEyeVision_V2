候选0x1800084B0 / 0x180007CE0
去向
对象+0x50指针 → 虚表+0x40；分开接口状态/业务结果/输出长度
已记录行为
0x84B0借两个helper检查对象+0x50所含首指针，空时返回E0000001；非空helper取该指针，空指针helper调用带80004003的异常函数。桥接把原第六输出指针的低32位读到局部int，连同命令、payload与原第五值交0x7CE0，原第四参数在此按32位搬运。0x7CE0通过接口虚表+0x40调用，并另传初始0的局部业务结果地址作为第七参数；EAX接口状态按有符号负值转异常helper，正常返回局部业务结果。0x84B0再把局部int长度符号扩展为64位写回原第六指针，并返回业务结果。故接口调用状态、业务返回码和长度输出是三个值，不能把任何一个0直接画为全流程执行完成。

VMGlobalScript.GlobalScript.HandleMsg

DLL模式门 → GlobalManager.HandleCmd / 4002 → StartOnce
