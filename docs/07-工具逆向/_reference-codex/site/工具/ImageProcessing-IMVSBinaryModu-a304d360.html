已记录行为
ImageBinaryPlugin非partial类只声明IVisionToolPlugin及两个WPF editor接口，IVisionToolPlugin自身不继承显示能力接口。RefreshRight的sources仅接IToolImageListProvider/IToolImageOutputProvider；当前二值化不进入该自动图像源列表。RefreshSelectedImageSourcePreview按所选来源的results及指定port找图，再有限回退文件预览，并非按任意选中算子取图。RefreshToolDisplay只把IToolDisplayProvider当provider，二值化走null分支，清通用presenter后显示普通Preview。主窗另在Preview.MouseLeftButtonDown且图像Tab/Preview.Source非null时调用InputImage(selected)，该函数实际从所选节点结果取首个图像输出并ToBitmap；名字InputImage不能被解释为图连线输入。因此自动源列表、通用frame和点击结果预览是三个不同入口，不能从Runtime输出Image自动连线到frame文字/几何呈现。
待分析项
此处证明当前源码的接口准入与独立鼠标路径，不是原版二值化主窗显示合同；未执行当前主UI、也未断言用户点击/切Tab实际差分。统一渲染能力若后续实施，应先核原二值化Display.xml及原图像源/显示对象身份，不能仅添加接口就声称等价。
