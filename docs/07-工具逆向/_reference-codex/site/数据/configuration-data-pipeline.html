OP01 · 原UserData[key] → 按Parent.ID普通键或动态复合键读写SDK界面数据

source-confirmed

UserData不是一个本地Dictionary。getter在Parent非活动或正在Dispose时返回null，否则调用SDK；setter在Parent为空或Dispose时直接返回。isUsedForDynamicUIParam决定路由：动态key用字面分隔符&?;?拆分，array[0]为名字、array[1]（若有）为optional，更多片段没有继续传递；普通路由传完整key和Parent.ID。Parent.IsDynamicModu控制撤销分支，是另一项判断，不能等同isUsedForDynamicUIParam。

OP02 · 原ModuleManager.SetUIParamValue / SetDynamicUIParamValue → 临时非托管字节副本 → native setter；空载荷改走删除

source-confirmed

两setter对非null且Length非0的byte[]按实际Length分配HGlobal并Marshal.Copy，传pointer和uint Length调用native；调用正常返回后FreeHGlobal，再检查返回码抛错。null和空数组都走对应删除方法，不能保存为可区分的零长度值。普通路由另有IsForbidden特殊分支：非null载荷先BytesToStruct<bool>再EnableModule，绕过一般UI键存储。

类型与复制：管理数组→独立临时HGlobal按Length复制；key的UTF8 custom marshaler与payload任意bytes是不同合同。

持有与失效：托管体调用后不保留HGlobal；native是否复制、如何保留以及setter何时提交到方案存储仍未知。

释放与失败边界：FreeHGlobal位于native正常返回后而非finally；native调用或Marshal.Copy抛异常时此体不保证走到Free。仅证明潜在异常路径，不宣称原机已泄漏。Delete成功只证明该SDK操作返回0，不证明所有历史副本已释放。

OP03 · 原普通/动态UserData读取 → native pointer+nDataLen → 新托管byte[]；正常尾请求释放返回块

source-confirmed

普通GetUIParamValueByKey成功时new byte[nDataLen]并在pData非0时Marshal.Copy；复制异常被吞，随后仍请求RELEASE_MEMORY_BASE_ARRAY，释放失败抛VmException。错误码-536870911返回null，其他非0抛错。动态ModuleManager getter经ServerSDKAPI展开：成功时同样按返回nDataLen新建数组及复制，但Release调用位于pData非0条件内，不能合并成同一无条件尾释放。动态wrapper将byte[]返回给调用者。

类型与复制：返回数组有nDataLen字节，是新分配的托管容器；这不证明内容语义正确，吞掉复制异常后仍可能返回未完整写入的数组。普通成功即使pData为0也会分配数组并请求Release；动态pData为0则不请求Release。

持有与失效：调用者可持有返回数组，SDK临时返回块与模型缓存不是同一持有者；重复读取可生成不同数组。

释放与失败边界：正常尾Release仅针对native返回块；托管数组继续由引用/GC决定寿命。分配等先行步骤抛异常时没有finally承诺，Release实际递归范围须native原体。

OP04 · 原UserData赋值 → 分支化撤销载荷持有，不是统一原子保存事务

independent-implementation

AdaptOldValue先调用adapt产生next，非同引用时先将OldValue=next，再ReleaseReplaced(previous)；AdaptNewValue同理且要求IsDataComplete。ReleaseReplaced失败把旧值加入retainedValues并重抛，因此适配失败不表示原payload仍是当前值。Release分别尝试OldValue、已捕获newValue和retainedValues，成功项设标志或移出；Root逐part聚合错误，Engine把失败Root加入retainedReleaseFailures。显式ReleaseRetainedPayloads才重试这些Root。

类型与复制：当前旧/新值、待释放旧值列表、根级失败保留列表分层持有；DocumentHistoryRoot/Part不是框架执行session。

持有与失效：View-only快照适配可保留缩放而替换快照载荷；失败Root仍保留未成功释放的payload，不把已切栈当全部文件释放完成。
