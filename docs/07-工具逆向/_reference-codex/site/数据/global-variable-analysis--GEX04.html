GEX04 · 原版 · 整数值：读取绑定描述指定的当前存储 → 按索引写目标

0x94700 逐索引调用 0x96fe0 取绑定值，再交 0x98630 写目标变量。0x96fe0 的描述种类 3 读取 +0x8c 来源模块 ID 与 +0x90 来源名，经 0xca500 按模块／名称／索引取值；种类 1 常量和种类 2 的另一来源分支另列，不用伪码 void 签名否认隐藏栈参数。0x98630 取目标模块记录后，经 0xf47f0 找名称值对象，再交 0xf3ee0。该叶体对负索引报错；已有索引直接向载荷 [+0x70 数组 +8+index*4] 写 4 字节，否则必要时扩容并在尾部追加，再增数量 +0x68。值在这里实际写入内部数组，不是仅转发指针。这些值读写 API 参数是模块、名称、索引、值／数量，所选路径未见全局 BatchId 或消费者要求的 ExecuteCount 参数。

这是选定整数绑定路径的静态合同，不把它外推为所有插件输入均调用同一函数；索引选择助手 0x99be0 与复杂订阅仍另需逐体核对。
