返回专题总览

GEX05 · 原版 · 独立整数读取：按名称、索引返回当前值及总数量

VM_M_GetGlobalVarInt 重排句柄、名称、索引、输出地址与数量地址到 0x127470；内部由句柄首 int 取模块键，进入 0xca500→0xf5f40。0xf5f40 取具名值对象后，从载荷 +0x68 读总数量，并从 [+0x70 指向数组 +8+index*4] 复制一个值到输出地址。负索引／超界返回错误，空记录另有错误。它读取的是本次调用时取得的存储，接口没有指定某轮的输入参数；这不单独证明上层调度是否另有配对。

不能把“读取当前存储”改称观察到并发旧值；未进行原机并发实验。
