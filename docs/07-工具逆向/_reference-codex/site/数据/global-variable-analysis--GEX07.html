GEX07 · 原版 · VmIO 执行计数检查属于结果读取，不是全局变量批次协议

VmIO.GetValue 在请求计数既非 uint.MaxValue、又不等于自身或 RelateIO.ExecuteCount，且来源不是 VmConstantIO 时，把 Value 清空并返回 null。get_Value 的关联输入可直接读 RelateIO.Value；其他分支在根流程计数与当前 IO 不一致且非 isSetCallBack 时调用 RefreshResult。这个托管 UI/结果合同不能代替原生算法订阅，更不能将 A 流程计数 N 自动视为 B 流程计数 N 的同一产品。

原件 CIL 对应 GetValue=0x0600052f、get_Value=0x0600051e；来源相等分支与 uint.MaxValue 绕过必须保留。
