VmProcedure.ContinuousRunEnable=true 先调 ContinousRunStart；false 先调 RefreshUIStopExecute，即使旧标志已为 false 也先进入 SDK。RefreshUIStopExecute 在 Task.Run 内调 StopExecute，只有正常返回才写完成位；外层 SyncWaitor.Wait 等待该位。StopExecute 调 IMVS_StopExecute_V30(handle,processID,3)。另已独立恢复 ModuleFrame.VM_M_StopRunProcedure→0x43cb0→0xdd030：选定普通流程分支发事件、写 +0x7c=0，调 0xda1c0 等 +0x88 句柄，普通分支 3000ms、另一参数分支无限；超时返回 0xe0000300。0xda1c0 的 WaitForSingleObject 调用点参数与返回分支另存汇编。SDK 导出到此 ModuleFrame 停止导出的桥未在本轮证实，因此两链不以同名合并。
