GEX10 · 自研 SunEye · 普通参数读取：本轮冻结的 __GlobalVars__ 合成结果

WorkflowRunRequest 复制字典容器；WorkflowExecutionEngine 为 RootContext 再建一份字典。每个算法节点执行前，ExecuteAlgorithmNode 从当前 Context.GlobalVariables 构造 GenericToolResults 并放到 __GlobalVars__。AlgorithmNode 把 NodeResults 与 GlobalVariables 交 ToolExecutor；普通参数路径由 ResolveRuntimeParameters→RuntimeParameterSnapshotResolver→ParameterResolver.ResolveDynamic→OutputVariableResolver 消费该合成结果。WorkflowContext.SetNodeResult 只写节点结果表，本身不回填 GlobalVariables。由这些已引用路径可知：建立同流程前置依赖，不能替代普通 __GlobalVars__ 参数的本轮值刷新；此处不宣称所有专用输入都存在同一问题。

同流程 __GlobalVars__ 生产消费需要独立执行探针；本次是源码差异定位，不将其写成已运行重现的故障。
