RunSolutionAsync 只把无生产绑定且有效的变量初值放进 runtimeGlobals，按生产／消费者依赖选就绪流程，每次 await 一条后 ApplyProducedGlobalValues。发布先移除该生产者旧值，节点成功且 Result.IsSuccess 才解析写入；失败不以设计初值补洞。整个流程失败仍可能发布其中成功节点的值。后继流程收到的是前面流程完成后形成的批次字典快照，设计期 GlobalVariables.Value 不被该方法写回。

这种批次私有顺序保证没有自动覆盖独立后台循环或全部单次 Task.WhenAll 入口；BatchId 字段本身尚非已实现合同。
