StartAllWorkflowsRun 通过 workflows.Select(RunSingleAsync) 后 Task.WhenAll；StartAllContinuousRun 则逐个 StartContinuousRun。两者均不是 RunSolutionAsync 的生产依赖批次循环。默认 ExecuteWorkflowInternal 从 globalVariablesOverride ?? _globalVariables 构造请求，SetGlobalVariables 仅保存传入字典引用。持续轮次创建新请求并复制容器，但“复制那一刻的种子字典”不等于已完成跨流程生产者输出发布。

没有据此断言其他项目路径永不更新 _globalVariables；已证的是这两入口不走引用的方案批次发布顺序。
