GEX15 · 自研 SunEye · 外层等待不等于所有子任务已退出：finally未等待running任务

就绪队列每轮检查取消，正常完成的节点写 Context.SetNodeResult；但该方法 finally 仅 foreach running 并 Dispose 资源租约，没有 await 剩余任务。外层 ExecuteWorkflowCore 捕获 OperationCanceledException 后返回取消结果，管理器因此可能结束本流程租约。静态条件路径：至少两个节点已启动，一个完成后返回循环，取消在下次循环检查被抛出，另一个尚未完成时进入上述 finally。于是 StopAndWaitAsync 等待的外层租约结束，不能单独证明所有工具子任务均已退出；这一选定私有队列路径现已通过合成工具运行重现，详见 GEX25；完整管理器、切方案和 UI 写回尚未运行验证。管理器 ExecuteWorkflowInternal 在 await 后更新展示快照；InvokeOnUI/InvokeOnUIAsync 的显式取消门取决于通信操作的 AsyncLocal token，不能推广成全局 SolutionEpoch 校验。

执行租约排空与 UI 队列／全局值发布代次校验是不同保证；本次未观察切方案后实际出现 UI 污染，不能把源码风险直接当已复现缺陷。
