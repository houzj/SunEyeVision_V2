返回专题总览

GEX16 · 原版 · 先区分存储，再谈“读哪一轮”

0x8e6c0 在参数为 0 的分支返回 key=0 的流程输出存储；0x8e910 返回静态全局存储 0x1802b2b50，两者不是同一个容器。但生产绑定的整数写入 0x98630 明确在全局门内调用 0xcae00(0x1802b2b50,变量模块ID)，再交 0xf47f0→0xf3ee0 更新具名值。消费者 0xbb4d0 通过 0xbcd20 识别选定来源后，优先读取同一个静态全局存储。因此该链靠绑定处理把流程输出的值写到全局记录，不要求两个容器共享记录。前一轮“还需共享记录才能连上”的疑问已由目的写入体和消费者分支消除；剩余重点是读写发生的先后及消费者是否被调度约束。

0x8e6c0 的非零上下文分支仍单列；本结论限于所取整数绑定与消费者分支，未推广到所有模式。
