0xbb4d0 在来源描述种类 3 分支读取生产模块 ID 与参数名，调用 0xbcd20 判断来源。0xbcd20 以模块 ID 经 0x10a720 找记录，仅当记录 +0x28 等于 10999 或 100000 时返回真。真分支进入门 0x1802b1208，先经 0x8e910→0xca500 读取静态全局记录；非零返回时再经 0x8e6c0(0)→0xca500 回退。假分支直接读流程存储。0xca500→0xf5f40 按模块、名称、索引和当时元素数量取值：整数有效索引读当前 4 字节；没有在该分支按消费者 ExecuteCount 或指定生产轮次检索历史版本。因而已成功发布且尚未被覆盖的值可在此读到；若消费者先于新发布运行，也没有这个读函数自身等待“本轮生产完成”的机制。

记录字段 +0x28 的比较、先读和回退已按原体确认；所有消费者入口与上层是否禁止跨轮读取，仍须从调度调用者核对。不能把无本地轮次检查扩写成整个产品没有同步。
