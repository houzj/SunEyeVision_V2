字符串读取路径 0x11d440 同样先按来源判断读全局或流程，但其全局失败回退排除了 0xE0000012；整数路径 0xbb4d0 则对非零返回执行回退。索引助手 0x124d40 也存在全局优先和失败回退。另一方面，种类 4 的绑定源读取 0x97d10 直接走 0x8e6c0(0)→0xcaa60；种类 5、6 的已恢复读者分别走 0xcaba0、0xcacd0，种类 7 走 0xca940。其目的写入 0x98ae0、0x98e00、0x99100、0x98950 则可见对静态全局记录取引用并调用各自写入成员。必须把“从生产输出取值”和“工具参数消费全局值”画成两种操作；读取来源、失败回退和复制细节逐路径保留。
