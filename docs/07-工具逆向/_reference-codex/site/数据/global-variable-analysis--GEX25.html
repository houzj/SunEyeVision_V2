GEX25 · 自研 SunEye · 实测：选定取消路径先返回，未响应取消的工具随后仍可完成副作用

探针在真实 ExecuteWorkflowWithReadyQueue 中并发启动两个声明 ExternalDataWait 的合成工具。慢工具已进入且等待探针闸门；快工具完成的 NodeExecutionFinished 回调发出取消。私有就绪队列抛出取消并返回时，慢工具尚未退出、迟到计数为 0；随后探针放开慢工具，它完成一次合成副作用，计数变为 1。与该方法 finally 仅 Dispose 剩余资源租约而不 await 任务的源码相符。该结果把“可能遗留运行任务”的静态条件推进为所选路径的运行重现，但不证明方案切换或 UI 已发生旧结果写回。

实际执行当前 Workflow/SDK 原体的有限路径，入口为私有就绪队列和节点执行方法；未运行 UI、方案管理器、切方案或全部连续入口。

合成工具由探针提供；迟到副作用是探针计数器，不是已经观察到产品界面或全局变量写回。

使用当前源码在 net10.0-windows 独立编译；不能冒充 net9.0-windows 发布产品的完整宿主等价。
