source-confirmed

OG06 · 输出处理失败与DoWork收尾 → 分开保存处理错误码、状态码和ModuStatus布尔值

source-confirmed

a7830继续遍历描述；在尚未捕获错误时，来源状态分类为3且来源记录存在、其工作状态不在0x75掩码允许集合时，复制该来源错误码与工作状态到本次错误/状态输出。汇编最终MOV EAX,R13D返回累计错误。DoWork收尾以其最终错误寄存器是否0写ModuStatus(index0)，把错误码写this+0x7c、另一个状态码写this+0x84，清this+0x1b8执行中标记，并另发布ModuRunTime。成功布尔、错误码与状态枚举不是一个字段。

本次局部错误、本次局部状态、this工作字段及模块输出值分开；返回0不构成所有来源/消费者都成功的证明。

失败体未见统一回滚前面已追加输出，不能以最终ModuStatus=false画成累积数据全部撤销。

收尾状态写入不等于结果仓销毁；本次描述节点退役见OG07。

待核：所有上游失败映射、mask中每个状态的名称、异常与取消的全路径未枚举；不由数值猜业务枚举语义。

GEC06 · WorkflowCalls.Validate与SolutionExecutor.Call → 普通Call单次执行，owned body循环执行与回传

independent-implementation

WorkflowCalls.Validate用active集合拒递归，核ProcedureId存在、当前签名等于保存Call接口；一般调用深度/展开有32/10000独立门，owned所有权另有三层限制。SolutionExecutor遇body.GroupOwner==null直接Execute一次；有owner才调用Group循环。父Graph把child保留到Calls，只有child.Success将WorkflowOutputs作为节点输出；失败回SubprogramFailed且节点输出Empty。嵌套helper仍可从Group输入显式收到LoopIndex，而不会自动成为另一个owned轮索引上下文。

Call metadata、owned parent身份、普通helper runtime session分开；返回是ExecutionSessionResult树及端口字典。

保留last session树与累计输出片段不同；Calls记录不等于保存每轮所有历史session。

调用返回不关闭整个solution scope；普通模块实例已在各Graph finally退役。

待核：普通helper中LoopIndex来源仅本矩阵源码可证明路径；实际3场景probe另在Group数据专题，不由此扩到所有调度分支。

GEC07 · Group正常结束/中断/失败/取消 → 末轮session改写聚合，父调用保留Calls但门控输出

independent-implementation

正常loop出口返回last或新Success空session，再with覆盖CompletedGroupIterations/GroupBroke/GroupBreakIndex/diagnostics/累积outputs与displays。零轮时last为null，Finish对可累积项产生空typed数组；成功break保留前轮节点记录。body返回非Success后先completed++再break，未Add该轮；返回状态仍取last，非累计输出可来自该last。父Graph收到child先存calls[id]，仅child.Success把WorkflowOutputs作为模块结果，否则输出Empty并SubprogramFailed。轮前Throw或Interval Delay抛取消会绕过Group最终聚合return，由父Graph catch/取消/超时门分类，不能宣称任何取消都保留部分累计结果。

最终Group session只保留last的Nodes/Calls等未被with覆盖字段；并不保存每轮完整session历史。

累积片段可包含此前Success轮，失败轮不加；但父调用失败时不向正常节点输出发布这些child值，Calls仍可持child诊断。

Graph finally对普通module先IAsyncDisposable后IDisposable；Dispose错误留error，之后才Record。scope租约与节点module实例是两种退出动作。

待核：超时/外部取消/Scope.Stopping涉及不同token，不能从一个分支推出所有race结果；本切片仅静态核顺序，没有新运行探针。
