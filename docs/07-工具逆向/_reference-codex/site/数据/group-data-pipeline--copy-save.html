GEC13 · CopyNodes/PasteNodes → CloneClipboardGroups → 递归克隆owned body与重映射ID

independent-implementation

CopyNodes保留来源solution/procedure/path与OwnedProcedures，粘贴先ResolveClipboardSources检查来源方案ID与图路径，并从当前source快照重新取仍存在且同名节点；PasteNodes为复制节点生成新ID，克隆参数/ROI与Call。CloneClipboardGroups递归给每个body及内部节点新Guid，写新的(parent,node) owner，并重映射内部配置/连接/执行边/GroupBreak，拒无owner与递归环。Edit再统一CloneOwnedCopies/PruneOwnedGroups，不能简单把旧body指针交给两个owner共享。

复制内部图结构及其ID映射；PortValue运行session不在GraphFragment复制合同里。

不是系统剪贴板已经存全部原native对象；来源已变时可能拒绝或回空片段。

事务后失去owner的body由PruneOwnedGroups递归移除，真正工具state清理由scope Retain/Remove生命周期另证。

待核：原ProcedurePaste的native对象/链接复制/回滚不以当前Guid重映射代替。
