GEC02 · MainWindow.EnterSubprogram / ReturnFromGroup → 守卫、选择body/父图及每根Tab显示位置

independent-implementation

真实WPF EnterSubprogram先拒绝Disabled/isLocked/activeRun；无Call或目标为owned body时EnterOwnedGroup，历史普通Call则SelectWorkflow。ReturnFromGroup在非Group、参数窗开着或activeRun时不动作；清手势/ghost/popup/选中节点与线，再doc.LeaveGroup按GroupOwner.ProcedureId返回父图。SelectWorkflow先RememberDisplayedWorkflow，再按根ID恢复显示body；不是把owned body另建顶层执行Tab。

CurrentProcedureId控制当前编辑图；displayedWorkflowContainers按root procedure ID保存当前显示容器ID。

Remember会删已失效root/body，Resolve复核body仍属于该root，失败移除并回root。

LeaveGroup只切当前ID并触发Changed，不销毁body、不Dispose其执行state。

待核：进入返回不是像素/缩放/搜索/树导航全部等价证明；运行模式界面继续保留待分析。
