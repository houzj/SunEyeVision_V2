GEO22 · DoWork每轮开始 → StartIndex/EndIndex/LoopIndex的第0项写入与严格上界

source-confirmed

GEC10 · GroupBreak.Evaluate与Resolve → 本轮索引/输入、前轮内部值与累计self分开读取

independent-implementation
