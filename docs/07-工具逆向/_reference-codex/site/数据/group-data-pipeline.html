进来的是一份配置，还是每轮重新读取？

当前SolutionExecutor先复制方案和节点参数；父节点解析输入后，多轮复用本次调用的输入值。每轮建立新的GraphExecutor和WorkflowRunContext，scope里的跨轮状态另有自己的持有关系。

前一轮、累积结果和最后一轮是三份不同的视图

当前last只指最后一次执行返回的session；累积仓收集成功轮的PortValue引用。Finish新建汇总容器，里面的值、图像是否复制，要按具体工厂和类型判断。

中断、失败、取消要分开看

当前break在执行本轮之前判断；失败轮已执行并计入completed，但不加入成功累积。取消可能在轮前或间隔抛出，绕过通常的Group汇总返回，不能统一当成“已清理并发布最后结果”。

模块结束后，结果仍可能持有数据

当前普通模块在GraphExecutor的finally退役；返回的session、Group累积、scope状态和显示投影分别保留引用。Dispose模块不是已经释放全部图像或最后读者的证明。

CG10 · 每轮scope.Enter/ForProcedure与solution关闭 → 跨轮state/有效参数持有，closing后等租约再释放
