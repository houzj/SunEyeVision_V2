具体可配置路线：本地灰度图 → 缓存图像 → 硬阈值 → 结果 → 显示

这是按当前源码核对的配置路线，非本轮运行实测。前提为本地图像源成功输出GrayImage、缓存数量大于0且刷新成功、连接正确、硬阈值模式1及合法参数/ROI。其它模式和输入格式有各自分支。

  1. ImageSource.Image → ImageBuffer.InputImage

    上游结果的PortValue/图像引用进入工具输入；缓存刷新时才复制像素。

  2. ImageBuffer.OutImage0Image → ImageBinary.Image

    选最旧缓存槽；通用IMAGE声明不保证每一轮实际都是GrayImage，缓存混合格式时要核实际值类型。

  3. ImageBinary.Image / ProcessedPixels → NodeRunRecord.Outputs

    算法生成新输出图像；框架校验并记录，字典复制不再深复制像素。

  4. NodeRunRecord → 显示消费入口

    二值化不在自动图像来源/通用frame provider中；主窗点击Preview取选中节点结果需图像Tab且Preview.Source已有值，专用ROI窗口另走自己的呈现。
