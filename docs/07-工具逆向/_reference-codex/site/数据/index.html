数据类型与数据流：从输入到最后读者

19条关系按原版、当前实现、未知分色；箭头各自独立，不代表连续调用。

先看数据关系：配置、取值、处理和结果持有是四件事

① 配置与绑定② 解析本轮输入③ 工具处理并返回结果④ 记录、下游读取与释放

原版已证事实

VmIO通过关联值与执行计数读取；ImageBaseData在byte[]和指针间有固定/复制路径。Dispose释放GC固定句柄，不等同于释放所有图像或共享映射。

当前实现

GraphExecutor克隆参数/ROI配置；输入可复用上游PortValue。工具返回ModuleResult后形成运行记录；缓存入队复制与结果发布复用图像引用是不同动作。

未知与边界

图中的19条关系按来源独立记录，不能串成一次端到端调用。跨记录的具体衔接、native回调及最后一个图像持有者的完整释放路径仍需逐项核实。
