数值与数值数组
原版已核片段当前独立实现

入口交来什么：托管临时pointer/count经typed wrapper进入ModuleFrame Batch；factory按名称查找或创建0x88值对象及独立共享控制块，不能把两张虚表视作同一对象。

具体复制哪一层：调用者先复制数值到临时HGlobal；wrapper本身不复制，已取ModuleFrame主写入后才明确按原pointer+i*4逐项读取并写入内部动态数组。字节非零分支还有辅助列表的4字节复制，辅助表与主仓不能并成一份缓存。

谁仍持有：数值临时块、辅助列表、typed值对象、其载荷及共享控制块分别持有。值对象+8槽仅清计数并保留分配；容量不足才扩容，旧header非0时本体不释放旧块。

哪里缓存或保留：调用期生成字节数组与HGlobal是实际复制；此包装没有长期缓存该HGlobal。；linked记录是另一个保留容器，当前新取值不自动删除它；wrapper临时格式化string退出后析构。；辅助字段和主共享记录可能同时保留数值；未取得全部创建/复用/清理分支，不推定它们是一份缓存。；取得的共享值对象和模块仓库可继续持有复制后的数组；本调用只减自己的控制块计数。；新对象进入名称map；后续同名可复用共享对象，局部shared pair不等于新建底层载荷。；旧数组容量、string堆分配可在清空后继续保留。；容量足够时保留块；header非零分支的外部内存关系不能凭形式命名。

退出到哪一步：临时HGlobal finally退役与typed map删除分开。强归零已绑定fa730→f7410，实际delete包装对象及名称/类型堆块；弱归零0210d0→0210f0实际delete控制块。payload只经callable未知动态槽关联，不因包装对象已delete就判其内容已free。

VZ03 · f4d10/f4dc0的数值主写入 → 输入每个4字节值复制进所取值记录的内部数组

source-confirmed

int写入先经f74b0取得共享值对象，空则返回0xe0000003；非空先调用其虚表+8槽，再对正count循环从原pointer+i*4读取4字节并交fc50。fc50经准备函数后取对象+0x10中的载荷，必要时扩容，并向其数组base+8+当前数目*4写入该值、增加计数。float的f4dc0对应fd30，写入另一组+0x40/+0x44/+0x48数组字段。这个层级已有实际标量复制，不能继续说数值始终只是原pointer转发；也不能把虚表+8未解体的行为擅称完整旧值清空。

类型、持有与复制
原数值buffer→逐个4字节值→内部动态数组；输入临时块寿命与已复制记录分开，float/int按实际4字节载体，不外推double。
缓存与失效
取得的共享值对象和模块仓库可继续持有复制后的数组；本调用只减自己的控制块计数。
退役与释放
