② 关闭工具窗口：窗口没了，结果还在谁手里？

原版：已证片段与未知父级桥

参数窗Closed只清窗口关联与ROI状态；结果宿主关闭是另一个入口。

谁持有：A链持有模块装饰器、结果仓库与选择图像；B链持有临时图像/图形仓库和控件属性。

已确认的收尾：CurTabControlBase_Closed清窗口引用/Tag，置IsOpenParams=false并隐藏ROI，没有清ModuleSource。另行发生OwnerWin_Closed或装饰器Dispose才按对应宿主路径清显示；不能把它们当成同一次关闭的必经后续。

此后仍可能存在：Unloaded退委托没有撤销此前Task.Run或Dispatcher委托；清仓库不等于生产者像素已归还。

待核：不同宿主的关闭路径不能拼成一个实例的统一释放协议；所有在飞工作和原生最后读者尚未闭合。

source-confirmed

independent-implementation
