当前实现与差异currentImplementation

ModuleIdBlobAnalysis
实现路径tools/SunEyeVision.BlobAnalysis/Runtime/BlobTool.cs（Runtime 层）+ Wpf/Views/BlobUiComposition.cs（界面层）
核对时间2026-11-05（静态读码，未运行对照）
差异
  • 原版是 XML 参数树 + 原生 Process 链；我方是 IToolDefinition<BlobSettings,BlobOutput> 强类型定义 + HALCON 执行，参数由 BlobParameterDefinition 的 Schema 描述而非资源 XML
  • 输入口不同：原版 InputImage / InputROI / InputROIAnnulus / InputMask / 位置修正信息；我方 input.image / input.inspection.region / input.mask.region / input.pose 加 BlobLocalRoi，名字与层次都不同，需要适配层而不是逐字段照抄
  • 阈值模式尚未全覆盖：BlobThresholdCapabilities.IsSupported 对未完成原厂语义对齐的模式直接报 BLOB_MODE_NOT_READY，属显式拒绝而非静默降级
  • 结果结构我方是 BlobSchema 定义的输出端口加 blob 表（含 oriented-bounds/center/width/height/angle）；原版是 95 个活动输出节点，字段命名与组合层次不同
  • 原版默认 Result List 的 Angle 对应外接矩形角度，我方 angle-degrees 在 oriented-bounds 成员上，语义一致但承载位置不同，需在对照基线中固定
  • 原版 ROI 走 InheritWayGroup2/ExternROITypeGroup 继承与外部 ROI 类型；我方由 BlobRoiInheritance 声明继承端口与校验，机制不同
