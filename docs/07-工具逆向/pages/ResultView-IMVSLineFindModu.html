当前实现与差异currentImplementation

ModuleIdLineDetect

核对时间2026-11-05（静态读码，未与原版对照运行）
差异
  • 参数规模：原版 24 个 ParamItem；我方 9 个强类型属性（LineStartPoint / LineEndPoint / MeasureLength1 / MeasureLength2 / NumMeasures / Sigma / Threshold / Transition / Select / DistanceThreshold）
  • 边缘选取：原版 FindModeEnum 4 值（Best 最强 / First 第一条 / Last 最后一条 / Mid 接近中线）；我方 EdgeSelect 3 值（All / First / Last）——原版有 Best 与 Mid，我方无；我方有 All，原版无
  • 极性：原版 EdgePolarityEnum（BlackToWhite / WhiteToBlack / Both）；我方 EdgeTransition（All / Positive / Negative）。Positive 对应黑到白，语义可映射但枚举名与第三值语义不同
  • 边缘强度：原版 EdgeStrength 默认 255、下限 1；我方 Threshold 默认 30。两者不可直接换算
  • 测量实例：原版 RayNum 默认 1000、下限 2；我方 NumMeasures 默认 10，量级差约 100 倍，模型不同（射线 vs 测量带实例）
  • 核宽：原版 KernelSize 单值 50；我方拆成 MeasureLength1=20 + MeasureLength2=5 + Sigma=1。HALCON 的带长/带宽语义与原版核宽不对应
  • 稳健拟合：原版 FitFun 可选 LS / Huber / Tukey；我方用 HALCON metrology 固定拟合，无稳健拟合选项
  • 缺失项：原版 RevertFindOrient、AngleNormalization、LineAngleEnable / ExpectAngle / RotateTolerance、RegionWidth、InitType（ALS/LLS 自适应阈值）、FitPointsLimitLow/High、ScoreLimitLow/High 在我方无对应
  • 判定位置：原版把 AngleLimit / ScoreLimit 放在参数层；我方放在 Judgments 层（edge-point-count / angle / rmse），语义相等但交互位置不同
  • ROI 模型：原版用 LineFindRoiManager 承载 LineCaliper 类型 ROI；我方用 RoiParameters + 两点引导线（LineStartPoint / LineEndPoint）
