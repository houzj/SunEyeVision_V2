## 六、对开发的直接约束

1. **已可用于对标**：类型 1 走「单阈值 / 区间阈值」二态（`[8] < [7]` 才启用低阈值），类型 2/3/4/8 是四条独立实现，不存在共用外层逻辑。
2. **不得凭空补参数语义**：参数名与下标的绑定尚未验证；数值口径（阈值是否 0..255 直接用、Gaussian sigma 单位、Sauvola 公式）在像素级函数反编译完成前不得按"标准二值化"实现。
3. **类型 5/6/7 存在但无 UI 语义**：我方只实现 1/2/3/4/8 时，遇到其它取值应直接报错（rule-015），不得静默回退到某一种类型。
