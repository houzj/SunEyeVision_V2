## 四、划片公式（原生 `ProcessAlg` 反编译推导，地址 0x18001f510）

设 ROI 盒：中心 `(cx,cy)`、宽 `W`、高 `H`、角度 `θ`（度）；`nX=NumX`、`nY=NumY`、`ox=OverlaprateX`、`oy=OverlaprateY`。

```
tileW = W / nX                      // 基础片宽
tileH = H / nY                      // 基础片高

// 单片实际尺寸（含重叠外扩），并夹到 ROI 尺寸以内
wTile = min(W, (W - tileW) * ox/100 + tileW)
hTile = min(H, (H - tileH) * oy/100 + tileH)

// 步进 = 片宽 - 片宽*重叠率  （由 fVar27 公式化简：tileW*(1 - ox/100)）
stepX = wTile - W * ox/100
stepY = hTile - H * oy/100

// 第 (row=Y, col=X) 片，row/col 从 0 起；col==0 与 row==0 时偏移强制为 0
offX = col == 0 ? 0 : stepX * col
offY = row == 0 ? 0 : stepY * row

// 片中心相对 ROI 中心的偏移，再按 ROI 角度旋转，最后加回 ROI 中心
localX = wTile * 0.5 + offX + (cx - W*0.5) - cx
localY = hTile * 0.5 + offY + (cy - H*0.5) - cy
tileCx =  localX * cos(θ*π/180) - localY * sin(θ*π/180) + cx
tileCy =  localX * sin(θ*π/180) + localY * cos(θ*π/180) + cy
```

每个分片以 4 个 float 连续存放（`*(param_2+0x10) + (nX*row + col)*4`），即 中心 x / 中心 y / 宽 / 高；片数 `DivideCount = nX * nY`（数组按 `nX*nY` 一次性分配）。

参数校验（原生）：`NumX<1 || NumY<1 || NumX>100 || NumY>100 || OverlapX>100 || OverlapY>100` → 记日志 `Param Range Error!` 并返回 `0xe0000001` 族错误码。

## 六、对实现的约束

- 工具身份：原厂显示名 **划片拆分**，类别 `SplitCombination`；建议 ToolId `ImageSplit`（避免与算术除法混淆）。
- 端口：输入 `image`（必填）+ `roi`（可选，Full/Box）；输出 `divide-rects`（矩形序列：中心/宽/高/角度）、`divide-count`(int)、`run-time`、`status`。**不要杜撰输出图像**。
- U1/U2/U3/U6 在实现时必须显式标注"未确认"，或按"未确认即不支持非默认值"处理，禁止按常识补公式。
