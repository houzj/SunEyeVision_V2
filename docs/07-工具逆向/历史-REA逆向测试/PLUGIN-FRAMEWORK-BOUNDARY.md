# 节点工具与框架双线边界及任务分配

> **2026-10-22 最新用户决定：**新任务的通用框架（包括插件面向的公共配置/交互/会话框架）由 `main` 源码恢复、实施并优先交付；`tool-plugins` 只负责具体工具，基于全局架构模型提出框架需求，待用户选择同步并确认共同 SHA 后接续工具实现。详见 [框架与插件逆向联动协议](FRAMEWORK-PLUGIN-REVERSE-HANDOFF.md)。下文 2026-10-17 的插件公共框架所有权、文件锁和旧基线是历史快照，不指导后续新任务，也不授权改动插件在制工作树。

更新：2026-10-17。**用户直接管控两个独立项目**；`main` 负责与具体工具无关的框架层，`tool-plugins` 负责具体工具及其所需的插件框架层。本文是双方共同遵守的职责和交接契约，不把 main 当成自动派工者，不建立第三套产品代码。双方当前 Git 基线和安全同步顺序见 [TWO-PROJECT-BASELINE.md](TWO-PROJECT-BASELINE.md)。插件线的详细任务表在其工作树 `docs/PLUGIN-FRAMEWORK-CHECKLIST.md`，未提交内容不能计入 main 成果。

## 用户管控下的任务分配与验收

| 管理事项 | 唯一负责方 | 交付规则 |
|---|---|---|
| 优先级、两个项目各自的任务、验收时点与是否集成 | 用户 | 两项目分别报告原始证据、提交号、实际验证与剩余差异；任何自动化只辅助提醒，不代替用户调度 |
| 跨线接口登记、冲突检查、最终集成与 `main` 推送 | `main`，在用户要求集成时执行 | 指定接口的单一提交所有者；审核双方提交及实际运行，不从另一工作树搬未提交文件 |
| 原生节点配置公共架构、配置模型和生产控件模板 | `tool-plugins` 插件线 | 插件线负责真实可复用的节点框架，不把每个工具做成孤立窗口；在其工作树内可修改必要共享代码，合流时逐文件审查 |
| 工具算法、独有参数、专属内容控件/操作适配器、工具依赖与原厂差分 | `tool-plugins` 插件线 | 每个工具任务须同时检查“原生证据→公共插件框架能力→工具适配→实际主窗口运行”；缺公共能力由插件线补齐，不把孤立工具测试当作集成完成 |
| 工作流画布、节点位置/连线/交互、Tab/工具箱外框、Group、流程/方案所有权 | `main` 框架线 | 负责稳定宿主入口、生命周期及流程数据传递，不复制插件线的配置模板、工具参数页和单节点调试系统 |
| 插件发现、注册与工具箱呈现 | `main` 负责通用发现/装载生命周期与工具箱入口；插件线负责工具清单/元数据 | `main` 不推断插件参数或专属UI；插件线不另造主界面工具箱。原生 `ToolBoxData.UpdateLoad` / `IMVSGroup.LoadAssemblies` 已提供审计线索，动态发现尚未闭合 |
| 数据类型、动态端口、复合叶、订阅执行和 ROI/Fixture/Polygon 的交叉契约 | 本轮按下表逐项锁定文件负责方 | 插件线有用户授权的在制共享改动；主线已有复合与 Group 实现。先比对提交基线与数据形状，再合并，禁止用复制未提交文件覆盖任何一方 |

两线可以并行逆向**不同原生证据**，但同一原生控件/状态机只设一个功能主责。用户反馈记录差异，不代替原生源码或受控运行依据。声明“已完成”必须分别说明源码确认、托管实现、实际产品操作、原厂同状态差分四级证据，缺一项就标该级未验证。每个插件交付必须列出所依赖的框架接口以及在主界面/Group中的使用结果；每个 main 框架接口必须由至少一个真实插件消费验证。

## 合流闸门与任务状态

1. 插件线完成 PF 子项与至少一个真实工具迁移，保存原生路径/哈希、接口差异、可运行证据；按用户要求先构建并留人工验收，再以中文提交和推送其分支。**当前未提交在制文件不能直接挑选或当作已交付。**
2. 用户决定合流时，`main` 比对两线提交与受影响文件，先合公共合同，再合宿主，最后注册一个真实插件。必要时在 main 做增量适配，不整文件覆盖。
3. 在实际主窗口完成“工具箱出现→拖放→配置→订阅/ROI→运行/停止→结果/错误→Group内调用→保存重开→关闭释放”。检查结果数值与 UI 状态；测试通过、离屏截图和原厂差分分别记录。
4. 主线更新框架验收表并发布人工验收版本；保留尚未复现的原生数据类型/ABI、设备服务和模板差异。两线中文提交各自工作树；最终 `main` 集成推送的时点由用户决定。

不额外创建“管理者代码项目”：用户可直接用两条对话和两份清单管控。定时提醒不是项目负责人，也不会在两轮人工沟通之间自动验收或合并。
