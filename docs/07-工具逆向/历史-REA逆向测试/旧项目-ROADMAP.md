## 插件线交付与框架线集成门槛

插件线详细目录由其自行维护；每个工具至少提交下列信息，框架线逐工具接收，不等待“所有工具完成”才集成。

| 编号 | 插件线提交 | 框架线验收 |
|---|---|---|
| P-01 | 原始模块 ID、版本、分类、程序集/资源位置、依赖 | 注册及工具导航身份一致，无占位工具冒充可运行 |
| P-02 | UI 模板、事件、参数、默认值、约束及可见性证据 | 创建/编辑/提交/关闭、配置持久化、运行期间状态 |
| P-03 | 输入输出类型、数组维度、缺失值及错误契约 | 订阅、调度、结果显示、上下游数据实际流通 |
| P-04 | 算法实现来源与未恢复的原生边界 | 原始样本/参数/预期结果差分；容差需有依据 |
| P-05 | 图像/ROI、设备与会话资源需求 | 宿主服务、取消/超时/关闭释放、重复打开运行 |
| P-06 | 提交编号、测试与实际操作记录、已知差异 | 审查提交后集成；在集成版本完整运行并记录结果 |

4. **S4：运行、变量和存储**。F-15 至 F-19，补齐真实调度与数据链、保存重开和错误清理。
