# 工具逆向资料与 UI 还原索引

本目录只保存工具逆向阶段材料，必须区分证据等级，不能把 HTML 页面当作 VM 实机 UI。

## 资料分层

| 路径 | 定位 | 数据来源 | 能否作为 VM UI 结论 |
|---|---|---|---|
| `../07-工具逆向/` | 原件证据、程序集、XML、资源和证据卡 | VM 原件或反编译材料 | 可以，按证据状态使用 |
| `ui/` | 参数配置面板还原 | `AlgorithmTab.xml`、`Group.xml`、真实控件 XAML、样式和图标 | 可作为控件结构候选；仍需标注未确认项 |
| `preview/` | 非 VM UI 的结构草图/合同预览 | 工具声明和本方静态 HTML 组装 | 不可以，不得称为真实 UI |

## 使用规则

- 需要判断 VM 参数面板、页签、分组、控件形态时，先看 `ui/index.html` 及其工具页面，再回到 `07-工具逆向` 查原件证据。
- `preview/` 页面只用于显示工具参数、输入输出和调试窗口区域的草图，不能作为 WPF 外观、布局、交互、模板或运行结果验收依据。
- VM 实机截图、控件模板、动态资源、父级状态、异步回调和生命周期证据统一放在 `docs/collaboration/evidence/`，并标记“已确认 / 推断 / 未确认 / 自研决策”。
- 任何页面若没有原件来源、版本、路径和证据等级，不得进入现行架构文档或作为批量工具实现合同。

- [结构草图索引（非 VM UI）](index.html)

## 维护责任

逆向负责人维护原件证据、`ui/` 还原材料和证据等级；主线技术负责人审核页面定位、合并现行文档结论，并清理重复或误标为真实 UI 的页面。工具批量实现必须以最终架构、源码树和已确认证据为准。
