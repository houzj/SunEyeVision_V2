  • 行容器：LeftRightControl.xaml，左列 ChildLeftWidth=90（LeftWidthConverter 中文值），行高 32，标签 14px #666666。

  • 中文：Lang/zh-cn.xaml 等三份语言字典；查不到的中文按原件英文键显示，标签带红色虚线下划线。
