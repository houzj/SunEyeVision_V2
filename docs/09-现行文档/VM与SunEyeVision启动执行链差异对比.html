核心差异

阶段VM 原厂SunEyeVision 当前目标设计
启动Server/Proxy 和模块运行环境常驻准备。应用内插件准入和公共初始化。启动页只准备服务、插件和公共框架，不执行工具。
方案VmSolution.Load 安装流程和模块对象。DocumentSession 同时承担模型、画布和部分宿主接缝。SolutionRuntime 统一方案会话，编辑状态与运行状态分离。
RunVmSolution.Run/VmProcedure.Run 进入常驻服务。CaptureRunBatch 和自研执行器承担较多每轮准备。Run/Trigger 请求进入 ExecutionServer，由 ExecutionCoordinator 按原厂模型协调。
结果常驻结果对象按 ExecuteCount 异步更新。结果快照、Owner、Presenter 和表格/图形多层协作。ResultStore 提交代次；模块结果、当前结果、历史结果、帮助四条 UI 链独立更新。
关闭服务统一排空和释放。宿主需要显式处理窗口、方案、运行和结果资源。停止请求、排空 Run、退役投影、释放结果/会话/方案、关闭服务。
