## 主仓当前实现与缺口

- `src/UI/Services/Workflow/WorkflowExecutionManager.LocalImages.cs` 的 `BeginLocalImagesAsync` 在执行前用 `File.Exists` 过滤输入；缺失项没有进入冻结序列。`src/UI/Services/LocalImageSequenceService.cs` 的 `Complete` 在整体成功后统一推进，并依据过滤后的末项停止。这两处与上述原厂缺图和多源按实际消费时序不一致。
- `src/Workflow/ImageSourceInvocationInputs.cs` 的 `ImageSourceRunInput` 目前只有地址和 SN；`CaptureAsync` 组装本地地址，不是实际读图。`tools/SunEyeVision.ImageSource/Runtime/ImageSourceSession.cs` 在设置、来源、SN 和设备身份校验之后执行地址及文件检查与解码；具体接纳点需保证已经过前置校验且早于对应实际读取尝试，地址语法错误是否消费仍须证据确认。
- `src/Plugin.Runtime/Execution/ToolExecutionIdentity.cs` 的 `EnterRun` 早于工具实际读图；`TryPublish/TryInvokeCallback` 是通用可重入通知，不提供该轮该输入的一次性消费接纳。已有 owner 准入回调可能重入退役，不能只在回调前检查身份。
- `AutoPlay`、导航单次命令、选择执行、失败、末项停止和 SN 必须分别建模。停止连续调度不应中断已接纳的本轮；输出失败与消费是否发生是两种状态。多源仅各自真实到达接纳点后推进，不能假设每轮全部节点都已取图。
- 工作流独立线只读指出多个独立入口：`WorkflowExecutionManager.RunCommunicationNodeAsync` 直接由冻结 `Overrides` 构造源输入，不经过连续流程 `BeginLocalImagesAsync/CaptureIteration`；通信触发整流程则通过另一条 `RunSingleAsync` 路径。`RunSolutionAsync` 和缩略图执行显式禁用当前批处理的自动推进，`RuntimeDebugInvocation` 使用私有 `PrepareDebug`。这些不能一律套用普通连续运行：先逐项核 VM 实际入口、导航一次性状态及游标归属，未证部分明确记录；该线候选尚未合入和运行。

## 统一合同应满足的约束

以下是自研实现要求，不声称为 VM 原始类或接口：

- 执行层提供非 UI、按正式输入端口识别的一次性接纳；绑定完整文档会话、根轮次、作用域、节点、请求和冻结序列身份。相同请求重复或迟到回调不得再次推进；退役、取消或配置代次变化须拒绝旧请求。
- 接纳与游标状态变更必须有单一原子提交点；外部回调重入、通知异常不得回滚已消费状态或重复消费。状态变更和通知的责任及锁序必须在落地前明确，算法和资源清理不能等待 UI Dispatcher。
- 已完成前置校验但尚未接纳的取消、验证失败和创建会话失败不推进；成功接纳后即使读取失败也保留已消费事实。取消与接纳同时发生须以单一提交点区分，不能按最终成功状态推断。
- 正式运行、连续运行及私有调试明确各自的游标拥有者与生命周期；导航按钮、已选集合及自动切换要经过相同来源身份和显式一次性规则，不能在不同入口分别猜一个时点。
- 保留当前生效的字段设置快照、资源所有权、节点和工作流运行互斥合同；不复制旧 SDK 接口，不以临时地址或显示文本作身份。

## 最低核收矩阵

原版与自研均记录 A/B/C 项身份、选中方式、调用入口、每次接纳/读取/输出、游标与 SN、停止请求及排空状态；至少覆盖：

1. 自动和手动、首尾环绕、下一张/上一张后再运行、选中子集和空选。
2. 前置失败、接纳前取消、接纳后读缺图/解码失败/取消，确认是否消费与 SN 是否变化。
3. AutoStop 开/关：末项成功、末项不存在；连续运行的停止请求与实际排空分开验证。
4. 多源顺序、其中某节点不执行、下游失败；各源只按真实消费改变游标。
5. 重复请求、并发/重入接纳、异步旧回调、退役/重建/取消、通知异常；不重复写入或污染新会话。
6. 正式单次/连续、方案运行、通信单节点、通信整流程、缩略图和私有调试分别验证入口/游标/一次性导航、保存重开及在途配置互斥；无 UI 消息泵时运行和资源释放。各入口先核原版，不预设共享游标。

此前旧用例中“缺图预过滤拒绝”和“只按最后有效图停止”的断言与原版证据冲突，须按正式新合同重设计并保留失败记录，不以旧用例通过宣称 VM 等价。原件的多源同步及地址语法等边界仍需进一步证据，未证明的内容不得静默写死。
