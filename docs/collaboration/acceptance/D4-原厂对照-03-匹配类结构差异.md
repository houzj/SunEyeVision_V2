# D4 参数页 · 原厂对照（第 3 批：匹配类工具结构差异）

## 1 结论速览

三个匹配类工具（轮廓匹配 / 灰度匹配 / 图形定位）与原厂存在**页面级结构差异**，不只是字段命名。

| 工具 | 原厂页签 | 我方页签 | 判定 |
|---|---|---|---|
| 轮廓匹配 ContourMatch | **基本参数 / 特征模板 / 运行参数 / 结果显示**（4 页） | 模板参数 / 运行参数（2 页） | ❌ **缺 2 页 + 顺序不同** |
| 灰度匹配 GrayMatch | 同上（4 页，按模块推定） | 模板参数 / 运行参数（2 页） | ❌ 同构差异 |
| 图形定位 MarkFind | 同上（4 页，按模块推定） | 模板参数 / 运行参数（2 页) | ❌ 同构差异 |
| Blob 标签分析 BlobLabels | 基本参数 / 运行参数 / 结果显示 | 基本参数 / 运行参数 | ⚠️ 待核对结果显示页 |

我方字段分布（`our-schemas.json`）：

```
ContourMatch  模板参数 9 + 运行参数 56   = 65（无基本参数、无结果显示）
GrayMatch     模板参数 6 + 运行参数 33   = 39
MarkFind      模板参数 12 + 运行参数 47  = 59
BlobLabels    基本参数 30 + 运行参数 52  = 82
```

## 2 轮廓匹配逐项对照（已实测截图）

### 2.1 我方缺失：基本参数页

原厂「基本参数」包含：

| 分组 | 字段 |
|---|---|
| 图像输入 | 输入源（引用选择） |
| ROI 区域 | 输出掩膜（开关）、ROI 区域类型（图形类型 / 图像类型）、ROI 创建（绘制 / 继承）、形状（矩形 / 圆 / 多边形）、屏蔽区创建（绘制 / 继承）、屏蔽区、位置修正（开关） |

我方**完全没有这一页**，也没有对应字段声明。

### 2.2 我方缺失：结果显示页

原厂「结果显示」包含结果判断项（判定开关 + 阈值）与图像显示项（Blob 类图形 + 文本显示），我方无。

### 2.3 页签顺序不同

| 位次 | 原厂 | 我方 |
|---|---|---|
| 1 | 基本参数 | 模板参数 |
| 2 | 特征模板 | 结果显示 |
| 3 | 运行参数 | 运行参数 |
| 4 | 结果显示 | — |

### 2.4 「特征模板」vs「模板参数」

| 项 | 原厂「特征模板」 | 我方「模板参数」 |
|---|---|---|
| 工具栏 | 创建 / 载入 | 新建模型 / 清空模型 / 导出 / 导入 |
| 主体 | **模板列表**（空态：「暂无数据」） | 直接是参数表单 |
| 右侧 | 模板预览图 + 编辑模板 / 删除所有模板 | 无 |
| 参数项 | 不在该页 | 金字塔比例 / 压缩比 / 特征尺度 / 阈值模式 / 边缘阈值 / 链式 / 最小链长 / 掩膜模型（9 项） |

说明：原厂把「模板创建与管理」做成独立页面，参数在运行参数页；我方把创建按钮和参数混在「模板参数」一页。

## 3 影响与等级

| # | 差异 | 等级 | 理由 |
|---|---|---|---|
| 1 | 缺「基本参数」页（输入源 / ROI / 位置修正） | **P0** | 用户无法在该工具内配置 ROI 与输入，功能缺口 |
| 2 | 缺「结果显示」页 | **P1** | 无法配置判定项与显示项 |
| 3 | 页签顺序与命名不一致 | P2 | 影响一致性与培训成本 |
| 4 | 「特征模板」形态差异（列表 vs 参数表单） | P1 | 交互模型不同，模板管理能力缺失 |

## 4 建议实施顺序（每个工具一遍，轮廓匹配作样板）

1. **补「基本参数」页**：输入源 + ROI 区域 + 位置修正（字段声明 + 分区 + 语义映射到执行）
2. **补「结果显示」页**：判定项 + 图像显示项 + 文本显示（沿用 Blob 的呈现声明范式）
3. **「模板参数」→「特征模板」**：拆成「模板列表页」+ 把 9 个参数移到「运行参数」页对应分组
4. 页签重排为：基本参数 → 特征模板 → 运行参数 → 结果显示
5. 同步更新 `scripts/migrate-solution-fields.ps1` 的迁移前缀，处理字段改名/移动
6. 回归：打开/关闭、三入口校验、保存重开、执行结果不变

> 注：步骤 3 涉及设置字段的跨页移动（不改变字段 id 则不需要迁移；只改 Layout.Page/Section）。
