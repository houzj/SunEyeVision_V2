## 8 补充：原厂「模板配置」编辑器窗口（形态重新认识）

用户在实测中打开原厂「特征模板 → 创建/编辑模板」，弹出独立窗口「模板配置」，此前未纳入对照，现补录。

| 区域 | 内容 |
|---|---|
| 顶部工具条 | 选择当前图像 / 选择其他图像 / 模板存图（开关+存图按钮） / 全部屏蔽（开关） |
| 绘图工具条 | 绘制 ROI（矩形/圆/环/多边形）、擦除、撤销、重做、放大、缩小、适应窗口、全屏 |

| 右侧上部 | 列表（模板列表，空态） |
| 右侧下部 | **配置参数**：尺度模式（自动）、速度尺度（5）、特征尺度（1）、阈值模式（自动）、边缘阈值（15）、链长模式（自动）、最小链长（4）、建模类型（直图建模…，可滚动） |
| 底部 | 匹配中心（0, 0）+ 锁定开关；确定 |

### 8.1 由此修正的结论

原厂分层是：

`\r
参数页「特征模板」  → 只做模板的创建/载入/预览/删除（列表管理）\r
模板配置（独立窗口）→ 绘制 ROI + 图像预览 + 全部建模参数 + 匹配中心\r
`\r

我方把**建模参数直接铺在「模板参数」页**，既没有独立编辑器窗口，也没有 ROI 绘制工具条与图像预览，更缺「匹配中心」与「锁定」。

### 8.2 差异升级

| 项 | 原厂 | 我方 | 等级 |
|---|---|---|---|
| 模板配置窗口 | 独立模态窗口（工具条 + 预览 + 参数 + 匹配中心） | 无 | **P0**（模板无法真正创建/标定） |
| ROI 绘制工具条 | 矩形/圆/环/多边形 + 擦除/撤销/重做/缩放/全屏 | 无 | **P0** |
| 匹配中心 + 锁定 | 有 | 无 | P1 |
| 建模参数归属 | 模板配置窗口内 | 参数页表单 | P1 |

### 8.3 工作量修正

单工具由约 1.5~2 小时升至 **3~4 小时**（新增：模板配置窗口 + ROI 绘制工具条 + 图像预览 + 匹配中心），三个匹配工具合计约 10 小时。
