## 6 结论与工作量

| 项 | 等级 | 说明 |
|---|---|---|
| 缺基本参数页（输入/ROI/位置修正） | P0 | 功能缺口，需新增字段声明 + 页面 + 执行语义 |
| 缺结果显示「结果判断」整组 | P0 | 无法配置判定 |
| 运行参数缺 2 项、极性控件错型 | P1 | 极性从数字框改下拉（考虑极性/不考虑极性） |
| 运行参数多 4 项 | P1 | 需确认原厂是否在「高级参数」内；否则移除或归入高级 |
| 特征模板形态差异 | P1 | 需要列表 + 预览 + 编辑/删除 |
| 图像显示命名不一致 | P2 | 按原厂改名 |

**预计 1.5~2 小时/工具**，三个匹配工具（轮廓/灰度/图形定位）同构，可复用同一套改法。
