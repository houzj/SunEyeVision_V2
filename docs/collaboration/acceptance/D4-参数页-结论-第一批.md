## 3 缺陷

### DEF-002 · 参数页使用浅色主题，与深色主界面不一致（**已裁定：非缺陷，保留浅色**）

- **现象**：主界面为深色（#121518 系），工具参数窗口为浅色（白底、深色文字、浅灰按钮），切换时视觉突变
- **复现**：打开任意工具参数页（图像源、Blob 分析均复现）
- **影响**：一致性下降；长时间调参刺眼；截图归档时容易被误判为“另一个产品”
- **初步定位**：参数窗口内容控件走的是框架默认（浅色）控件样式，未接入 `Themes/Dark/DarkTheme.xaml` 的工具参数控件样式
- **裁定（2026-11-17，用户）**：**参数页保持浅色，不改深色**。关闭为“符合设计”，仅作观察记录（P3），不进入缺陷闭环
