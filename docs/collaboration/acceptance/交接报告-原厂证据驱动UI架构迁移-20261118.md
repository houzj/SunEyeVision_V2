### 原厂 Blob 证据

原厂反编译文件位于 `docs/07-工具逆向/decompiled/Managed/BlobFind/IMVSBlobFindModuCs/BlobFindRoiManager.cs`。已确认以下事实。

- 原厂 `BlobFindRoiManager` 持有统一的 `RoiManager`。
- 矩形和扇环 ROI 先设置 `ROIAreaType`，再通过 `InputItem(...).SetInputValue(...)` 写入几何字段。
- 盲多边形和 Mask 图像也通过同一 ROI 输入管理边界写入。
- ROI 模式、字段创建、参数写回属于同一个输入组装事务。

对照分析见 `docs/evidence/blob-input-assembly-difference-analysis-20261118.md`。

### 颜色抽取原厂依赖

`HikHistogramSingle` 和 `SquareArea` 的最小依赖闭包已建立。对应证据见 `docs/evidence/color-extract-histogram-dependency-review-20261118.json`。已有的静态取证不能替代尚未取得的原厂动态行为，尤其是图像回调、ROI 点同步和销毁性能。

### 参数根和页构建

涉及文件如下。

- `src/Plugin.Wpf/Presenters/Parameters/DeclaredSettingsView.cs`
- `src/Plugin.Wpf/Fields/DeclaredFieldsView.cs`
- `src/Plugin.Wpf/Presenters/Parameters/DeclaredInputFieldsView.cs`

当前正式行为如下。

- 输入字段按声明的 VM page/section/order 安装到同一参数根。
- 输入字段不再由第二套嵌套参数视觉链绘制。
- 目标页尚未物化时，字段进入待处理页事务，目标页构建时再安装。
- `DeclaredFieldsView` 现在先执行 pending page actions，再触发 `PageBuilt`，最后刷新可见性。
- 外部字段注册允许已经进入页事务但尚未取得最终位置的行，避免同一字段重复创建。
- Blob 专用 ROI 组装只引用外层已注册的输入字段。
