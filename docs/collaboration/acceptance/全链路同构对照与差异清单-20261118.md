> 依据：原厂反编译（`Apps.XmlParser` / `Apps.XmlUI` / `VM.PlatformSDKCS` / `VMControls.WPF`）+ 我方源码逐行比对。

## 一、全链路总图

```
用户双击节点
   ↓
[1] 打开参数窗（RuntimeToolEditorWindow）
   ↓
[2] 构造参数页（DeclaredSettingsView ← BlobParameterEditor 桥接）
   ↓
[3] 加载参数声明（BlobParameters.xml → Schema）
   ↓
[4] 创建参数行（DeclaredFieldRow ← ComposeInputEditor）
   ↓
[5] 页签切换（TabControl.OnSelectionChanged）
   ↓
[6] ROI 组装（RoiGroupModel + RoiGroupView）
   ↓
[7] 执行（BlobSession → BlobAlgorithm）
   ↓
[8] 结果呈现（DeclaredResultTable / ModuleResultView）
```

## 三、未同构的三项（按依赖排序）

### R1. ParameterStore（平台参数引擎）— 最高优先级
- **对应原厂**：原生参数表 + `CModuleParamBase`
- **解决**：#5 值存储、#9 执行传参、以及一切"代码与界面不一致"的可能性
- **做法**：平台按 `(nodeId, 参数名)` 存取；类型转换 + 范围校验；导出/导入沿用方案 JSON 格式
- **完成后**：`BlobSettings` 降级为只读视图；算法接收只读快照

### R2. FieldRowNode（参数行数据节点）— 第二优先级
- **对应原厂**：`NameValueItem : BaseNode`
- **解决**：#4——行从"UIElement 合体"变为"数据节点 + 模板生成的 UI"
- **做法**：把 `DeclaredFieldRow` 的数据部分（`FieldRowModel` + 状态 + 订阅）抽成 `FieldRowNode`（按 id 唯一、跨页常驻）；`DeclaredFieldRow` 只剩"从 Node 读、往 Node 写"的模板壳
- **完成后**：切页零重建、`ComposeInputEditor` 的防重复保护自然消失、所有 `pendingPageActions`/`EnsureAttachable` 防御代码可删

### R3. 结果渲染器注册表 — 第三优先级
- **对应原厂**：`ModuleResultView` 按数据类型分区（已反编译证实四区域 + `exceptTypes`）
- **解决**：#8——"直方图+表格"这类复合形态
- **做法**：`rendererKey → IToolResultView 工厂`注册表，替换 `DesktopToolPresentation.cs:58` 的 `_ => throw`；内置 `standard-table` 与 `histogram-table`（我方已有 `HikHistogramSingle`）
