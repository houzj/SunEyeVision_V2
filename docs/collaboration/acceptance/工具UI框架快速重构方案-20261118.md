# 工具 UI 框架快速重构方案

日期：2026-11-18  
范围：当前仓库已经登记并可加载的全部工具  
原则：先统一项目结构和 UI 装配框架，再迁移工具适配器；原厂证据不足时停在证据阻断状态

## 目标

把当前所有工具收口到统一的原厂化装配框架。

- 所有工具都有明确的项目结构、入口、页面、输入组装、资源注册和生命周期映射。
- 简单工具复用统一参数页。
- 图像、ROI、引用和模板工具复用公共组合控件。
- 特殊工具通过受控适配器接入专用控件，不再在工具内复制第二套参数视觉链。
- 任何未完成工具都有可查询的覆盖状态和差异清单。

## 全量工具清单

第一步从 `product/ToolComponents.props`、工具目录、Runtime 注册和 WPF Editor 注册生成实际清单。当前已确认的首批工具包括：

- BlobLabels
- ContourMatch
- GrayMatch
- MarkFind
- ColorExtract
- DivideImage
- FrameMean
- If
- IntensityMeasure
- PixelCount

清单生成后，其他已经实现但未出现在首批清单中的工具自动追加到同一迁移矩阵，不允许留在未知状态。

## 按装配模式并行迁移

### 模式一：纯参数页

FrameMean、DivideImage、IntensityMeasure、PixelCount 和同类工具先迁移统一窗口根、Tab、分组、数值/枚举行和底栏命令。

### 模式二：图像与 ROI 输入

BlobLabels、ColorExtract 和同类工具迁移平面输入组装、图像来源、ROI 继承、引用状态和释放链。

### 模式三：特征模板

ContourMatch、GrayMatch、MarkFind 和同类工具迁移 FeatureMatch 公共面板、模板列表、模板配置窗口、图像区、掩膜工具和模型生命周期。

### 模式四：动态分支或动态字段

If 和同类工具迁移动态字段集合、条件可见性、分支命令、字段提交和保存重开。

### 模式五：专用图像或结果控件

ColorExtract 直方图、特殊结果展示和同类工具先补公共控件与资源，再通过适配器进入统一窗口根。

## 公共框架改造顺序

1. 建立原厂证据索引和全量工具迁移矩阵。
2. 建立统一窗口根，收口标题、帮助、Tab、底栏、关闭退订和资源释放。
3. 建立平面参数页宿主，输入行、ROI 行和引用行加入同一参数页分组，禁止把完整输入列表作为外层单行嵌套。
4. 建立公共输入组装器，统一图像来源、ROI、继承、引用校验和输入写回。
5. 建立原厂控件目录和资源注册入口。
6. 建立 FeatureMatch 公共模板面板与 900×534 模板配置窗口适配边界。
7. 用每种装配模式各迁移一个代表工具，验证框架合同。
8. 按模式批量迁移剩余工具，工具只提供声明、模型转换和行为回调。
9. 批量执行静态映射、定向测试、Release 构建和 Agent Desktop 真实窗口复核。

## 未覆盖工具的处理

每个工具必须处于以下三种状态之一。

### NativeAligned

已接入新公共框架，原厂窗口结构、控件来源、输入链、生命周期和 Release 快照均已闭合。该工具可以进入人工验收和功能联调。

### LegacyCompatibility

原有工具暂时通过隔离的兼容宿主继续运行。兼容宿主只负责承载旧视图和旧生命周期，不向新框架反向注入第二套公共状态。工具必须记录旧视图入口、已知差异、未迁移原因和迁移顺序。

兼容状态的工具可以继续构建和打开，但不能标记为 UI 对齐完成，也不能把旧视图作为新工具的组装模板。

### EvidenceBlocked

原厂静态资源、运行窗口或控件行为证据不足时，工具冻结在证据阻断状态。保留当前可运行代码，不凭自研推测补控件，不改变视觉或交互语义。补齐证据后再进入 NativeAligned 或 LegacyCompatibility。

## 兼容期边界

- 新框架与旧兼容宿主通过工具注册表选择，单个工具只进入一个入口。
- 公共框架改动必须保留旧工具的加载和关闭合同。
- 不把旧工具的自研参数行重新注册进新公共模板表。
- 不允许通过“看起来相似”的控件消除 EvidenceBlocked 状态。
- 兼容工具的差异记录必须进入迁移矩阵和当前任务账本。
- 所有工具最终都要从 LegacyCompatibility 或 EvidenceBlocked 退出，不能长期隐藏。

## 快速验收矩阵

每个工具迁移批次都执行同一组检查。

- 工具项目入口、Runtime/Editor 组件登记和资源注册
- 窗口尺寸、标题、帮助、Tab 顺序和底栏命令
- 基本参数、运行参数、结果显示和工具专用页
- 输入图像、ROI、引用、常量、枚举、数值和范围控件
- 模板创建、列表、保存、载入和配置窗口
- 字段编辑、取消、保存重开、换节点和关闭
- 迟到回调拒写、窗口退订、执行会话关闭和资源释放
- 静态证据、原厂快照、自研 Release 快照和差异项回溯

## 收口条件

全部工具均有迁移状态，且不存在未知工具、未登记兼容工具或未记录的证据阻断。所有 `NativeAligned` 工具通过框架级 Release 构建和真实窗口复核。`LegacyCompatibility` 与 `EvidenceBlocked` 工具保留明确入口和差异记录，直到完成迁移或补齐证据。
