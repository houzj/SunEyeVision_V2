## ② 原厂行为链（基线结论）

```
框选拖框中         → 只画橡皮筋框（灰虚线2,1），不改节点选中
松开（命中≥1节点） → 设 CurBoxOfItems + 显示外包框（橙虚线5,2）
                      ↑ 全程不写 IsSelected
点击空白           → 外包框 LostFocus → IsShowRectDragPanal=false → CurBoxOfItems=null
                      ↑ 节点选中完全不动
拖外包框移动       → DataObject(CurBoxOfItems) + 双层预览（节点快照 + 外包框快照）
松手               → 按预览 offset+(10,10) 批量移动 CurBoxOfItems 中的节点
```

## ⑤ 回归方法

- 框选两个节点 → 检查节点选中状态与外包框是否独立（点外包框内空白区域应只清框）
- 点画布空白 → 节点选中保持、外包框消失
- 拖外包框 → 移动中同时看到节点半透明快照 + 外包框半透明快照
