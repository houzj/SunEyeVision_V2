# 模板配置窗口 A 路线（ImageViewBox ROI）实施方案（2026-11-21）

## 决策

选 A：激活 `ImageViewBox` ROI 路线，真正 1:1 原厂。不用 NativeRoiEditHost 近似替代。

## 取证结论（静态，已验证）

### ImageViewBox ROI 数据格式
- `ROIList`/`SelectedSubROIList`/`ShapeList` = `IList`（`ImageViewBox.xaml.cs:71,73,89`），元素须实现 `IROI`
- `DrawROIType` = `Type`（:85），是**数据接口类型**（如 `IRectROI`），由 `ROITempConverter.cs:35-85` 按 `[ROIDisplayForInterfaceType]` 映射到绘制控件
- 本方 `RectROI.cs:20` 有 `[ROIDisplayForInterfaceType(typeof(IRectROI))]` —— **绘制体系完整可用**
- 本方有全套 `IROI` 数据接口（`IRectROI`/`IPolygonROI`/`ICrossROI`…，`PresentationControls.RenderInterface`）
- `ImageDataSource` = `IImageData`（`ImageViewBox.xaml.cs:133`），接口只需 Width/Height/Buffer/MemoryAddress/PixelFormat（`IImageData.cs:3-14`）
- 绘制完成流程：`e.Param as IROI` → `AddROI` 写入 SelectedSubROIList/ROIList → 执行 `RoiAddCommand`（:2128-2133, 2312-2325）

### 原厂装配模式（HPFeaturepatMatchDialogUI.cs）
- `OnApplyTemplate()`（:381-394）：`Template.FindName` 拿控件（imageViewBox/BtnCurImage/Arrow/cbIsSaveImage/viewGrid）
- `Init()`（:396-408）：`this.DataContext = featurepatMatchDialogData` + `imageViewBox.DataContext = 同一模型`
- 命令宿主 = **数据模型**（不是窗口）；窗口通过 `RelativeSource TemplatedParent` 绑定
- `AddROICommandExecute`（HPFeaturepatMatchDialogData.cs:469-490）：十字 ROI→匹配中心；其它→`AddRoiDelegate`

### 本方已有桥接资产
- `NativeRoiProjection : IROI,IROIVisible`（`src/Plugin.Wpf/Adapters/Regions/NativeRoiProjection.cs:13`）—— 本方 ROI → IROI 投影（需 session，给 NativeRoiEditHost 用）
- `RoiDocumentValue`（`src/Plugin.Contracts/`）—— 本方 ROI 文档模型
- `CameraBitmapImageData`（取证报告 :9-26）—— IReadOnlyImage → IImageData

## 实施清单（按顺序，每项可独立验证）

### 第 1 项：建本方数据模型 `TemplateConfigData`（等价 HPFeaturepatMatchDialogData）
- 位置：`tools/.../Editor/Views/TemplateConfigData.cs`
- 持有：16 个 ICommand + 数据属性（ImageDataSource/ROIList/ShapeList/ItemsData/SignList/DrawROIType/IsStateForDrawROI/SelectedROIList/训练参数 8 项/匹配中心 FixX/Y）
- 实现 INotifyPropertyChanged
- 命令实现：
  - SelectCurImage：借当前帧 → CameraBitmapImageData → ImageDataSource
  - AddROICommand：十字→匹配中心；其它→ROIList.Add
  - Match：生成模型（调 createTemplate 回调，用当前 ROIList 编码）
  - Save/Confirm/Clear/撤销重做/缩放/形状选择：见原厂语义
- 验证：编译 + 单元测试构造模型、命令可调用

### 第 2 项：ROI 数据桥接
- 本方 `RoiDocumentValue` → `IROI` 数据对象（矩形/多边形）；复用 `NativeRoiProjection` 的几何字段映射思路，但做成不依赖 session 的持久对象
- 验证：构造测试 ROI → 检查 IROI 接口属性

### 第 3 项：窗口装配（OnApplyTemplate + DataContext）
- `TemplateConfigWindow.xaml.cs`：改 `OnApplyTemplate()` 用 `Template.FindName` 拿 imageViewBox
- `DataContext = new TemplateConfigData(...)`（替代现在的 `DataContext = this`）
- imageViewBox.DataContext = 同一模型
- 验证：实机打开窗口无异常、xaml 绑定能解析

### 第 4 项：命令/数据逐项接线与实机验证
- 16 个命令逐个接功能，用 agent-desktop 实机验证每个按钮行为
- 验证：构建 0 error、专项测试 30/30、实机窗口功能逐项通过
