# 画布交互：原厂完整基线（全源码通读版）

> 方法：子代理通读 `decompiled/WpfControls` 全部画布交互类（ItemsPage/DiagramPage/DiagramArea/DiagramItem/Connector/Connection/ToolControl/ZoomArea 等，合计约 7000 行），提取完整交互状态机。替代此前"哪里报差异修哪里"的碎片化方式。
> 本文件是后续画布交互对齐的**唯一基线**：任何画布交互修改必须先在此确认原厂行为与证据行号。

源码根目录：`docs/07-工具逆向/decompiled/WpfControls/`。总体架构：`DiagramArea`（外壳）→ `ZoomArea`（缩放/平移/鹰眼）→ `DiagramPage : ItemsPage`（ListView 画布）→ `DiagramItem`（ListViewItem 节点）→ `Connector`（端口）/`Connection`（连线）。

## A. 鼠标交互矩阵

### A1. 空白区（DiagramPage / ItemsPage 本体）

| 输入 | 行为 |
|---|---|
| 左键按下 | 条件 `!IsLockWorkArea && !IsOpenParams && CodeManager.IsAdmin`：记录 `startPoint`（ZoomArea 坐标）、`startPointofPage`，置 `IsMouseDown=true`，挂接 `PreviewMouseMove`/`PreviewMouseLeftButtonUp` [ItemsPage.cs:582-592]。模板内 Canvas `MouseDown` 仅做 `Focus()` [DiagramPage.xaml:59]。重写 `OnIsMouseCapturedChanged` 为空，防止长按左键导致选中变化 [ItemsPage.cs:307-309] |
| 左键移动（空白） | 首次移动：宿主 `CaptureMouse()`，创建 AdornerPanel + **虚线框选矩形**（`LightSlateGray`，Dash 2,1，起点=按下点）[ItemsPage.cs:705-752]；此后持续更新矩形折线（三段 PolyLine）[ItemsPage.cs:754-790] |
| 左键释放（空白） | 移除装饰器；若 `IsEditCommentModel` 且矩形足够大 → `AddCommentBox(rect)` 创建**注释框**并退出编辑模式 [ItemsPage.cs:633-640]；否则 `GetItemsByRect(rect)` → 非空则设 `CurBoxOfItems`、`RectDragPanalRect=GetBoxRect()`（包围盒 inflate 10）[ItemsPage.cs:604-609]、`IsShowRectDragPanal=true` [ItemsPage.cs:642-652]；复位 `IsMouseDown` [ItemsPage.cs:611-667] |
| 单击空白 | `GetItemsByRect` 返回 0 项 → 不设 `CurBoxOfItems`；面板隐藏回调把 `CurBoxOfItems=null`（清除框选）[ItemsPage.cs:594-602]。**节点选中保持不变** |
| 双击空白 | 无专门处理（未确认） |
| 右键 | 空白菜单（见 A5）；菜单打开时记录鼠标位置 `ptPos`（粘贴/导入落点）[ItemsPage.cs:294-300, 311-314] |

## B. 拖放会话

### B1. 工具箱拖入
预览 `VirualForToolBoxGragDrop`：真实 `DiagramItem` + 0.7 Grid；3px 死区、`Round(pos/5)*5` 吸附（预览中心对鼠标）[VirualForToolBoxGragDrop.cs:34-100]。落点：`ItemsPage.OnDrop` → `GetDropItems`（5px 取整 + clamp [0,5000-尺寸]）→ `DoDropItems` → `DropItemsCommand` [ItemsPage.cs:322-404]。

### B2. 画布内单节点移动
`DiagramItem_PreviewMouseMove` 启动 DoDragDrop；`_dragDrop` 写入 `Point(预览偏移-controlOffset)` [DiagramItem.xaml.cs:716-737] → `ItemsPage.OnDrop`：Move→提交；**Ctrl 按住（Copy）→ 走复制粘贴路径**（OnCopyItems+OnPasteItems）[ItemsPage.cs:385-403]；取消时 `e.Handled=true` 原节点不动 [DiagramItem.xaml.cs:716-722]。

### B3. 框选后批量移动（CurBoxOfItems 机制）
1. 框选释放填充 `CurBoxOfItems` + `IsShowRectDragPanal=true` → DiagramPage 插入 `rectDragMask`（遮罩，收焦点/吃点击）+ `rectDragPanal` 面板 [DiagramPage.xaml.cs:564-580]
2. 面板按下拖整框 → `DiagramPage_PreviewMouseMove`：`DataObject{CurBoxOfItems}` + **双层 VisualBrush（整框快照+面板自身）0.7 预览** + **阻塞式 DoDragDrop** [DiagramPage.xaml.cs:613-696]
3. `_dragOver`：5px 吸附/3px 死区 + **逆变换缩放矩阵** [DiagramPage.xaml.cs:714-753]；`_dragDrop` 写落点（+10,10 校正）[DiagramPage.xaml.cs:698-712]
4. 提交/取消同走 `ItemsPage.OnDrop`；DoDragDrop 返回后恢复 `RectDragPanalRect=GetBoxRect()` [DiagramPage.xaml.cs:686-696]
5. 框选失效：面板 `LostFocus` → `IsShowRectDragPanal=false` [DiagramPage.xaml.cs:554-557]；隐藏回调清 `CurBoxOfItems` [ItemsPage.cs:594-602]
6. `CurBoxOfItems` setter 写镜像 DP `CurBoxOfItemsOfData`，并按 IsForbidden 比例设置 `IsCollapsedEnableItems/IsCollapsedForbiddenItems` [ItemsPage.cs:173-214]

### B4. 连线拖拽
端口按下 → 虚线跟随 → 命中节点（端口显示+最近端口高亮）→ 释放取最近端口 → `Connect()` [Connector.xaml.cs:81-276]；路径由 VM 层写入后 AStar 寻路渲染 [DiagramPage.xaml.cs:438-480]。

## C. 选中模型

- 节点选中 = `ListBoxItem.IsSelected`（`SelectionMode=Single` [ItemsPage.cs:292]）；连线选中 = `Connection.IsFocused`；框选集合 = `CurBoxOfItems` + 镜像 DP `CurBoxOfItemsOfData` [ItemsPage.cs:69, 173-226]
- 点击节点：ListView 标准单选；`IsOpenParams` 时单击拦截仅双击可选
- Ctrl+点击：无专门处理（Single 模式，未确认多选）
- 点击空白：不清节点选中；仅面板隐藏回调清 CurBoxOfItems [ItemsPage.cs:594-602, 644-652]
- 框选：`rect.Contains(itemRect)` 完全包含才入选 [DiagramPage.xaml.cs:382-389]
- 锁定态：禁拖 [ItemsPage.cs:584]、禁端口注入 [diagramitemtemplate.xaml:1154]、连线 IsEnabled=false [connectionstyle.xaml:28-30]、菜单 null
