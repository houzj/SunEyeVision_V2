## 三、稳定操作方法（本轮验证可用，后续沿用）

1. **先清障+置前**：Edge 等全屏窗口会遮挡画布导致 `occluded by link`。先 `focus-window --window-id <VM窗口> --headed` + `maximize --window-id <VM窗口> --headed`，确认 VM 为焦点、1936×1056。
2. **枚举节点**：`find --app VisionMaster --role option --limit 0 --timeout-ms 15000`。默认 5s 会枚举失败；给到 15s 可稳定拿到 42 个 option（含各节点 ref）。按 `name`（如"直线查找1""N点标定1"）取 ref。
3. **打开参数窗**：`double-click <ref> --headed`。焦点会丢，每次双击前先 focus VM。
4. **切页/关闭**：对参数窗 `snapshot --window-id <参数窗>` 取 tab/关闭 ref，再 `click <ref> --headed`（不带 --headed 不生效）。切页后用 snapshot 校验 states 含 selected。
5. **截图**：`screenshot <路径> --window-id <窗口id>`。参数窗固定 420×500。
6. **关闭参数窗**：`click <关闭ref> --headed`，校验参数窗数量归零。

## 四、自动化限制（历史记录）

1. 原厂画布节点的 accessibility 枚举不稳定：find 有时返回 option ref（可双击打开参数页），有时因参数窗/流程页切换导致枚举失败。
2. 参数窗关闭必须用 `click <close_ref> --headed`（带 headed 激活语义 API）；不带 --headed 的 click 不生效。
3. agent-desktop 的物理坐标点击与截图显示尺寸存在缩放差，按目测坐标点击易误中（曾误切到"流程2"页签）；优先用 accessibility ref + --headed。
4. 已得关键证据（圆查找三页）已足够验证 A 线 UI 对齐。后续如需逐节点取证 34 个工具，建议按"find option ref → double-click --headed → snapshot 拿 tab ref → click --headed 切页 → screenshot → click close --headed"的固定脚本批量执行，每步校验窗口列表，避免状态漂移。
