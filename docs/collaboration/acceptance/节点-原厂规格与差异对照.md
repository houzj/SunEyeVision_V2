# 节点规格：原厂源码提取 vs 我方实现（代码级对照）

> 方法：从反编译模板 `diagramitemtemplate.xaml` 程序化提取全部 75 条触发设置（`TargetName / Property / Value`），
> 再在 `WorkflowCanvasControl.xaml` + `ConnectionPort.xaml` 中逐条对照。**不再依赖截图喂图。**

## 1 原厂节点状态机（提取结果，两条模板变体规则一致）

| 触发条件 | 目标元素 | 设置 |
|---|---|---|
| `RunState = null` | `LogoIm` | `Image.Source = NormalImagePath`（彩色图标） |
| `RunState = True` | `StateFlag` | `Background = Col_EditProcess_Modular_OK_Status`（#0ABF3D） |
| `RunState = False` | `StateFlag` | `Background = Col_EditProcess_Modular_NG_Status`（#EC0000） |
| `IsModuleConfigCorrect = False` | `errorBorder` | `Visibility = Visible`、`StrokeDashArray = 3,2`；`itemBorder.Fill = 渐变 #FAF7F5→#E1E5E1` |
| 选中（`ListBoxItem.IsSelected`） | `errorBorder` | `Visibility = Visible`、`Stroke = #E76900`（**实线**） |
| `IsModuleFailed = True` | `itemBorder` / `StateFlag` / `LogoIm` / `Id` | 渐变填充 + 红状态条 + 白图标 + 编号 0.4 |
| `IsHited && !IsLockWorkArea` | 4 个 `ContentPresenter` | 注入连接点（`left/right/top/bottom`） |
| `IsModuleForbidden` | 循环箭头 | 换 `ic_cycle_right_disable` |
| `IsLoadFailed` | 右键菜单项 | 复制/粘贴参数/重命名 禁用 |

## 2 关键结构（原厂横向节点）

```xml
Path itemBorder          ← 圆角几何 + 阴影 #121111 / depth 3 / opacity 0.45
Canvas StateFlag         ← 状态条：Width=26，水平靠左，Clip 到 itemBorder
Image LogoIm             ← 图标 1:1（Stretch=None），Margin 4,0，靠左居中
Path errorBorder         ← 描边：默认 Collapsed，#636468 2px
Grid Margin="26,0,0,0"   ← 让开状态条宽度
  TextBlock Id           ← 编号，12px Bold，#4C4C4C
  HeadReNameTextBox      ← 名称，12px Bold，可原地重命名
```

## 4 剩余实现清单（按优先级）

1. **P1 状态条 StateFlag**：节点内左侧 26px 竖条，绑 `RunState` → OK #0ABF3D / NG #EC0000；须裁剪到节点圆角内
2. **P1 端口悬停保持**：端口 `OnMouseEnter` 时把 `PortLayer` 置 Visible，`OnMouseLeave` 时若节点未悬停再 Collapsed
3. P2 NG 编号透明度 0.4、失败态渐变填充
4. P2 节点宽度随内容（或统一放大到 135）
5. 待定：编号 0 基

## 5 说明

第 11 项（状态条）是当前最大视觉差异：原厂"状态色"画在节点左侧一条竖条上，图标保持白/彩切换；
我方把状态色画在图标底色上，观感不同。其余差异均已在本轮或前几轮修掉。
