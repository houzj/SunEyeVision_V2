## 3 我方现状（代码实证）

`CanvasNodeProjection`：

```csharp
public enum CanvasNodeRunState { None, Passed, Rejected, Failed, Cancelled }
```

`WorkflowCanvasControl.xaml` 已实现：

| 状态 | 我方绑定 | 颜色 |
|---|---|---|
| 运行通过 | `RunState=Passed` | `Col_EditProcess_Modular_OK_Status`（同原厂 #0ABF3D） |
| 运行拒绝/失败 | `RunState=Rejected / Failed` | `Col_EditProcess_Modular_NG_Status`（同原厂 #EC0000） |
| 未配置必需输入 | `HasUnconfiguredRequiredInputs` | 虚线描边 |
| 禁用 | `IsEnabled=false` | 描边显示 |
| 选中 | `IsSelected` | `Col_EditProcess_Modular_BorderBrush`（同原厂 #E76900） |
| 图标状态底色 | `NodeIconStatusBackgroundConverter` | 按状态着色 |

**结论：OK/NG 两态已用原厂同款颜色实现；缺的是「运行中」态与「加载失败」态。**
