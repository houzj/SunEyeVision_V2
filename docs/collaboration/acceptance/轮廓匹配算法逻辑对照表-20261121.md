## 本轮代码改动

- `ContourMatchTemplate.cs`：metric 由 Polarity 决定；CreateScaledShapeModel 宽范围建模型
- `ContourMatchSession.cs`：FindScaledShapeModel + scale 输出 + HomMat2dScale + Candidate.Scale + 尺度判断
- `ContourMatchResult.cs`：Measurement/Projection/ToValues/Row 全链路填充 scale（原为 null + Unavailable）
- `ContourMatchSettings.cs`：撤销 Polarity/等比尺度/尺度判断的 NOT_READY 拒绝；X/Y 独立尺度仍拒绝（新码 SCALE_XY_NOT_READY）
- 测试同步更新：30/30 通过，构建 0 error
