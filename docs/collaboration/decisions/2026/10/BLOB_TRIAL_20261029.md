# Blob 基础链路试用说明（2026-10-29）

此版本用于核对图像输入、Blob 实际执行与结果查看。它是两阶段目标中的**试用候选**，不是控件库或 Blob 全部完成。试用期间不重建主仓的正式 Release 或设计器依赖；结束验收后再集中整合修改。

## 可试用范围

- 本地图片导入、图像源与 Blob 连线；Blob 参数编辑及确认、取消。
- 工作流实际执行 Blob；查看结果树、结果表和图像。结果树和表从同一次运行的输出声明与结果发布读取。表格行有图像高亮；树选择本身不等于图像高亮。
- 可选：将上游 Blob 的区域输出作为下游 Blob 的检测区域来源；保存方案、重新打开后再次运行。

## 操作步骤

1. 运行 `Release/SunEyeVision_v1.0.0/SunEyeVision/SunEyeVision.UI.exe`，通过“文件 → 新建方案”建立测试方案。
2. 从工具箱拖入“采集 → 图像源”和“定位 → Blob分析”，连接图像源到 Blob 分析。
3. 选中图像源，在底部“图像源”条选择“添加图像 → 本地”，选择图片并选中缩略图。也可使用本轮整链自动测试生成的 `Release/_validation/S4-20261025/FullChain/attempt-163/document/input.png`：64×64 灰度图，包含两个亮区域。
4. 按“运行 (F5)”先运行整条流程，让上游图像结果发布。打开 Blob 窗口，在“基本参数 → 图像输入 → 输入源”检查图像来源；位置修正保持关闭。
5. 在“运行参数”设置单阈值；对上述测试图可先使用阈值 128。点击窗口“执行”查看私有调试，点击“确定”提交参数，然后再按 F5 查看正式结果。本轮自动整链在默认参数下得到两个区域；自己的图片结果以实际内容为准。
6. 选中 Blob 查看结果树与结果表；可检查表格行高亮。需要测试保存时，请将测试方案另存为新文件，再重新打开、执行。
