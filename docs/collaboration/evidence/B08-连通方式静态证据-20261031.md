## 已证实

- VM 4.4 原始 `D:/Program Files/VisionMaster4.4.0/Applications/Module(sp)/x64/Location/IMVSBlobFindModu/IMVSBlobFindModuAlgorithmTab.xml:1392` 声明枚举 `connectivity`，可读写，算法索引 `0x060B`，当前值和默认值均为 `0x8`；`Connected_8` 值 `8`、`Connected_4` 值 `4`，均标为已实现。此项还声明 `CustomVisible=False`；不能仅凭此判定所有运行状态的界面可见性。
- 同目录 `IMVSBlobFindModuAlgorithm.xml:108` 独立声明 `connectivity` 默认值 `8`；`IMVSBlobFindModuCs.xml:493` 将两个选项分别标注“8连通”“4连通”。资源文件只证明声明，不证明每次运行的当前值。

- `analysis/full-audit/b08-blob-low-20261030/output/0x18001e3c0-18001e3c0.c:338` 和 `0x180022500-180022500.c:625` 的原模块反编译均出现小写 `connectivity` 字符串分支。这证明名字进入相关分派代码，不能单凭名称比较证明具体值已送达连通域算法。
