# B08 解绑与触发文本：集中迁移决策

本文件汇总本轮对 Blob `LowThreshold` 和触发字符串的静态取证。适用身份、原指令、SHA、精确分支及失败记录分别见下列证据；未运行原厂程序、SDK、COM 或修改用户方案。尚未证明的值不得据 XML 或 UI 惯例填补。

## Blob 低阈值

原 XML `LowThreshold` 的算法索引为 `0x0603`，CurValue/DefaultValue 是 `0x64`；这只是 XML 配置，并非已证明的解绑回读值。普通读取请求从 `IMVS_GetParamValue` 的 0x3f8、`Get` 分支经代理 0xbc0 到候选 ModuleFrame `VM_M_GetModuleParam`，正常对象调用 vtable `+0x10`。Blob 工厂/构造的 vtable `+0x10` 对应其 `GetParam`；该参数命中后转发 Blob 算法实例 `+0x58`，再通过句柄调用 `MVD_Algorithm_GetValueByString`。同名 Set 走 `+0x18 → +0x60 → MVD_Algorithm_SetValueByString`。实际加载映像身份和句柄内部存储/订阅注入仍按证据边界保留。

补核算法内核：句柄类型 `0x12d` 的虚表读写分别进入 `18004aed0` / `18004b360`，通过实例 `+0x510` 的运行时名称表进行分派。名称允许、非特殊分支、解析/回调成功且是同一实例时，Get 与 Set 通过 `180007c30` 定位同一按名树；Get 取节点值，Set 更新对应值并标脏。尚未证明 LowThreshold 在该表中的实际索引及是否命中该普通分支，不能用 XML 的 0x0603 代替运行时映射。之前全量 Ghidra 工程 OOM；本轮用 `-noanalysis` 定点取得相关导出及原指令，失败与新结果均保留在 Blob 分册。

回读与执行订阅是两个入口：`VM_M_GetString` 的特定查无订阅分支返回 `0xe000031b`，不能作为 `IMVS_GetParamValue` 的返回值，也不能直接判定算法消费的最终值。解绑删除关系后有无间接写该算法句柄尚未闭合。**迁移决定：禁止把 XML 默认 100、最近执行值或旧常量作为已证恢复值；保留读取失败、未确认解绑和参数回读的区分。**

证据：[SDK 代理桥](B08普通参数回读SDK代理桥证据-20261030.md)、[Blob 具体对象](B08-Blob低阈值原生参数对象追踪-20261030.md)、[解绑读取消费](B08解绑后运行时读取缺失关系补证-20261030.md)。

## 触发文本

已核单次或连续允许分支将入参复制到流程对象 `+0xa8`；已核 GLOBAL=2 字符串 IO 从相应流程对象读取它。正常执行路径随后可将该字段复制到关联任务对象的 `+0x100`。另有 `##TriggerCmd##` 写入从具体任务输入对象的 `+0x100` 取值；尚未证实该对象就是上述关联列表中的对象，不能将名称、两个对象字段与写入点视为同一个存储。普通忙拒绝分支在复制前返回；特殊递归例外单列。停止、取消、关闭重开和所有间接清理不应推断为一律清空或保留。

证据：[流程与任务传播](B08触发文本流程与任务对象传播-20261030.md)、[内部键与对外读取](B08触发字符串内部键与执行后写入-20261030.md)、[连续和停止](B08触发字符串连续运行及停止补证-20261030.md)。

## 最小区分矩阵与剩余工作

| 问题 | 最小区分输入／原始函数 | 判定边界 |
|---|---|---|
| 解绑后 Blob 参数 | 配置常量 A、绑定提供 B，执行一次后解绑；分别读 UI 配置与执行消费者，再重开；A、B、XML 默认应取不同值 | 尚需 `+0x510` 名称表创建及 LowThreshold 实际索引、执行订阅注入是否写名称树，以及解绑 `1800bd7c0` 子调用的间接影响；隔离实例可用前不执行 |
| 正常、忙拒绝与连续 | 在同一流程以互不相同的 A/B 分别触发，覆盖允许、忙拒绝、连续开始和停止 | 只能对命中相同对象和所核分支给结论；特殊递归及并发单独核 |
| 任务和流程身份 | 追 `180115440` 的关联列表成员与 `proc+0xc8` 构造/指针关联；必要时在隔离实例比较身份及 A/B 文本 | 目前不能断言所有 `+0x100` 是 `+0xa8` 对应副本 |
| 关闭重开 | 追 `18006ee20` 的移除及引用析构、加载与反序列化；隔离条件具备后执行带区分文本的关闭重开 | 目前未知文本或内部命名项最终对外值 |

这份矩阵不是运行验收结果；B08 尚未闭合。原始材料中 SHA 与具体代码位置以各分册为准。
