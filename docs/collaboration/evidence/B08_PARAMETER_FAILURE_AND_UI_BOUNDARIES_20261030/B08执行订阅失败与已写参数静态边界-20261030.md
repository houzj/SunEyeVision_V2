# B08 执行订阅失败与已写参数的静态边界

只读已保存原 ModuleFrame.dll、Blob DLL、MVD_Algorithm.dll 的反编译及 x64 指令；未运行原 SDK/VM。结果限于所核对象、正常绑定分支与相应二进制身份。成功样本和历史失败另见 [集中决策](B08解绑与触发文本迁移决策-20261030.md)；不能将本报告的静态路径冒充失败样本实测。

## 条件分支与可实施决策

| 场景 | 已核证据 | 可实施结论及边界 |
|---|---|---|
| 多参数第 N 项来源读取失败 | `ModuleFrame!1800b98c0` 遍历已取得的绑定链表，每项调用 `1800b9c70`，汇编 `1800b9a53–a84` 保存返回值，非零跳往错误分支、结束遍历；`1800ffd00:180100051–05d` 的非零分支跳过该任务对象 `vtable+8`。整数分支 `1800ba0e0` 的 `GetBindingInt` 返回非零不进入该项 `1800bc680` setter。 | 所核框架分支不是“所有来源先验证后批量提交”；在失败项前已成功调用的 setter 没有在 `1800b98c0` 已读循环中看到对应逆向写回。**但**失败处理、共享引用析构、其它线程和下游 helper 全部副作用未闭合，不能把“该函数未见回滚”升级为失败后最终值必然保留的运行事实；失败项未进入其 setter不代表以前运行/其他线程没有写同名参数。绑定遍历顺序以真实容器为准，不能当 UI 显示顺序。 |
| 参数名/数值解析失败 | MVD 内核 `18004b360` 原指令 `18004b524–52d` 调 `180002af0` 解析，非零跳至错误路径，位于该方法 `180007020` 写入调用之前。`180002af0` 检查元数据、数据类型并对字符串调用相应解析器。 | 对已核普通分支，可确认该条解析失败不进入 `180007020` 写调用；更早分支、解析器本身副作用或并发未证，不得说所有非法输入绝对保持所有状态。XML 的 `0x0603` 不是已经证实的运行时分派编号。 |
| Setter 写入后报告失败 | `18004b360:18004b6f4–70a` 调 `180007020`；成功后 `18004b761–77b` 再调 `180002e70` 并将返回值传出。已核 `180007020 → 180006ec0` 回调成功后进入 `180006c70 → 180007790`，同名称树命中且内容变化时写节点并标脏。 | 有一条**先成功进入缓存写路径、再调用可能返回错误的后续函数**的静态顺序；故“setter 返回非零 ⇒ 本次未写缓存”不成立。具体 LowThreshold 是否走此分支、`180002e70` 实际错误及其可能补偿/改写尚未取体，当前只能要求保留结果不确定及后续真实回读，不能宣称现场必现已写。 |
| 算法执行返回异常／失败 | `1800ffd00` 只在绑定处理为零后调任务对象 `vtable+8`；Blob 的 `CVmAlgModuleBase::Process@180010840` 输入及 `180010a70` 成功后调用本模块 `+0x38`，并执行 `1800103d0` 及临时资源释放；被调算法结果可能非零。 | 已证明正常任务入口在绑定写之前/之后的顺序为“绑定处理成功→任务调用”，已读函数未出现以保存的旧 LowThreshold 还原参数调用；但未经闭合调用对象身份、所有异常/析构及 callback，不能断言任何算法失败后参数必保留。应把执行失败与参数写结果分开观察，保留失败信息。 |
| 停止/取消 | `1800dd030` 设置停止事件、清流程连续标志并等待；`1800dd330` 有运行循环和结束状态更新。 | 所核函数体没有明确的逐参数旧值恢复；停止时与调度/本轮 setter 的先后、下游和线程交错未知。不能承诺取消必回滚或必保留，也不能把一次停止当成保存重开结论。 |

`1800ffd00` 失败分支还调用 `18001e4e0`，该已取函数直接在锁内更新其输入对象 `+0x58` 及关联向量，并无直接工具参数写入；`18001f010`、后续其他调用和共享引用的间接影响仍需单独取证。

## 精确尚未闭合的最小边界

1. `MVD_Algorithm!180002e70` 函数体及其失败/补偿副作用、`180006ec0` 实际回调对象：确定“缓存先写后后续失败”对最终值的完整效果。
2. `ModuleFrame!1800ffd00` 失败处理的动态销毁/回调及所有线程交错；明确多绑定执行次序和前项写入是否在其它路径回滚。
3. 某个已确认任务实例与 Blob `vtable+8` 的对象身份、算法/异常/停止在该实例内的触发顺序。
4. UI `ValueBase` 的额外读取校验和解绑行为不属于本页；整数成功样本不能直接扩展到 Bool/Float/String 或失败后的原厂 UI 行为。
