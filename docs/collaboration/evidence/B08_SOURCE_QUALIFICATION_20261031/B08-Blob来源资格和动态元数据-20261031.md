## Blob 资源的具体例子和限制

原 XML Output 声明 `Area` float 且 IsArray=true、`TotalArea` float、`BlobNum` int、`CentroidPoint` POINT 组合含 CentroidX/Y float；这些是类型/层级原始声明，并非 SDK 必然返回结果。XML Output 中 `Output Position Correction Info` 及其 fixtured/unfixtured 子组合和各个相关叶均显式 Visible=false（行 246–265）；`OutputMask` 四叶 `AllowAutoSubscribeByOther=False`（240–243），该标记影响自动订阅能力，不能据此直接剔除手动来源树。`CanSubscribe=false` 若出现在 XML 被注释的 ContourX 等行，不是活动声明。已按 XML parser（忽略注释）确认活动 Output 树中无显式 CanSubscribe/IsPrivate；不代表返回 SDK 结构在运行中必然没有覆写。

`IOData_Undo/Redo`（VmModule.cs:5412–5472）以 `SetModuOutputIOInfo` 修改 SDK 输出配置，再 InitDynamicIO/Done_IOData；这确认存在可变输出配置与重建路径，不证明 Blob 任意静态项由哪一端写入或每次会自动通知消费者。选择树应基于当前返回结构、真实标记和类型构建，兼顾动态更新、失败、重复名与叶父链；不能直接将 XML 默认等同所有运行实例资格。`IsArray` 是声明的单独维度，本文普通 GetOutputTreeNode 未见用它筛选。
