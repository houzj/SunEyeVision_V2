# VM 4.4 Blob 整工具迁移：原始证据链与边界

基准为 VisionMaster 4.4.0 Build20250516@1555331 的现有材料。本报告汇总已取证的调用边，不宣称整个算法、全部分支或 UI 与原版等价。状态：**已证**＝指定文件/分支的静态或限定样本事实；**条件推断**＝关联依赖明确前提；**未证**＝不得作为原行为。本文不运行 VM/SDK，也不改插件工作树。原始 DLL 和分析文件仅在本机，部分被 Git 忽略；下列哈希用于锁定身份。

## 一、整体链和身份

## 三、迁移设计可直接采用的边界

1. 工具专属层消费统一框架的参数模型、来源选择、ROI/屏蔽与会话合同；公共能力由框架线交付，工具层不可擅自复制另一套。两个工作树保持各自所有权。
2. 静态清单中的字段、名称、层次和默认声明可用于构造适配器，但必须区分声明默认与当前实例状态。显示、订阅关系、算法参数和输出 IO 分开建模；不按图像输出名称臆造数值结果。
3. 原行为缺证时，只有在既定调查范围内找不到可操作证据而实施确需继续时，使用标注为“自研假设”的可替换策略：记录具体取值、影响字段、调用位置和替换条件；本文不指定某种算法冒充原版。
4. 固定已证资源合同的版本和摘要；审阅时每个迁移字段回链 JSON 或具体源码/成员；底层输出值、异常码和生命周期分别记录其验证状态。通过本地测试不等于原厂等价。

## 四、需隔离条件的原机差分及优先顺序

1. **参数与执行**：各阈值模式的边界值/极性、软阈值，填孔 `T-1/T/T+1`、对角接触 4/8 连通；比较多组件筛选前后及排序顺序，并记录实际参数回读、输入输出像素、返回码。
2. **输入交互**：不同 ROI、非矩形 Domain、屏蔽区、位置修正、无输入/错误格式；记录执行状态、结果及显示与保存重开。
3. **输出**：每项数据的类型、索引、排序、数值单位及几何基准；BinaryImage/BlobImage 原始字节、像素格式、尺寸、筛选关系和 Domain。
4. **绑定与生命周期**：多参数订阅顺序、更新和失败中断、解绑、保存重开、取消、连续运行停止、关闭后的句柄及订阅状态。

现有 attempt03 是有限单绑定材料，不是上述全套差分。由于原 SDK 初始化可能影响共享脚本、COM 和清理目录，须先获得隔离 Windows 环境并审查副作用；本次没有可用隔离环境，也没有执行上述试验。历史隔离审计见 [受控探针边界](B08与图像源受控探针隔离审计-20261030.md)。
