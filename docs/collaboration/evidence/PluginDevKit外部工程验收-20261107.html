PluginDevKit 外部工程验收

来源包：PluginDevKit　验收目录：_validation/ExternalSdkAcceptance

验收目录仅复制开发包，不复制主解决方案、主仓库源码或旧 Plugin.SDK。SDK 目录只包含 Contracts、Runtime、Wpf、Foundation 以及 Contracts XML。

程序集身份验证

通过标准命令 PluginDevKit/scripts/validate-components.ps1 读取 RuntimePlugin 与 WpfTool 程序集，确认已写入 ToolComponentAttribute。Runtime 组件为 ExternalRuntimePlugin.Runtime，Editor 组件为 ExternalRuntimePlugin.Editor，两者共享 ExternalRuntimePlugin 工具身份，契约版本来自 Contracts 6.0。随后使用 Runtime 中的 ToolComponentCatalog.Prepare 完成 Runtime/Editor 配对准入。

外部 Runtime 执行烟测

独立目录中的 Smoke 工程从发布 SDK 加载 RuntimePlugin.Template.dll，通过 ToolRuntimeExecutor 执行输入并返回 external-smoke，验证外部 Runtime 组件可以被加载和调用。

外部 Editor WPF 烟测

STA WPF Smoke 工程从发布 SDK 加载 WpfTool.Template.dll，创建 IToolPresentationFactory 并成功生成结果视图。

Debug 外部开发宿主启动

使用 PluginDevKit/scripts/build-runtime.ps1 -Configuration Debug 生成 dev/Debug 宿主后，将 RuntimePlugin 与 WpfTool 放入开发插件目录，启动 PluginDevKit/runtime/SunEyeVision.UI.exe 12 秒保持运行，进程正常存活并可被停止。Debug 宿主不使用正式 Release 的强清单。正式 Release 仍只接受 product/ToolComponents.props 中声明的产品组件。
