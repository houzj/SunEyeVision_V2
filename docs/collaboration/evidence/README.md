# 证据区（evidence）

> 这里只放**可以复核的原始材料**：原件源码副本、原件窗口截图、扫描器/检测器输出、导出包。产品结论不要写在这里，写进 `decisions/` 或 `docs/09-现行文档/`。

## 为什么单独成区

证据文件数量大（876 个文件、约 25 MB），如果混进文档索引，会把真正要读的文档淹掉。因此 `docs/00-索引/文档索引.html` 对证据区**只登记目录级汇总**（目录 / 文件数 / 体积 / 最后更新），不逐条列文件。要具体文件就直接进对应子目录。

## 目录构成

| 子目录 | 内容 |
| --- | --- |
| `公共控件未编译原件资料-20261103/` | 原厂公共控件未编译源码副本（按 `src/Plugin.Wpf/...` 原路径保存） |
| `公共控件原始本地化资料-20261103/` | 原厂控件本地化字符串与资源 |
| `UI旧测试源码保全-20261103/` | 旧测试源码保全 |
| `B08_*`、`BLOB_WHOLE_TOOL_VM_20261031`、`WORKFLOW_BLOB_SYNC_20261031` | B08 / Blob 系列取证批次 |
| `previews/` | 预览截图 |
| `根流程集合UI外观-20261104/`、`暂停Group宿主旧依赖归档-20261103/` | 对应批次的界面外观与旧依赖留档 |

根目录散放的 json / html 是单批次检测与审计输出（如 `B08_*_2026103x.json`、`*证据-20261102.html`），文件名带日期，按日期检索即可。

## 关于 `.pending` 后缀

`公共控件未编译原件资料-20261103/` 下约 102 个 `*.cs.pending`、`*.xaml.pending` 是**原件源码副本的刻意命名**（加 `.pending` 防止被当作工程源码参与编译），不是临时文件、不是垃圾，禁止清理。迁移目录时整树保留，不要重命名。

## 写入约定

1. 一批证据一个子目录，目录名带日期：`<主题>-YYYYMMDD/`；
2. 目录内保持原始相对路径，便于和原厂目录对照；
3. 新增证据后重跑 `docs/00-索引/更新索引.ps1`，汇总行会自动更新。
