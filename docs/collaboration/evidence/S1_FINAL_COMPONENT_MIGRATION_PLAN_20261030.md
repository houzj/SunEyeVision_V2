## 接入、所有权与验证

ContentToggleSwitch的源码和两个dark资产从总监提交按原样接纳；源分支仅Catalog追加登记处存在基线差异，按B01.content-toggle-switch单条合并，其余公共源码/manifest增量原样应用，不引入总监无关工作区/当前任务/构建产物。原PCUI旧类型不留别名，另一个Apps.XmlUI参数开关保持其家族语义，不误合并。

纯UI投影DP不是第二套正式模型：Refresh读取Session值，在_refreshing内用SetCurrentValue回填；内部TO.Checked/Unchecked读取sender.IsChecked并只发送一次SetAutoSwitch意图。初始化和程序性回填不落编辑；只读或退役输入恢复；请求拒绝仍保留原配置、历史和结果，界面恢复到正式值。Attach订阅OnCheckedChange，Detach先退订再取消旧请求/释放可视范围，内部ElementName Binding不持有外部业务对象。多个实例不共享Image视觉对象。

验收整条链：实际源条内部TO的两向Click、初始化/回填零执行、一次正式接纳、拒绝恢复、只读恢复、所有者更换/旧事件不落新源、卸载重载及迟到事件；与保存、历史、结果只显示的已有真实宿主回归合并验证。模式与标题按现有资源查询，标签重建不改模式、不执行、不产生配置历史。之后同版正式UI及全量Release构建和相称回归，复用356项基线，仅因新变更/失败补测。
