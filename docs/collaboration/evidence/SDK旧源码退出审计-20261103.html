核心判断

被 Compile/Page Remove 只表示当前不编译，不证明全仓不使用。Group/循环代码按现行暂停约定保留，普通旧工具和历史测试不能偷偷复活。未准入旧工具的源码引用应列迁移待办；不可因为搜索到引用就保留兼容桥，也不可把工具已迁移与源码清理混称。
对象证据和决策
5 个 RoiEditor.ModelsNodeOutputInfo 是旧节点输出选择器树；ParamSettingItem 是旧 ROI 参数与字符串绑定；RoiEditorSettings 是 WPF 颜色与编辑器显示；RoiSourceMode 是绘制/订阅 UI 模式；RoiType 是旧图形选择枚举。源码主要被已排除的旧 ROI 编辑器使用，当前 Wpf NativeRoiSession 的同名 RoiType 来自 Apps.XmlParser，不是这套。实际 SDK/ToolRegistry 中存在 RoiEditor.Models 的 using，需确认并清除这些无具体类型使用的引用后整体退出；新原件 ROI 不应依赖旧模型。
Plugin.Editing.WpfSDK 项目仍直接引用；检索调用仅在已排除的 SDK UI/Windows 和 UI/Controls。建议在完成真实编译引用清点后删 SDK 此项目引用，不能删除 Plugin.Editing.Wpf 项目本身：正式编辑事务消费者仍需它。
System.Drawing.CommonSDK 直接包引用；源码中的 System.Drawing 使用在已排除 UI/Controls/Roi/Rendering/RotatedCursor.cs；先以实际编译清单和构建/打包验证再撤引用与锁文件，不能单凭注释判定。
UseWPF仍有活跃 System.Windows 几何与显示模型、IVisionImageDisplayBridge.BitmapSource、IToolEditorFactory.Window。App.xaml.cs 注册显示桥、CameraPreviewHost 消费；Workflow/GlobalVariableValueConverter 使用 RoiShape、AffineMatrix 序列化。不可本批直接关闭 WPF；需先按目标职责迁合同和所有消费者，含持久化与相机生命周期。
工具分类资源Metadata/ToolGroups.xml 被 SDK/Core/ToolCategories 反射读取，Plugin.Infrastructure/ToolRegistry 排序使用；UI csproj 作为 Resource 和 Content 链接，VmToolboxCatalog 加载。迁资源需同步所有链接、资源名、部署与排序测试，不可随 Generic.xaml 一并删除。
打包与主题SDK csproj 描述仍称零依赖、旧 IToolPlugin、调试控件；PackageReadmeFile 指向 README.md，但 SDK 目录未找到此文件，csproj 未见明确 Pack 项，须执行 pack 查明实际结果。AssemblyInfo ThemeInfo 和 Generic.xaml 注释指向已退出控件，退出前查其余程序集主题及设计器引用，更新 PackageTags、readme 与文档，不能只改描述。
测试静态检索 tests 中 33 个文件含旧 SDK UI/相关词；需逐项目确认是否当前正式测试、暂停 Group/循环或历史旧工具，迁移有价值的行为验证，退出已失效旧测试。Group 相关源码/证据保留，不将其通过作为本批完成条件。

包验证与准确出口

  1. 候选独立 worktree 固定基线，源和依赖变更一次提交；离线 restore 检查锁文件变化，正常 SDK Release 和全量 Release，使用本地正式 HalconSourceRoot，不覆盖其他工作区。
  2. 使用独立产物路径执行 dotnet pack（指定输出目录与隔离 MSBuild 输出），检查 nupkg 内 README、nuspec 描述、依赖声明、SDK DLL 和 XML，验证内容 SHA/版本；确认无旧可视资源和五类型，同时确认 ToolGroups 嵌入资源及 UI 发布路径有效。不要据 pack 通过宣称工具行为通过。
  3. 执行已准入 ImageLoad/Blob 正式/调试宿主、分类加载及排序、ROI 绑定和结果、根流程编辑保存重开、相机帧与关闭现有回归；负载与实际构建提交哈希记录。同一正式验收链不得借用其他 worktree 的 Release。
  4. 禁用入口、未准入旧工具、暂停 Group、物理相机、设计器及人工验证分别记录；新问题需要追证时整批收敛，不为清理引入 WPF 图像桥或全局变量架构重写。
