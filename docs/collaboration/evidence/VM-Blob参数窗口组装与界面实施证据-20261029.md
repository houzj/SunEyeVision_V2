# VM Blob 参数窗口：组装、界面与最小适配

基准：VisionMaster V4.4.0 Build20250516@1555331。此文服务于“先完成界面，再完成算法功能”的实施批次；资源确认指随版 XML/XAML 或反编译托管代码，待确认指现有材料不能判断的行为。

## 完整资源与组装

[参数资源索引](Blob参数资源索引-20261029.json) 保存三个页面的 96 个直接项和 8 个被引用的 Group 定义，每项包含原始 XML、源行号、候选、默认值、绑定和触发器。[导出脚本](导出Blob参数资源索引-20261029.ps1) 从指定安装路径生成索引。XML 注释项不纳入活动字段；直接项数不等于最终可见控件数。索引不替代运行时条件与算法证据。

1. 工具的 IMVSBlobFindModuAlgorithmTab.xml 定义三个页面及其类别、控件与条件；Applications/Module(sp)/Group.xml 定义共享输入、ROI、文本组。GroupLinkItem 展开成组中的各项。
2. VMControls.WPF/ParamsConfigControlBase.xaml.cs 的 OnParamsConfigChanged 处理旧根、加载模块控件 DLL、检查 XmlPath、取得 AlgorithmTabRoot，调用 DoIniter 和 GetItemsValueUnit，再设 DataContext。AlgorithmTabRoot 构造器加载 XML 并 DynamicSetProperty。打开已有节点应先恢复其现有参数，而非每次强制采用 XML 默认。
3. ParamsConfigControlBase.xaml 挂 ParamsTabUserControl。后者绑定 TabsA 和 TabIndex，以 IsVisible 控制标签；普通页使用 ParamListView，特殊面板使用 gridPanal；底部按钮由 BottomExcuteButtonsA 等数据提供。顺序遵循 XML，滚动与样式查原模板。
4. Apps.XmlUI/ParamUserControl.xaml.cs 以数据 DisplayType 选择模板，外部类型可从程序集加载 DataTemplate/ParamUserControlDataTemplate.xaml。EnumerationG、ButtonSelecter、普通 Enumeration 使用不同的模型和交互。
5. Window_Closed 关闭连续自执行状态、注销列出的相机等委托，再调用 AlgorithmTabRoot.Dispose 和 DoFinish；当前 Dispose 源码仅设置 IsSubscribeInWindow=false，不能推断全部算法和设备资源已释放。替换 ParamsConfig 时旧根 Dispose，关闭订阅窗另清理 DataContext；关闭窗口不应清除节点参数。

## 基本参数

ImageSourceGroup 在 Group.xml 第 5 行展开为图像输入类别及 EnumerationG ImageSource：GetFrontParamItemsOperation(IMAGE) 初始化上游图像候选，GetSelectedCombinationOperation(InputImage) 恢复当前选择，改变值调用 SetCombinationSourceOperation(InputImage)。候选应从当前流程可用上游结果取得，显示来源的可读名称，不能固定为某个图像源。

ROI Area 依次引用 OutputMaskImageGroup、InputMaskImageGroup、RoiSelectGroup，接 RoiType，再接 InheritWayGroup2、ExternROITypeGroup、AssistGroup。ROISelecter RoiType 声明 Mul、Box/SectorRing/Polygon/Sector、最多 16 个、FullScreenEnable=True、初始 CustomVisible=False；各组具体字段及触发器见索引 linkedGroups。

## 运行参数

ThresholdType 默认 2；切换触发以下界面显示，XML 不证明具体算法公式：

| 值 / 枚举 | 显示依赖项 |
|---|---|
| 1 BinaryImage（无二值化） | Polarity |
| 2 SingleThreshold | Polarity、LowThreshold |
| 3 DoubleThreshold | LowThreshold、HightThreshold |
| 4 AutoThreshold | Polarity |
| 5 FixedSoftThreshold | Polarity、ThresholdRangArea、Softness |
| 6 RelativeSoftThreshold | Polarity、Softness、SoftLeftRatio、SoftRightRatio、SoftLowRatio、SoftHighRatio |

Polarity 默认 0。原 XML 的内部枚举名与展示描述看似相反：DarkOnBright=0 对应 Brighter Than Background，BrightOnDark=1 对应 Darker Than Background；保留值和资源展示映射，算法语义另核。Low/High 默认 100/150、范围 0–255；Softness 默认 254；四个比例默认 5/5/40/60、范围 0–100。FindNum 默认 100，HoleMinArea 默认 0，面积过滤默认启用；另有轮廓类型、Blob 图和二值图选项。HightThreshold、BolbImageEnable 是原资源拼写。

Expert 默认折叠，展开后触发直方图信息、最大内接矩形数、角度、矩形宽高、周长、长短轴、圆度、矩形度、中心偏差、轴比等过滤及排序、连通性、最大输出像素数。各范围依赖自身开关和 CustomVisible=True；多个项初始 CustomVisible=False，其运行时如何打开尚未完整证实。排序有 13 个特征；排序模式 1 升序、2 降序（默认）、3 不排序；连通性默认 8，可选 4。OverlapRatio、MaxOutPixelNum 等全部直接项及条件均保存在索引。

## 结果显示

ResultShow 的 Check Result 先包含零个 Blob 判定、数量/面积/总面积开关及范围；展开后包含质心 X/Y、角度、中心 X/Y、外接框宽高、周长、长短轴、圆度、矩形度的判定项及范围。结果区 Expand 指向 ScoreLimitEnable，但 ScoreLimitEnable/RangScoreLimit 本身被原 XML 注释，不能当作已确认活动控件。

Image Display 配置 Blob、最大内接矩形、ROI、轮廓点、基准点、文本、屏蔽区、环形区域等显示对象，具体显示条件见索引。TextDisplayGroup 包含内容、OK/NG 颜色、字号 6–72、透明度 0–1 和 PositionX/Y；内容/颜色等由显示对象操作桥接到 Show Text，位置候选取前序及自身 int/float filter，修改通过 SetResultIOToModuleOperation 写对应订阅关系。显示控件与算法结果是两个不同状态。

## 选择器及范围

- 图像输入是 EnumerationG：初始化 IMAGE 候选、恢复 InputImage 组合，切换写组合来源，不可只保存显示文字。
- 数值订阅为 ButtonSelecter 和 SubTreeView。后者递归绑定 EnumEntrysA 和本地化名称，叶节点双击选择。普通 VmIO 按 ModulePathName 加旧方括号后缀或空 [] 构建表达式；空 Holder 或 Delete 可以清除。选叶即更新并关闭，未见独立确认命令；setter 异常时尝试恢复旧值。
- 整数/浮点范围两端各自绑定值、IsSubA 和 SubData，左右端独立切换订阅；失焦更新，popup 关闭会更新来源和触发端点变更。WPF RangeRule 根据全局及启用的 XML 范围验证；未找到通用成对原子确认或 Escape 回滚依据。

## 最小非视觉适配和集中验收

UI 可以先完成标签、布局、模板、模式切换、展开、显隐、文本编辑、颜色和范围交互。真实消费至少需要：节点参数读写与重开回填；流程 IMAGE 候选及数值来源树、已选值和独立上下限订阅；ROI 绘制/继承状态及视口接口；文字/图形显示对象桥接；执行命令及结果模型接口。受控占位数据应明确标记，不能冒称算法或真实连接已完成。

集中验收：新建和重开；三页顺序与滚动；六种阈值逐项切换及保值；高级全部开关与双端独立切换；结果判定、图形、文本及位置树；无上游、单图、多上游、清除重选；绘制与继承 ROI；关闭重开、订阅事件不重复。对照索引逐项检查全部 96 项与 8 组，按实际条件确认可见性。

待补证：高级范围的 CustomVisible 在实际宿主的改变路径；图形/ROI 点击反向选择结果行（当前仅证实选表行高亮图形）；同主题、DPI 和窗口环境的实际像素差异；以及阈值、筛选和排序等算法结果。此次没有启动或修改用户正在试用的程序。
