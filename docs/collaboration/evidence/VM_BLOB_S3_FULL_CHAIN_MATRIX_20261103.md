## 2. 六种阈值模式

枚举名称来自 `IMVSBlobFindModuAlgorithmTab.xml`，是参数声明，不自动证明处理公式。表内 HALCON 组织方式是迁移方案，并非原内核实现。

| 模式 | 原版已证与边界 | 自研组织 / 缺口 |
|---|---|---|
| 1 BinaryImage | XML 声明该模式。输入值解释、非二值像素和域语义未闭合。 | 可设计独立二值输入适配策略；策略及输入验证须标为自研，不能把任意非零解释成已证原行为。 |
| 2 SingleThreshold | 8 位已核标量分支 `180724740`：`p≥t` 输出 255；`180724c20`：`p<t` 输出 255。极性写入及对应跳转见 [极性链](B08-极性写入跳表与执行链-20261101.md)。 | HALCON 可按上述端点组织 `Threshold` 与补集；受整数阈值范围和域限制。其他像素格式、CPU 分支与全域效果分别核验。 |
| 3 DoubleThreshold | `180724630` 的已核 8 位标量分支在 `low≤p≤high` 输出 255，补分支在区间外输出 255。 | 使用包含两端的区间和域内补集；上下限倒置、其他格式与输出图像关系另核。 |
| 4 AutoThreshold | XML 声明模式；阈值计算方法及取样域未证。 | 不把某种直方图算法冒充原版；在具体静态入口耗尽后，可选显式、可替换的自研策略或保持未实现。 |
| 5 FixedSoft | XML 声明模式；软阈值计算和参数含义未完整恢复。 | 同上，不能仅凭名称猜公式。 |
| 6 RelativeSoft | XML 声明模式；相对量基准、公式和边界未完整恢复。 | 同上；独立于 FixedSoft 管理策略和替换点。 |

端点和具体函数见 [像素静态补证](B08-阈值像素与区域处理静态补证-20261101.md) 与 [优化路径补证](B08-阈值优化路径与参数索引补证-20261101.md)。不同日期的旧报告对尚未追到的字段持保留态度；以其后具体写入和跳表证据为准，不将局部分支推广为全部模式。
