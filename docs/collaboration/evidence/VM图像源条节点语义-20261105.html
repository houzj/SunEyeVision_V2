图像源条「按节点差异」语义 —— 五项取证

取证日期 2026-11-05 ｜ 原件 VisionMaster 4.4.0（Build20250516@1555331）｜ 反编译源码库 docs/07-工具逆向/decompiled/WpfControls/VMControls.WPF/｜ 完整卡片 docs/07-工具逆向/tools/imagesourcemodule/

三条纠偏，会影响实现方式：
1. 「自动切换 / 运行全部 / 运行」不是三个按钮：「运行全部 / 运行选中」是一个 ComboBox 的两个选项，「自动切换」是一个开关，两者都属于模块参数，不是主工具栏命令。
2. 条内显示的图不是"上游来源的图"，而是当前参数页所属模块自己的图像参数（Root.FindBaseNodeByName("CurrentImagePath")）。
3. 计数 0/0 不是"当前序号/总数"这么简单：前一个数未选中时为 0，后一个数是列表项数，删除当前图或清空会把它打回 0。

结论摘要

问问题档位结论
1选中图像源节点时条内显示什么；0/0 两个数字含义 直读 条头文字 = 「图像源 (N/M)」。N = CurImageIndexT（当前图序号，内部 0-based，对外 +1；未选中为 0）；M = lst.Items.Count（图像列表项数）。0/0 = 未选中且列表为空。
2选中下游节点（Blob）时，条隐藏还是显示父来源图 直读 显示的是「该参数页所属模块自己」的图像参数，不是上游来源图。数据源 = Root.FindBaseNodeByName("CurrentImagePath")，模块 = AlgorithmTabRoot.Owner as IVmModule。Blob 模块无这些参数 → 列表空、计数 0/0，不是"保留父来源图"。
3多上游来源汇入时的选择规则 未证 条内控件本身不含多来源选择逻辑（全部按单模块参数取图）。多来源归属应发生在流程/执行层的输入绑定，需 VM.Core 或流程执行器源码，本轮未取证。
4条内内容是否随选中节点变化；运行前后如何变 直读 随节点变：宿主换 Root → 清空 AutoPlay/Interval/CurrentImagePath 缓存并重新解析。运行前：AutoPlay 决定取第一张或最后一张。运行后：AutoPlay 开启时每次执行后自动切下一张（本地化原文可证），计数 N 递增。
5非图像源节点上三个控件的可用性 直读 不按节点类型灰掉，按展开状态与订阅模式显隐。开关 AutoPlay：IsExpanded 为真才可见。ComboBox：IsExpanded && !IsSubscribeFolderMode 才可见。唯一按模块类型判的是中间 130px 占位块：IsImageSourceModule 为真才占位。

依据三：什么情况下回到 0

时机位置行为
删除当前图像ImageListPanelBase.cs:587-590if (CurImageIndex == num) CurImageIndexT = 0; → 删除的正是当前图时回到「无选中」
删除左侧图像ImageListPanelBase.cs:602-605if (num < CurImageIndex) CurImageIndexT--; → 序号前移一位
清空列表ImageListPanelBase.cs:697-698ImageList.Clear(); CurImageIndexT = 0;
选中项变化ImageListPanelBase.cs:1316CurImageIndexT = CurSelectedIndex + 1;

结论：N 是「当前第几张（人类从 1 数）」，没有任何选中时显示 0；M 是列表实际项数。用户看到 0/0 表示「列表里没图，也没选中」。看到 0/10 表示「有 10 张但一张都没选中」。

依据三：面板取图只认「自己所在模块」的参数

文件 ImageListPanelBase.cs:647-660、:442-475

public IVmModule GetVMModule()
{
    if (OwnerModule == null)
    {
        AlgorithmTabRoot algorithmTabRoot = GetRoot();
        if (algorithmTabRoot == null) return null;
        OwnerModule = algorithmTabRoot.Owner as IVmModule;   // ← 参数页根节点的 Owner 模块
        return OwnerModule;
    }
    return OwnerModule;
}

// 取图：全部来自该模块的参数
string value = ((IUserStringData)GetVMModule().Params)["ImageNumber"];
for (int i = 0; i < num; i++)
{
    string text = ((IUserStringData)GetVMModule().Params)["ImagePath" + i];
    AddImageToList(text);
}

结论：条不"继承父来源"，它是按参数页所在模块取参。选中 Blob 节点时，若其参数页也放了该控件，Root 指向 Blob 模块，而 Blob 模块没有 ImageNumber / ImagePath0..N / CurrentImagePath 这些参数 → 列表为空，显示 0/0，开关与下拉都无内容。
这不是 bug，而是"哪个模块的参数页，就显示哪个模块的图"。若要实现"选中下游节点时显示其上游图像源的图"，需要我方额外做一层「向上游解析图像源」的逻辑，原件没有这层。

补充：ImageListPanelBase.cs:182 的 IsImageSourceModule 只用于判定「当前模块本身或其沉淀模块是否为图像源节点」，用途是控制 130px 占位块与图像名悬停按钮的显隐，不改变取图来源。
