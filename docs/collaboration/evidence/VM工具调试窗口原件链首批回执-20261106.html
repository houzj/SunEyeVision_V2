主题与性能结论

  • 主题：当前回执未找到 VM 运行时主题切换证据。历史材料包含颜色资源字典和主题审计，但不能据此证明 VM 支持运行时切换；因此 SunEyeVision 删除主题切换属于产品架构决定，不能写成 VM 已证事实，须保留“VM 无运行时主题切换：待逆向统筹用程序入口/命令/资源加载证据确认”。
  • 性能：现有材料没有证明 VM 采用缓存、异步、虚拟化或延迟加载。窗口控件多时仍流畅的真实机制尚未确认；在取得构造/切换/释放时序、实例计数、UI 线程和资源加载日志前，不得把这些机制写入目标实现。

本批未确认项与下一步取证

  1. 固定 VM 安装版本，补齐上述程序集/资源的路径、MVID、SHA-256 和来源许可；复核反编译文件是否对应同一身份。
  2. 沿 ParamsTabControl、ParamsTabUserControl、BottomCommands 的构造器、Loaded/Closing、DataContext、命令回调和异步回调闭合入口到退出。
  3. 最小运行场景：首次打开同一节点、切换 Tab、切换到另一节点、返回原节点、关闭窗口；记录视图/模型实例是否复用、释放顺序和迟到回调。
  4. 在同一场景观察主题命令/资源重载入口及 UI 线程耗时；若无入口，交付“静态已查范围 + 未发现可追入口”，不得写成绝对不存在。

采用边界：本回执可支持“原件窗口组装入口和局部 Tab 集合行为”的设计审查；不能支持删除旧模型、承诺 Tab 复用、解释性能、或宣称 VM 完整生命周期已闭合。

生命周期结论分级

  • 静态已确认（本方材料）：关闭事件可先取消 Closing、等待调试会话结束，再移除会话并重新关闭；执行作用域存在 lease 门禁；结果记录、配置结果、窗口 session 是不同持有者。
  • 静态部分确认：参数模板、资源字典和底栏命令来源已入库；具体 DataContext、Loaded/Unloaded、命令回调的完整 VM 消费链仍未从同一版本原件闭合。
  • 运行未确认：同节点 Tab 切换是否复用同一视图/模型、换节点是否先退订再释放、结果 reader/图像租约最后读者何时退出、重复打开是否共享窗口，均没有 VM 原机运行记录。
  • 性能未确认：没有 VM 证据证明缓存、异步、虚拟化或延迟加载；不能用本方静态实现中的字段或测试解释“控件多仍流畅”。
