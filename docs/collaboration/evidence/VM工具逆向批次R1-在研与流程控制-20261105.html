三处细节（观察到，均属"原件缺陷/不一致"，不得当成设计范例迁移）：

  • 输出端口 MeasurePoint1 的内部 Filter 名是 InputPoint1X/InputPoint1Y（输出名里嵌 Input），与结果类 MeasurePoint1 字段不对应。
  • Base/ServerRepAddress 写死 tcp://127.0.0.1:5555，而 Server\ServerConfiguration.ini 的服务端监听是 5556。两者用途不同（模块代理由 ModuleProxy 承载），不据此推断冲突，仅记录。
  • MeasureCalibMatrix 标 Visible="false"：存在"可计算但不展示/不可绑定默认"的输出项。
