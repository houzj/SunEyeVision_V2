0 结论摘要

问题档位结论
方案里有版本字段吗观察到 有，且是产品版本字符串，不是整数 schema 号：<SoftVersion><Version CurrentVersion="V4.4.0" /></SoftVersion>，位于方案包内 ProcFile\ProcedureInfo.xml 的第 2 个元素。
方案是什么容器观察到 ZIP 包（头 50 4B 03 04），7 个条目、内部路径用反斜杠：ProcFile\ProcedureInfo.xml（明文 XML）、ProcFile\ProcedureMoudleFrame（二进制，原文拼写 Moudle）、ProcFile\UiParamData\_<流程号>+<模块号>+<模块类型名>（每模块一条二进制参数）。
版本不匹配怎么办观察到 不是拒绝，是显式迁移：CompatibleTool.exe 读 当前方案版本：V4.3.0 → 5 阶段升级 → SaveAs 另存为 ..._V4.4.0_1.sol，原文件保留。
缺模块能打开吗观察到 能。WARN Load Warning，Failed Module Num:4 之后继续升级、继续另存。待转换列表里还出现本机未装的 IMVSCnnCodeRecgModuC → 缺模块只计数不阻断。
迁移分几步观察到 固定 5 段：FrontendUI Upgrade → DynamicIO Upgrade → GlobalVar Upgrade → CustomizedHandleModule Upgrade → SaveAs。
字段改名靠什么观察到 靠映射表 CompatibleTool.xml 的 <IOInfo SrcName="MinWidth" DstName="MinWidths"/>，逐字段旧名→新名。这解释了 R4/R5 观察到的 SortModule→DataSortModule 与结果字段复数化。
全局变量怎么迁观察到 单独一轮：GlobalVarToVM4_4: get all var → update module param binding → update module result binding。参数绑定与结果绑定分开重写。
扩展名是什么观察到 .sol 是方案（日志实录 一拖一.sol）；.prc 是流程/子流程文件，与方案同构（同为 ZIP + ProcFile\）。
我方该怎么改推断 原件语义＝「版本是产品串、不匹配走迁移、结果另存、失败计数可见」。我方「版本≠1 硬拒」会让用户既打不开也迁不了，且把"格式不兼容"误判为"文件损坏"。建议：保留整数版本做内部结构校验（缺→允许合理），不符时改为「只读打开 + 明确提示 + 另存新文件」。需中心裁决，本文件不实施。
能否闭合观察到 六项已闭（版本字段存在／迁移流程／失败容忍／改名映射／.sol 与 .prc 同构／映射表全量规模），2026-11-06 补见于 §1.7。仍开两项：迁移失败只补到「崩溃形态」这一层（无符号、无方案路径），方案版本高于软件时的表现仍无证据。

2 原件 vs 我方对照

原件事实我方现状结论与建议优先级
版本字段是产品串 CurrentVersion="V4.4.0"ValidateSchema 用整数 schema 版本（≠1 拒绝）两者不是同一概念，不能互证。原件的串用于"选哪条迁移路径"，我方的整数用于"结构能否解析"。建议：整数版本继续管结构；若将来要记产品兼容性，另加一个独立字段，不要把两者混成一个数P1
版本不符 → 迁移 + 另存，原件保留版本不符 → 拒绝核心分歧。原件给用户留了退路（另存新文件、原文件不动）；我方硬拒后用户无路。建议改为「只读打开 + 提示 + 另存」，并保留失败计数可见P0 待裁决
缺模块 → WARN + Failed Module Num:4 继续缺工具时行为本批未核对建议我方也走"计数 + 继续 + 可见"，而不是"整方案打不开"P1
字段改名靠 CompatibleTool.xml 映射表无对应机制未知 我方是否已有版本演进需求。现在不必建，但方案格式一旦发布就要预留"字段改名"通道，否则将来只能硬断P2
模块实例身份 = Guid(32 位无连字符) + Index(序号)节点身份机制本批未核对原件两者并存：Index 用于图连接，Guid 用于跨引用。我方需确认是否只用了其中之一（若只有序号，复制粘贴/合并会撞号）P1（专项）
UiParamData 是私有二进制，与 ProcedureInfo.xml 分离我方参数与方案结构一样用 JSON（同文件）原件的分离带来的好处：结构可明文 diff、参数体积不膨胀 XML。不建议照搬二进制（反调试、不可审计），但"结构 vs 大量参数分离"值得借鉴P2
流程级有 RunTimeout/StopWhenNG/ShieldGlobalCtrl/ContinueExecuteTimGap超时与 NG 策略本批未核对这 4 项是"产线连续运行"的必需要素。建议核对方案持久化里是否已有对应字段P2
