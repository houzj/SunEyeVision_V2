中立插件准入与运行目录：整链设计

本方设计；基线 80d09b28。不是 VM 内部实现证据；不包含 87f4 未提交工作。Group 不在范围。

单一身份和生产链

载荷生成 / Foundation 身份→ 文件与 PE 校验→ 不可变准入目录→ 配置恢复 / 执行→ 结果交接 / 释放→ 桌面 Editor 投影

运行定义、schema 与元数据以同一目录代际为准；桌面 Editor 是可选消费者，不拥有第二套 Runtime。当前默认 ALC 已加载程序集无法回滚，只有尚未发布的目录可拒绝；不能声称实现程序集卸载或运行排空。

边界与现状

边界现状与拟处理
发布与发现ReleasePayloadAuthority 逐项验摘要、程序集身份、PE 组件声明、Foundation；保留全部校验。桌面载荷含非可选桌面条目，删除文件不构成合格 headless 载荷；需正式构建规则生成独立闭包及其清单。
运行目录从 ToolRegistry 中拆出准入 Runtime 身份、schema、创建与原子发布；清单、目录、Runtime 与编辑器使用一个候选及代际。不得以旧静态注册表或双工厂桥接。
桌面呈现CreateEditorFactory、CreateSettingsView、CreateCurrentResultView 和 WPF 模板留于桌面组合。Editor 缺失不阻断 Runtime，但声明、身份或 PE 不一致必须拒绝；不冒称可加载错误编辑器。
消费者RuntimeFieldJson、RuntimeToolConfiguration、WorkflowJsonConverter、SolutionRepository、WorkflowNode、WorkflowNodeFactory 与桌面工具箱、配置和结果视图均切换同代目录；复用 ToolRuntimeExecutor 的 session 清理及异常聚合。
生命周期冻结配置、请求身份、取消、输入租约及输出读取者所有权保持分离。图像源正式与调试共用获取语义但各自回执；不能先释放相机快照或运行结果。等待与排空能力尚待逐项证实。

实施顺序与验收

  1. 冻结中立目录、目录寿命及正式封包闭包，列清文件及消费者；不依赖未集成资源候选。
  2. 整体替换准入、注册、运行定义创建和桌面投影，同步恢复及现行消费者；无兼容双轨。
  3. 正式规则构建 net9.0 宿主及真实 ImageLoad、Blob Runtime 清单；分别测试 Editor 缺席和桌面装配。
  4. 校验实际 deps.json 与加载程序集不含 WPF / UI / Editor，执行真实输入、输出、取消和清理；损坏摘要、PE、重复身份、缺依赖须拒绝且不发布半套目录。
  5. 完整 Workflow 仍依赖 WPF / SDK，未完成剥离前只报告中立插件调用宿主，不称完整无 WPF 工作流。

正式/调试工作流调用、资源最后读者、前台 UI、主线集成与用户人工验收分列记录。身份和摘要一致性不等于已验证可信清单签名。

具体共享合同与关闭链（本方候选）

对象职责和数据传递
RuntimeReleaseAdmission输入宿主根目录与正式清单；沿用文件、PE 声明、路径及 Foundation 身份校验，验证完整候选后交给目录发布者。
RuntimeDirectorySnapshot只读保存代际 ID、ToolId 到已准入 Runtime Type、目录元数据、schema 指纹及创建定义能力。全部候选准备成功后原子发布；默认 ALC 已加载的程序集不承诺回滚。

关闭顺序为拒绝新入场→停止并等待实际执行与读者→关闭 session 和输入租约→完成根作用域→退役 owner 与目录。现有 ToolExecutionOwner 的 ActiveRuns 和 EnterRun 仅跟踪计数；CompleteRoot / Retire 在未归零时抛错，不主动取消或等待。应接入真实调度等待与资源读者所有权，未完成前不得声称关闭排空已实现。

正式载荷生成器调整

New-ReleasePayload 接收 AppPath、BuildId、SourceCommit、ArtifactVersion、ProductComponents、FrameworkOriginPath，返回 schema 2 对象；Write-ReleasePayload 输出 release-payload.json。原有 Foundation PE 版本/提交、各文件 SHA、程序集身份及 PE 组件声明校验应复用；现有流程未证明可信清单签名验证，不能称现有签名链。

当前实现硬编码 Plugin.SDK.dll、SunEyeVision.UI.runtimeconfig.json 和完整 Get-ProductToolComponents；Release.Payload.targets 仅为 UI 执行。须增显式宿主 runtimeconfig 与宿主组件集合并允许只读 runtime 清单，复用相同封包及校验代码为真正的 net9.0 host 输出独立闭包，排除 Editor/WPF；不得削弱桌面完整载荷门或通过删除现有发布文件来模拟。

ImageSource 与 Blob 的 Runtime 项目均为 net9.0，引用 Contracts 和 HalAdapter.Runtime；它们能否连同原生算法依赖从正式规则部署及执行，仍需真实构建与运行证明。
