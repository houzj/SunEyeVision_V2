已具备与占位

区域本批行为依赖和边界
文件新建、打开、保存、退出接已有真实命令；最近、示例、另存、导出和导入保留禁用。原件最近方案动态子菜单和另存命令未证明有同态正式入口，不借用行为不相同的控件冒充。
设置/工具/系统按原件分类列入口，通信和相机使用现有管理命令；其他没有对应基础的入口禁用并提供说明。权限、运行策略、标定引导、日志和光源等需后续完整合同。保留本方路径拐点和全屏作为显示扩展。
帮助帮助文档、关于、欢迎页复用现有命令；原件语言切换和在线入口缺基础时禁用。欢迎页对应原件 WecPage 菜单位置；本方欢迎页外观与原件是否等价尚未验证。
撤销历史独立历史文字按钮移除；撤销按钮右下角提供原位鼠标悬停菜单，记录项明确禁用。原件 MenuItems.xml 的 UndoList 是 DownPopTemplate 子项，点击打开独立记录窗口；现有 ContextMenu 并不等于原窗口，待正式历史窗口基础后接入。
主题保留本方主题切换，用随亮暗状态切换的太阳/月亮图标及动态主题前景。本方扩展，不冒称 VM 原件功能。

本批实施及独立验证

已按五组重排菜单，复用现有新建、打开、保存、通信、相机、帮助、关于与欢迎页命令；缺基础项目禁用。独立欢迎页/历史文字按钮已移除；操作记录保留撤销右下角悬停禁用占位。主题切换为本方扩展，随主题状态显示不同图形并使用动态主题前景。

独立 worktree UI Release 最终构建 0 错误、0 警告（WarningLevel=0）；ShellLayout WPF 测试 4/4，覆盖菜单顺序、欢迎页命令、占位及主题变化。首轮测试发现 Popup.IsOpen 默认双向绑定只读属性导致加载异常，已按原件改为 OneWay 并复验。构建依赖使用 HalconSourceRoot 指向主仓 libs/halcon 来源，产物写入本 worktree。真实主窗外观截图、VS 设计器、原件动态权限/模式与主线集成仍未验证；不可据此认定整体 VM 菜单机制已完成。
