本批整组实施设计

按 VM 菜单声明的 group0–group3 组织工具条；Save/Open/Undo/Redo、相机、变量、通信及单次运行使用已确认来源的资源和现有正式命令，全流程连续运行入口暂时禁用：现有状态无法区分单次与连续运行，不能依据任意运行状态展示停止或执行切换。原厂运行范围与本方命令的等价尚未验证，保留本方清晰提示；锁定、全局触发、全局脚本、综合配置及运行界面等尚无本批可用完整链的入口只展示禁用说明。起始页与主题为本方扩展，显示文字而不伪造 VM 图标。Logo 不变。功能切换、禁用和资源加载走真实 ShellTopBarControl，自测不代表用户人工验收。

批次验证与剩余范围

本独立分支真实 ShellTopBarControl 经 WPF 宿主加载，验证保存按钮资源与命令绑定、禁用后图标、单次运行状态不改变连续入口的禁用与无基础入口禁用；布局和顶栏共 4 项自动测试通过。命令用测试替身验证绑定和状态，未执行真实工作流。用户人工验收、VS 设计器及主线集成尚未验证。

本批不宣称原厂整个菜单已迁移：文件、系统、设置和帮助菜单的项目与权限未整体对照；窗口最小化/最大化/关闭目前仍为本方模板，原件依据 Apps.Style/buttonstyle/normalbuttonstyle.xaml，须后续整组迁移；运行范围与 VM 差异、可用/隐藏条件，以及图像视口和源条全部图标需分别核查。缺基础的全流程连续运行、锁定、触发、脚本、综合配置和运行界面以禁用文字占位；起始页和主题为本方文字入口。Logo 保留。

后续动态菜单与运行状态边界

原件 VisionMaster.Exe.Audit/VisionMaster/MainWindowData.cs 的 PreLoad 根据版本/远程模式选 XML、读取菜单；MenuToolSource 从菜单后代按 groupName 和 Priority 分组排序并缓存，语言刷新重载菜单和工具箱。VisionMasterMain/AppMainWindow/TitleBar.xaml 的菜单和 TitleToolBar.xaml 的工具栏消费同一菜单源。TitleMenueItemData.cs 的动态子项、方法、可见状态及 RunData 订阅/退订各须沿完整依赖链验证，不能用硬编码的本批模板冒称动态重建。

原件 TitleToolBar.xaml 的单次运行受运行、空模块和加载后执行限制；连续按钮根据 ContinuousRunEnable 选择运行/停止，且单次运行期间禁用；撤销重做同时检查历史、锁定和运行。当前自研 IsAllWorkflowsRunning 实际来自 IsAnyWorkflowRunning，单次和连续使用同一运行状态，不能安全代表原件连续运行。顶栏全流程连续入口因此禁用并去掉命令接线；保留共享协调器合同及流程 Tab 行为，待正式连续运行状态、停止排空与动态菜单切换整链具备后再接入。只证明本工作区静态路径，不将缺少同名属性等同于原厂不存在其他机制。
