结论
- 当前代码已经按 VM 可确认顺序实现：启动阶段 → 方案管理器/方案选择 → 主工作区轻量壳与遮罩 → 发布准入 → 服务和方案会话 → 工作区 → 工具节点窗口。
- 当前 Release 的慢点不在方案管理器和方案初始化；准入阶段已从旧日志的 5 秒级 `ComponentLoading` 收敛到 325ms。旧日志中的 5 秒级读数来自旧载荷，不能作为当前基线。
- 首帧在准入完成前已出现，加载遮罩保持在主工作区上方；遮罩保留窗口拖动入口，避免启动阶段窗口不可移动。
- 本次使用空流程验证启动链，未把 ImageSource/BlobAnalysis 的节点窗口动态打开写成同一次启动验收；两个工具的完整 Session→参数树/模板→执行/结果→关闭释放回归见 `VM完整链路代码落地回归-20261109.txt` 与 `RuntimeEditorProductionProbe-20261109-atomic-final.txt`。
- 仍未确认 VM 同版本的动态 UI 线程耗时、同节点实例复用边界、真实硬件连接和 Visual Studio 实际附加；这些不能用本次隔离启动读数代替。
