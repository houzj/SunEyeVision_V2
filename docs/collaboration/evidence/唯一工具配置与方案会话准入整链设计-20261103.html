唯一 ToolConfiguration、DocumentSession 与准入视图

实施前整体设计 · 基线 95ba00f6f81066e9740705dc0bca730e8493e599 · 2026-11-03。本文不是已实施声明；UI 投影由界面线审查。Group 与循环新增暂停。

Domain 只保存一份工具配置；正式文档会话提供方案和节点归属、目录代次与运行 owner 的可信证据。准入视图不能由配置自身证明所属文档，也不能因当前值变化把后续合法运行判为过期。

Domain 可依赖中立 Plugin.Contracts，不依赖 WPF、SDK、Runtime 或 UI；Application 和 Execution 复用现有 Plugin.Runtime。箭头示意调用而非 Domain 反向依赖。节点不持有目录、IToolDefinition 或 owner；复用现有字符串 ID、ScopedNodeIdentity 和 OutputReference。

对象唯一职责
ToolConfiguration不可变版本含 ToolId、Fields、CurrentValues、ParameterBindingOrder 和仅内存的字段 revisions；字段与嵌套值深冻结。常量权威在 Fields，当前值仅承载引用参数已接纳值且不得持有调用资源；同会话复制、草稿和运行快照携 revisions，加载从 0 开始。
DocumentSession正式打开或新建时拥有唯一实际文档，持有既有执行 owner 与准入目录，协调编辑、历史、成员归属和作用域。DocumentEditSession 的编辑 SessionId 与结果所用 ExecutionOwner.Id 分别保留。
AdmittedNodeView会话核验后签发的只读视图，关联节点对象、作用域、目录代次、定义和配置版本；不是持久化实体或第二张可写表。CurrentValues 更新时重新取配置版本但复用已准入 definition，不按旧配置引用长期拒绝后续运行。
定义与资源沿用 RuntimeDirectorySnapshot.CreateDefinition 的 ToolId、类型、schema、宿主声明检查及 AcquireInvocation、reader 和资源释放；跨程序集只开放受控入口，不复刻准入、不增加同义 owner，值变化不重建模块。

V3 配置 JSON 只写 ToolId / Fields / CurrentValues / ParameterBindingOrder；不写 revision、目录、准入视图或 owner。旧格式继续明确拒绝，失败不改源文件。

2. 会话与可信作用域（目标签名）

sealed class DocumentSession {
    Guid EditSessionId { get; } // 现编辑 SessionId 语义
    internal SolutionDefinition Document { get; }
    internal RuntimeDirectorySnapshot Directory { get; }
    internal ToolExecutionOwner ExecutionOwner { get; }
    internal WorkflowScope OpenScope(string workflowId);
    internal AdmittedNodeView? FindNode(WorkflowScope scope, string nodeId);
    internal AdmittedNodeView RequireNode(WorkflowScope scope, string nodeId);
}
sealed class ScopedNodeInfoProvider : INodeInfoProvider {
    ScopedNodeInfoProvider(DocumentSession session, string workflowId);
    string ScopeId { get; } // 读取时重验；不可改写
    ToolSchema? GetSchema(string nodeId); // 只有节点不存在返回 null
}

签名是待审目标而非当前 API。Scope 与视图仅由会话构造，不允许公开伪造或设置目录；访问级别随实际程序集边界确定。

  1. OpenScope 捕获实际文档对象、文档 ID、流程对象和 ID、目录及 owner；要求会话开放、owner 未退役、目录有效，流程对象和 ID 在文档内各唯一。
  2. 每次读取重验文档和流程身份、原对象成员关系、目录和 owner 同一对象与生命周期；节点 ID 重复明确拒绝，只有当前流程确无节点才返回 null。
  3. 存在节点时以会话持有的可信目录解析声明、核 ToolId、配置和代次；错代、缺配置、未准入或目录退役均明确失败。禁止从节点或配置自身取得目录作为自证。
  4. 跨异步在副作用、安装和调用接纳前复验；删除后同 ID 新节点不是旧实例，不能接收旧回调或旧结果。撤销按既有实例与历史语义处理，不以 ID 相同代替对象校验。

正式运行快照和私有草稿不是实际文档成员：由已验证会话与原节点派生，携带来源身份和受控凭据；对原对象、scope、代次及声明重新校验，不能将快照伪装成文档成员。

3. 正式运行与私有草稿是不同协议

路径必须保持不可做
正式接纳CaptureParameterValueAcceptance 捕获 owner、真实节点实例和不含实时值的 ConfigurationIdentity；回调核执行身份、实例仍属文档和声明身份；准备不可变候选，在 identity 门禁内比较本次 store baseline 与 prior 配置对象，安装前重验以防重入。不能按运行开始时的配置对象引用或字段 revision 做长期 CAS，否则第一次接受值后后续运行被误拒。
私有草稿合并MergeCurrentValues 逐引用字段比较 opening revision 与值；草稿和正式均变且值不同才冲突，同值可合并；草稿未改则采用最新正式值，接纳后按原语义更新 revision。不能把草稿三方合并改造成正式接纳规则，也不能私有调试直接覆盖正式值。
历史PreserveCurrentValuesFrom 保留仍有引用身份的实时值；常量编辑是权威。运行不写编辑历史；显示样式变化与执行配置身份变化保持区分。撤销重做不能回放旧运行值，也不能因为纯显示变更错误退役 publication。
