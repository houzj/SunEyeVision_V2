证据与已有能力

环节已有证据与实现处置
原件参数容器Plugin.Wpf/Catalog/controls.json 记录 Apps.XmlUI ParamsTabUserControl、底栏模板的程序集、文件与哈希；NativeToolEditorFrame 实现内容、外部槽、底栏并借用命令。当前 Catalog 明确生产宿主未接入。复用原件容器和模板；不将设计预览算作正式接入。外窗本体另核原件资源及行为，不凭容器推断。
正式打开NodeOpenDecisionChain 将 RuntimeNodeConfigurationControl 包入 SDK DefaultDebugWindow；MainWindowRuntimeEditing 依赖该类型和 ContentHost 查找控件。一次切换为 Plugin.Wpf 原件组合及正式宿主；按声明的编辑器建立图像源和 Blob，禁止旧窗口回退。
参数视图和目录DesktopToolPresentation 从同代 RuntimeDirectorySnapshot 创建设置视图并持有代次租约；RuntimeNodeConfigurationControl 负责草稿、引用、ROI 及调试捕获。保留正确的目录身份、私有草稿与租约，接入新的原件宿主并验证完整释放。
执行与结果当前执行通过 SDK 路由命令及事件；主窗反射订阅结果，持有 DeclaredOutputSnapshot reader 并按窗口、节点、方案和代次判定有效。宿主通过明确的命令/结果合同直接连接真实调试；确认结果借用、发布、失效及异步关闭时序，不通过复制旧可视控件替换。
提交与关闭ProductionEditorContext 是文档草稿生命周期；SDK ToolEditorCommit 还服务文档保存、全局变量和 Group。DefaultDebugWindow 的草稿关闭分支交由会话管理，确认提交走 TryCommit。明确唯一编辑事务合同并统一消费者；确认失败保持窗口和草稿，取消关闭不得释放，实际关闭停止连续执行、退订、释放编辑器/ROI/结果租约。不得另造第二套并行事务。

集中实施和验收出口

  1. 先核原件外窗、标题、关闭和按钮行为与资源闭包；确认既有框架仅覆盖的原件范围，证据缺口说明具体影响。
  2. 以窗口、宿主命令、Runtime 参数视图、上下文、结果事件与关闭释放作为一个切换批；审计所有实际消费者和共享事务合同，暂停 Group 新增迁移，禁止误破坏其现有行为。若共同合同无法安全切换，不以双轨或仅外观替换冒充完成。
  3. 真实图像源和 Blob：打开、编辑、执行、连续执行与停止、结果和 ROI 引用、确认提交、撤销重做与保存重开；覆盖无效值、拒绝关闭、取消、关闭期间运行与旧代回调。使用本工作树正式 Release 和载荷验证；隐藏桌面测试需避免交互弹窗。
  4. 独立记录 VS 设计器、实际 VM 对照和用户人工验收；不可验证的明确原因，不计通过。
