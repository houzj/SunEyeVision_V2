职责与交接

组件现状及决定验收
ImageInputSource / ImageInfo仅持 UI 列表、图片引用、缩略图和版本；复用现有通知、导入事务、重复引用及迟到保护。正式写入改为真实 session、节点引用和字段草稿；不再依赖旧 Workflow 或全局方案回退。新增、删除、选择、勾选、模式和自动切换；失败不更新投影，取消/释放。
ImageSourceStripSession复用现有控件交互、异步导入、可见缩略图、取消和 dispatcher 生命周期。来源事务和会话身份由宿主提供，不持第二套正式配置。大批导入、快速键盘、焦点、滚动折叠、迟到回调及关闭。
节点参数页ImageSourceDraftContent 复用 Plugin.Wpf 控件；字段来自唯一 IToolSettingsDraft，设备列表与解析通过实际 session 注入，不查询全局旧 SolutionManager。设备选择/缺设备、取消/应用、调试关闭及资源释放。
运行与预览执行层负责游标、单轮接纳和释放，使用 session.CreateResourcePathResolver；显式选择与当前票据双方核实际节点、根流程、投影版本和运行身份。显示由持有 reader 的结果通道接纳。快速左右切换无旧轮次回弹，导入/开关不自动执行或清图，切流程/关闭后旧回调无效。
保存与历史实际 ToolConfiguration 为唯一字段源，按 Session 草稿/回执写入；Undo/Redo/重开驱动投影重建；跨目录以真实资源基址解析。删除撤销、保存重开、SaveAs 后运行；失败不覆源。

独占图像源 partial、来源条会话、来源投影、图像信息、解析器、参数页、节点显示适配和相关独立测试；共享主窗、编辑器组合、ServiceInitializer 由另一线持有。以实际 DocumentSession/节点实例为身份，不能以节点 ID 或 UI model 自证。
