// 名称示意，最终位置由根统一冻结；不暴露 SDK、厂商设备对象或第二图像模型。
public sealed record CameraFrameRequest(string DeviceId, TimeSpan Timeout, RunIdentity Run);
public interface ICameraFrameProvider {
    ValueTask<ICapturedCameraFrame> CaptureAsync(CameraFrameRequest request, CancellationToken cancellation);
}
public interface ICapturedCameraFrame : IAsyncDisposable {
    string DeviceId { get; }  long DeviceFrameId { get; }  DateTimeOffset Timestamp { get; }

保留当前同一设备判等策略与 RunIdentity/RequestId，设备返回的 Image.Frame.ProducerRun、SourceId、实际 device FrameId/timestamp 分清；不能用新随机值替代物理设备帧号或把设备帧号冒充 invocation ID。Image 使用已有 ImageLayout（Gray8/Bgr24/Bgra32、正 stride、含 padding 的长度）、ImageFrameAddress 与实际 EffectiveDomain；复制前验证尺寸、stride、像素格式、域帧/坐标与数据一致，明确不支持的格式诊断。若原适配器声明“此帧是完整有效的采集网格”，驱动必须在采集边界基于该具体帧语义显式提供域，不由通用宿主依据宽高猜域；若不能证实真实域，则拒绝并指出设备适配缺口。

所有权 / 场景精确合同
采集成功同一个 CameraRuntimeManager 获取设备 gate / 采集 lease，使用实际 connected session 或按既有规则创建 temporary session；驱动输出采集数据的明确有效期。设备适配在释放帧/SDK缓冲前一次性冻结实际像素与域，原帧及临时连接按原规则释放；只有完成全部验证且取消未生效才转移独立图像租约。
执行/调试IPreparedHostInputs 独占相机租约并在工具结束、失败、取消或预览被丢弃时 DisposeAsync；工厂 preparer 结算本次票据，不同步阻塞等待异步设备。输出资源经既有 OutputResources / reader retain 独立续存，释放输入 owner 后已获取 reader 依合同可读。
借用与拥有现正式 HostInputFactory 只注入采集服务；直接传 borrowedFrame 的使用在静态搜索中是测试和旧序列 API，未发现生产调用。不可把测试形参当正式产品契约；若最终调用链确实需要外部借帧，须由同一 provider 明确输入是借用且只复制，不释放调用者原帧。未确认之前不保留旧 SDK CameraFrame 重载。
竞争与关闭预览/单帧/运行/调试共享现有 CaptureLease；不绕过锁，也不因窗口关闭立即释放仍被 reader/调用使用的图像。关闭先拒新→取消→等待 worker/设备帧与结果 reader→释放会话和工厂；租约释放幂等。设备 capture 失败与 cleanup 同时失败时保留 primary 并聚合 cleanup，不能只报后者。
不同数据类型Infrastructure.Persistence/SdkVariableValueExtensionCodec 的 Mat/ROI/矩阵/Binary 是方案候选作用域，不是相机帧租约；失败仅释放本次新建资源，成功转 Session owner。此批保现有真实存储和关闭路径，不为了本地帧删除或伪造复杂值。
