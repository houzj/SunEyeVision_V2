现有几何的逐字段表达与复用裁决

RoiShape.Geometry 当前类型唯一基本字段与单位现有中立复用边界
Point2dX、Y，有限双精度。坐标空间明确且值有效时可投影 PointGeometry；原独立变量不含 frame，不得从名字捏造物理帧。
Circle2dCenter.X/Y、Radius。正半径且有真实逻辑坐标时可投影 CircleGeometry；空/未完成定义与执行合法性分开，禁止加载时自行丢失。
RotatedRect2dCenter.X/Y、Width、Height、Angle；Angle 单位度。宽高正且 frame 真实时投影 OrientedRectangleGeometry，角度乘 π/180；写回度数，方向按原类型不自行变号。
Line2dPoint.X/Y、Direction.X/Y；构造器归一化方向，表达无限直线。LineGeometry 存有限 Start/End，不等价；持久定义必须存点与方向，不以任意 100 像素终点替代。运行显示必须在真实区域/约定下显式裁剪。
Annulus2dCenter.X/Y、InnerRadius、OuterRadius、StartAngle、EndAngle；角度弧度，完整环原构造是 0 到 2π。GeometryKind 无环，不能等同 Circle；现有 RoiDeclarations.Record 有内外半径和角度，可作声明/运行投影，其自身未包含样式也未声明独立变量 frame。
Arc2dCenter.X/Y、Radius、StartAngle、EndAngle、IsMajorArc；角度弧度，端角是物理终点。ArcGeometry 使用 start+sweep 且禁止零或超过 2π，必须按 Arc2d.AngularSpan 的实际方向与大小弧换算并对非法/未完成定义显式处理；不能丢 IsMajorArc 或以 end-start 直接替代。
Polygon2d按序 Vertices 每项 X/Y、IsClosed。PolygonGeometry 要求≥3点且无 IsClosed；开放、多边形未完成草稿不能直接等同。RoiDeclarations.Record 含 vertices/closed，可在指定真实逻辑坐标后作投影。

每个 ROI 条目的唯一完整外层字段为 Geometry（允许显式 null）、FillColorArgb:uint、StrokeColorArgb:uint、StrokeThickness:double、Opacity:double；派生 ShapeType、扁平中心/端点/Points 均标记 JsonIgnore，不作为第二权威。现有 RoiShapeValueAdapter.Freeze 只投影几何而丢四样式，Materialize 亦不处理 kind=none，因此不能直接替代持久值。建议以现有 TypeRef.RecordOf / RecordValue / SequenceValue 构造唯一持久 ROI 记录（七种 kind 或 none，附四样式）；运行 RoiDeclarations.Shape / GeometryValue 保持原声明，只能在真实 frame 和语义完全满足时显式投影，不能把二者混成兼容别名或另留 SDK RoiShape 作为第二持久权威。

现有 GeometryJsonConverter 不只输出上述基础字段，还会输出 IsEmpty、BoundingBox、Slope 等派生 getter。实际自建隐藏审计使用当前 GlobalVariableValueConverter + SdkVariableValueExtensionCodec，七类样式均通过、六类基础字段在所测样本相等，但大圆弧 IsMajorArc=true 重读 false；垂直线 Direction=(0,1) 因派生 Slope=Infinity 序列化失败。日志 Release/_validation/roi-shape-audit/wrapper-vertical.stdout.log，脚本 SHA256 131A6126EC2C98657F7E37C1AEB9B93EF8D03BF020B67ECBE193FB456BE39E75；进程以列出反例退出 0，不等于全部通过。拟议唯一 writer 只写权威字段，解决非有限派生字段和大小弧丢失；这会改变当前 V4 冗余字节而非声称字节不变。版本已审定升级并拒旧，不读取原冗余格式；不能静默承诺旧字节等价，也不能把历史 Point2D/Rect 迁移分支当作新格式需求。

    void WriteValue(Utf8JsonWriter writer, string token, object value, JsonSerializerOptions options);
}

GlobalVariableValueConverter 仍唯一写/读外层 Type+Value；新 codec 的 WriteValue 只写相应 V5 内层值，不再通过旧 SDK runtime CLR 名或反射生成一个中途可变对象。TryGetToken 只能识别唯一 BinaryValue、既有 RecordValue/SequenceValue 的精确声明及受控 StoredRaster 资产；错误类型、错误 TypeRef、任意外部实现和不匹配序列必须拒绝，不能把任意 Object 推断为类型。所有编码在现有 owner + ValueGate 同步完成，codec 不持有调用者传入的 JsonElement、RecordValue 枚举器、读者或借用像素越过方法返回。现有 SolutionSerializationOptions.Configure 仍只为 GlobalVariable.Value 配置唯一 converter；同步修改上述接口全部调用者并删除旧 TryWrite API，不做别名。

StoredRaster 必须具备受控创建与冻结：Infrastructure.Persistence 的封闭实现以 PNG 解码得到的 8/16 位像素复制成私有只读资产，单次 DecodedResourcesScope 登记自己的 owner；已知自身受控实现才可在 ValueGate 下取得只读 reader，不能让可任意实现的外部 reader 回调在锁内运行。SolutionDocumentReader/VariableArchive candidate 现有 Transfer 是唯一 scope→Session 解码 owner 移交，失败由 scope 清理并保留 primary；Session 的 ReleaseDecodedResources 在原编辑/历史/活动排空后释放根 owner。与现有 FrozenImageResource 一样，根 owner 退役拒绝新 reader，已取得的独立 reader 持有自己的 retain、Dispose 恰好一次并不暴露可写像素；这是资产本身不可替代的 reader，不是第二个 Session-wide VariableValuesLease 或注册表。

同步保存中 reader 在 ValueGate 保护的编码方法内创建并 finally 释放；V5 writer 对当前存在的 Image 值支持本次可保存的 8/16 位 1/3/4 通道，不把活动 Runtime 的借用对象/Native Mat 直接塞到异步文件写入。当前 UI 不提供复杂图像编辑或变量导入，尚无 Session 从外部任意资产接纳新 owner 的生产入口；保持原保护。若未来启用该入口，必须在既有编辑候选/一次 Commit 中先冻结或受控 retain，由候选 scope 把 owner 移交给 session，失败释放且不接纳任意调用者 IDisposable；不得现在为了测试增加万能公开 owner 注入口。

UI 异步工作若已获正式授权而需长读，owner 线程在操作启动前取得 AcquireActivityLease，再获取资产 reader；完成/取消/failure 时 finally 依序释放 reader 与 activity。Session 关闭可依原活动门禁拒绝或等待排空。已发布工作流结果仍由 AcquirePublishedResult 及其独立 reader 负责，绝不把其 RunIdentity 加给持久 PNG。流程被删除、方案替换或目录退役时继续由现有 Session 实际身份与目录检查阻断迟到更新。
