职责现状与迁移边界
变量定义和身份Workflow/GlobalVariable.cs 混合名称、绑定和值；生产者/消费者完整身份由 Domain/Solutions/VariableBindings.cs 提供，不另造同义类型。
值原子性与通知ValueGate、revision、数组拷贝、原始配置与值的批量提交及锁外通知是现有语义。NodeConfigurationEditHost 直接消费内部操作；迁移时需跟方案会话唯一发布事务一起接线，保证失败回滚和观察者异常不留半完成。
词汇和序列化变量类型校验依赖 GlobalProducerBindingRules 与 SDK 类型映射；Value 属性 converter 依赖 SDK/OpenCV。先确定正式中立类型描述、资源不透明生命周期与持久化注册路径，禁止向 Domain 加 SDK 或复制第二份类型表。
通信Communication.cs 包含持久化配置及运行连接状态；事件、心跳、自动化、Modbus/OpcUa 点位在 Workflow。定义按领域归属，连接状态/协议执行保留运行侧，UI 订阅同一状态所有者；不可因为旧 SDK 可视退出禁用已有驱动。
通知基类Communication、Modbus、事件、变量当前依赖 SDK ObservableObject；域模型须消除 SDK 依赖并保留必要 INotifyPropertyChanged 行为，禁止引入旧 SDK 兼容桥。
