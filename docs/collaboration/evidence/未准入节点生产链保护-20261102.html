统一合同

类型行为
正式已准入普通工具节点 ToolType、RuntimeConfiguration.ToolId、工作区当前活跃目录实例一致，配置不含旧 SDK 参数和旧 ParamSettings；在执行租约中使用已准入声明。
未实现或未部署普通工具工具箱展示禁用；方案读取和保存明确拒绝，不覆盖来源；内存节点的打开、调试、执行均拒绝，不回退旧 SDK。
Group / 控制流目前暂停新增与语义迁移；标识为 Subroutine/Condition 或带 SubroutineId 的节点明确拒绝打开与执行，不因元数据可用而放行。后续实现接入此统一准入口。

生产链与验证

现有 SolutionRepository 在候选读取及保存冻结快照时检查整个方案的目录成员；保持严格拒绝、保持原文件。WorkflowRunConfiguration 由真实执行入口捕获后，先对所有节点逐一校验，拒绝同代不一致、空配置和控制流，删除执行转换中的旧 SDK 回落。调试捕获显式传入方案实际目录并持有 lease；打开决策链在任何控制流导航或编辑器实例化前做同一检查。节点创建、拖动及右键目录仍复用既有运行目录检查。

不实现新的缺工具只读文件结构或兼容桥。加载失败保留源文件；不能声称缺工具方案可编辑或运行。原件完整 Group/控制流语义不在本批。
