## 普通节点复制：已核可复用链

`VmModuleBaseDecorator.CopyItemsCommandExecute` 保存来源 FullName；粘贴进入 `VmModuleSet.ProcedurePaste:1318`，逐名称从当前 `VmSolution.Instance` 查源，源不存在则跳过。普通模块按源实际类型创建目标，建立旧对象→新对象映射，去除目标初生动态输出，`CopyModuleParam(old.ID,new.ID)`，复制禁用状态、注册 IO 并 `InitDynamicIO`；所有创建完成后逐目标调用 `ModulePaste(map)`，再逐目标 `ModulePasteFinish(map)`。Group 是 Export→LoadGroup→CopyModuleParam 单独分支。细节与历史证据见 [B02](../reverse/B02-identity-preflight-batch6.md)。

`VmModule.ModulePaste:2746` 对执行前驱优先使用映射后的副本；原前驱未复制且与目标同父级、`SpModuleCheck(false)` 通过时可保留原连接，并复制 SourceIndex/TargetIndex（缺省分别 2/0）。随后按条件挑选输入，`PasteIO` 复制/映射输入输出，非 Group 刷新 ready，`UpdateRunParamBind(FullName,map)`，再调用工具 `Paste` 及显示路径 `PasteNode`；`ModulePasteFinish` 的具体工具重写仍依各工具实现。

`VmModule.PasteIO:3530` 根据 IO 名字找目标：常量创建新的常量 IO；ID 13000 的特殊全局源沿用原引用；映射中存在 producer 时取得新 producer 的同名 IO，并相应复制常量索引或映射索引；未映射源按触发字符串、父子关系/同父级分支处理，有些分支不设置引用。不能概括成“所有外部引用都保留”或“跨根一律清空”。

## 整根流程复制

`VmProcedureDecorator.CopyCommandExe:442` 注册根历史并调用 `VmProcedure.CopyProcedure:1208`：设置导出结束标志、Export；路径非空则 `ImportProFile(..., isForceIgnoreGlobal:false, nIdAllocateWay:0, isFromCopy:true)`，导入非空结果才调用 `procedureInfoCopy(oldProcedure)`；Export 返回 null 时新建流程。`VmSolution.ImportProFile:3039–3155` 对复制且非对话框路径等待导出，调用 SDK `ImportProcess` 时复制模式参数为 2，并等待导入结束后返回结果。
