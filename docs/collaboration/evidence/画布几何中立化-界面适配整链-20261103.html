唯一模型与边界

单一节点/连接模型 CanvasPoint ←→ UI 显式转换 ←→ WPF Point / 路由、手势与绘制

CanvasPoint 为有限 double X/Y，值相等，无隐式转换；节点 PositionX/Y、尺寸及 V3 手动折线形状保持。位置、端点、箭头、手动/预览/路径集合统一领域值，只有实际 WPF 几何算法边界转换；不建立影子节点/布局、兼容重载或双写。
