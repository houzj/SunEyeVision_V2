职责正式合同所有权和退出
中立 WPF 编辑事务层草稿附加属性、待提交状态、验证/刷新/放弃以及统一打开编辑器登记；仅依赖 WPF，不依赖 SDK、工具或宿主。仅负责编辑视图和验证，不拥有文档、运行目录、图像或执行结果。关闭和卸载按会话注销；无第二个事务服务或旧命名转发。
编辑视图参与者提供视图身份、节点身份、参数验证与待编辑数值的提交/放弃；SDK 旧控件暂按同一合同参与，Group 只改接线。旧控件按原行为登记和注销；原 ToolEditorCommit 对具体 NumericUpDown、ToolDebugControlBase 的直接引用删除。旧控件最终迁移后删除其合同实现及 SDK 对本层的 WPF 引用。
文档事务ProductionEditorContext 和 DocumentEditSession 使用中立草稿合同；全局变量、保存、Group 与节点打开链均调用唯一事务。DocumentEditSession 仍为配置发布唯一所有者；验证失败不发布；取消关闭不注销，实际关闭注销并释放调试、ROI 与结果 reader。

工程依赖已核：Plugin.Wpf 当前仅直接引用 Plugin.Contracts；Plugin.SDK 引用 Plugin.Runtime 和 Tool.Kernels，SDK 当前自身开启 WPF。中立事务层不得引用 Plugin.SDK 或 Plugin.Wpf；两个消费者均引用中立层，不能将整个 Plugin.Wpf 反向加到 SDK 作为最终方案。
