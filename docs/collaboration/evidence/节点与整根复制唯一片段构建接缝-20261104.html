共同边界与关键约束

事实 / 当前实现需要抽取的职责
DocumentSession.NodeClipboard.cs 已有 CaptureNodeClipboard 与 PasteNodeClipboard；后者直接 OpenScope、PrepareGraphEdit、CreateNode、编译并 CommitGraphEdit。把“输入已冻结片段 + 已签发映射 → 定义与引用/边的纯转换”抽为唯一内部构建器。Clipboard 保留实际活动源和目标验证、会话寿命/外部依赖、前驱策略、放置偏移和既有单次图事务；不对根复制调用 Paste。
GraphState 当前绑定 actual WorkflowDefinition；GraphBindingReconciliation / GraphDependencySnapshot 仍枚举 live Workflows；根集合提案需候选有序 flows 的新增、删除及同 proposal 编辑。根唯一负责最终候选视图、作用域与历史；构建器仅处理调用方提供的冻结数据，不调用 OpenScope、CreateNode、History、Session 发布或反射，也不自建 Solution / registry / 兼容模型。
RootWorkflowConfiguration.Remap 能映射 proxy 的 NodeId 并生成 ID，但当前遇不到映射会保留旧 NodeId，且每次调用会重新生成 Guid。整根方案必须要求所有 proxy 对应的源节点/字段都在映射并已准入；ID 由同一 proposal 一次签发、重复 Validate 稳定，不能直接重复调用现有 Remap。Root 配置与 WorkspaceSettings 语义由根集合协调器负责，不塞入通用构建器。
RootCollection.Copy 的目标 root 由草稿签发，尚未成为 Session 成员；同一个 proposal 可含该源节点的 pending 配置。先合并 proposal 并冻结候选源配置，再构建副本；不得读旧 live 覆盖 pending，也不为校验未发布 root 先 Add 后 Paste 两次历史。候选上下文由根提供，不借用节点本身目录自证。

这里的计划是一次提案内部的不可变临时构建结果，不是可写第二图或新持久模型。不可把可执行 callback、live node 借用、RuntimeDirectory 或宿主放入纯 Build。签发器在 Build 之前由 Application 在 owner/提案门禁内使用实际最终保留节点与候选先算 FirstFree；builder 接固定身份表。TargetFlowId 必须与根发出的未发布目标令牌匹配，令牌由调用方验证，不用任意裸 ID 证明所有权。冻结列表/字典递归复制，重复验证重用相同结果，不生成新 Guid。

输入约束及来源
源流程与节点集合提案先核 actual 源 root + flow generation、owner / directory 与编辑版本；同 proposal 节点草稿的已准入最终配置覆盖其 opening 配置，再形成深冻结节点/连接快照。未选节点、编外 Group / 控制流不隐式纳入；整根按全部普通节点集合捕获，空根允许。
最终候选 flows 与目标最终保留/删除的真实 flow 身份、顺序与图状态 + 同草稿签发的未发布目标 flow；每个 ID 唯一、声明只读，未发布 flow 并非活动 Session 成员。流代次、节点退役与实际引用校验属于根 Application，不由 Build 决定。
声明与变量由 Session 在同一可信目录代捕获 Input/Settings/Display schema、手动引用规则、引用行为、Host/资源声明及当前候选变量的实际身份/类型；目录同代与新提案再次终审由根负责。可用当前 FrozenToolDeclarations，不复制 CLR/SDK 表。
资源与数值仅声明字段的纯路径和 session ResourceBaseDirectory 快照；同 Session 新 root 保留路径含义，不复制 Mat、结果、reader、图像游标或引用借用。常量和当前值使用 FieldSettings / ValueRules / ToolConfiguration 的现行深冻结；非纯/opaque 借用拒绝。
签发映射每个源节点、被复制边分别签发新 ID，global/local 基于最终保留节点与本 proposal 已签发集合分配；删除释放的编号能否在同一 proposal 重用由根统一决策，失败不得推进 live 计数。编号、名字和根名遵根集合规则，不能在 builder 另外发号。

共用算法与调用方差异

对象纯构建器只做Clipboard / 根事务分别处理
节点新身份映射、冻结字段与配置、启用/尺寸/AdditionalData 深拷贝、统一坐标平移；不挂 live flow。Clipboard 使用用户首节点中心 anchor；整根使用根的初始总览规则和冻结源节点内部坐标，不套键盘 20 偏移。
执行边 / 路径内部边映射端点与新边 ID、保端口；内部手工折点随 Translation 平移；边形状值只读返回。Clipboard 同 scope 允许核过代次的外部前驱入线并清手工折点，跨 scope 不复制；整根复制全内部边，不制造外部入线。边唯一/环和最终依赖由候选规则验证。
配置引用OutputReference 的真实 scope/node、成员路径、PortId、Storage、Conversion、AtField 递归映射；VariableSetting / AtVariable 保持同方案实际变量身份；DisplayExpression.Reference 同映射而 Self 保持相对，文本/slot/format 保持。调用方供应本次边界策略和映射；调用方用最终候选声明 compiler 验证所有已配置引用，显示引用使用 Display 规则而不造执行边。未完成字段可以保持未配置，非活动非法引用按复制合同诊断拒绝。
Origin 与 CurrentValuesconnection:OriginId 只映射已签发且真实归属的边；未知/不匹配/需丢弃外部边时返回结构化诊断，不静默解绑。比较规范字段身份，身份改变不携旧值；身份未变仅保允许的纯当前值，本方复制策略。源自动来源在完整源图和最终候选两次校验；提交前根再次验证真正 candidate 和目录。结果 publication、reader、正式/调试运行/取消、cap 一律不复制。
RootParameterProxy不修改 root 元数据。整根调用方从同一 NodeId 映射转换 proxy，保 FieldId、ToolType、StoragePath、显示名，独立签发新 proxy Guid；若源节点/字段不在最终拷贝声明中则拒绝，不能保旧 NodeId。Clipboard 不改既有 root proxy。
全局 producer不克隆全局变量、producer 或值，也不改变任何外部对象。根候选对原变量/producer 与全流程消费者统一做 GraphBindingReconciliation / GraphDependencySnapshot；复制后的 VariableSetting 仍指同一实际变量，不能让副本抢原 producer。跨流程依赖和删除候选在最终方案统一校验。

冻结快照与必要资源 scope
Proposal 获唯一租约
冻结一次身份与计划
验证失败 / 取消

纯 builder 不调用 codec、文件系统、设备或 WPF，不新建和 Dispose native 资源；路径本身是声明驱动的纯值。若同一 proposal 的其他参与者本来拥有新解码资产，其 scope 仍由根的 proposal owner 持有，与 builder 返回结果不混同。取消/失败仅释放本 proposal 确实新建的资源、尝试全部清理并保主异常；成功发布后一次转移到实际 Session，关窗、编辑、运行与 reader 排空后释放。重复 Validate 不改源、不修改目录、不重建资源或 ID。

提交前校验 Session 活跃、目录同代、源对象及 flow generation、最终候选成员顺序/配置和外部依赖；普通节点片段允许捕获后删除选中源，但其外部来源按既有节点代次和变量实际实例重新核验。根提案若源编辑发生变化则按冻结 proposal 版本与参与者回执协调，不能因 live 实例相同漏掉过期配置。一次 Commit / History 失败须保源与目标集合、引用、编号、dirty、资源和焦点；提交后通知失败独立报告，不倒写已发布事务。Undo 移除整个副本并退休新 flow/node 旧 cap，Redo 恢复同历史身份并签新代次，绝不恢复旧运行 publication。
