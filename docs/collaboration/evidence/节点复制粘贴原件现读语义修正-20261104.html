受保护定位与一次粘贴

  1. 复制时校验真实活动 Session、目录、流程及选择对象，记录稳定顺序、真实源流程与节点引用、身份和名称路径，以及 UI 入口位置。不冻结参数、图边或 native 资源作复制权威。
  2. 粘贴时在同一 Session/目录门禁下逐项重新解析：源流程须为真实成员且路径一致；节点须是同一个实际成员、ID 与原名称路径一致。缺失、改名和同名替身均不得用于粘贴。底层来源恢复为同一个实际对象时可按当前代次重新准入，绝不复活旧 capability；UI 删除已清空定位，Undo 不自动恢复。
  3. 按有序幸存子集捕获最新字段、纯 CurrentValues、Origin、边与路径，重新建立本次外部节点/变量身份与声明。非法引用、失效依赖或准入失败整体拒绝，源图、历史和编号不变；合法未完成字段不因未执行就绪而拒绝。
  4. 唯一 FragmentBuilder 只消费本次冻结的节点/边、签发身份、平移与入边策略，不改变其 ABI。内部引用和显示表达式递归映射；同流程有效外部入边保留并清手工路径，跨流程仅内部边。配置身份变化不携带旧 CurrentValues 是本方复制规则；结果、reader、游标与 native 资源不复制。
  5. 正式声明、作用域与同代复核后一次 CommitGraphEdit；无幸存者返回可辨识无操作，不产生图事务、历史或编号，也不推进粘贴偏移。

界面、坐标与整根复制

应用层锚点采用当前幸存子集首节点中心；UI 从当前投影换算右键世界坐标，Ctrl 拖采用当前首节点中心与实际 delta。重复键盘偏移 20/40 为既定本方策略，不能称原件行为。原件无坐标路径使用复制时 Position 加 100、5 像素吸附与边界裁剪；是否调整既定策略交主线裁定。全部失效不改变选择。切方案和关闭清理定位。整根复制继续在同一 Proposal 冻结最终源图并复用唯一 Builder，不借 Clipboard 已发布流程接口。
