复制生命周期与身份

阶段建议合同（待主线审定）
复制UI 在所属线程读取当前 session、workflow 和真实所选 NodeDefinition 对象。Application 先验证成员引用、声明与控制流准入，捕获独占不可变片段：源会话身份、源流程身份、各实际节点代次/配置身份、字段和必要的资源来源、被选节点及有关执行边。不得把 live 节点集合、reader、图像帧或可变 ROI 借用放进剪贴板。捕获成功才替换当前片段。
粘贴目标必须是相同活动方案会话的实际流程与活动目录，禁止用 ID 自证。预生成独立新 ID 映射、编号、偏移、引用和边；全部在目标同一个 GraphEditDraft 中准备、校验并一次 CommitGraphEdit。任何失败不改源、目标、历史、选区或编号；不得先发布节点再补边。跨方案剪贴板行为未证，本批建议明确拒绝，待合同及资源所有权审定。
源变化显式待决：复制时冻结定义快照使稍后删除源仍可粘贴，还是要求源节点代次仍活跃。建议区分内部复制快照与保留外部引用：内部映射可从安全冻结快照构造；保留外部引用和入线必须在粘贴时核实际对象及代次。禁止同 ID 新实体冒充旧源。实际对标需补证，先由主线冻结。
撤销 / 重做一个历史条目含全部新节点、边和绑定；Undo 整体移除并退休其运行及结果；Redo 恢复同一历史身份并由会话重新准入/分配活动代次，不复活已退役结果或 reader。期间复制后用户进行的其他事务遵循普通历史顺序；失败必须完整回滚。
关闭 / 切换片段归宿主剪贴板会话所有，切换/关闭源或目标时按已冻结的有效期策略显式清理或拒绝；异步回调必须核真实 session 和代次，不能只比较节点字符串。

引用、显示与自动来源映射

内容建议规则 / 验证
内部 OutputReference若被引用节点也在片段：统一映射 NodeId 与 ScopeId；PortId 原始字符串、TypeRef、Storage、成员路径保持；递归处理 Selection.AtField（包括其构造策略）和层层引用；不通过名称或 CLR/Guid 推断。
外部 OutputReference同流程：建议保留源身份并重新验证真实节点、合法可达范围与声明；跨流程：不把源流程节点伪装成目标前驱，严格按输入/参数与 Display 各自合法作用域验证；不合法时保留可诊断的失效引用还是拒绝整次粘贴是待定产品决策。不得静默清空、凭同名匹配或建立执行边来强行通过。
VariableSetting / Selection.AtVariable同方案变量保持 SolutionId + VariableId 原身份，粘贴时重验实际变量与类型；数组索引按现行引用声明与用途校验。跨方案目前拒绝，不克隆变量或按名称寻找。Display 禁止变量索引仍按既有显示验证。
DisplayExpressionSetting保留文本及 slot 顺序、token、format；对 Reference slot 递归映射，对 Self 路径保相对自身（自然指向新节点），重新走 CandidateDisplayValidation / ResultDisplayBindingScope，不能因为显示引用生成执行依赖。SelectedDisplayReference 若有值同样解析规范引用后映射并验证。
OriginId / RebindingReason复制前在完整源图验证 connection:edge 确实属于该输入；边被复制时映射新边 ID；同流程被选目标的外部入线若复制则映射新入线 ID。无对应边不得继续声称自动归属：保留明确失效原因或拒绝，不能洗白；已有 RebindingReason 原样保留并显示诊断。经现行 ConnectionBindingPolicy 和 CandidateInputValidation 复核。

位置、常量、资源与结果

项目建议
节点及连线按选区统一平移 Δ 到用户放置点，尺寸、启用、AdditionalData 深克隆，编号与显示名按目标会话唯一分配；边端口保持；内部边手工折点按同一 Δ 平移并验证有限值。外部前驱入线两端并未同时平移，旧折点不能原样平移充当证据：建议清手工折点并重新路由，具体原件行为待核。
配置与 CurrentValues字段使用唯一 ToolConfiguration / FieldSettings 深冻结，按目标目录真实声明重新准入；常量按 ValueRules 独立冻结，不携带资源借用。旧代码 Copy 会复制 CurrentValues；建议只对仍指同一有效外部引用的可持久纯值保留，内部映射或来源改变的当前值应清除直至新运行，避免把旧节点运行值当新结果。该策略改变需主线决策及原件证据；不能凭已有旧测试断言全保或全清。
资源路径同一 session / 同一 ResourceBaseDirectory 时复制相对路径保持含义；SaveAs 后 live 字段仍按 session 固定资源基址解析。未来跨方案需根据真实源/目标基址和冻结声明逐字段重定位，不能按文本猜路径或复制 native 对象；本批跨方案拒绝。
运行与结果不复制活动调用、正式/私有 publication、图像空间、reader、debug session、图标和选择等 UI 状态；新节点执行身份/代次独立，重新运行后才产生新结果。仅复制被允许的纯值快照，受上条待决规则约束。
