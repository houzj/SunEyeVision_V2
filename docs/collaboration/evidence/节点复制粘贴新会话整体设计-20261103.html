复制生命周期与身份

阶段建议合同（待主线审定）
复制UI 在所属线程读取当前 session、workflow 和真实所选 NodeDefinition 对象。Application 先验证成员引用、声明与控制流准入，捕获独占不可变片段：源会话身份、源流程身份、各实际节点代次/配置身份、字段和必要的资源来源、被选节点及有关执行边。不得把 live 节点集合、reader、图像帧或可变 ROI 借用放进剪贴板。捕获成功才替换当前片段。
粘贴目标必须是相同活动方案会话的实际流程与活动目录，禁止用 ID 自证。预生成独立新 ID 映射、编号、偏移、引用和边；全部在目标同一个 GraphEditDraft 中准备、校验并一次 CommitGraphEdit。任何失败不改源、目标、历史、选区或编号；不得先发布节点再补边。跨方案剪贴板行为未证，本批建议明确拒绝，待合同及资源所有权审定。
源变化显式待决：复制时冻结定义快照使稍后删除源仍可粘贴，还是要求源节点代次仍活跃。建议区分内部复制快照与保留外部引用：内部映射可从安全冻结快照构造；保留外部引用和入线必须在粘贴时核实际对象及代次。禁止同 ID 新实体冒充旧源。实际对标需补证，先由主线冻结。
撤销 / 重做一个历史条目含全部新节点、边和绑定；Undo 整体移除并退休其运行及结果；Redo 恢复同一历史身份并由会话重新准入/分配活动代次，不复活已退役结果或 reader。期间复制后用户进行的其他事务遵循普通历史顺序；失败必须完整回滚。
关闭 / 切换片段归宿主剪贴板会话所有，切换/关闭源或目标时按已冻结的有效期策略显式清理或拒绝；异步回调必须核真实 session 和代次，不能只比较节点字符串。

主线冻结合同（实施基线 d9182ab66）

以下是本方产品合同，原件精确行为仍待集中取证；覆盖上文建议中冲突的待定项。同一实际活动 Session 与同代目录；纯定义片段支持源节点之后编辑或删除。外部依赖及同流程外部入线在粘贴时必须核真实对象和代次，失效整次拒绝；跨方案拒绝。内部引用和 Origin 递归重映射，跨流程仅保内部边，失效引用不得洗白。变量保持同 Session 身份。

调用方向：Session.CaptureNodeClipboard(flowId, actualNodes) 得到不可伪造冻结片段；Session.PasteNodeClipboard(targetFlowId, fragment, anchor) 以同一个 GraphEditDraft、同一提交发布并返回实际节点和边。复制纯值依 ToolConfiguration 的冻结能力；设置身份改变时对应当前值失效是本次复制专属本方新规则，不是现有 WithFieldSettings 的行为，也不宣称 VM 事实，不复制运行结果或 native 资源。新节点和编号沿正式创建分配；内部手工折点统一平移，外部入线清折点；默认每次粘贴偏移20是本方策略。

UI 完整接菜单、快捷键、Ctrl拖副本/取消和框选；选择新节点，重复粘贴，切换/关闭清空片段，不经 OS 发布未知对象。Undo/Redo 是一次完整事务且旧能力不复活；严格测试实际引用、失败回滚、资源及保存重开。Group/控制流暂停。

复制候选对所有已配置的非显示引用（包括当前非活动字段）检查真实身份、范围及声明，非法时按字段诊断并整体拒绝；正常编辑允许保存的非活动失效引用因此可能无法复制。未配置或合法未完成的字段不要求达到执行就绪，也不调用算法执行验证。这是本方复制专属更严格策略，不改变普通编辑，不冒称原件事实。

变量身份冻结策略：以本方案当前实际 GlobalVariable 对象引用及当前声明类型编译为准，同 ID 不同实例拒绝；删除后 Undo 恢复同一对象时允许按当前合法声明重新使用。该策略不等同节点的生命周期代次；未来若引入变量 generation，在片段外部依赖捕获与粘贴重验处接入，本批不新增代次框架。

坐标合同：Application 的 anchor 是捕获顺序中首个实际节点中心，不依赖 Domain 宽高推测视觉尺寸；UI 捕获同一首节点的视觉左上角至中心偏移，右键世界坐标加该偏移后提交。Ctrl 拖使用首节点中心与实际位移；键盘重复偏移 20/40。源删除后仅用片段保存的锚点和 UI 已冻结偏移，不读退役节点。
