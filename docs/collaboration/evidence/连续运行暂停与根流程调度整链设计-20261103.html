建议生产责任与数据流

owner 一次检查并冻结图、声明、根设置、排序
→
同一根预约：连续运行句柄
→
owner 门禁准备下一轮新请求/游标票据
→
执行层单轮顺序流程与变量生产
→
接纳结果 + 判定停止条件 + 排空轮次
→
可中断间隔 / 下一轮

一次连续会话冻结工作流集合、顺序/依赖、节点实例和配置声明、根 RunIntervalMs/StopOnNg；每轮从同一活动文档、同一 owner 与目录复核当前值，并重新生成每轮配置/变量快照、运行接纳捕获、producer基线与一次性请求。前一轮合法接纳的值可成为下一轮初始值；不能重用第一轮 prior CAS 或把可变 Document 原对象交给执行器。若变量或节点身份被退役、目录变更或快照不再合法，结束并诊断，不吞错继续。冻结图期间根预约保护编辑、删除和方案替换；跨流程消费者按本轮依赖拓扑取得生产者结果，不能先读取上一轮残留值顶替本轮应有的生产。

保留真实 ExecutionRunBatch（一个根预约）与既有就绪队列/资源租约；内部拆分“一次准入冻结”与“逐轮在同预约内创建 ExecutionRunRequest”，每轮每流程新 RunIdentity/ScopeId/RequestId，顺序使用同一 owner root，运行中/间隔中均不可释放或被第二根运行抢占。每轮新建、完成并释放 host preparer 与图像租约，不能重用已Claim请求。原先单次公开 API 保持自身语义，连续层复用同一逐轮执行核心，不能形成两套算法。

宿主完成摘要由实际准备器一次结算结果提供，Application验证与本轮已签发的RunIdentity、节点实例代次及Session身份一致；显示回执仍独立消费，陈旧或未接纳不得驱动停止。

每轮准备需 owner 执行：由 Application 保存创建时的 owner 同步上下文并异步 Post 到它，工作线程 await 结果，禁止 Dispatcher.Send、持 Session/Owner 锁回调或 UI 定时器驱动。无同步上下文宿主使用已有 owner 显式 drain 机制或明确的 owner 驱动入口；不能静默等待永不发生的 Post。factory 回调前后复核真实 session/节点、声明/版本和取消；已创建的准备器在锁外统一释放。轮间完成安装可能使配置对象换版，复核应比较同节点及执行配置身份/声明，允许合法 current value 变化，不用首轮配置引用拒绝合法后续轮。

状态和停止语义

事件建议本方合同；非已证原件语义
暂停 / 恢复暂停阻止下一次节点调度及下一轮启动；已在途工具按现有边界完成，不将其未开始的下一节点提前执行。间隔期间暂停须停止间隔计时并在恢复后等待剩余时间；Stop 总能唤醒暂停和间隔。UI 展示“暂停”与“连续中”而不是把两者当空闲。
停止 / 关闭Stop 幂等：设置会话取消并向当前引擎传播，唤醒间隔/暂停；等待当前调用、host输入、回调与发布接纳排空，再由 owner 释放根预约和资源。连续句柄运行期间 Dispose 拒绝；关闭方案应先取消并异步等待，失败聚合后仍尽力释放，不借超时伪称排空。
间隔每轮完成、结果接纳及输入结算后以冻结 RunIntervalMs 作轮间最短等待；0 为允许立即继续，使用异步可取消等待而非忙转；不把执行时长扣抵或偷偷按新设置动态改间隔。多根不同设置：建议多根连续采用各自根的结束到下一次启动间隔；若采用整批一次最大间隔会改变语义，须主线先裁决。
NG建议仅已成功产出且 Judgment == Fail 算业务 NG；NotEvaluated 不算 NG，执行故障/取消分别为失败/取消并保护性停止，不能当OK。StopOnNg=true 时完成本根本轮已启动调用、接纳和清理后停机；多根作用范围及原件对应待确认，不能把 Success=false 一概称NG。
最后图像仅真实接纳票据、AutoAdvance 和 StopAtLast 成立且本轮实际读取最后项才触发；失败或取消后若已越过接纳点，保持现有票据不回滚；未读取节点不产生停止信号。重复路径按 EntryId/OriginalIndex/RequestId，不靠路径去重。用户选择与旧结果回显继续按节点代次及SelectionVersion防迟到。
多根 RunAll维持当前跨流程生产依赖拓扑和同级请求顺序、单根预约内顺序执行；不引入并行调度。建议每轮所有选定根各执行一次，产生的变量对本轮后继可见、下一轮再从实际接纳值冻结。一个根最后图/NG后如何影响其他根及下一轮属于本方策略，须主线冻结；不能假称VM语义。

成批验收矩阵

  1. 真实ImageLoad→Blob：多轮实际图片顺序、最后图停止、单张/空列表、自动切换关闭、选择冲突、重复路径、停止与清理；验证实际回执与显示一致。
  2. 可控异步正式工具：运行内/节点间/间隔暂停恢复、间隔0、暂停后Stop、外部取消、最后一轮与Stop竞态、关闭等待和超时后实际排空；根预约直到最终释放，禁止并发编辑/运行。
  3. 多个根生产/消费：拓扑顺序、本轮与下一轮变量值、合法连续current值接纳、源失败/未知值、循环依赖拒绝；每轮身份均不同，旧发布和迟到通知不可复活。
  4. 业务Fail、NotEvaluated、工具异常和取消分别断言 StopOnNg 行为；根不同间隔、多源和多根停止策略按最终冻结选择测试。
  5. 连续期间多reader与晚释放、保存/重开根设置、轮间快照、host创建失败和释放失败聚合、目录/节点退休、操作完成后资源不泄漏；单次链回归不变。
  6. 真实主窗标签、总览、工具栏、RunAll、状态栏与来源条切换；用户人工与VS设计器独立记录。真实VM执行/计时证据未取得前不得宣称行为完全一致。

待主线裁决：多根不同间隔的调度策略；单根 NG 或来源结束对全选连续会话的影响；原件证据缺口及是否需要集中补证。以上均为设计建议，不能以本文作为实现完成证明。

主线冻结裁决与本批实施（2026-11-03）

以 d9182ab66（含 cd579cd60）为独立开发基线。同一连续会话持有一个根预约；所选根按既有依赖拓扑顺序逐轮执行，不扩并行、Group或循环。首轮立即执行；每根下一次启动不能早于该根上次完成后加自身冻结 RunIntervalMs，依赖次序可延迟实际启动；不得以多根最大间隔取代单根设置。该规则为本方顺序调度，不声称原件精确频率等价。

任一根明确业务 Fail 且该根 StopOnNg 启用，或真实已接纳末图信号成立，停止整个连续会话；本根已开始调用排空并正常接纳合法结果，后续未开始根和轮次不执行。NotEvaluated 非 NG；执行异常及取消分别报告。暂停保持剩余间隔，Stop 可唤醒，间隔与暂停一直持有根预约。每轮 owner 线程重新冻结当前值、变量和 CAS，每流程新请求/Scope/图像preparer，reader可跨轮保留。

owner以真实 SynchronizationContext 异步 Post；无上下文须显式 owner 调度接缝且验证线程，宿主只负责线程转交，不在UI运行循环。末图来自实际preparer完成/Dispose后的独立结构化摘要，与 Session、节点代次、本轮签发 RunIdentity 匹配；不得消费 UI 回执队列。候选只写 Application Runtime、Execution、Plugin.Infrastructure/ImageSources 及直接非UI运行测试/探针；UI由主线并行接线，整个产品闭口需集中联编验收。
