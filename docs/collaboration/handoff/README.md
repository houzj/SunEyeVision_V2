## 命名与归位

- 文件名：`HANDOFF_<主题>_YYYYMMDD.md`，内容用 `../HANDOFF_TEMPLATE.md` 模板；
- 归位：`handoff/<年>/<月>/`，按文件名里的日期决定月份；
- 没有日期的老文件进 `_未分月/`。

## 旧路径怎么找

老文档里可能还写着 `collaboration/HANDOFF_xxx.md`。全部改名的对照关系在 `迁移映射.md`（旧路径 → 新路径）。检索技巧：直接搜文件名本身（不带目录）仍能命中，因为文件名没改。

## 读交接单的顺序

1. 先看最近的月份目录（当前是 `2026/11/`）；
2. 一份交接单只看四件事：交接了什么、验证到哪一步、还有什么没验、下一责任人是谁；
3. 结论性口径以 `../CURRENT_TASK.md` 顶部摘要和 `docs/07-现行文档/` 为准，交接单只是当时状态。
