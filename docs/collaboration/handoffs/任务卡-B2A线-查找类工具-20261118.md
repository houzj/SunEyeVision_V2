## 一、任务目标与优先级

按"新工具基线清单"实现查找类工具。**本阶段第一步：按原厂证据对齐 UI**（工具箱身份/图标/分类、参数页页签与字段分组、结果页列与呈现），UI 对齐先于算法数值。优先级固定：

1. **圆查找** `IMVSLineFindModu` 的同族 `IMVSCircleFindModu` / 目录 `imvscirclefindmodu` / ToolId `CircleFind`（用户点名"远查找"为"圆查找"笔误）
2. **直线查找** `IMVSLineFindModu` / 目录 `imvslinefindmodu` / ToolId `LineFind`
3. 其余查找工具作为第二波，须先完成各自取证后再开工：椭圆查找、阵列圆查找、直线查找组合、多直线查找、四边形查找、平行线查找、中线查找、垂线查找、角平分线查找、边缘查找。

本阶段只要求前 2 个（圆查找、直线查找）完成完整 UI 对齐闭环；其余工具可先做取证与 UI 设计，不得用推测补齐语义。
