## 二、agent-desktop 自测配方（已验证可用）

命令入口：`E:\SunEyeVision_V2\.tools\agent-desktop\agent-desktop.cmd`（PowerShell 里 ref 必须加单引号）

```powershell
# 0) 健康检查
& $ad status                     # 期望 accessibility=granted, platform=windows

# 1) 启动正式 Release
$exe = "d:\MyWork\SunEyeVision_V2\Release\SunEyeVision_v1.0.0\SunEyeVision\SunEyeVision.UI.exe"
Start-Process $exe

# 2) 取窗口（app_name 用 list-apps 得到的精确名，如 SunEyeVision.UI.exe）
$j = (& $ad list-windows | Out-String | ConvertFrom-Json); $j.data | Where-Object app_name -like "*SunEye*"

# 3) 抓交互树（大窗口必须给足 --timeout-ms，否则 ref 不唯一）
& $ad snapshot --window-id <id> -i --compact --timeout-ms 8000

# 4) 语义点击（按钮/列表项等有名字的元素）
& $ad click '@sX:e6'             # 例：欢迎页最近方案条目

# 5) 画布节点等“同名同卵”元素：ref 无法区分（AMBIGUOUS_TARGET），
#    改用 -include-bounds 取屏幕坐标后物理点击
& $ad snapshot --window-id <id> --include-bounds --timeout-ms 8000
& $ad focus-window <id>
& $ad mouse-click --xy <x>,<y> --count 2 --headed     # 双击打开参数页

# 6) 取证据
& $ad screenshot --window-id <id> <输出.png>
```

**已知限制（当前）**：
- 画布节点在无障碍树中是 `CanvasNodeProjection` 同名行，语义 ref 不唯一；必须用坐标物理点击，且**坐标以截图为基准重新校准**（窗口位置变化会使缓存坐标失效）。
- 参数页是否成功打开，以 `%LOCALAPPDATA%\SunEyeVision\Logs\suneye.log<日期>.log` 中 `ToolWindow stage=CreatePresentation` / `参数页组装失败` 判定，不只看截图。

## 三、REA 取证配方

```powershell
$env:GHIDRA_INSTALL_DIR = "E:\SunEyeVision_V2\.tools\ghidra\ghidra_12.1.4_PUBLIC"
$env:JAVA_HOME = "E:\SunEyeVision_V2\.tools\jdk25\jdk-25.0.5.0.2+1"
# 托管程序集：先判是否托管
rea inspect-managed-artifact <dll> --format json      # classification.status
# 非托管：导出表 → 目标函数反编译
rea inspect-native-exports <dll> --format json
rea decompile <dll> <addr> --format json
# 托管源码级：ILSpy（已安装 ilspycmd）
ilspycmd -p -o <输出目录> <dll>
```

## 四、判定标准（任一条不满足即未闭环）

1. 构建：全量 Release 0 错误
2. 单测：该工具测试项目全通过
3. 真实程序：工具箱可见 → 拖入画布 → 参数页可开且无 `参数页组装失败` → 结果显示正确
4. 日志：无新的 ERROR、无兜底告警
5. 证据：截图/日志片段写入交接单，commit 已产生
