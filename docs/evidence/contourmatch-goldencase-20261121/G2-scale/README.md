## 结论

**两态结果完全相同，scale 仍输出 1**——该图上模板以原始尺度匹配最优，放宽范围未改变最优匹配。

- 原厂确实有 scale 输出列（值 1），证明 A 类尺度搜索有执行语义。
- 但本 Case 无区分度（scale 始终 1），不能用它验证"原厂如何算非 1 尺度"。需换一张含缩放目标的图才能取到 scale≠1 的基准。
- 状态：G2 基准有效但区分度不足，尺度迁移的精确验证仍缺基准。
