## 基准区分度总结（G1/G2/G4 全部无区分度）

| Case | 参数 | 结果 | 原因 |
|---|---|---|---|
| G1 | 极性两态 | 相同 | 图上边缘极性单一 |
| G2 | 尺度 1.0 → 0.8~1.2 | 相同(scale=1) | 图上目标为原始尺度，放大范围无更优匹配 |
| G4 | 全部搜索模式 | 相同 | 单模板，无第二个模型 |

**这三个 Case 无法作为算法迁移的区分性基准**。要取得有区分度的 GoldenCase，必须换测试素材：
- 极性：含明暗反转边缘的图
- 尺度：含缩放目标（如 0.8 倍/1.2 倍）的图 + 对应模板
- 多模型：训练 ≥2 个不同模板

当前 G0/G1/G2/G4 只能证明"字段映射与坐标口径正确"，不能证明 A 类迁移的数值等价。
