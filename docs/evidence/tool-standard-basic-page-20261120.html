工具标准基本参数页

目标：大多数工具的基本参数页共用同一套装配，不再由每个工具重复拼控件、抑制行或接位置修正。

标准结构

图像输入（共享输入行，标签「输入源」）
ROI区域
  输出掩膜
  ROI区域类型
  ROI创建（绘制 / 继承）
  形状
  位置修正（开关）
  ↳ Assist 组（仅在开关开启时显示）
工具差异：是否显示屏蔽区、标签、字段身份

规则

1. 新增工具不得复制 ROI/Assist 装配代码，只提供 NativeStandardBasicPageSpec。

2. 工具差异必须能指向原厂证据；没有证据的差异不进入标准页。

3. 标准页之外的专属内容只允许作为锚定内容插入，不改共享行模板。

4. 字段身份变化后必须同步测试与保存的测试方案；旧方案缺字段时由工具在 Bind 前补默认值。
