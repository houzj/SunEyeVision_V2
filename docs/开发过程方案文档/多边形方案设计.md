## 一、需求汇总

| # | 需求 | 说明 |

| 1 | 多边形绘制 | 点击添加顶点，双击/Enter 完成 |

## 二、交互流程

```
点击多边形按钮 -> OnPolygonButtonClick
    |
    v
SelectShapeTool(Polygon) -> 进入绘制模式
    |
    v  左键点击
首次点击：_isDrawingPolygon = true, _polygonPoints.Add(point)
    |
    v  鼠标移动 (>=2个顶点)
- 临时加入鼠标位置到 ShapeParameters.Points
- WpfShapeRenderer 渲染多边形填充
- DrawPolygonRubberBand 画橡皮筋线
    |
    v  左键点击 (>=2次)
_polygonPoints.Add(point) -> 确认顶点，更新预览
    |
    v  双击 / Enter (>=3顶点)
_isDrawingPolygon = false -> FinishInteraction()
    |
    v
验证 Points.Count >= 3 -> 加入 Regions 集合
    |
    v  选中多边形
顶点手柄 (PolygonVertex) + 中心手柄 (Center)
    |
    v  拖拽顶点手柄
更新对应顶点位置 -> 实时重绘

撤销：右键 -> 移除最后一个顶点，<3点时填充消失
取消：Escape -> 清空所有状态
```

{

            : "已取消多边形绘制";
        e.Handled = true;
        return;
    }

    // 首次点击：初始化
    if (!_isDrawingPolygon)
    {
        _isDrawingPolygon = true;
        _isDrawing = true;
        _polygonPoints.Clear();
        _currentDrawingRegion = RegionData.CreateDrawingRegion(
            GenerateRegionName(), _currentTool);

    SyncPolygonToShapeDef();
    ClearRubberBand();
    UpdateRegionOverlay();

**h) 橡皮筋线绘制 + 清理**

```csharp
private void DrawPolygonRubberBand(Point mousePosition)
{
    var canvas = OverlayCanvas;
    if (canvas == null || _polygonPoints.Count == 0) return;

    ClearRubberBand();

    var zoom = _mainImageControl?.Zoom ?? 1.0;
    var lastPoint = _polygonPoints[_polygonPoints.Count - 1];

    // 虚线：最后一个顶点 -> 鼠标位置
    var line = new System.Windows.Shapes.Line
    {
        X1 = lastPoint.X, Y1 = lastPoint.Y,
        X2 = mousePosition.X, Y2 = mousePosition.Y,
        Stroke = Brushes.DodgerBlue,
        StrokeThickness = 2.0 / zoom,
        StrokeDashArray = new DoubleCollection { 4, 3 },
        Tag = RubberBandTag
    };
    Canvas.SetZIndex(line, 50);
    canvas.Children.Add(line);

    // 小圆点：鼠标位置
    var dotSize = 6.0 / zoom;
    var dot = new Ellipse
    {
        Width = dotSize, Height = dotSize,
        Fill = Brushes.DodgerBlue, Tag = RubberBandTag
    };
    Canvas.SetLeft(dot, mousePosition.X - dotSize / 2);
    Canvas.SetTop(dot, mousePosition.Y - dotSize / 2);
    Canvas.SetZIndex(dot, 50);
    canvas.Children.Add(dot);
}

private void ClearRubberBand()
{
    var canvas = OverlayCanvas;
    if (canvas == null) return;
    var toRemove = canvas.Children
        .OfType<FrameworkElement>()
        .Where(e => e.Tag as string == RubberBandTag)
        .ToList();
    foreach (var item in toRemove)
        canvas.Children.Remove(item);
}
```

private void CreatePolygonHandles(ShapeParameters shape)

        AddHandle(HandleType.PolygonVertex, pt);

public static EditHandle[] CreatePolygonHandles(List<Point2D> vertices, double scale = 1.0)
{
    var handles = new List<EditHandle>();
    for (int i = 0; i < vertices.Count; i++)
    {
        var v = vertices[i];
        var size = GetScaledHandleSize(scale);
        handles.Add(new EditHandle
        {
            Type = HandleType.PolygonVertex,
            Position = new Point(v.X, v.Y),
            HandleSize = size,
            Bounds = new Rect(v.X - size / 2, v.Y - size / 2, size, size),
            Cursor = Cursors.SizeAll,
            VertexIndex = i
        });
    }

    // 中心手柄（各顶点均值）
    if (vertices.Count > 0)
    {
        var centerX = vertices.Average(v => v.X);
        var centerY = vertices.Average(v => v.Y);
        var centerSize = GetScaledHandleSize(scale);
        handles.Add(new EditHandle
        {
            Type = HandleType.Center,
            Position = new Point(centerX, centerY),
            HandleSize = centerSize,
            Bounds = new Rect(centerX - centerSize / 2, centerY - centerSize / 2, centerSize, centerSize),
            Cursor = Cursors.SizeAll
        });
    }

    return handles.ToArray();
}
```

private static Polygon CreatePolygon(ShapeParameters shape, Brush fillColor, Brush strokeColor, double strokeThickness, bool isPreview)
{
    if (shape.Points.Count < 3) return null;

    var polygon = new Polygon
    {
        Fill = fillColor,
        Stroke = strokeColor,
        StrokeThickness = strokeThickness,
    };

    var pointCollection = new PointCollection();
    double minX = double.MaxValue, minY = double.MaxValue;
    foreach (var pt in shape.Points)
    {
        pointCollection.Add(new System.Windows.Point(pt.X, pt.Y));
        if (pt.X < minX) minX = pt.X;
        if (pt.Y < minY) minY = pt.Y;
    }
    polygon.Points = pointCollection;
    polygon.Tag = new { X = minX, Y = minY };

    return polygon;
}
```

## 九、风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| 橡皮筋线在缩放下线宽失真 | 使用 2.0 / zoom 计算线宽，随缩放自适应 |
| 顶点拖拽时 Point2D 不可变 | 使用 shape.Points[index] = new Point2D(...) 替换元素 |
| 参数面板 XY 绑定不触发更新 | 暂用 TextBox 绑定，后续可改为 ObservablePoint |
| PolygonVertex 手柄视觉统一 | 与现有手柄共用橙色圆形样式 |
