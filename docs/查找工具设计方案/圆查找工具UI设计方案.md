## 一、整体架构概览

### 1.1 工具定位与设计理念

**CircleCaliperTool** 是一款**引导式精密圆测量工具**, 与传统的全局盲搜式圆检测(HoughCircles)有本质区别:

```
┌───────────────────────────────────────────────────────────────────────┐
│                        设计理念对比                                    │
├───────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  ┌─ HoughCircles (v2.0, 已废弃) ─────┐  ┌─ ArcCaliper (v3.0, 当前)─┐ │
│  │                                   │  │                           │ │
│  │  全局盲搜                          │  │  引导式精密测量            │ │
│  │  - 输入: 整张图像                 │  │  - 输入: 灰度图 + 圆形ROI  │ │
│  │  - 搜索: 全图扫描找圆            │  │  - 搜索: 沿ROI弧线采样     │ │
│  │  - 输出: 所有可能的圆(多目标)     │  │  - 输出: 单个精确圆(单目标) │ │
│  │  - 精度: 像素级(float)           │  │  - 精度: 亚像素级(0.01px)  │ │
│  │  - 用途: 发现/计数/定位          │  │  - 用途: 测量/检测/定位     │ │
│  │                                   │  │                           │ │
│  │  类似: "在一堆沙子里找所有圆石子" │  │  类似: "用卡尺量一个圆孔"   │ │
│  └───────────────────────────────────┘  └───────────────────────────┘ │
│                                                                       │
│  核心差异:                                                             │
│  • ArcCaliper 需要用户先提供一个近似的圆形ROI(圆心+半径作为初始引导)      │
│  • ArcCaliper 沿弧线法线方向做1D投影边缘检测, 而非2D全图梯度累加         │
│  • ArcCaliper 天然支持边缘极性(从亮到暗/暗到亮), 抗干扰能力更强           │
│  • ArcCaliper 边缘点经亚像素插值后做最小二乘圆拟合, 精度可达 0.01px       │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

### 1.2 算法链路总览

```
┌─ ArcCaliper 圆卡尺算法链路 ─────────────────────────────────────────────┐
│                                                                       │
│  输入                                                                  │
│  ├── 灰度图像 (Mat, 单通道)                                           │
│  └── 圆形 ROI (圆心 cx,cy + 半径 r)    <-- 用户在 Tab1 绘制            │
│       |                                                                │
│       ▼                                                                │
│  ┌───────────────────────────────────────────────────────────────┐     │
│  │ Step 1: 采样点生成                                            │     │
│  │   沿圆形ROI均匀分布 N 个采样点                                  │     │
│  │   每个采样点位置:                                              │     │
│  │     px_i = cx + r * cos(startAngle + i * angleStep)            │     │
│  │     py_i = cy + r * sin(startAngle + i * angleStep)            │     │
│  │   其中 i = 0, 1, ..., N-1                                      │     │
│  └───────────────────────────────┬─────────────────────────────────┘     │
│                                  ▼                                       │
│  ┌───────────────────────────────────────────────────────────────┐     │
│  │ Step 2: 1D 投影边缘检测 (每个采样点独立执行)                    │     │
│  │                                                               │     │
│  │        投影窗口 (半宽 = projectionWidth 像素)                   │     │
│  │             ←──── projectionWidth ────→                        │     │
│  │             ┌──────────────────────┐                           │     │
│  │   ◄─────── │ ~~~~~~~~|~~~~~~~~~~ │ ◄── 法线方向                │     │
│  │   外侧     │  像素值  ↑边缘点    │   (沿半径方向)              │     │
│  │             └──────────────────────┘                           │     │
│  │                        圆心侧                                    │     │
│  │                                                               │     │
│  │   对每个采样点的1D剖面:                                        │     │
│  │   a) 提取灰度值序列 g[0..2*projectionWidth]                   │     │
│  │   b) 计算一阶微分 dg/dx (梯度)                                 │     │
│  │   c) 在梯度幅值 >= edgeThreshold 的位置寻找极值                 │     │
│  │   d) 根据边缘极性筛选(亮->暗 / 暗->亮 / 任意)                  │     │
│  │   e) 找到边缘点后, 用亚像素插值精确定位                         │     │
│  └───────────────────────────────┬─────────────────────────────────┘     │
│                                  ▼                                       │
│  ┌───────────────────────────────────────────────────────────────┐     │
│  │ Step 3: 亚像素边缘点集合                                       │     │
│  │                                                               │     │
│  │   输出: M 个有效边缘点 (M <= N, 部分采样点可能未检出边缘)      │     │
│  │   每个边缘点包含:                                             │     │
│  │   ├── 精确坐标 (x, y), 精度 0.01px                            │     │
│  │   ├── 边缘强度 (edgeStrength), 即该点梯度幅值                   │     │
│  │   └── 极性标记 (polarity), 亮->暗(+1) / 暗->亮(-1)            │     │
│  └───────────────────────────────┬─────────────────────────────────┘     │
│                                  ▼                                       │
│  ┌───────────────────────────────────────────────────────────────┐     │
│  │ Step 4: 圆拟合                                                 │     │
│  │                                                               │     │
│  │   使用选定的拟合方法对 M 个亚像素边缘点做圆拟合:               │     │
│  │                                                               │     │
│  │   方法A: 最小二乘圆拟合 (默认, 快速稳定)                       │     │
│  │     最小化 Σ((xᵢ-cx)² + (yᵢ-cy)² - R²)²                     │     │
│  │                                                               │     │
│  │   方法B: Huber鲁棒拟合 (抗离群点)                              │     │
│  │     对大残差点降权, 减少异常边缘的影响                          │     │
│  │                                                               │     │
│  │   方法C: RANSAC拟合 (最强抗噪)                                 │     │
│  │     随机采样+一致性投票, 可容忍高达50%的离群点                  │     │
│  └───────────────────────────────┬─────────────────────────────────┘     │
│                                  ▼                                       │
│  输出                                                                  │
│  ├── 拟合圆心 (fitCx, fitCy)          [像素坐标, 亚像素精度]           │
│  ├── 拟合半径 (fitR)                  [像素, 亚像素精度]               │
│  ├── 边缘点数量 (M)                    [整数]                            │
│  ├── 平均边缘强度 (avgEdgeStrength)    [浮点数]                          │
│  ├── 边缘强度标准差 (stdEdgeStrength)  [浮点数]                          │
│  └── 拟合残差 RMSE                    [浮点数, 单位: 像素]              │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

### 1.3 调试控制面板结构

调试控制面板采用 **4 Tab 分页布局**, 完全对齐 BlobAnalysis / ShapeMatch / LineFinder 工具的实现风格:

```
+-----------------------------------------------------------------------------+
|  +------+------+------+------+                                             |
|  | Tab1 | Tab2 | Tab3 | Tab4 |                                             |
|  | 基本 | 卡尺 | 拟合 | 结果 |                                             |
|  | 参数 | 参数 | 筛选 | 显示 |                                             |
|  +------+------+------+------+                                             |
|                                                                             |
|  +---------------------------------------------------------------------+   |
|  |                                                                     |   |
|  |                     当前选中 Tab 的内容区                             |   |
|  |                                                                     |   |
|  +---------------------------------------------------------------------+   |
+-----------------------------------------------------------------------------+
```

**Tab 功能定位:**

| Tab | 名称 | 核心职责 | 与 LineFinderTool 的对齐关系 |
|-----|------|----------|---------------------------|
| Tab1 | 基本参数 | 图像源选择、圆形ROI编辑器（圆心+半径）、位置补正 | 完全一致，但 ROI 默认推荐使用**圆形** |
| Tab2 | 卡尺参数 | 采样参数、投影参数、边缘极性、边缘阈值、亚像素插值模式 | 对应 LineFinder 的「检测参数」，但内容完全不同（卡尺专用参数） |
| Tab3 | 拟合筛选 | 拟合方法选择、离群过滤、输出偏差容差 | 对应 LineFinder 的「筛选合并」，但聚焦于圆拟合质量 |
| Tab4 | 结果显示 | 结果判断（半径/圆度/边缘点）、图形显示（拟合圆/射线/边缘点）、文本显示 | **完全一致的 Expander 三分组模式** |

### 2.2 各区域详细说明

#### 2.2.1 图像源选择区

| 属性 | 值 | 说明 |
|------|-----|------|
| 控件类型 | `ImageSourceSelector` | SDK 内置下拉选择器组件 |
| 标签文本 | `"输入图像"` | 通过 LabeledControl.Label 设置 |
| PlaceholderText | `"请选择输入图像源"` | 未选择时的占位提示文字 |
| Width | `250` | 控件宽度（与 ShapeMatchTool / LineFinderTool 对齐） |
| 数据绑定 | `AvailableDataSources` | 继承自 ToolDebugControlBase 父类，自动获取工作流中的 Mat 类型数据源 |
| 选择结果绑定 | `ImageSource` | 双向绑定到 Parameters.ImageSource |

**交互行为:**
- 点击控件展开下拉列表，显示当前工作流中所有可用的图像数据源
- 选择后控件显示选中的数据源名称
- 数据源变更后自动触发图像预览刷新

**与其他工具的完全一致:** 使用同一套 ImageSourceSelector + LabeledControl 组合，行为无差异。

#### 2.2.2 圆形ROI编辑器（核心差异点）

RegionEditorManagerControl 是本工具的**核心输入组件**, 与 v2.0 (HoughCircles 版本) 的关键区别在于:

````
+- 圆形ROI的特殊意义 -------------------------------------------------------+
|                                                                           |
|  在 ArcCaliper 模式中, ROI 不再是"搜索范围", 而是"初始引导":               |
|                                                                           |
|  ┌─ HoughCircles (v2.0) ──────┐  ┌─ ArcCaliper (v3.0) ───────────┐      |
|  │                             │  │                                │      |
|  │  ROI = 搜索范围             │  │  ROI = 初始圆形引导            │      |
|  │                             │  │                                │      |
|  │  在此范围内找出所有可能的圆  │  │  以此圆为基准沿弧线采样边缘     │      |
|  │  可能找到 0~N 个圆          │  │  拟合出 1 个精确圆             │      |
|  │                             │  │                                │      |
|  │  矩形 ROI → 搜全图一块区域  │  │  圆形 ROI ★★★ → 直接提供      │      |
|  │  圆形 ROI → 搜圆形区域      │  │     圆心(cx,cy)+半径(r)        │      |
|  │                             │  │                                │      |
|  │  ROI 大小影响: 搜索范围      │  │  ROI 大小影响:                 │      |
|  │  (越大越慢, 但可能找到更多)  │  │  采样弧长和覆盖角度            │      |
|  └─────────────────────────────┘  └────────────────────────────────┘      |
|                                                                           |
|  强烈推荐: 使用【圆形】ROI!                                               |
|  - 圆形的几何参数(圆心+半径)可直接传递给 ArcCaliper 作为初始引导            |
|  - 用户可通过拖拽圆心手柄调整圆心位置                                      |
|  - 用户可通过拖拽圆周手柄调整半径大小                                      |
|  - 图像上实时显示圆形 ROI 叠加(蓝色半透明填充 + 蓝色圆周线条)              |
|                                                                           |
|  若用户坚持使用非圆形 ROI:                                                |
|  - 矩形/旋转矩形 → 自动取内接圆(以矩形中心为圆心, min(W,H)/2 为半径)     |
|  - 多边形 → 取最小外接圆(MinEnclosingCircle)                               |
|  - 会显示警告: "非圆形ROI已转换为近似圆, 可能影响测量精度"                   |
|                                                                           |
+---------------------------------------------------------------------------+
```

**语义映射（对齐项目约定）:**

| SDK 内部术语 | UI 显示标签 | 说明（ArcCaliper 特殊含义） |
|-------------|------------|------------------------------|
| Inspection（有效区） | **搜索范围 / 初始引导** | 定义 ArcCaliper 采样的圆形区域。**推荐使用圆形形状**，此时直接提供圆心和半径 |
| Mask（屏蔽区域） | **排除区 / 橡皮擦** | 排除干扰区域，防止在这些区域的假边缘被采集 |

**有效区支持的形状及特殊说明:**

| 形状 | 快捷键 | ArcCaliper 兼容性 | 说明 |
|------|--------|-------------------|------|
| **Circle（圆形）** ⭐ | C | **完美兼容（强烈推荐）** | 直接提取圆心(cx,cy)和半径(r)作为 ArcCaliper 引导参数。用户体验最佳 |
| Rectangle（矩形） | 默认 | **兼容（自动转换）** | 自动计算内接圆：圆心=矩形中心，半径=min(W,H)/2 |
| Polygon（多边形） | P | **兼容（自动转换）** | 计算 MinEnclosingCircle 得到近似圆 |
| RotatedRect（旋转矩形） | O | **兼容（自动转换）** | 同矩形，取内接圆 |

**排除区支持的形状:**

| 形状 | 说明 |
|------|------|
| Rectangle Eraser（矩形擦除） | 矩形橡皮擦，快速擦除规则干扰区域 |
| Circle Eraser（圆形擦除） | 圆形橡皮擦，适合擦除点状/圆形干扰 |

**橡皮擦尺寸:**
- 通过 NumericUpDown 控件调整，单位为像素
- 默认值: `20` px
- 取值范围: `5 ~ 200` px
- 调整后即时生效，仅影响后续绘制的擦除区域
- 已有擦除区域不受尺寸更改影响

#### 2.2.3 位置补正模块

```
+- 位置补正 UI 结构 ---------------------------------------------------------+
|                                                                            |
|  (1) 启用开关                                                              |
|  +---------------------------------------------------------------------+   |
|  |  Label: "位置修正"                                                   |   |
|  |  Control: ToggleSwitch (SwitchWidth=48, SwitchHeight=24)            |   |
|  |  Binding: IsPositionCorrectionEnabled.Value                          |   |
|  +---------------------------------------------------------------------+   |
|                                                                            |
|  (2) 修正信息绑定 (条件显示: 仅当开关=ON时可见)                             |
|  +---------------------------------------------------------------------+   |
|  |  Label: "修正信息"                                                   |   |
|  |  Visibility: 绑定到 IsPositionCorrectionEnabled                      |   |
|  |             使用 BoolToVisibilityConverter                           |   |
|  |                                                                      |   |
|  |  Control: ParamBinding                                               |   |
|  |  - ParameterName: "位置修正"                                        |   |
|  |  - Width: 200                                                       |   |
|  |  - BindingSource: PositionCorrectionBindingSource                  |   |
|  |  - AvailableDataSources: 继承自父级 ToolDebugControlBase           |   |
|  +---------------------------------------------------------------------+   |
|                                                                            |
+----------------------------------------------------------------------------+
```

**功能说明:**

| 状态 | 行为 |
|------|------|
| OFF（默认） | 工具直接使用原始坐标进行圆卡尺测量 |
| ON | 从绑定的数据源获取位置偏移量（如前置定位工具输出的偏移坐标），对 ROI 圆心和拟合结果进行补偿校正 |

**典型应用场景:** 工件在传送带上存在位置偏移时，通过前置定位工具（如 Blob 分析 / 模板匹配 / 直线交点定位）获取偏移量，自动校正后续圆卡尺测量的起始圆心位置，确保每次测量都在正确的相对位置进行。

**与其他工具的对齐:** 完全一致的 ToggleSwitch + ParamBinding 双层结构。

### 2.3 区域编辑器的集成机制

### 3.2 采样参数详解

#### 3.2.1 采样原理可视化

```
+- 采样参数工作原理 ----------------------------------------------------------+
|                                                                           |
|   圆形 ROI (圆心 C, 半径 r)                                               |
|                                                                           |
|                    结束角(180°)                                           |
|                       |                                                  |
|                  ····|····                                                |
|              ···        ··                                              |
|            ··    P(N-1)   ·                                             |
|           ·                 ·                                           |
|          ·  P(3)    ·P(4)   ·  P(2)                                     |
|         ·                     ·  ·                                       |
|        ·  P(5)    ·C····    ·    ·P(1)                                  |
|         ·         ·          ·  ·                                        |
|          ·       ·  P(6)     · ·                                          |
|           ·                 ·   ·                                        |
|            ··    P(i)      ··  P(0)  <-- 起始角(-180°)                   |
|              ··        ···                                                |
|                ······|                                                     |
|                       |                                                  |
|                                                                           |
|   采样点总数: N                                                          |
|   角度步长: angleStep = (endAngle - startAngle) / (N - 1)                |
|   第 i 个采样点位置:                                                     |
|     Px[i] = Cx + r * cos(startAngle + i * angleStep)                     |
|     Py[i] = Cy + r * sin(startAngle + i * angleStep)                     |
|                                                                           |
|   示例: startAngle=-180°, endAngle=180°, N=72                           |
|     → 覆盖完整360°圆周                                                   |
|     → 每5°一个采样点 (360°/72=5°)                                       |
|     → 适用于完整圆形边缘测量(如圆孔内径)                                  |
|                                                                           |
|   示例2: startAngle=0°, endAngle=90°, N=36                                |
|     → 仅覆盖90°扇形(四分之一圆弧)                                         |
|     → 每2.57°一个采样点                                                  |
|     → 适用于局部圆弧边缘定位(如零件圆角)                                  |
|                                                                           |
+---------------------------------------------------------------------------+
```

#### 3.2.2 参数详情表

| # | 参数 | UI 标签 | 控件 | 默认值 | 取值范围 | 步长 | 算法属性名 | 调参建议 |
|---|------|---------|------|--------|----------|------|-----------|----------|
| 1 | sampleCount | 采样点数(N) | ConfigSetting(int) | **72** | 12 ~ 720 | 1 | SampleCount | 决定边缘采样密度。每10°约2个点是良好起点(360°→72点)。完整圆孔用72~144；局部圆弧用24~60。值越大精度越高但计算量增大 |
| 2 | startAngle | 起始角度(度) | ConfigSetting(double) | **-180.0** | -360.0 ~ 360.0 | 0.5 | StartAngle | 采样弧段的起始角度(单位:度)。负值表示顺时针。-180°表示最左侧点。配合结束角度定义采样范围 |
| 3 | endAngle | 结束角度(度) | ConfigSetting(double) | **180.0** | -360.0 ~ 360.0 | 0.5 | EndAngle | 采样弧段的结束角度(单位:度)。180°表示最右侧点。start=-180,end=180 表示完整360°圆周 |

|                                                                           |

### 3.3 投影参数详解

#### 3.3.1 1D投影边缘检测原理

```
+- 1D 投影边缘检测示意 ------------------------------------------------------+
|                                                                           |
|   采样点 Pᵢ 位于圆形 ROI 上某位置                                         |
|                                                                           |
|                          外侧(远离圆心)                                    |
|                             :                                              |
|   · · · · o o o o O · · · ·  ← 原始灰度值剖面                             |
|             ↑            ↑                                               |
|             |            |                                               |
|        projectionWidth  projectionWidth                                   |
|             |            |                                               |
|   ──────────Pᵢ───────────→   ← 法线方向(沿半径向外)                      |
|             |                                                            |
|            圆心侧                                                         |
|                                                                           |
|   1D剖面数据: g[k] = image(Pᵢ + k * n̂),  k ∈ [-W, W]                    |
|   其中 W = projectionWidth, n̂ = 单位法向量(从圆心指向外侧)                |
|                                                                           |
|   边缘检测流程:                                                           |
|   ┌─────────────────────────────────────────────────────────────────┐     |
|   │ ① 提取 1D 灰度剖面 g[0..2W], 长度 = 2*W + 1                    │     |
|   │                                                                 │     |
|   │ ② 计算一阶差分(梯度): dg[k] = g[k+1] - g[k]                    │     |
|   │    或 Sobel 1D: dg[k] = (g[k+1] - g[k-1]) / 2                   │     |
|   │                                                                 │     |
|   │ ③ 寻找梯度幅值峰值: max(|dg[k]|) >= edgeThreshold ?             │     |
|   │    ↓ Yes                                                         │     |
|   │ ④ 根据极性筛选:                                                    │     |
|   │    LightToDark: 只保留 dg < 0 的负峰(亮度下降处)                 │     |
|   │    DarkToLight: 只保留 dg > 0 的正峰(亮度上升处)                 │     |
|   │    Any:  两种都保留                                                │     |
|   │                                                                 │     |
|   │ ⑤ 亚像素精确定位 (见§3.5)                                         │     |
|   └─────────────────────────────────────────────────────────────────┘     |
|                                                                           |
+---------------------------------------------------------------------------+
```

### 3.4 边缘极性与阈值详解

#### 3.4.1 边缘极性的物理含义

```
+- 边缘极性示意 --------------------------------------------------------------+
|                                                                           |
|  边缘极性定义了期望检测到的边缘的灰度变化方向:                              | 
|                                                                           |
|  【从亮到暗 (LightToDark)】                                               | 
|                                                                           |

|   ════════════════│════════════════  ← 边界                               | 
|   ~~~~~~~255~~~~~│~~~0~~~~~                                     | 
|                   │                                                    | 
|              梯度 < 0  (负峰)                                             | 
|                                                                           |
|  典型应用:                                                              | 
|   - 白色背景下黑色圆孔的内径测量                                          | 
|   - 亮金属表面上的暗色划痕边缘                                            | 
|   - 光照良好的工件暗边缘                                                  | 
|                                                                           |
|  ------------------------------------------------------------------------+
|                                                                           |
|  【从暗到亮 (DarkToLight)】                                               | 
|                                                                           |
|    暗背景(低灰度)          亮目标(高灰度)                                 | 
|   ════════════════│════════════════  ← 边界                               | 
|   ~~~~~~~~0~~~~~~│~~~255~~~                                      | 
|                   │                                                    | 
|              梯度 > 0  (正峰)                                             | 
|                                                                           |
|  典型应用:                                                              | 
|   - 黑色背景下的亮色圆点/焊点                                            | 
|   - 暗色工件上的反光亮点边缘                                             | 
|   - OLED屏幕上的亮像素点                                                 | 
|                                                                           |
|  ------------------------------------------------------------------------+
|                                                                           |
|  【任意极性 (Any)】                                                       | 
|                                                                           |
|   同时接受正峰和负峰, 不管亮度变化方向                                     | 
|                                                                           |
|  典型应用:                                                              | 
|   - 边缘极性不确定或不一致的场景                                          | 
|   - 同一圆上既有亮到暗又有暗到亮的混合边缘                                 | 
|   - 初期调试阶段用来观察实际边缘情况                                      | 
|                                                                           |
+---------------------------------------------------------------------------+
```

**边缘强度阈值的调参逻辑:**

```
+- 边缘阈值调参示意 ----------------------------------------------------------+
|                                                                           |
|  阈值过低 (如 5.0):                                                       | 
|                                                                           | 
|   检测到的边缘点: ●●●●●●●●●●●●●●●●●●●●●●●●●●  (几乎所有点都有响应)       |

|   → RMSE 增大                                                              | 
|                                                                           |
|  ------------------------------------------------------------------------+
|                                                                           |
|  阈值适中 (如 30.0, 默认) ★:                                             | 
|                                                                           | 
|   检测到的边缘点:     ·    ●●●●●●●●●●●●●●●●    ·   (真实边缘清晰可见)       |

|                                                                           |
|  ------------------------------------------------------------------------+
|                                                                           |
|  阈值过高 (如 150.0):                                                     | 
|                                                                           | 
|   检测到的边缘点:     · · · · · ● · · · ● · ·     (只有最强边缘残留)       | 
|   → 真实边缘点也大量丢失                                                  | 
|   → 边缘点太少(M很小), 拟合不稳定甚至失败                                 | 
|   → "边缘点不足" 警告                                                     | 
|                                                                           |

```

**典型场景推荐值:**

| 场景 | 推荐极性 | 推荐阈值 | 原因 |
|------|---------|---------|------|
| 白底黑孔 (标准螺栓孔) | **亮到暗** | **30~50** | 高对比度清晰边缘 |
| 黑底亮孔 (PCB 过孔背光) | **暗到亮** | **30~50** | 背光下孔比周围亮 |
| 低对比度边缘 | **亮到暗** | **10~20** | 降低阈值捕获弱边缘 |
| 高噪声环境 | **亮到暗** | **50~80** | 提高阈值抑制噪声 |
| 不确定极性 | **任意** | **20~40** | 先用 Any 观察, 再锁定极性 |

### 3.5 亚像素插值模式详解

#### 3.5.1 三种插值方法对比

当1D梯度检测找到一个整数位置的边缘候选点后, 亚像素插值将其精确定位到子像素精度:

```
+- 三种亚像素插值方法对比 ---------------------------------------------------+
|                                                                           |
|  1D 梯度曲线中的边缘峰值附近:                                             | 
|                                                                           |
|  幅度 ^                                                                  | 
|       |         ·                                                       | 
|       |       ·   ·   ·                                                  | 
|       |     ·       peak ·                                               | 
|       |   ·               ·                                              | 
|       | ·                   ·                                            | 
|       +----|----|----|----|---> 像素位置                                | 
|          k-1   k   k+1   k+2                                            | 
|               整数边缘位置                                               | 
|                                                                           |
|  ┌─────────────────────────────────────────────────────────────────┐     |
|  │ 方法A: 二次抛物线插值 (Parabolic) ★ 默认                         │     |
|  │                                                                 │     |
|  │  用峰值及其左右各1个点共3个样本拟合抛物线:                       │     |
|  │  p(x) = ax² + bx + c,  顶点 x* = -b/(2a)                        │     |
|  │                                                                 │     |
|  │  精度: ~0.05 ~ 0.1 px                                           │     |
|  │  速度: 极快 (仅需3次乘法)                                         │     |
|  │  适用: 大多数工业场景                                              │     |
|  └─────────────────────────────────────────────────────────────────┘     |
|                                                                           |
|  ┌─────────────────────────────────────────────────────────────────┐     |
|  │ 方法B: 高斯插值 (Gaussian)                                       │     |
|  │                                                                 │     |
|  │  用高斯函数拟合边缘峰形(利用更多邻域点):                         │     |
|  │  g(x) = A * exp(-(x-μ)²/(2σ²)) + B                               │     |
|  │                                                                 │     |
|  │  精度: ~0.01 ~ 0.05 px (最高)                                   │     |
|  │  速度: 中等 (需要迭代优化)                                        │     |
|  │  适用: 计量级超高精度需求                                         │     |
|  └─────────────────────────────────────────────────────────────────┘     |
|                                                                           |
|  ┌─────────────────────────────────────────────────────────────────┐     |
|  │ 方法C: 线性插值 (Linear)                                         │     |
|  │                                                                 │     |
|  │  用峰值点左右线性插值:                                          │     |
|  │  x* = k + (dg[k+1] - dg[k-1]) / (2*(2*dg[k]-dg[k-1]-dg[k+1]))  │     |
|  │                                                                 │     |
|  │  精度: ~0.1 ~ 0.2 px (较低)                                     │     |
|  │  速度: 最快 (闭式解, 无迭代)                                     │     |
|  │  适用: 速度优先 / 精度要求不高的场合                               │     |
|  └─────────────────────────────────────────────────────────────────┘     |
|                                                                           |
+---------------------------------------------------------------------------+
```

#### 3.5.2 参数详情

| 属性 | 值 | 说明 |
|------|-----|------|
| UI 标签 | `"插值模式"` | |
| 控件 | ComboBox (三选一) | |
| 默认值 | **二次抛物线插值 (Parabolic)** | 平衡精度与速度 |

### 4.2 拟合方法详解

#### 4.2.1 三种拟合方法对比

```
+- 三种圆拟合方法对比 ---------------------------------------------------------+
|                                                                           |
|  ┌─────────────────────────────────────────────────────────────────┐     |
|  │ 方法A: 最小二乘圆拟合 (Least Squares) ★ 默认                   │     |
|  │                                                                 │     |
|  │  目标函数: min Σ[(xᵢ-cₓ)² + (yᵢ-cᵧ)² - R²]²                  │     |
|  │                                                                 │     |
|  │  算法特点:                                                       │     |
|  │  • 闭式解(代数方法, 如 Pratt/Taubin 方法)                        │     |
|  │  • 计算速度快 (~0.01ms for 100 points)                          │     |
|  │  • 对离群点敏感 (一个坏点就能明显拉偏圆心/半径)                  │     |
|  │                                                                 │     |
|  │  适用场景: 边缘干净, 离群点少于 5% 的常规测量                    │     |
|  │  典型应用: 标准螺栓孔内径、O型圈外径、轴承孔径                   │     |
|  │                                                                 │     |
|  │  缺点: 抗差能力弱, 有离群点时结果会被拉偏                       │     |
|  └─────────────────────────────────────────────────────────────────┘     |
|                                                                           |
|  ┌─────────────────────────────────────────────────────────────────┐     |
|  │ 方法B: Huber 鲁棒拟合                                             │     |
|  │                                                                 │     |
|  │  目标函数: min Σ ρ(rᵢ), 其中 ρ 是 Huber 权重函数                │     |
|  │  • |rᵢ| ≤ kσ:   ρ = 0.5*rᵢ²   (正常点, 二次惩罚)              │     |
|  │  • |rᵢ| > kσ:   ρ = kσ|rᵢ| - 0.5*k²σ²  (离群点, 线性惩罚)    │     |
|  │                                                                 │     |
|  │  算法特点:                                                       │     |
|  │  • 迭代加权最小二乘 (IRLS)                                       │     |
|  │  • 计算速度中等 (~0.1~1ms for 100 points)                         │     |
|  │  • 对中等比例离群点(5%~20%)具有鲁棒性                             │     |
|  │                                                                 │     |
|  │  适用场景: 有少量杂点/污渍/反光的边缘测量                         │     |
|  │  典型应用: 有油污的金属表面圆孔、有轻微反光的塑料圆边            │     |
|  │                                                                 │     |
|  │  缺点: 离群点超过20%时性能下降明显                               │     |
|  └─────────────────────────────────────────────────────────────────┘     |
|                                                                           |
|  ┌─────────────────────────────────────────────────────────────────┐     |
|  │ 方法C: RANSAC 拟合                                                │     |
|  │                                                                 │     |
|  │  算法流程:                                                       │     |
|  │  ① 随机选取 3 个点拟合一个圆候选                                  │     |
|  │  ② 计算其余点到该圆的距离                                       │     │
|  │  ③ 距离 < inlierThreshold 的点计为内点(inlier)                   │     |
|  │  ④ 重复①③共 K 次, 保留内点最多的圆                               │     |
|  │  ⑤ 用所有内点重新拟合最终圆                                       │     |
|  │                                                                 │     |
|  │  算法特点:                                                       │     |
|  │  • 概率性算法, 结果有微小随机性                                   │     |
|  │  • 计算速度较慢 (~1~10ms for 100 points)                          │     |
|  │  • 极强抗噪能力 (可容忍高达 50% 的离群点)                        │     |
|  │                                                                 │     |
|  │  适用场景: 边缘严重受干扰的情况                                  │     |
|  │  典型应用: 有大面积遮挡/刻字/划痕的圆边缘、部分缺损的圆          │     |
|  │                                                                 │     |
|  │  缺点: 速度最慢; 结果有一定随机波动                               │     |
|  └─────────────────────────────────────────────────────────────────┘     |
|                                                                           |
+---------------------------------------------------------------------------+
```

### 4.3 离群点过滤详解

#### 4.3.1 参数详情

| # | 参数 | UI 标签 | 控件 | 默认值 | 取值范围 | 步长 | 算法属性名 | 说明 |
|---|------|---------|------|--------|----------|------|-----------|------|
| 1 | minEdgeRatio | 最小边缘占比(%) | ConfigSetting(double) | **50.0** | 10.0 ~ 100.0 | 1.0 | MinEdgeRatio | 有效边缘点占采样点数的最低百分比。低于此值判定为"边缘不足"NG |
| 2 | maxOutlierDistance | 最大离群距离(px) | ConfigSetting(double) | **3.0** | 0.5 ~ 20.0 | 0.5 | MaxOutlierDistance | 边点到拟合圆的最大距离阈值。超过此距离的点被视为离群点并在二次拟合前剔除 |

#### 4.3.2 离群剔除流程

```
+- 离群剔除工作流 -------------------------------------------------------------+
|                                                                           |
|  采样得到 N 个候选边缘点, 经初步筛选后剩 M 点                              | 
|       |                                                                  | 
|       ▼                                                                  | 
|  ┌───────────────────────────────────────────────────────────┐           | 
|  │ 第一次拟合 (使用全部 M 个边缘点)                           │           | 
|  │   方法 = 用户选择的拟合方法 (最小二乘/Huber/RANSAC)       │           | 
|  └───────────────────────────┬───────────────────────────────┘           | 
|                              ▼                                           | 
|  ┌───────────────────────────────────────────────────────────┐           | 
|  │ 计算每个边缘点到拟合圆的残差距离 dᵢ                       │           | 
|  │                                                           │           | 
|  │   dᵢ = |√((xᵢ-Cx)² + (yᵢ-Cy)²) - R|                   │           | 
|  │       (即点到圆周的垂直距离)                               │           | 
|  └───────────────────────────┬───────────────────────────────┘           | 
|                              ▼                                           | 
|  ┌───────────────────────────────────────────────────────────┐           | 
|  │ 分类:                                                      │           | 
|  │   Inlier (内点):  dᵢ <= maxOutlierDistance                │           | 
|  │   Outlier (离群点): dᵢ >  maxOutlierDistance               │           | 
|  │                                                           │           | 
|  │   示例 (maxOutlierDist = 3.0 px):                         │           | 
|  │     点A: d=0.2 px → Inlier ✓                              │           | 
|  │     点B: d=1.8 px → Inlier ✓                              │           | 
|  │     点C: d=3.1 px → Outlier ✗                              │           | 
|  │     点D: d=8.5 px → Outlier ✗ (明显的飞点)                │           | 
|  └───────────────────────────┬───────────────────────────────┘           | 
|                              ▼                                           | 
|  ┌───────────────────────────────────────────────────────────┐           | 
|  │ 检查内点比例:                                              │           | 
|  │   ratio = inlierCount / M * 100%                           │           | 
|  │                                                           │           | 
|  │   ratio >= minEdgeRatio ?                                  │           | 
|  │     ↓ Yes: 用内点重新拟合 → 输出最终结果                  │           | 
|  │     ↓ No:  输出 NG ("边缘点不足, 有效占比 XX%" )          │           | 
|  └───────────────────────────────────────────────────────────┘           | 
|                                                                           |
+---------------------------------------------------------------------------+
```

### 4.4 输出验证详解

#### 4.4.1 参数详情

| # | 参数 | UI 标签 | 控件 | 默认值 | 取值范围 | 步长 | 算法属性名 | 说明 |
|---|------|---------|------|--------|----------|------|-----------|------|
| 1 | radiusTolerance | 半径偏差容差(px) | ConfigSetting(double) | **5.0** | 0.1 ~ 100.0 | 0.1 | RadiusTolerance | 拟合半径与原始ROI半径的最大允许偏差。超出则 NG |
| 2 | maxRmse | 最大允许残差RMSE(px) | ConfigSetting(double) | **2.0** | 0.1 ~ 20.0 | 0.1 | MaxAllowedRmse | 拟合残差的均方根上限。超出则表示拟合质量不佳 |

#### 4.4.2 验证判断逻辑

```
+- 输出验证流程 ---------------------------------------------------------------+
|                                                                           |
|  拟合完成, 得到: (fitCx, fitCy, fitR, rmse, edgeCount)                   | 
|       |                                                                  | 
|       ▼                                                                  | 
|  ┌───────────────────────────────────────────────────────────┐           | 
|  │ 验证1: 半径偏差检查                                        │           | 
|  │   radiusDeviation = |fitR - originalRoiR|                   │           | 
|  │                                                           │           | 
|  │   radiusDeviation <= radiusTolerance ?                     │           | 
|  │     ↓ Yes → 继续                                           │           | 
|  │     ↓ No  → NG ("半径偏差 X.X px 超过容差 Y.Y px")        │           | 
|  └───────────────────────────┬───────────────────────────────┘           | 
|                              ▼ (通过验证1)                              | 
|  ┌───────────────────────────────────────────────────────────┐           | 
|  │ 验证2: 拟合残差检查                                        │           | 
|  │   rmse = √(Σdᵢ² / M)  (所有内点到拟合圆的距离均方根)      │           | 
|  │                                                           │           | 
|  │   rmse <= maxRmse ?                                       │           | 
|  │     ↓ Yes → 最终 OK, 输出拟合结果                          │           | 
|  │     ↓ No  → NG ("拟合残差 X.XX px 超过容差 Y.Y px")      │           | 
|  └───────────────────────────────────────────────────────────┘           | 
|                                                                           |
|  RMSE 的直观理解:                                                        | 
|  ┌───────────────────────────────────────────────────────────┐           | 
|  │  RMSE = 0.2 px → 所有边缘点几乎完美地落在拟合圆上 (极佳)  │           | 
|  │  RMSE = 0.5 px → 平均偏离半个像素 (优秀, 亚像素级别)    │           | 
|  │  RMSE = 1.0 px → 平均偏离1个像素 (良好)                  │           | 
|  │  RMSE = 2.0 px → 平均偏离2个像素 (可接受边界)            │           | 
|  │  RMSE > 3.0 px → 拟合质量较差, 需要排查原因              │           | 
|  └───────────────────────────────────────────────────────────┘           | 
|                                                                           |
+---------------------------------------------------------------------------+
```

## 六、ArcCaliper vs HoughCircles 核心差异

> 本章节作为**独立突出章节**, 详细对比 ArcCaliper (v3.0) 与 HoughCircles (v2.0) 的全面差异,
> 帮助开发者理解本次重构的本质变化。

### 6.1 维度对比总表

| 维度 | HoughCircles (v2.0 已废弃) | ArcCaliper (v3.0 当前) | 差异说明 |
|------|------------------------------|--------------------------|----------|
| **工具定位** | 全局盲搜式圆发现工具 | 引导式精密圆测量工具 | 从"找所有圆"变为"精确测量一个圆" |
| **输入要求** | 灰度图像 | 灰度图像 + **圆形ROI**(圆心+半径) | ArcCaliper需要用户提供初始引导 |
| **输出数量** | 0~N 个圆 (多目标) | **1个**拟合圆 (单目标) | ArcCaliper每次只输出一个精确圆 |
| **核心算法** | 2D 梯度空间累加投票 | 1D 法线方向投影边缘检测 | 完全不同的算法路径 |
| **边缘极性** | **不支持** | **支持** (亮→暗/暗→亮/任意) | ArcCaliper 可按极性筛选, 抗干扰更强 |
| **亚像素精度** | float (~0.5px) | **double (~0.01~0.1px)** | ArcCaliper 通过插值达到更高精度 |
| **典型精度** | 像素级 (±0.5px) | **亚像素级 (±0.01~0.1px)** | ArcCaliper 适合精密测量场景 |
| **抗噪机制** | 中值滤波预处理 + param2 阈值 | 边缘极性筛选 + 阈值 + **Huber/RANSAC 拟合** | ArcCaliper 抗噪手段更多层次 |
| **拟合输出** | 无 (直接返回累加器结果) | **圆心/半径/RMSE/边缘强度/残差分布** | ArcCaliper 提供丰富的质量指标 |
| **适用场景** | 发现/计数/粗定位 | **测量/检测/精密定位** | 互补而非替代关系 |
| **行业对标** | OpenCV HoughCircles | **Halcon measure_arc / VisionPro Caliper** | ArcCaliper 对齐行业标准 |
| **速度** | ~2~15ms | ~1~5ms (取决于采样点数) | ArcCaliper 因无需构建累加器反而更快 |
| **参数复杂度** | 6个Hough参数 + 3个Blob参数 + 预处理 | 3个采样 + 1个投影 + 极性 + 阈值 + 插值 + 拟合 | 参数更专业更有针对性 |
| **调试友好度** | 中等 (只能看到检出的圆) | **高** (可看采样射线/边缘点/拟合过程) | ArcCaliper 可视化信息丰富 |

### 6.2 算法原理对比图

```
+- 算法路径对比 ---------------------------------------------------------------+
|                                                                           |
|  HoughCircles (v2.0)                    ArcCaliper (v3.0)                   | 
|                                                                           | 
|  灰度图像                                 灰度图像 + 圆形ROI               | 
|      |                                       |                              | 
|      ▼                                       ▼                              | 
|  ┌─────────┐                            ┌─────────────┐                    | 
|  │ 可选:    │                            │ 生成 N 个    │                    | 
|  │ 中值滤波  │                            │ 采样点       │                    | 
|  └────┬────┘                            └──────┬──────┘                    | 
|       ▼                                         ▼                          | 
|  ┌─────────┐                            ┌─────────────┐                    | 
|  │ Canny    │                            │ 每个采样点:  │                    | 
|  │ 边缘检测  │                            │  1D法线投影  │                    | 
|  └────┬────┘                            │  梯度检测    │                    | 
|       ▼                                 │  极性筛选    │                    | 
|  ┌─────────┐                            │  亚像素插值  │                    | 
|  │ 全图2D   │                            └──────┬──────┘                    | 
|  │ 梯度计算  │                                   ▼                          | 
|  └────┬────┘                            ┌─────────────┐                    | 
|       ▼                                 │ M个边缘点    │                    | 
|  ┌─────────┐                            │ (M<=N)      │                    | 
|  │ 3D参数空间│                            └──────┬──────┘                    | 
|  │ 累加投票  │                                   ▼                          | 
|  │ (cx,cy,r)│                            ┌─────────────┐                    | 
|  └────┬────┘                            │ 圆拟合       │                    | 
|       │                                 │ (LS/Huber/  │                    | 
|       ▼                                 │  RANSAC)     │                    | 
|  ┌─────────┐                            └──────┬──────┘                    | 
|  │ 峰值查找  │                                   ▼                          | 
|  │ (>=thresh)│                            ┌─────────────┐                    | 
|  └────┬────┘                            │ 输出:        │                    | 
|       │                                 │ fitCx,fitCy, │                    | 
|       ▼                                 │ fitR,RMSE,  │                    | 
|  ┌─────────┐                            │ 边缘统计     │                    | 
|  │ 输出0~N个│                            └─────────────┘                    | 
|  │ 圆(c,r)   │                                                          | 
|  └─────────┘                                                          | 
|                                                                           | 
|  关键差异:                                                               | 
|  • Hough: 2D全局操作 → 计算量大, 无法利用先验知识                         | 
|  • Caliper: 1D局部操作 → 计算量小, 充分利用ROI引导信息                   | 
|  • Hough: 无极性概念 → 亮边缘和暗边缘都会响应                             | 
|  • Caliper: 有极性筛选 → 可以只关注特定方向的边缘                        | 
|  • Hough: 无拟合过程 → 直接返回累加器峰值                                 | 
|  • Caliper: 显式拟合 → 可选多种拟合策略, 输出质量指标                    | 
|                                                                           |
+---------------------------------------------------------------------------+
```

│       │       ├── 1. 检查边缘极性是否设反了                           │
│       │       │      (亮↔暗互换试试)                                │
│       │       │                                                     │
│       │       ├── 2. 降低 edgeThreshold (30 → 10~20)                │
│       │       │                                                     │
│       │       ├── 3. 增大 projectionWidth (10 → 15~25)              │
│       │       │      (让投影窗口覆盖完整的边缘过渡带)                  │
│       │       │                                                     │
│       │       ├── 4. 检查ROI是否准确对准了圆边缘                      │
│       │       │      (ROI太大→采样点在平坦区域, ROI太小→漏掉边缘)     │
│       │       │                                                     │
│       │       └── 5. 开启高斯平滑 (sigma=0.8~1.5) 抑制噪声          │
│       │                                                             │
│       ├──► 「有明显的离群点/飞点, 拉偏了拟合圆」                      │
│       │       │                                                     │
│       │       ├── 1. 切换拟合方法: 最小二乘 → Huber → RANSAC        │
│       │       │      (根据离群点比例选择)                             │
│       │       │                                                     │
│       │       ├── 2. 确保离群剔除已开启                               │
│       │       │      增大 maxOutlierDistance (3.0 → 5.0~8.0)        │
│       │       │                                                     │
│       │       └── 3. 检查排除区(Mask)是否需要排除干扰区域             │
│       │                                                             │
│       ├──► 「RMSE过大 (圆度不好, > 2px)」                             │
│       │       │                                                     │
│       │       ├── 1. 增加采样点数 (72 → 144~200)                     │
│       │       │      (更密集的采样提升拟合稳定性)                     │
│       │       │                                                     │
│       │       ├── 2. 改用 Gaussian 插值 (精度最高)                   │
│       │       │                                                     │
│       │       ├── 3. 检查目标本身是否真的接近圆形                     │
│       │       │      (椭圆/变形圆必然RMSE大)                         │
│       │       │                                                     │
│       │       └── 4. 检查是否有局部遮挡/缺陷影响了部分边缘           │
│       │           → 用 RANSAC + 更宽松的离群距离                     │
│       │                                                             │
│       ├──► 「拟合半径与预期偏差很大」                                  │
│       │       │                                                     │
│       │       ├── 1. 检查ROI圆形是否与目标边缘基本对齐                │
│       │       │      (ArcCaliper在ROI附近采样, ROI偏差大→系统偏差)    │
│       │       │                                                     │
│       │       ├── 2. 检查是否有系统性的边缘偏移                      │
│       │       │      (如镜头畸变未校正)                               │
│       │       │                                                     │
│       │       └── 3. 如果是有意为之(测量真实偏差), 调整radiusTolerance│
│       │                                                             │
│       └──► 「只想测量部分圆弧, 不是完整圆」                            │
│               │                                                     │
│               └── 设置起始角度和结束角度限制采样范围:                  │
│                   上半圆:  start=-90,  end=90                       │
|                   右半圆:  start=0,    end=180                      │
|                   第一象限: start=0,    end=90                       │
|                   自定义:   根据圆弧实际位置设定                      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 9.3 圆形ROI绘制操作指南

```
+=============================================================================+
|                           圆形ROI绘制操作指南                                  |
+=============================================================================+
|                                                                              |
|  【为什么推荐圆形ROI?】                                                       |
|  +----------------------------------------------------------------------+   |
|  |  ArcCaliper 是一种"引导式"测量方法, 它需要一个近似的圆形作为起始引导    |   |
|  |  圆形ROI直接提供了圆心(cx,cy)和半径(r)两个关键参数                      |   |
|  |  其他形状(矩形/多边形)虽然也可以用, 但需要额外的转换步骤                 |   |
|  +----------------------------------------------------------------------+   |
|                                                                              |
|  【绘制步骤】                                                                |
|  +----------------------------------------------------------------------+   |
|  |  (1) 在 Tab1 中确保已选择输入图像源（否则无法绘制）                    |   |
|  |  (2) 在「搜索区域」组中选择 ★圆形(Circle) 工具                        |   |
|  |  (3) 在图像预览区按下鼠标左键 → 此点即为圆心                         |   |
|  |  (4) 按住左键拖拽 → 圆形随鼠标扩大, 释放时确定半径                   |   |
|  |  (5) 拖拽圆心手柄(中心十字) → 微调圆心位置                           |   |
|  |  (6) 拖拽圆周手柄(圆周上的方块) → 微调半径大小                      |   |
|  +----------------------------------------------------------------------+   |
|                                                                              |
|  【绘制技巧】                                                                |
|  +----------------------------------------------------------------------+   |
|  |  ★ ROI应该稍微大于目标的实际圆边缘                                      |   |
|  |    (建议半径比实际圆大 1~3 像素, 让采样点落在边缘过渡带上)          |   |
|  |                                                                      |   |
|  |  ★ 利用图像缩放功能放大后再绘制, 提高定位精度                        |   |
|  |                                                                      |   |
|  |  ★ 如果一次绘制不到位, 可以直接拖拽手柄微调, 无需重画              |   |
|  +----------------------------------------------------------------------+   |
|                                                                              |
|  【与非圆形ROI的兼容性】                                                     |
|  +----------------------------------------------------------------------+   |
|  |  如果你使用了矩形/多边形/旋转矩形ROI:                                  |   |
|  |                                                                      |   |
|  |  系统会自动转换为等效圆形:                                           |   |
|  |    矩形/旋转矩形 → 内接圆 (圆心=矩形中心, 半径=min(W,H)/2)        |   |
|  |    多边形 → 最小外接圆 (MinEnclosingCircle)                           |   |
|  |                                                                      |   |
|  |  会显示警告: "非圆形ROI已自动转换为近似圆, 可能影响测量精度"         |   |
|  |                                                                      |   |
|  |  建议: 除非有特殊原因, 否则始终使用 ★圆形 ROI                       |   |
|  +----------------------------------------------------------------------+   |
|                                                                              |
+=============================================================================+
```

## 十、设计约束与约定

### 10.1 必须遵守的项目规范

| 规范类别 | 要求 | 本工具落实方式 |
|----------|------|---------------|
| MVVM架构 | UI层(XAML)不包含业务逻辑，所有逻辑在ViewModel | View仅负责绑定，ViewModel(CircleCaliperToolDebugViewModel)持有参数和命令 |
| 属性通知 | 继承 ObservableObject/ViewModelBase，使用 SetProperty() | 所有可绑定属性通过 SetProperty() 设置，支持 displayName |
| 日志系统 | ViewModel用 LogInfo/LogError/LogWarning，Service用 _logger.Log() | 调试面板的关键操作(运行/参数变更/错误)均有日志记录 |
| 命名规范 | PascalCase(类/方法/属性)，camelCase(变量)，_camelCase(私有字段) | 如 CircleCaliperParameters / _sampleCount / _edgePolarity |
| 序列化 | System.Text.Json，PascalCase，[JsonPolymorphic]+[JsonDerivedType] | CircleCaliperParameters 使用 JsonDerivedType 标记 |
| JSON配置 | WriteIndented=True, PropertyNamingPolicy=null(PascalCase), Encoder=UnsafeRelaxedJsonEscaping | Recipe 存储遵循统一 JSON 规范 |
| KISS原则 | 选择最简单合理的实现方式 | 复用现有SDK控件，不造轮子 |
| YAGNI原则 | 只实现当前明确需要的功能 | 不预留未来扩展接口，不需要的功能不做 |
| 参数系统 | Dictionary<string, object> 存储 + ParametersTypeName 强类型恢复 | CircleCaliperParameters 作为强类型参数类 |
| ConfigSetting | 所有数值参数支持常量/绑定双模式 | Tab2/Tab3 的参数全部使用 ConfigSetting |
| 代码纯净 | 原型期不考虑向后兼容、不用Obsolete、不注释旧代码 | 直接删除废弃代码 |

### 10.2 不需要的功能

| 功能项 | 决策 | 原因 |
|--------|------|------|
| 键盘快捷键 | 不实现 | 项目约定不支持 |
| 向后兼容处理 | 不考虑 | 原型期代码，Git提供版本历史 |
| Obsolete标记 | 不使用 | Git已有版本历史，保持代码纯净 |
| 条件编译 #if DEBUG | 不使用 | 保持代码纯净 |
| 多目标检测模式 | **不需要** | ArcCaliper每次只测量一个圆，多目标应多次调用或用其他工具 |
| HoughCircles 备选模式 | **不需要** | v3.0已确定只用ArcCaliper，不走双模式 |
| 模板创建对话框 | **不需要** | 圆卡尺无需模板训练，不像轮廓匹配需要手动提取模板轮廓 |
| 每实例参数覆盖 | **不需要** | 单目标测量不存在"每模型不同参数"概念 |
| 数据分析控件 | 暂不实现 | Phase 1/2 不需要，后续有需求再加 |
| ROI截图预览区 | **不需要** | 圆卡尺没有模板概念，不需要独立的ROI裁剪预览 |
| 自动ROI拟合(ellipse fitting) | **暂不实现** | v1.0要求用户手动给出圆形ROI，自动拟合可作为后续增强 |

### 10.3 与其他查找工具的差异对照

| 维度 | CircleCaliperTool (v3.0) | LineFinderTool | ShapeMatchTool | CircleFinder (v2.0 已废) |
|------|----------------------------|----------------|-----------------|------------------------|

### D. 角度系统说明

ArcCaliper 中的角度定义遵循以下数学约定:

```
┌─ 角度坐标系 ────────────────────────────────────────────────────────────┐
│                                                                             │
│                       90° (-Y方向, 图像上方)                                │
│                         │                                                 │
│                         │                                                 │
│                         │                                                 │
│  180° (-X方向, ←) ───────┼─────────────→ 0° (+X方向, →, 图像右方)       │
│  (图像左方)              │                                             │
│                         │                                                 │
│                         │                                                 │
│                    270°/-90° (+Y方向, 图像下方)                           │
│                                                                             │
│  重要性质:                                                                   │
│  • 角度单位: 度 (degree), 内部计算时转换为弧度 (radian)                   │
│  • 正方向: 逆时针 (标准数学约定, 与OpenCV/Halcon一致)                      │
│  • 0° 方向: +X轴方向 (图像水平向右)                                       │
│  • 90° 方向: -Y轴方向 (图像垂直向上, 注意图像坐标系Y轴向下为正)           │
│  • 完整圆周: -180° ~ 180° 或 0° ~ 360° 均可                              │
│                                                                             │
│  常用预设:                                                                   │
│  • 完整圆:   start=-180, end=180   (或 start=0, end=360)                │
│  • 上半圆:   start=-90,  end=90                                        │
│  • 下半圆:   start=90,   end=270 (或 -90~90 反向)                     │
│  • 左半圆:   start=-180, end=0                                         │
│  • 右半圆:   start=0,    end=180                                       │
│  • 第一象限: start=0,    end=90                                        │
│  • 第二象限: start=90,   end=180                                       │
│  • 第三象限: start=180,  end=270                                       │
│  • 第四象限: start=-90,  end=0  (或 270~360)                           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
