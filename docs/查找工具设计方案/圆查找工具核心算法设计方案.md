# 圆查找工具（CircleFinder）核心算法设计方案

> 版本: v1.0 | 日期: 2026-05-07 | 状态: 设计完成

---

## 1. 方案选型与决策

### 1.1 候选方案对比

| 方案 | API | 圆形检测 | 半径范围 | 多实例 | 亚像素 | 抗噪性 |
|------|-----|----------|----------|--------|--------|--------|
| **A: HoughCircles** | `Cv2.HoughCircles()` | ✅ | ✅ | ✅ | ⚡(1) | 中 |
| **B: Blob分析+圆度筛选** | Connection + Circularity | ✅ | ✅ | ✅ | ❌ | **高** |
| **C: 轮廓拟合圆** | FindContours + MinEnclosingCircle | ✅ | ❌ | ✅ | ✅ | 低 |
| **D: 基于梯度的边缘圆查找** | 自建边缘投票 (自研) | ✅ | ✅ | ✅ | ✅ | **高** |

> ⚡(1): HoughCircles 返回的圆心/半径已是亚像素精度（float类型）

### 1.2 最终选择：方案 A + B 混合策略

**核心方案：HoughCircles (方案A)**
- OpenCV 最成熟的圆检测方法
- 直接支持半径范围过滤和多实例检测
- 输出即为浮点精度（亚像素级别）
- 性能优秀，适合实时应用

**辅助方案：Blob圆度筛选 (方案B)**
- 当 HoughCircles 检测效果不理想时（低对比度/噪声大）
- 先做阈值分割（借用 CvOp.Threshold）
- 再连接域分析 + 圆度过滤
- 最后用 MinEnclosingCircle 拟合精确圆

**选择理由：**
1. **HoughCircles 优先**：90% 场景适用，性能和精度平衡
2. **Blob 方案兜底**：HoughCircles 失效时自动回退，保证检测率
3. **复用已有 CvOp**：Threshold、Connection、Circularity 等算子已有实现
4. **对齐 Halcon 语义**：`HoughCircles` ≈ Halcon `hough_circles`，Blob方案 ≈ Halcon `select_shape` + `fit_circle_contour_xld`

│  │                                                                 │ │

│  │   - minDist: 圆心之间的最小间距 (NMS 作用)                      │ │
│  │   - param1: Canny 边缘检测高阈值 (50~200)                       │ │
│  │   - param2: 累加器阈值，越小检测到越多假圆 (10~100)            │ │

## 3. 核心：HoughCircles 评分与参数分析

### 3.1 参数敏感性分析

| 参数 | 影响 | 推荐范围 | 调参策略 |
|------|------|----------|----------|
| dp (累加器分辨率) | dp=1: 原始分辨率, dp=2: 一半分辨率 | 1.0~2.0 | 大图用 1.5~2.0 提升性能，小图用 1.0 |
| minDist (最小间距) | 控制重叠圆合并 | 10~50px | 设为预期圆直径的 1/2 |
| param1 (Canny高阈值) | 边缘检测灵敏度 | 50~200 | 高对比度用 150~200，低对比度用 50~100 |
| param2 (累加器阈值) | 检测灵敏度（最关键） | 10~100 | 越小检测越多(含假圆)，越大检测越少(漏检) |
| minRadius | 最小半径 | 0~max | 设为预期圆的最小尺寸 |
| maxRadius | 最大半径 | min~Width/2 | 设为预期圆的最大尺寸 |

### 3.2 参数自适应策略

```
if (dp == 0):    dp = min(2.0, max(1.0, 图像宽 / 1000))
if (param1 == 0): param1 = 100  (默认值)
if (param2 == 0): param2 = 30   (默认值)
if (minDist == 0): minDist = max(10, (minRadius + maxRadius) / 4)
```

### 3.4 C# 实现关键代码

```csharp
public static void HoughCircles(CvImage grayImage, CvRegion? region,
    out CircleInfo[] circles,
    double dp, double minDist,
    double param1, double param2,
    int minRadius, int maxRadius)
{
    circles = Array.Empty<CircleInfo>();
    if (grayImage.Empty) return;

    var mat = grayImage.Image;

    // 应用中值滤波降噪
    using var processed = new Mat();
    if (region != null && !region.IsEmpty)
    {
        var masked = new Mat();
        mat.CopyTo(masked, region.Mask);
        Cv2.MedianBlur(masked, processed, 5);
    }
    else
    {
        Cv2.MedianBlur(mat, processed, 5);
    }

    // HoughCircles 检测
    var rawCircles = Cv2.HoughCircles(
        processed, HoughMethods.Gradient,
        dp, minDist, param1, param2,
        minRadius, maxRadius);

    if (rawCircles == null || rawCircles.Length == 0) return;

    int n = rawCircles[0].Length;
    circles = new CircleInfo[n];
    for (int i = 0; i < n; i++)
    {
        var c = rawCircles[0][i];
        circles[i] = new CircleInfo
        {
            CenterX = c.X,
            CenterY = c.Y,
            Radius = c.Z,
            Label = i + 1
        };
    }

    // ROI 边界过滤
    if (region != null && !region.IsEmpty)
    {
        circles = circles.Where(c =>
            region.Mask!.At<byte>((int)c.CenterY, (int)c.CenterX) > 0
        ).ToArray();
    }
}
```

## 4. 数据结构设计

### 4.1 CircleInfo（检测结果项）

```csharp
/// <summary>
/// 单个圆检测结果 — 对齐 Halcon hough_circles 输出行
/// </summary>
public class CircleInfo
{
    /// <summary>圆心 X（浮点亚像素精度）</summary>
    public double CenterX { get; set; }

    /// <summary>圆心 Y（浮点亚像素精度）</summary>
    public double CenterY { get; set; }

    /// <summary>半径（浮点亚像素精度）</summary>
    public double Radius { get; set; }

    /// <summary>匹配得分 (0~1, 仅 Blob 方案有效)</summary>
    public double Score { get; set; } = 1.0;

    /// <summary>是否通过判断</summary>
    public bool JudgmentPassed { get; set; } = true;

    /// <summary>标签序号</summary>
    public int Label { get; set; }

    /// <summary>包围盒区域</summary>
    public Rect BoundingBox =>
        new Rect((int)(CenterX - Radius), (int)(CenterY - Radius),
                 (int)(2 * Radius), (int)(2 * Radius));
}
```

## 5. 检测模式对比

| 维度 | Hough 模式 (默认) | Blob 模式 (备用) |
|------|-------------------|------------------|
| **原理** | 梯度累加器投票 | 连通域 + 圆度筛选 |
| **适用场景** | 中高对比度、边缘清晰 | 低对比度、噪声大 |
| **性能** | ~2-10ms (1920×1080) | ~5-20ms |
| **亚像素** | ✅ 原生 float | ❌ MinEnclosingCircle 后也可达 |
| **参数数量** | 6个参数 | 3个参数 |
| **圆度过滤** | 间接(Canny) | 直接(圆度公式) |
| **重叠圆处理** | minDist控制 | NMS合并 |

## 10. 技术风险与缓解措施

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| 高噪环境下 HoughCircles 误检多 | 高 | 中 | 中值滤波预降噪 + param2 自适应 + Blob 回退方案 |
| 小半径圆检测困难(半径<5px) | 中 | 低 | 建议使用 Blob 方案替代 |
| 椭圆被误检为圆 | 低 | 中 | 圆度过滤可配置性 + 用户可调整 param2 严格度 |
| 重叠圆合并导致漏检 | 中 | 低 | NMS overlapThreshold 可配置 |
| 大图性能问题(4096+) | 中 | 中 | dp 自适应(大图用 2.0 减半分辨率) |
