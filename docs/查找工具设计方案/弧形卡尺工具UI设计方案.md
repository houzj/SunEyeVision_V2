### 1.1 调试控制面板结构

**Tab 功能定位：**

| Tab | 名称 | 核心职责 | 与 LineCaliper 差异 |

### 1.2 ArcCaliper vs CircleCaliper 关系说明

```
ArcCaliperTool (弧形卡尺):                CircleCaliperTool (圆环卡尺):
                                    
    ╭────╮                                 ╭──────────╮
   ╱  ↗ ↗ ╲                                │  ↗↗↗↗↗   │
  ╱   ↗  ↗  ╲     ← 法线采样方向           │  ↗↗↗↗↗   │
  ╰──╯      ╰                              │  ↗↗↗↗↗   │
  部分圆弧 (可调起止角)                     ╰──────────╯
                                           完整 360° 圆 (无起止角)
```

| 维度 | ArcCaliper | CircleCaliper |
|------|-----------|---------------|
| 角度范围 | 可调起始角~结束角 (如30°~150°) | 固定 360° |
| ROI 拖拽 | 圆心/半径/起止角 4个手柄 | 圆心/半径 2个手柄 |
| Tab2 参数 | 多起止角 + 角度步长区块 | 无起止角参数 |
| 用户场景 | "我要测这段圆弧" | "我要测这个圆孔" |

**ArcCaliper 是 CircleCaliper 的超集**——前者多了角度范围控制，后者的参数更简洁。

### 2.2 ArcCaliper ROI 详细说明

ArcCaliper ROI 定义了一个**可调角度范围的弧形测量区域**：

```
+-- ArcCaliper ROI 结构详解 ------------------------------------------+

                 采样射线 (沿法线方向均匀分布)
                      ↑   ↑   ↑   ↑
                 ↗      ↗   ↗   ↗      ↗
              ╱           SampleCount=12      ╲
             ╱                                  ╲
            │    ● 圆心                          │
             ╲                                  ╱
              ╲                                ╱
                 ↘    半径 Radius            ↗
                      ↓   ↓   ↓   ↓

   可交互操作:
    |- 拖拽圆心 --> 移动整个弧形区域
    |- 拖拽圆弧边缘 --> 调整半径 (Radius)
    |- 拖拽起始角度手柄 --> 调整起始角 (StartAngle)
    |- 拖拽结束角度手柄 --> 调整结束角 (EndAngle)
    |- 双击圆心 --> 打开精确数值输入对话框

   内部几何属性:
    |- Center: 圆心坐标 (cx, cy)
    |- Radius: 圆弧半径 (R, 单位:像素)
    |- StartAngle: 起始角度 (度, 0°=水平向右)
    |- EndAngle: 结束角度 (度)
    |- SampleCount: 采样射线数量 (默认12, 均匀分布在角度范围内)

+----------------------------------------------------------------------+
```

### 2.3 与 CircleCaliper ROI 的交互差异

| 交互特征 | ArcCaliper (弧形) | CircleCaliper (圆环) |
|---------|-------------------|---------------------|
| 拖拽手柄数量 | 4个 (圆心+半径+起止角x2) | 2个 (圆心+半径) |
| 起止角拖拽 | ✅ 有 (角度范围可调) | ❌ 无 (固定360°) |
| 采样射线可视化 | 在弧段角度范围内均匀分布 | 在整个圆周上均匀分布 |
| 角度补正 | 通过拖拽起止角调节 | 无此需要 |

### 3.2 弧形卡尺工作原理

```
+-- 弧形卡尺(ArcCaliper)工作原理 ---------------------------------------+

  Step 1: 定义测量区域
    根据 ArcCaliper ROI 确定: 圆心(Cx, Cy), 半径(R), 起始角(Sa), 结束角(Ea)

  Step 2: 在角度范围内均匀生成 N 个采样射线 (N = SampleCount)
    θ_i = StartAngle + (EndAngle - StartAngle) * i / (N-1)
    For each θ_i:
       射线方向 = 从圆心指向圆周的径向方向 (沿法线)

  Step 3: 对每个采样射线做1D剖面采样
    沿径向方向, 以内半径到外半径的范围取灰度剖面
    profile_i[x] = gray(C + (R ± x/2) * unit(θ_i))

  Step 4: 对1D剖面做平滑处理 + 梯度计算

  Step 5: 寻找边缘候选点 (梯度极值)

  Step 6: 极性过滤 + 幅度阈值过滤

  Step 7: 亚像素精确定位 (抛物线插值)

  Step 8: 边缘点集合 --> 圆弧拟合
    所有有效边缘点参与圆弧拟合, 输出圆心/半径/起止角/RMSE

  输出: 边缘点集合 + 拟合圆弧
+----------------------------------------------------------------------+
```

### 3.3 参数详解

#### 测量配置参数

| 参数 | 控件类型 | 默认值 | 范围 | 算法属性 | 说明 |

### 4.2 三种拟合方法对比

| 方法 | 精度 | 抗离群点 | 速度 | 适用场景 |
|------|------|---------|------|---------|
| **最小二乘(LS)** | 优秀 | ❌ 无 | 最快 | 干净边缘,已知无异常点 |
| **Huber稳健** | 良好 | ✅ 中等 | 中等 | 少数离群点(<10%) |
| **RANSAC** | 良好 | ✅ 强(50%) | 最慢 | 噪声大,离群点多 |

### 4.3 输出验证

| 验证项 | 参数名 | 说明 |
|--------|--------|------|
| RMSE 容差 | RMSE_Tolerance | 拟合圆弧的均方根误差上限 |
| 半径偏差 | Radius_Deviation | 实测半径与标准半径的偏差范围 |
| 角度覆盖 | Angle_Coverage | 实际检测到的角度范围占比 |

```
│   共同: LS/Huber/RANSAC 拟合方法 / 排序 / 过滤                       │
│   差异:                                                             │
│    ├── LineCaliper: 共线性判定 → 直线拟合                             │
│    ├── ArcCaliper:  共圆心判定 → 圆弧拟合 (圆心+半径+起止角)         │
│    └── CircleCaliper: 径向一致性 → 圆拟合 (圆心+半径)                │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│ Tab4 结果显示 -- 结构一致, 图形元素适配几何类型                         │
└─────────────────────────────────────────────────────────────────────┘
```

## 七、典型应用场景

### 场景A: 1/3圆弧边缘测量

目标: 测量 120° 弧段上的边缘位置 (如图像中的零件弧形缺口)

| Tab | 参数设置 |
|-----|---------|
| **Tab1** | ArcCaliper ROI 覆盖弧段: 圆心对准预期中心, 半径覆盖弧段, 起止角=30°/150° |
| **Tab2** | 采样点数=12, 投影长度=30, 宽度=5, 极性=LightToDark, 选取=All, 对比度=30, 亚像素=ON |
| **Tab3** | LS拟合, 离群过滤 ON, RMSE<=2.0px, 半径偏差<=5px |
| **Tab4** | 数量判断 ON (3~36条), 置信度判断 ON (RMS<=2.0px) |

### 场景B: 弧形定位

目标: 找圆弧段的精确圆心位置 (用于后续对齐)

| Tab | 参数设置 |
|-----|---------|
| **Tab1** | ArcCaliper ROI 框住弧段, 起止角=0°/120° |
| **Tab2** | 采样点数=18, 投影长度=20, 宽度=3, 极性=Any, 选取=Strongest, 对比度=50, 亚像素=ON, 高斯插值 |
| **Tab3** | Huber拟合, 离群过滤 ON, RMSE<=1.0px, 最大离群=20% |
| **Tab4** | 位置偏差判断 ON, 圆心偏差范围 [+/-0.5]px |

### 场景C: 半圆弧孔径检测

目标: 检测 180° 半圆弧的内径

| Tab | 参数设置 |
|-----|---------|
| **Tab1** | ArcCaliper ROI: 起止角=0°/180°, 半径≈孔径/2 |
| **Tab2** | 采样点数=24, 投影长度=40, 宽度=8, 极性=DarkToLight, 选取=First, 对比度=40 |
| **Tab3** | RANSAC拟合, RMSE<=3.0px, 半径容差 +/-0.5% |
| **Tab4** | 半径范围判断 ON, 范围=[预期值-公差, 预期值+公差] |

### 场景D: 圆弧段同心度检测

目标: 检测内外两个圆弧的同心度偏差

| Tab | 参数设置 |
|-----|---------|
| **Tab1** | 两个 ArcCaliper ROI (内弧 + 外弧) |
| **Tab2** | 采样点数=36(高精度), 极性=Any, 亚像素=ON |
| **Tab3** | LS拟合, 输出内外圆圆心坐标 |
| **Tab4** | 位置偏差判断 ON, 圆心偏差范围 (同心度容差) |

## 九、设计约束

### 9.1 必须遵守的项目规范

同 LineCaliperTool (参考直线卡尺工具UI设计方案.md 第8.1节)。

### 9.2 不需要的功能

| 功能 | 决策 | 原因 |
|------|------|------|
| HoughCircle作为备选 | 不实现 | 使用卡尺1D剖面方式,非全局搜索 |
| 完整360°圆测量 | 由CircleCaliper承担 | 工具职责分离,Arc仅做部分圆弧 |
| 自动圆心估算 | 不实现 | 应由用户在ROI中明确指定,符合引导式语义 |
| 多圆弧段同时测量 | 不实现v1.0 | YAGNI,可用多ROI实现 |
| 圆弧与直线混合测量 | 不实现 | 跨工具组合在工作流中完成 |

### 9.3 三件套参数数量对比

| 参数分组 | LineCaliper | ArcCaliper | CircleCaliper |
|---------|------------|------------|---------------|
| Tab2 测量配置 | 4 (方向+长度+宽度+间隔) | 6 (圆心XY+半径+起止角) | 3 (圆心XY+半径) |
| Tab2 采样配置 | 1 (行数) | 3 (点数+步长+间隔) | 2 (点数+间隔) |
| Tab2 投影/边缘/阈值 | 7 | 7 | 7 |
| Tab2 高级设置 | 2 | 2 | 2 |
| Tab3 拟合筛选 | 7 | 6 | 6 |
| **总计** | **~47** | **~45** | **~42** |
