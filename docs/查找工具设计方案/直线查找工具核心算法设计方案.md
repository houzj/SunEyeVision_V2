# 直线查找工具 (LineFinder) 核心算法设计方案

> 版本: v2.0
> 日期: 2026-05-07
> 状态: 设计完成 (卡尺测量方式)
> 对标: Halcon measure_pos / VisionPro Cognex Caliper / Cognex EdgeFinder

---

## 1. 方案选型

### 1.1 候选方案对比

| 方案 | API/方法 | 直线检测 | 线段检测 | 亚像素 | 边缘极性 | 先验需求 |
|------|---------|----------|---------|--------|---------|---------|
| A: HoughLines | Cv2.HoughLines() | Yes | No(无限长线) | Yes(后处理) | No | 无 |
| B: HoughLinesP | Cv2.HoughLinesP() | Yes | Yes(有端点) | Yes(后处理) | No | 无 |
| C: LSD | Cv2.CreateLineSegmentDetector() | Yes | Yes | Yes | No | 无 |
| D: **Caliper卡尺** | **自研(对标measure_pos)** | **Yes** | **Yes** | **Yes(内建)** | **Yes** | **需要(ROI+方向)** |

### 1.2 最终选择：方案D (Caliper 卡尺)

**核心决策理由:**

1. **工业场景适配性**: 工业视觉中绝大多数直线检测任务属于"引导式测量"(已知大致位置和方向), 而非"全局盲搜"
2. **亚像素精度**: 卡尺方式天然支持亚像素, 作为内建能力而非后处理补丁
3. **边缘极性**: 支持亮->暗/暗->亮过滤, 这是Hough系列完全无法提供的
4. **测量语义**: 输出的是"边缘位置+置信度", 符合计量学语义; 而非"图像中的线段"
5. **行业对齐**: Halcon measure_pos、VisionPro Caliper、Cognex EdgeFinder 均采用此路线

**辅助方案保留:** 当用户确实需要全局盲搜场景时, 未来可考虑增加 HoughLinesP 作为备选模式(v2.0不实现).

## 2. 算法流程

### 2.1 总体Pipeline

```
Phase 0: 预处理 (灰度转换 + ROI裁切 + 位置补正变换)
    |
    v
Phase 1: 采样点生成 (沿Rake方向 + 垂直剖面)
    |
    v
Phase 2: 1D剖面平滑 (高斯/均值滤波)
    |
    v
Phase 3: 梯度计算与边缘候选点提取 (一阶数值微分)
    |
    v
Phase 4: 过滤 (幅度阈值 + 极性过滤 + 对比度检查)
    |
    v
Phase 5: 亚像素精确定位 (抛物线/Gauss/线性插值)
    |
    v
Phase 6: 选取模式应用 (First/Strongest/All/Nth)
    |
    v
Phase 7: 多行聚合 + 共线性判定 (可选, SampleRows>1时)
    |
    v
Phase 8: 直线拟合 (OLS/RANSAC/Theil-Sen)
    |
    v
Phase 9: 后处理筛选 (长度/角度/数量/排序)
    |
    v
输出: CaliperResult[] (边缘点集合 或 拟合直线集合)
```

### 2.2 各Phase详细设计

#### Phase 0: 预处理

**输入:** 原始图像(Mat, 可能是彩色或灰度)
**输出:** ROI区域内灰度图 + 变换后的坐标系

步骤:
1. 若输入为彩色 --> 转灰度 (Cv2.cvtColor BGR2GRAY)
2. 应用位置补正变换 (若启用): 对ROI施加平移+旋转变换矩阵
3. 从 LineCaliper ROI 提取参数: CenterPoint(cx,cy), RakeAngle(theta), MeasureLength(L), SampleWidth(W)
4. 计算局部坐标系:
   - Rake方向单位向量: r_hat = (cos(theta), sin(theta))
   - 法向单位向量: n_hat = (-sin(theta), cos(theta))  [垂直于Rake, 向右旋转90度]
5. 计算StartPoint = CenterPoint - (L/2) * r_hat
6. 计算EndPoint   = CenterPoint + (L/2) * r_hat

#### Phase 1: 采样点生成

**输入:** 灰度图像, StartPoint, EndPoint, RakeAngle, SampleWidth, SampleInterval, SampleRowCount
**输出:** 采样点坐标数组 SamplePoints[row][col]

算法:
```
N_cols = floor(MeasureLength / SampleInterval) + 1
for row in 0..SampleRowCount-1:
    offset_n = (row - (SampleRowCount-1)/2.0) * (SampleWidth / (SampleRowCount+1))
    for col in 0..N_cols-1:
        t = col * SampleInterval  // 沿Rake方向的距离
        base_point = StartPoint + t * r_hat
        SamplePoints[row][col] = base_point + offset_n * n_hat
```

#### Phase 2: 1D剖面平滑

对每个采样点col, 提取垂直方向的1D灰度剖面:
```
for each col c:
    profile_c[row] = image.Sample(SamplePoints[row][c])  // 双线性插值取灰度
    smoothed_c = GaussianSmooth(profile_c, kernel_size=SmoothKernelSize)
```

#### Phase 3: 梯度计算

对每个平滑后的一维剖面求一阶导数:
```
gradient_c[i] = (smoothed_c[i+1] - smoothed_c[i-1]) / 2.0   // 中心差分
// 边界用前向/后向差分
gradient_c[0]     = smoothed_c[1] - smoothed_c[0]
gradient_c[N-1]   = smoothed_c[N-1] - smoothed_c[N-2]
```

**边缘候选点 = gradient的局部极值点** (满足 gradient[i-1]*gradient[i+1] < 0 且 |gradient[i]| > 0)

#### Phase 4: 过滤

对每个候选点 edge at position i:

1. **幅度检查:** |gradient[i]| >= MinEdgeAmplitude ?
2. **极性检查:**
   - Any:         通过
   - LightToDark: gradient[i] < 0 ? (正->负跳变=从亮到暗)
   - DarkToLight: gradient[i] > 0 ? (负->正跳变=从暗到亮)
3. **对比度检查:** |smoothed[i - delta_left] - smoothed[i + delta_right]| >= MinContrast ?
   其中 delta 取梯度峰值的半高宽

#### Phase 5: 亚像素精确定位

**方法A: 二次抛物线插值 (默认 Parabolic)**

在梯度峰值 i 处取3点拟合抛物线 f(x) = ax^2 + bx + c:
```
y0 = |gradient[i-1]|, y1 = |gradient[i]|, y2 = |gradient[i+1]|
// 抛物线顶点的偏移量:
delta = (y0 - y2) / (2 * (y0 - 2*y1 + y2))
subpixel_position = i + delta  // delta in [-0.5, 0.5]
edge_amplitude = y1 - 0.25 * (y0 - y2) * delta
```

**方法B: 高斯插值 (Gaussian)**

用高斯函数 G(x; mu,sigma) 拟合梯度曲线:
```
// 在峰值附近取 2*k+1 个点(k>=2)
// 用非线性优化求解 mu 和 sigma
// subpixel_position = StartPosition + mu
// 精度最高但最慢
```

**方法C: 线性插值 (Linear)**
```
delta = y1 / (y0 + y2)  // 简单线性插值
subpixel_position = i + sign(gradient[i]) * delta * 0.5
```

输出: 亚像素级边缘位置 (float, 相对于StartPoint的距离)

#### Phase 6: 选取模式

根据 SelectionMode 决定最终输出:

- **First:** 返回 position 最小的那个边缘点
- **Strongest:** 返回 |amplitude| 最大的那个边缘点
- **All:** 返回所有通过过滤的边缘点
- **Nth:** 返回按position排序后的第 NthIndex 个 (1-based)

#### Phase 7: 多行聚合 (SampleRowCount > 1 时)

当有多行采样时, 将每行的结果按 "第几个边缘" 分组:

```
Group_k = { edge_from_row0_kth, edge_from_row1_kth, ..., edge_from_rowM_kth }
```

共线性判定条件 (全部满足才保留):
1. 初步OLS拟合 --> 计算 residuals[]
2. max(|residuals|) <= MaxCollinearDeviation
3. abs(fit_angle - expected_angle) <= MaxAngularDeviation
4. count(inliers) >= MinInlierCount

#### Phase 8: 直线拟合

对通过共线性判定的每组边缘点执行直线拟合:

**OLS (Ordinary Least Squares):**
```
给定 N 个点 {(x_i, y_i)}, 最小化 sum((y_i - a*x_i - b)^2)
解正规方程: [sum(x^2) sum(x)] [a] = [sum(xy)]
              [sum(x)   N     ] [b]   [sum(y)]
```

**RANSAC:**
```
迭代 K 次:
  1. 随机取2个点拟合一条直线 L
  2. 计算所有点到L的距离
  3. distance <= threshold 的点为inliers
  4. 保留inliers最多的模型
  5. 用所有inliers重新拟合得到最终直线
K = log(1-p) / log(1 - w^n)  // p=成功率, w=内点率, n=最小样本数
```

**Theil-Sen:**
```
对所有点对(i,j), i<j, 计算斜率 s_ij = (yj-yi)/(xj-xi)
中位数斜度 = median({s_ij})
截距 = median({yi - median_slope*xi})
// 天然抗异常点: 即使50%异常点仍正确
```

输出: 直线表示为 Point2d + DirectionVector2d + Confidence(RMS)

#### Phase 9: 后处理筛选

1. **长度过滤:** 直线两端点距离 >= MinOutputLength?
2. **角度过滤:** 直线方向角在 [AngleMin, AngleMax] 内?
3. **数量截断:** 按 SortMode 排序, 只保留前 MaxOutputCount 条
4. **输出格式化:** 封装为 CaliperResult[]

## 3. 核心数据结构

### 3.1 CaliperResult (单次检测结果)

```csharp
public class CaliperResult
{
    // 基础信息
    public int Index { get; set; }                    // 结果序号
    public EdgePolarity Polarity { get; set; }         // 检测到的实际极性
    public double EdgeAmplitude { get; set; }          // 边缘梯度幅度
    public double Contrast { get; set; }               // 边缘两侧对比度
    
    // 位置信息 (亚像素精度)
    public double SubpixelPosition { get; set; }       // 沿Rake方向的亚像素位置
    public OpenCvSharp.Point2d EdgePoint { get; set; }  // 图像坐标系中的边缘点(x,y)
    
    // 直线拟合信息 (仅SampleRows>1或多卡尺合并时有值)
    public bool HasFittedLine { get; set; }
    public OpenCvSharp.Point2d FitLinePoint { get; set; }       // 拟合直线上一点
    public OpenCvSharp.Point2d FitLineDirection { get; set; }   // 拟合直线方向向量(单位向量)
    public double FitLineLength { get; set; }                   // 拟合直线长度
    public double FitLineAngle { get; set; }                    // 拟合直线角度(度)
    
    // 质量指标
    public double RMSResidual { get; set; }             // 拟合残差均方根
    public int InlierCount { get; set; }                // 用于拟合的内点数量
    public double ConfidenceScore { get; set; }         // 综合置信度 (0~1)
}
```

### 3.2 CaliperParameters (运行参数)

```csharp
public class CaliperParameters : ToolParameters
{
    // 搜索方向
    public double RakeAngle { get; set; } = 0.0;          // 度, 与ROI双向同步
    
    // 采样配置
    public double MeasureLength { get; set; } = 100.0;     // px
    public double SampleWidth { get; set; } = 20.0;        // px
    public double SampleInterval { get; set; } = 1.0;      // px
    public int SampleRowCount { get; set; } = 1;
    
    // 边缘检测
    public EdgePolarity EdgePolarity { get; set; } = EdgePolarity.LightToDark;
    public SelectionMode SelectionMode { get; set; } = SelectionMode.All;
    public int EdgeIndexForNth { get; set; } = 1;
    
    // 过滤阈值
    public double MinContrast { get; set; } = 30.0;
    public double MinEdgeAmplitude { get; set; } = 10.0;
    public int SmoothKernelSize { get; set; } = 5;
    
    // 高级选项
    public bool EnableSubpixel { get; set; } = true;
    public InterpolationMethod SubpixelMethod { get; set; } = InterpolationMethod.Parabolic;
    
    // 合并参数
    public bool EnableMerge { get; set; } = true;
    public double MaxCollinearDeviation { get; set; } = 5.0;
    public double MaxAngularDeviation { get; set; } = 3.0;
    public int MinInlierCount { get; set; } = 3;
    
    // 拟合参数
    public FitMethod FitMethod { get; set; } = FitMethod.OLS;
    public int MinFitPoints { get; set; } = 2;
    public double MaxFitResidual { get; set; } = 3.0;
    
    // 后处理过滤
    public double MinOutputLength { get; set; } = 10.0;
    public double AngleRangeMin { get; set; } = 0.0;
    public double AngleRangeMax { get; set; } = 180.0;
    public int MaxOutputCount { get; set; } = 50;
    public SortMode ResultSortMode { get; set; } = SortMode.ConfidenceDescending;
}

public enum EdgePolarity { Any, LightToDark, DarkToLight }
public enum SelectionMode { First, Strongest, All, Nth }
public enum InterpolationMethod { Parabolic, Gaussian, Linear }
public enum FitMethod { OrdinaryLeastSquares, RANSAC, TheilSen }
public enum SortMode {
    None,
    ConfidenceDescending, ConfidenceAscending,
    LengthDescending, LengthAscending,
    AngleDescending, AngleAscending,
    XAscending, YAscending,
    XYAscending, YXAscending
}
```

## 4. 与Halcon对标

| Halcon算子 | 本方案对应 | 映射关系 |
|-----------|----------|---------|
| `measure_pos` | CaliperEngine.Detect() | 完全对标, 1:1参数映射 |
| `measure_pairs` | 两次 First 选取 + 外部宽度计算 | 可组合实现 |
| `fit_line_contour_xld` | CaliperEngine.FitLine() | 多行聚合时的直线拟合 |
| `select_lines` | 后处理筛选(长度/角度/数量) | Phase 9 |
| `get_sub_pix` | Phase 5 亚像素精化 | 内建, 默认开启 |
| `lines_gauss` | 不适用 | 本方案不用Hough |

**关键差异说明:**
- Halcon 的 `measure_pos` 返回单个边缘点; 我们的 Caliper 在多行模式下直接返回拟合直线
- 我们额外提供了 Theil-Sen 拟合(Halcon无原生对应, 需要外部实现)
- 我们内置了多卡尺合并功能(Halcon需手动循环多次 measure_pos)

## 5. 性能预估

| 配置 | 单卡尺耗时(估算) | 说明 |
|------|------------------|------|
| 单行, 100px长, 1px间隔 | ~0.05ms | 101个采样点, 极快 |
| 5行, 200px长, 1px间隔 | ~0.3ms | 1005个采样点 + OLS拟合 |
| 5行, 500px长, 0.5px间隔 | ~1.5ms | 5005个采样点 + OLS拟合 |
| 5行, 500px长, 0.5px间隔 + RANSAC | ~3ms | 含迭代拟合开销 |
| 多卡尺(10个x5行x300px) | ~5ms | 典型高级用法 |

参考基准: 1080p图像上, Halcon measure_pos 单次调用约 0.02~0.1ms.

## 6. 测试验证计划

### 6.1 单元测试

1. **1D剖面梯度计算**: 已知三角波输入, 验证边缘位置和幅度
2. **抛物线插值精度**: 用已知高斯边缘模拟数据, 验证亚像素误差 < 0.02px
3. **极性过滤**: 正/负梯度混合输入, 验证只保留目标极性
4. **OLS/RANSAC/Theil-Sen对比**: 注入离群点, 验证鲁棒性差异
5. **共线性判定**: 近似共线的点集应通过, 非共线的应被拒绝

### 6.2 集成测试

1. **标准件测量**: 使用标定板/量块图像, 验证重复精度 < 0.05px
2. **不同光照条件**: 正常/过曝/欠曝/非均匀光下的一致性
3. **边缘类型覆盖**: 阶跃边缘/渐变边缘/噪声边缘/低对比度边缘
4. **ROI偏移鲁棒性**: ROI轻微偏移时结果的稳定性
