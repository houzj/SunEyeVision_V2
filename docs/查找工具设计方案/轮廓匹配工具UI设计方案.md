## 一、整体架构概览

### 1.1 调试控制面板结构

调试控制面板采用 **4 Tab 分页布局**，完全对齐 BlobAnalysis 工具的实现风格：

```
+---------------------------------------------------------------------+
|  +------+------+------+------+                                     |
|  | Tab1 | Tab2 | Tab3 | Tab4 |                                     |
|  | 基本 | 模版 | 运行 | 结果 |                                     |
|  | 参数 | 创建 | 参数 | 显示 |                                     |
|  +------+------+------+------+                                     |
|                                                                     |
|  +-------------------------------------------------------------+   |
|  |                                                             |   |
|  |                    当前选中 Tab 的内容区                      |   |
|  |                                                             |   |
|  +-------------------------------------------------------------+   |
+---------------------------------------------------------------------+
```

**各Tab功能分工：**

| Tab | 名称 | 核心职责 | 典型操作 |
|-----|------|----------|----------|
| Tab1 | 基本参数 | 配置输入图像源、搜索区域范围、位置补正 | 选图、画ROI、开/关位置修正 |
| Tab2 | 模版创建 | 创建/编辑/管理匹配轮廓模板 | 绘制ROI区域 → 提取轮廓 → 保存模板 |
| Tab3 | 运行参数 | 设置匹配算法参数（分数、角度、缩放等） | 调灵敏度、选排序方式、设并行策略 |
| Tab4 | 结果显示 | 配置结果判断条件与可视化输出样式 | 设OK/NG阈值、配色方案 |

### 2.2 关键说明

- **图像源选择**: 使用 SDK 的 `ImageSourceSelector` 控件（拉下选择器），通过 `AvailableDataSources` 绑定到工作流数据源，控件自动过滤 Mat 类型源。非三个硬编码按钮。
- **搜索区域**: 复用 RegionEditorManagerControl，通过 SetMainImageControl() 与下方图像控件绑定 ROI 叠加层
- **语义映射**:
  - Inspection（检测区域）-> 显示标签为「有效区」— 用于限定搜索范围
  - Mask（屏蔽区域）-> 显示标签为「排除区」— 用于排除无效匹配点

### 3.1a 预览区优化设计

> **核心原则**：只显示 ROI 区域裁切放大 + 提取轮廓叠加，不显示全图/缩略图

**为什么不显示全图？**

| 问题 | 说明 |
|------|------|
| 空间浪费 | 全图(如1920x1080)缩小后模版区域几乎不可见 |
| 无实际价值 | 用户关注的是模版ROI本身，非整张图像 |
| 性能开销 | 每次切换模板都要渲染完整大图 |
| 行业惯例 | Halcon/VisionPro 均只显示模型区域 |

**预览区数据流：**

```
+- 预览区数据流 -------------------------------------------------------+
|                                                                      |
|  模版数据 (TemplateModel)                                            |
|    |                                                                |
|    → 裁切: Crop(ROI +/- margin, 20~30px)                             |
|          → 等比缩放填充预览区                                        |
|          → 叠加绘制: 提取轮廓线 (#00FF00)                             |
|          → 居中显示                                                  |
|                                                                      |
+----------------------------------------------------------------------+
```

**技术参数：**

| 参数 | 建议值 | 说明 |
|------|--------|------|
| 边距(margin) | 20~30px | ROI四周保留上下文像素，帮助观察边缘特征 |
| 缩放模式 | Uniform（等比缩放） | 保持比例，居中显示 |
| 轮廓颜色 | #00FF00 (绿色) | 提取成功的轮廓叠加色 |
| 轮廓线宽 | 1~2px | 清晰可见但不遮挡图像细节 |
| 未提取状态 | 显示ROI区域原图，无轮廓叠加 | 提示用户需要先编辑并提取 |

### 3.3 对话框组件详细说明

#### 左侧栏 — 图像操作区

**① 图像源选择面板**

两个按钮选项:
- 📷 **当前图像**: 使用 Tab1 基本参数中 ImageSourceSelector 输入的图像（即上层工作流传入的图像）
- 📂 **本地载入**: 从文件系统加载图片文件（支持 bmp/png/jpg/tiff），用于在编辑模板时使用不同的参考图

附加信息:
- 当前图像来源标识显示（文件名或工作流节点名）
- 图像尺寸信息 (宽 x 高)

**② 图像显示区 (ImageControl)**

| 属性 | 设置值 | 说明 |
|------|--------|------|
| ShowToolBar | True | 显示工具栏（缩放/全屏等），但隐藏其中的 ComboBox |
| ShowStatusBar | True | 保留底部坐标状态栏 |
| EnablePanning | True | 启用鼠标平移 |
| EnableZoom | True | 启用滚轮缩放 |
| OverlayHitTestVisible | True | ROI 叠加层可接收鼠标事件 |

**集成机制**: 通过 SetMainImageControl() 将右侧 RegionEditorManagerControl 的绘制层绑定到 ImageControl 的 InteractionOverlayCanvas 上。

#### 右侧栏 — 编辑与配置区

**③ 区域编辑管理器 (RegionEditorManagerControl)**

> 注意: 实际控件布局为**两个带圆角+主题色的 Border 垂直堆叠**，每个内部包含一个 RegionEditorControl，非树形列表。

每个 RegionEditorControl 包含:
- **模式切换**: 绘制 / 订阅（RadioButton 组）
- **形状工具按钮** (横向排列): 选择/编辑(V) | 圆形(C) | 旋转矩形(O) | 多边形(P)
- **绘制参数面板**: Expander 可折叠，显示中心X/Y、宽/高（矩形）、半径（圆形）、角度（旋转矩形）等
- **订阅参数面板**: Expander 可折叠（仅订阅模式可见），支持继承方式选择（矩形/圆形）+ ParamBinding

两个区域的主题色差异:

| 区域 | SDK 类型 | 主题色 | 标题 |
|------|---------|--------|------|
| 检测区域（有效区） | Inspection | 蓝色 #4488FF | "检测区域" |
| 屏蔽区域（排除区/橡皮擦） | Mask | 橙色 #FFA500 | "屏蔽区域" |

**橡皮擦尺寸设置：**
- 擦除区域（矩形擦/圆形擦）支持预设擦除范围尺寸
- 用户通过数值输入控件调整橡皮擦尺寸（默认20px）
- 调整后即时生效，后续绘制的擦除区域使用新尺寸
- 已有擦除区域不受尺寸更改影响（仅影响新绘制）

**④ 轮廓提取参数**

| 参数 | 控件类型 | 默认值 | 说明 | 调参建议 |
|------|----------|--------|------|----------|
| 边缘检测算法 | 下拉框 | Canny | Canny / Sobel | Canny适合边缘清晰工件；Sobel适合边缘模糊但有渐变的场景 |
| 低阈值 | 数值输入 | 50 | Canny 低阈值 | 降低可检出更弱边缘，但可能引入噪声。一般30~80 |
| 高阈值 | 数值输入 | 150 | Canny 高阈值 | 升高使边缘更连续，但可能丢失弱边缘。一般100~250 |
| 孔径大小 | 数值输入 | 5 | Sobel 孔径 | 必须是奇数(3/5/7)。越大抗噪越强但边缘模糊 |
| 近似方法 | 下拉框 | ApproxPolyDP | Douglas-Peucker 多边形近似 | ApproxPolyDP适合直线/多边形轮廓；None保留原始像素级轮廓 |
| 精度 | 数值输入 | 2.0 | 近似精度(epsilon) | 越小保留越多细节(慢)，越大简化越多(快)。建议1.0~5.0 |

**操作按钮说明：**

| 按钮 | 功能行为 | 适用时机 |
|------|----------|----------|

#### 4.3.3 跟随全局交互逻辑

**核心原则**: 某参数留空/不勾选/显示占位符 = **继承全局默认值**。用户只需改「不一样的」，相同的自动继承。

| 参数状态 | UI表现 | 存储含义 | 运行时解析 |
|---------|--------|----------|-----------|
| 已设置具体值 | 正常显示数值 | 该模型的参数覆盖记录中存储了此值 | 使用该覆盖值 |
| 留空/跟随 | 灰色占位文字「跟随全局 X.XXX」 | 覆盖记录中没有该字段，或者字段值为空 | 回退到全局默认值 |

**存储层数据结构设计：**

系统维护两层参数：

| 层级 | 数据实体 | 职责 | 生命周期 |
|------|----------|------|----------|
| **全局参数层** | 公共参数集合 | 存储所有模板共享的默认值（如 MinMatchScore=0.5） | 始终存在，作为基准 |
| **模型覆盖层** | 按模型ID索引的覆盖字典 | 仅存储用户显式修改过的差异化值 | 动态增减，仅在多模板且有差异时才有内容 |

**覆盖层的数据组织方式（表格描述）：**

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| TemplateId | string | 关联的模板标识 | "#1" 或模板GUID |
| MinMatchScore | double? | 可空的匹配分数覆盖值 | 0.8 (表示覆盖)、null (表示继承全局) |
| AngleMin / AngleMax | double? | 可空的角度范围覆盖值 | 0 和 360 (表示覆盖为全角) |
| ScaleMin / ScaleMax | double? | 可空的缩放范围覆盖值 | null (表示继承全局) |
| MaxMatchCount | int? | 可空的最大匹配数覆盖值 | null (表示继承全局) |

> **关键设计**: 使用可空类型(nullable)，null 即表示「未设置→继承全局」。这样运行时只需简单的 null 判断即可完成解析，无需复杂的"是否存在于字典"逻辑。

**运行时解析流程（文字描述）：**

当引擎需要获取某个模板的某个参数有效值时，解析过程如下：

1. **查找覆盖记录**: 在模型覆盖层中找到对应 TemplateId 的覆盖条目
2. **判空检查**: 检查该条目中目标参数字段是否有非null值
3. **命中覆盖**: 如果有非null值，直接返回该覆盖值
4. **回退全局**: 如果为null或找不到覆盖条目，返回全局参数层的对应值

整个流程是一个简单的二段式查找，时间复杂度为 O(1)（基于字典索引），不会带来性能开销。

#### 4.3.4 方案对比（v1.3 vs v1.4）

| 维度 | v1.3 内联面板 | v1.4 下拉选择器 |
|------|----------------|----------------|
| 参数位置 | 分散在Tab2列表各行内 | **集中在Tab3运行参数区顶部** |

### 4.5 结果排序

对匹配结果进行排序，控制输出结果集的排列顺序。当最大匹配数量 > 1 时排序效果明显。

**排序选项清单：**

| 排序选项 | 显示文本 | 排序规则 | 典型场景 | 效果示例 |
|----------|----------|----------|----------|----------|
| 无排序 | `无排序` | 保持引擎原始输出顺序（默认） | 不关心顺序，只需前N个最高分 | 引擎内部顺序，不可预测 |
| 分数降序 | `按分数降序` | Score 从高到低 | 取最佳匹配优先显示 | 0.95 → 0.88 → 0.72 ... |
| 角度降序 | `按角度降序` | Angle 从高到低 (如 180 到 -180) | 按旋转角度归类查看 | 175° → 90° → -45° → -170° |
| X升序 | `按X由小到大` | CenterX 从左到右 | 从左到右扫描工件 | x=120 → x=350 → x=580 |
| Y升序 | `按Y由小到大` | CenterY 从上到下 | 从上到下扫描工件 | y=80 → y=240 → y=400 |
| X升序+Y升序 | `X由小到大, Y由小到大` | 先按X排，X相同再按Y升序 | 网格/阵列工件，逐列遍历 | 先排完第1列，再排第2列... |
| Y升序+X升序 | `Y由小到大, X由小到大` | 先按Y排，Y相同再按X升序 | 网格/阵列工件，逐行遍历 | 先排完第1行，再排第2行... |

**ROI绘制操作详细指引：**

**第一步：选择图像并定位**
1. 打开对话框后，左侧图像区自动加载「当前图像」（或点击「📂本地载入」选择参考图）
2. 利用鼠标滚轮放大图像到目标区域清晰可见
3. 拖拽图像平移，使目标物体居中显示
4. 观察底部状态栏的实时坐标，了解当前位置信息

**第二步：绘制有效区域**
1. 在右侧「检测区域」组中选择合适的形状工具：
   - **矩形**：最常用，适用于轴对齐的方形/矩形物体
   - **圆形**：适用于圆柱/圆形零件（螺母、轴承等）
   - **多边形**：适用于不规则边界（紧贴物体轮廓）
   - **旋转矩形**：适用于已知的倾斜摆放物体
2. 在图像上按下鼠标左键开始绘制
3. 拖拽到合适大小后释放鼠标
4. 形状出现蓝色调整手柄，可进一步微调位置和尺寸

**第三步：处理干扰区域（可选）**
1. 切换到右侧「屏蔽区域」组（橙色主题标识）
2. 如背景有强反光、刻字或其他干扰特征，使用橡皮擦工具覆盖
3. 调整橡皮擦尺寸以适应干扰区域的大小
4. 在干扰位置拖拽擦除

**第四步：提取轮廓并验证**
1. 在右侧「轮廓提取参数」区选择边缘检测方法
2. 调整阈值参数（初学者可直接使用默认值）
3. 先点击「👁 预览」查看轮廓叠加效果
4. 若轮廓不完整或不准确，返回第二步调整ROI或第四步调整参数
5. 满意后点击「▶ 提取」保存
