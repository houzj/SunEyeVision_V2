> 版本: v1.1 | 日期: 2026-05-07 | 状态: 设计完成
> 更新: v1.1 新增第12章「多模板匹配」完整设计

## 1. 方案选型与决策

### 1.1 候选方案对比

| 方案 | API | 旋转支持 | 缩放支持 | 多实例 | 亚像素 | 可控性 |
|------|-----|----------|----------|--------|--------|--------|
| **A: 模板匹配** | `Cv2.MatchTemplate()` | ❌ | ❌ | ✅ | ❌ | 中 |
| **B: Hu矩形状对比** | `Cv2.MatchShapes()` | ✅ | ✅ | ❌ | ❌ | 低 |
| **C: 广义霍夫变换** | `Cv2.GeneralizedHoughGuill/Ballard` | ✅ | ✅ | ✅ | ❌ | 低 |
| **D: 自建GOH匹配器** | 梯度方向直方图 (自研) | ✅ | ✅ | ✅ | ✅ | **高** |

### 1.2 最终选择：方案 D — 自建梯度方向直方图 (GOH) 匹配器

**选择理由：**

1. **完全可控** — 算法每一步都可调优、可扩展、可调试
2. **对齐 Halcon 语义** — `create_shape_model` / `find_shape_model` 的完整对标
3. **旋转+缩放+多实例+亚像素** — 四维全支持，工业视觉刚需
4. **光照鲁棒性** — 使用梯度**方向**而非灰度值作为特征
5. **部分遮挡容忍** — 归一化评分机制，遮挡只降低分数而非归零
6. **可渐进增强** — V1 基础版 → V2 加入 NCC 金字塔验证 → V3 加入深度学习特征

### 1.3 为什么不选用其他方案？

- **MatchTemplate**：仅支持平移，无法处理旋转/缩放，工业场景不适用
- **MatchShapes(Hu矩)**：仅输出相似度分数，无法定位目标位置，需配合其他方法
- **GeneralizedHough**：OpenCvSharp 封装不完善，训练过程繁琐，参数敏感难调试

## 2. 算法流程总览

```

│                    ShapeMatch 核心算法流程                            │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─ Phase 0: 模板创建（离线/编辑时执行一次）─────────────────────┐  │
│  │                                                                 │  │
│  │   输入: ROI区域图像 + 有效区/排除区                              │  │
│  │   输出: ShapeModel（模板数据）                                  │  │
│  │                                                                 │  │
│  │   ① Canny/Sobel 边缘检测 → 边缘二值图                          │  │
│  │   ② FindContours(ApproxPolyDP) → 轮廓点集                      │  │
│  │   ③ 计算每个轮廓点的:                                           │  │

│  │   ④ 构建 ModelData:                                            │  │
│  │      - ContourPoints[]: 归一化坐标(相对于质心)                 │  │

│  │      - CenterOfMass: 模板质心                                   │  │
│  │      - BoundingBox: 包围盒                                     │  │
│  │      - ContourArea: 轮廓面积                                   │  │
│  │                                                                 │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                    ↓                                   │
│  ┌─ Phase 1: 金字塔构建（运行时）────────────────────────────────┐  │
│  │                                                                 │  │
│  │   输入: 待搜索图像                                              │  │
│  │   输出: ImagePyramid[0..N]                                      │  │
│  │                                                                 │  │
│  │   Level 0 = 原始尺寸 (1x)                                       │  │
│  │   Level 1 = 1/2 尺寸    (高斯模糊↓2)                             │  │
│  │   Level 2 = 1/4 尺寸    (高斯模糊↓2)                             │  │
│  │   ...                                                            │  │
│  │   Level N = 最小层 (≥ 模板最小边长)                              │  │
│  │                                                                 │  │
│  │   同时构建模板金字塔 (模型点坐标同步降采样)                       │  │
│  │                                                                 │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                    ↓                                   │
│  ┌─ Phase 2: 粗匹配（最低分辨率层）──────────────────────────────┐  │
│  │                                                                 │  │
│  │   在金字塔最底层执行全图滑动窗口扫描:                            │  │
│  │                                                                 │  │
│  │   for each (x, y) in 搜索区域(降采样后):                        │  │
│  │     for each angle in [minAngle..maxAngle] step angleStep:     │  │
│  │       for each scale in [minScale..maxScale] step scaleStep:   │  │
│  │         score = ComputeGOHScore(imagePyr, modelPyr, x,y,a,s)  │  │
│  │         if score > threshold → 候选列表                         │  │
│  │                                                                 │  │
│  │   输出: CandidateList[(x,y,angle,scale,score), ...]            │  │
│  │                                                                 │  │
│  │   ⚡ 加速: 低分辨率层像素少，且可用 step=4~8 大步进             │  │

│  └─────────────────────────────────────────────────────────────────┘  │

│  │                                                                 │  │

│  │     坐标 × 2 (映射到上一层)                                      │  │

│  │     缩放范围缩小到 ±scaleStep                                   │  │

│  │   最终输出: MatchResult[] (原始图像坐标系)                      │  │
│  │                                                                 │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                    ↓                                   │
│  ┌─ Phase 4: 亚像素优化 & 后处理 ────────────────────────────────┐  │
│  │                                                                 │  │
│  │   ① 亚像素精化: 在最优解附近 ±1px 微调 (插值评分曲面)         │  │
│  │   ② 分数过滤:   score < MinScore 的剔除                        │  │
│  │   ③ 最大数量截断: 取 Top-N (MaxMatches)                        │  │
│  │   ④ 排序:       按 SortMode 排序 (分数/角度/X/Y)               │  │
│  │   ⑤ 输出 MatchResult[]                                        │  │
│  │                                                                 │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 3. 核心：GOH 评分函数（ComputeGOHScore）

这是整个匹配器的"心脏"，衡量模板与图像局部区域的形状相似度：

```csharp
/// <summary>
/// 计算梯度方向直方图 (GOH) 匹配分数
/// </summary>
/// <param name="gradX">预计算的X梯度图像（某金字塔层级）</param>
/// <param name="gradY">预计算的Y梯度图像（某金字塔层级）</param>
/// <param name="model">模板数据（对应层级）</param>
/// <param name="cx">候选中心点X</param>
/// <param name="cy">候选中心点Y</param>
/// <param name="angle">候选旋转角（弧度）</param>
/// <param name="scale">候选缩放比</param>
/// <returns>匹配分数 (0~1, 越高越相似)</returns>
double ComputeGOHScore(
    Mat gradX, Mat gradY,
    ShapeModel model,
    double cx, double cy,
    double angle, double scale)
{
    double totalScore = 0;
    double totalWeight = 0;
    
    // 旋转变换矩阵
    double cosA = Math.Cos(angle);
    double sinA = Math.Sin(angle);
    
    foreach (var mp in model.ContourPoints)
    {
        // 1. 模型点 → 变换到图像坐标系（旋转+缩放+平移）
        double rx = (mp.X * cosA - mp.Y * sinA) * scale + cx;
        double ry = (mp.X * sinA + mp.Y * cosA) * scale + cy;
        
        // 2. 边界检查
        int ix = (int)rx, iy = (int)ry;
        if (ix < 0 || ix >= gradX.Cols || iy < 0 || iy >= gradX.Rows)
            continue;
        
        // 3. 双线性插值读取图像梯度
        double gx = BilinearInterpolate(gradX, rx, ry);
        double gy = BilinearInterpolate(gradY, rx, ry);
        
        // 4. 计算图像梯度幅值
        double imageMag = Math.Sqrt(gx * gx + gy * gy);
        if (imageMag < 1e-6) continue; // 无梯度区域跳过
        
        // 5. 计算期望梯度方向（模型梯度方向 + 旋转角）
        double expectedAngle = NormalizeAngle(mp.GradientAngle + angle);
        double actualAngle = Math.Atan2(gy, gx);
        
        // 6. 方向一致性得分（核心公式）
        double angleDiff = AngularDistance(expectedAngle, actualAngle);
        double pointScore = Math.Cos(angleDiff); // cos(Δθ), 范围 [-1, 1]
        
        // 7. 幅值加权（弱边缘贡献小，强边缘贡献大）
        double weight = Math.Min(mp.GradientMagnitude, imageMag);
        
        totalScore += pointScore * weight;
        totalWeight += weight;
    }
    
    // 归一化: 加权和 / 总权重
    return totalWeight > 0 ? totalScore / totalWeight : 0;
}
```

### GOH 评分函数特性分析

| 特性 | 实现机制 | 效果 |
|------|----------|------|
| **光照鲁棒性** | 使用梯度**方向**而非灰度值 | 光照变化不影响匹配 |
| **旋转一致性** | 模型梯度方向 + 旋转角 = 期望方向 | 自动适应任意角度 |
| **缩放自适应** | 点坐标 × scale | 自动适应不同大小目标 |
| **弱边缘抑制** | 梯度幅值加权 | 噪声区域自然被抑制 |
| **部分遮挡容忍** | 归一化除以有效权重 | 遮挡只降低分数不归零 |
| **边界安全** | 越界点跳过 | 部分超出图像仍可匹配 |

## 4. 数据结构设计

### 4.1 ShapeModel（模板数据）

```csharp
/// <summary>
/// 形状匹配模板数据 — 对应 Halcon ShapeModel
/// </summary>
public class ShapeModel
{
    /// <summary>模板ID（短GUID）</summary>
    public string Id { get; set; } = Guid.NewGuid().ToString("N")[..8];
    
    /// <summary>模板名称</summary>
    public string Name { get; set; } = string.Empty;
    
    /// <summary>是否启用</summary>
    public bool IsEnabled { get; set; } = true;
    
    /// <summary>轮廓点集（相对于质心的归一化坐标）</summary>
    public List<ModelPoint> ContourPoints { get; set; } = new();
    
    /// <summary>模板质心（原始图像坐标系）</summary>
    public Point2d CenterOfMass { get; set; }
    
    /// <summary>包围盒（原始图像坐标系）</summary>
    public Rect BoundingBox { get; set; }
    
    /// <summary>轮廓面积</summary>
    public double ContourArea { get; set; }
    
    /// <summary>轮廓点数</summary>
    public int PointCount => ContourPoints.Count;
    
    /// <summary>创建时的源图像ROI（用于预览显示）</summary>
    public Mat? SourceRoiImage { get; set; }
    
    /// <summary>金字塔层数（由模板尺寸自动决定或手动指定）</summary>
    public int PyramidLevels { get; set; }
    
    /// <summary>创建参数（用于重建/验证）</summary>
    public ModelCreationParams? CreationParams { get; set; }
}

/// <summary>
/// 单个模板轮廓点（携带梯度信息）
/// </summary>
public struct ModelPoint
{
    /// <summary>X坐标（相对于质心）</summary>
    public double X;
    
    /// <summary>Y坐标（相对于质心）</summary>
    public double Y;
    
    /// <summary>该点梯度方向角（弧度, [-π, π]）</summary>
    public double GradientAngle;
    
    /// <summary>该点梯度幅值</summary>
    public double GradientMagnitude;
}

/// <summary>
/// 模板创建参数（记录创建条件，用于重建和验证）
/// </summary>
public class ModelCreationParams
{
    public EdgeDetector EdgeDetector { get; set; }
    public double CannyLowThreshold { get; set; } = 50;
    public double CannyHighThreshold { get; set; } = 150;
    public double ApproxEpsilon { get; set; } = 2.0;
    public int MinContourArea { get; set; } = 25;
    public int TargetPointCount { get; set; } = 60;
}
```

### 4.2 ShapeMatchResult（单次匹配结果）

```csharp
/// <summary>
/// 单次形状匹配结果 — 对应 Halcon find_shape_model 输出行
/// </summary>
public class ShapeMatchResultItem
{
    /// <summary>匹配分数 (0~1, 越高越像)</summary>
    public double Score { get; set; }
    
    /// <summary>匹配中心点 X（原始图像坐标）</summary>
    public double CenterX { get; set; }
    
    /// <summary>匹配中心点 Y（原始图像坐标）</summary>
    public double CenterY { get; set; }
    
    /// <summary>匹配角度（弧度）</summary>
    public double AngleRad { get; set; }
    
    /// <summary>匹配角度（度, -180 ~ 180）</summary>
    public double AngleDeg => AngleRad * 180.0 / Math.PI;
    
    /// <summary>缩放比例</summary>
    public double Scale { get; set; } = 1.0;
    
    /// <summary>匹配到的模板引用</summary>
    public ShapeModel? MatchedModel { get; set; }
    
    /// <summary>匹配框（旋转矩形，原始图像坐标）</summary>
    public RotatedRect? BoundingBox { get; set; }
    
    /// <summary>变换后的轮廓点（原始图像坐标，用于绘制）</summary>
    public Point[]? TransformedContour { get; set; }
    
    /// <summary>是否通过分数阈值</summary>
    public bool IsAccepted(double threshold) => Score >= threshold;

    /// <summary>计算变换后的轮廓点（延迟计算）</summary>
    public Point[] GetTransformedContour()
    {
        if (TransformedContour != null || MatchedModel == null)
            return TransformedContour ?? Array.Empty<Point>();
        
        var cosA = Math.Cos(AngleRad);
        var sinA = Math.Sin(AngleRad);
        TransformedContour = new Point[MatchedModel.ContourPoints.Count];
        for (int i = 0; i < MatchedModel.ContourPoints.Count; i++)
        {
            var mp = MatchedModel.ContourPoints[i];
            double rx = (mp.X * cosA - mp.Y * sinA) * Scale + CenterX;
            double ry = (mp.X * sinA + mp.Y * cosA) * Scale + CenterY;
            TransformedContour[i] = new Point((int)Math.Round(rx), (int)Math.Round(ry));
        }
        return TransformedContour;
    }

    /// <summary>获取匹配包围盒（旋转矩形）</summary>
    public RotatedRect ComputeBoundingBox()
    {
        if (BoundingBox != null || MatchedModel == null)
            return BoundingBox ?? default;
        
        var size = MatchedModel.BoundingBox.Size;
        double scaledW = size.Width * Scale;
        double scaledH = size.Height * Scale;
        var center = new Point2f((float)CenterX, (float)CenterY);
        BoundingBox = new RotatedRect(center, new Size2f((float)scaledW, (float)scaledH), (float)AngleDeg);
        return BoundingBox.Value;
    }
}
```

## 5. 性能优化策略

```
┌─ 性能优化层次 ───────────────────────────────────────────────────┐
│                                                                    │
│  Layer 1: 图像金字塔                                               │
│  ├── 1920×1080 → Level0(原) → Level1(960×540) → Level2(480×270)  │
│  ├── 粗匹配在 Level2 执行，像素数仅为原图的 1/16                   │
│  └── 角度步长随层级放大：Level2=8°, Level1=2°, Level0=0.5°        │
│                                                                    │
│  Layer 2: 梯度预计算                                                │
│  ├── Sobel(Gx,Gy) 对每层金字塔只算一次                              │
│  ├── 存为 float 通道图像 (Gx=Ch0, Gy=Ch1)，避免重复计算              │
│  └── 评分时直接查表插值，无需再调用 Sobel                            │
│                                                                    │
│  Layer 3: 模板点降采样                                              │
│  ├── 原始轮廓可能有 200+ 个点 (ApproxPolyDP 后)                     │
│  ├── 降采样到 50~80 个均匀分布的点                                  │
│  ├── 保持形状特征的同时大幅减少计算量                                │
│  └── 降采样策略：等间距选取 + 曲率关键点保留                        │
│                                                                    │
│  Layer 4: NMS (非极大值抑制)                                        │
│  ├── 匹配完成后，合并距离 < minMatchDistance 的重复检测结果          │
│  ├── 保留分数最高的那个                                             │
│  └── 避免同一物体被多次检出                                         │
│                                                                    │
│  Layer 5: 并行化                                                    │
│  ├── 不同候选位置的评分互相独立 → Parallel.ForEach                  │
│  ├── 不同角度的循环也可并行                                         │
│  └── 注意：OpenCV Mat 读操作是线程安全的（只读）                      │
│                                                                    │
│  Layer 6: 早停策略                                                  │
│  ├── 累积分数已不可能超过阈值 → 提前终止当前候选                    │
│  ├── 已找到足够多的高分匹配 → 终止搜索                              │
│  └── 显著减少无效计算                                               │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

## 6. 与 Halcon find_shape_model 对标

| Halcon 概念 | 本方案对应 | 说明 |
|-------------|-----------|------|
| `create_shape_model()` | `ShapeMatcher.CreateModel()` | Canny→轮廓→梯度方向 |

## 12. 多模板匹配（Multi-Template Matching）⭐

### 12.1 需求场景

| 场景 | 说明 | 示例 |
|------|------|------|
| **多品种检测** | 同一工位检测多种不同工件 | 螺丝+螺母+垫片同时检测 |
| **多姿态匹配** | 同一物体的不同视角模板 | 正面/侧面/倾斜各建一个模板 |
| **分层筛选** | 先粗模版定位，再精模版验证 | 粗轮廓找候选 → 细特征确认 |
| **缺陷对比** | 标准品 vs 多种缺陷模式 | OK模板 + 划痕模板 + 缺口模板 |

### 12.3 执行策略

#### 策略 A：串行逐模板（默认）

```
for each model in EnabledModels:
    results = SingleModelSearch(image, model, params)
    allResults.AddRange(results)
→ 合并 → NMS → 过滤 → 排序 → 输出
```

- **优点**: 实现简单、内存占用低、复用单模板全部逻辑
- **适用**: 模板数 ≤ 5，或内存敏感环境

#### 策略 B：并行多模板 — ParallelShared（推荐）

```
主线程: 预计算 imagePyramid + gradX/gradY (一次, 所有模板共享)
    │
    Parallel.ForEach(enabledModels, model =>
    {
        results = SingleModelSearch(sharedGrads, modelPyramid, params)
        ConcurrentBag.Add(results)
    });
→ 收集 → 合并 → 全局 NMS → 过滤 → 排序 → 输出
```

- **优点**: 梯度只算一次(省时), 评分阶段并行(加速), 内存可控
- **关键点**: `Mat` 只读操作线程安全; 用 `ConcurrentBag` 收集结果

### 12.4 梯度复用优化

| 方案 | 做法 | 节省 | 适用模式 |
|------|------|------|----------|
| 完全共享 | 预计算一次梯度金字塔,所有模板共用 | N-1次Sobel | Sequential |
| 各线程独立 | 每线程自建梯度 | 无,但无锁 | ParallelIndependent |
| **共享梯度+并行评分** | 主线程预计算梯度(只读),多线程并行评分 | N-1次Sobel + 并行加速 | **ParallelShared (推荐)** |

### 12.6 结果合并与去重

```csharp
/// <summary>多模板结果合并器</summary>
public class ResultMerger
{
    public List<ShapeMatchResultItem> Merge(
        Dictionary<ShapeModel, List<ShapeMatchResultItem>> perModelResults,
        MergeOptions options)
    {
        // 1. 收集 + 应用每模板权重
        var allResults = perModelResults
            .SelectMany(kv => kv.Value.Select(r =>
            {
                r.Score *= GetWeight(kv.Key);
                r.MatchedModel = kv.Key;
                return r;
            }))
            .ToList();

        // 2. 跨模板 NMS（不同模板检出的同一位置物体）
        if (options.CrossModelNmsEnabled)
            allResults = CrossModelNMS(allResults, options.MinDistance);

        // 3. 全局分数过滤
        allResults = allResults.Where(r => r.Score >= options.GlobalMinScore).ToList();

        // 4. 排序
        allResults = SortResults(allResults, options.SortMode);

        // 5. 全局数量截断
        if (allResults.Count > options.MaxTotalCount)
            allResults = allResults.Take(options.MaxTotalCount).ToList();

        return allResults;
    }
}
```

**跨模板 NMS 示意**:
- 模板A(螺丝)检出 Pos=(100,200), Score=0.92
- 模板B(螺母)检出 Pos=(103,198), Score=0.88
- 距离 ≈ 3.6px < minDistance(10px) → 保留高分Result-A1, 抑制Result-B1
