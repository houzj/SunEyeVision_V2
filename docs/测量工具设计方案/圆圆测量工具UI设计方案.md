# 圆圆测量工具 (CircleToCircle) UI 设计方案

> 版本: v1.0 | 日期: 2026-05-07 | 状态: 设计完成
> 参考基准: CircleFinderTool / BlobAnalysisTool 实现风格

---

## 一、工具概述

圆圆测量工具用于测量两个圆之间的距离关系。该工具接受两个原始圆的输入（可直接拾取图像中的圆，或手动设置圆心和半径参数），然后根据用户选择的测量模式计算两圆之间的中心距、最小边距或最大边距，并输出测量结果。

核心工作流程:

```
输入图像 -> 圆1检测/参数 -> 圆2检测/参数 -> 测量计算 -> 结果显示
```

---

## 二、整体布局

采用 3 Tab 分页布局:

| Tab | 名称 | 内容概要 |
|-----|------|----------|
| Tab1 | 基本参数 | 图像源选择、圆1输入、圆2输入 |
| Tab2 | 测量参数 | 测量模式、单位、精度、公差 |
| Tab3 | 结果显示 | 结果判断、图形标记、测量文本 |

---

## 三、Tab1 — 基本参数

### 3.1 图像源选择

**控件: ImageSourceSelector (LabeledControl 标题: "输入图像")**

放置在该 Tab 的最上方，作为后续所有测量步骤的图像数据来源。

布局示意:

```
+---------------------------------------------+
|  输入图像:  [ImageSourceSelector     v]      |
|  +-----------------------------------------+ |
|  |         (图像预览缩略图区域)              | |
|  +-----------------------------------------+ |
+---------------------------------------------+
```

ImageSourceSelector 支持:
- 选择前置工具的输出图像作为输入源
- 支持通过链接按钮绑定到其他工具的图像输出结果
- 预览缩略图显示当前选中的图像

---

### 3.2 圆1 输入

**分组标题: "圆1 输入"**

输入方式使用 RadioButton 切换:

**方式A: 按圆拾取 (从图像中检测/选择已有的圆)**

通过一个 LinkButton 链接到前置的圆查找工具 (CircleFinder) 的输出。用户点击链接按钮后，从已运行的圆查找工具结果中选择一个圆作为圆1。

```
+---------------------------------------------+
|  圆1 输入                                     |
|  O 按圆拾取                                   |
|     [链接: 选择圆...] 当前: 无                |
|  O 按参数输入                                  |
|     圆心X: [________]  圆心Y: [________]     |
|     半径R: [________]                         |
+---------------------------------------------+
```

链接按钮行为:
- 点击后弹出工具连线对话框，选择输出 CircleFinder 结果的工具
- 选中后自动读取该工具的输出圆列表
- 用户可进一步选择具体是第几个圆 (通过下拉框选择圆索引)
- 当链接的工具重新运行时，自动更新引用

**方式B: 按参数输入 (手动输入圆心和半径参数)**

直接提供三个数值输入框:

| 参数 | 控件类型 | 默认值 | 范围 |
|------|----------|--------|------|
| 圆心X | NumericTextBox | 0 | 0~图像宽度 |
| 圆心Y | NumericTextBox | 0 | 0~图像高度 |
| 半径R | NumericTextBox | 100 | 1~图像对角线/2 |

---

### 3.3 圆2 输入

**分组标题: "圆2 输入"**

与圆1 输入结构完全相同，但独立配置。用户可以为圆2选择不同的输入方式、不同的链接工具。

```
+---------------------------------------------+
|  圆2 输入                                     |
|  O 按圆拾取                                   |
|     [链接: 选择圆...] 当前: 无                |
|  O 按参数输入                                  |
|     圆心X: [________]  圆心Y: [________]     |
|     半径R: [________]                         |
+---------------------------------------------+
```

两个圆独立配置的设计原因:
- 实际应用中，圆1和圆2可能来自不同的检测工具
- 也可能圆1来自工具检测，圆2来自固定参数
- 保持灵活性，不限制用户选择

---

## 四、Tab2 — 测量参数

### 4.1 测量模式

**控件: RadioButton 组**

三个互斥选项，决定距离计算方式:

```
+---------------------------------------------+
|  测量参数                                     |
|                                              |
|  测量方式:                                    |
|  O 中心距  (圆心到圆心的距离)                 |
|  O 最小边距 (圆心距 - R1 - R2)               |
|  O 最大边距 (圆心距 + R1 + R2)               |
|                                              |
|  测量单位:  [ComboBox: px | mm v]            |
|  像素当量:  [_________]  mm/pixel            |
|  小数位数:  [_________]  0~6                 |
+---------------------------------------------+
```

各模式图解:

```
中心距:         最小边距:         最大边距:
  C1--d--C2       C1--d--C2        C1--d--C2
   |<--->|         |<----->|        |<--------->|
   d = centerDist  d - R1 - R2      d + R1 + R2
```

**测量方式说明:**

| 模式 | 计算公式 | 物理含义 | 典型应用 |
|------|----------|----------|----------|
| 中心距 | sqrt((x2-x1)^2 + (y2-y1)^2) | 两个圆心之间的欧氏距离 | 孔距测量、位置度检测 |
| 最小边距 | centerDist - R1 - R2 | 两个圆最近部分之间的距离 | 壁厚测量、间隙检测 |
| 最大边距 | centerDist + R1 + R2 | 两个圆最远部分之间的最大距离 | 外径范围检测 |

---

### 4.2 测量单位

**控件: ComboBox**

| 选项 | 说明 |
|------|------|
| 像素 (px) | 直接输出像素距离 |
| 毫米 (mm) | 通过像素当量换算为物理距离 |

**像素当量 (PixelCalibration)**

当选择 mm 单位时，像素当量输入框变为可编辑状态:
- 类型: NumericTextBox
- 默认值: 1.0
- 范围: 0.0001~1000.0
- 标签: "mm/pixel"

换算公式:
```
Distance_mm = Distance_px * PixelCalibration
```

---

### 4.3 小数位数

**控件: NumericTextBox**

- 默认值: 2
- 范围: 0~6
- 影响所有测量数值的显示精度（包括距离值、圆心坐标）

---

### 4.4 公差设定

**控件: ToggleSwitch + 数字输入框**

```
+---------------------------------------------+
|  公差设定                                     |
|                                              |
|  启用公差: [ToggleSwitch]                    |
|                                              |
|  公差上限: [_________]  (mm或px,根据单位)     |
|  公差下限: [_________]  (mm或px,根据单位)     |
+---------------------------------------------+
```

公差行为:
- 启用公差开关关闭时，上限/下限输入框禁用 (灰色)
- 启用公差开关打开时，上限/下限输入框可编辑
- 公差值单位与"测量单位"保持一致 (px 或 mm)
- 公差判定: Distance 在 [LowerLimit, UpperLimit] 范围内为 OK，否则为 NG

## 五、Tab3 — 结果显示

### 5.1 结果判断

显示当前测量结果是否在公差范围内:

```
+---------------------------------------------+
|  结果判断                                     |
|                                              |
|  判断结果:  [OK] / [NG]                       |
|                                              |
|  状态说明:                                     |
|  - OK: 测量值在公差范围内                      |
|  - NG: 测量值超出公差范围                       |
|  - 如果未启用公差，始终显示 OK                  |
+---------------------------------------------+
```

---

### 5.2 图形显示

图像上绘制测量相关的图形标记，用于直观展示测量结果。

**绘制要素:**

| 绘制项 | 颜色 | 样式 | 说明 |
|--------|------|------|------|
| 圆心1 标记 | 红色 (Red) | 十字线 + 点 | 标记圆1的圆心位置 |
| 圆心2 标记 | 黄色 (Yellow) | 十字线 + 点 | 标记圆2的圆心位置 |
| 两圆心连接线 | 绿色 (Green) | 实线 2px | 连接两圆心的测量辅助线 |
| 圆1轮廓 | 青色 (Cyan) | 实线 2px | 圆1的圆周轮廓 |
| 圆2轮廓 | 青色 (Cyan) | 实线 2px | 圆2的圆周轮廓 |

图形布局示意:

```

        +-----+
   +---(  C1  )---+-------------- 青色轮廓(圆1)
   |    +-----+    \
   |                \    +-----+
   | 绿色连接线       +---(  C2  )---+
   |  (两圆心之间)        +-----+   |
   |                              |
   | C1: 红色十字     C2: 黄色十字 |
   +------------------------------+
                   青色轮廓(圆2)
```

**十字标记尺寸:**
- 十字线长度: 6px (每个方向)
- 十字线线宽: 1px
- 圆心点半径: 2px

---

### 5.3 文本显示

测量结果以文本形式叠加在图像上，放置在图像右上角区域。

**显示内容:**

| 文本项 | 颜色 | 字体大小 | 内容格式 |
|--------|------|----------|----------|
| 测量值 | 白色 (White) | 14pt | "测量值: 123.45 px" |
| 圆心1坐标 | 红色 (Red) | 12pt | "圆心1: (123.45, 678.90)" |
| 圆心2坐标 | 黄色 (Yellow) | 12pt | "圆心2: (123.45, 678.90)" |

文本布局 (图像右上角):

```
+-------------------+
| 图像区域            |
|                    |
|  +--------------+  |
|  | 测量值: XX.XX|  |  白色, 14pt
|  | 圆心1: (..)  |  |  红色, 12pt
|  | 圆心2: (..)  |  |  黄色, 12pt
|  +--------------+  |
|                    |
+-------------------+
```

## 六、参数数据模型

### 6.1 CircleToCircleParameters 结构

工具参数分为三组，对应三个 Tab:

**基本参数 (Tab1):**
- 图像源: InputSource (ImageSourceSelector 输出)
- 圆1输入方式: Circle1InputMode (圆拾取/参数输入)
- 圆1链接: Circle1LinkSource (链接工具名称+圆索引)
- 圆1参数: Circle1X, Circle1Y, Circle1R
- 圆2输入方式: Circle2InputMode
- 圆2链接: Circle2LinkSource
- 圆2参数: Circle2X, Circle2Y, Circle2R

**测量参数 (Tab2):**
- 测量模式: MeasureMode (中心距/最小边距/最大边距)
- 测量单位: MeasureUnit (px/mm)
- 像素当量: PixelCalibration
- 小数位数: DecimalPlaces
- 启用公差: IsToleranceEnabled
- 公差上限: ToleranceUpper
- 公差下限: ToleranceLower

**显示参数 (Tab3):**
- 显示圆心1标记: ShowCenter1Marker
- 显示圆心2标记: ShowCenter2Marker
- 显示连接线: ShowConnectingLine
- 显示圆轮廓: ShowCircleOutline
- 显示文本: ShowTextInfo

## 七、交互行为

### 7.1 图像源选择交互

- 选择新图像源时，自动清除之前的测量结果
- 图像源为空时，Tab2 和 Tab3 的所有控件禁用 (灰色)
- 图像源改变时触发自动重算 (如果已配置圆源)

### 7.2 圆输入切换交互

- 按圆拾取 与 按参数输入 切换时，保持另一方式的值
- 从按圆拾取切换到按参数输入: 从链接工具的当前结果中提取圆参数填充到输入框
- 从按参数输入切换到按圆拾取: 保留已配置的链接关系，如果没有链接则要求用户链接

### 7.3 单位切换交互

- 从 px 切换到 mm: 自动根据像素当量换算并更新显示值
- 从 mm 切换到 px: 自动换算回像素值
- 像素当量为 0 时显示警告 "像素当量不能为0"

### 7.4 公差与结果联动

- 公差值改变时，自动更新结果判断 (OK/NG)
- 公差开关关闭时，结果始终为 OK
- 测量模式改变时触发重算，并更新判定

## 八、错误与异常处理

| 场景 | 用户提示 | 工具行为 |
|------|----------|----------|
| 未选择图像源 | "请选择输入图像" | 禁止运行，Tab2/Tab3 禁用 |
| 圆1未配置 | "请配置圆1输入" | 禁止运行 |
| 圆2未配置 | "请配置圆2输入" | 禁止运行 |
| 圆1圆2为相同圆 | "圆1和圆2不能相同" | 禁止运行 (仅链接模式) |
| 像素当量为0 | "像素当量不能为0" | 使用默认值 1.0 替代 |
| 链接工具无输出 | "链接工具未产生结果" | 显示提示，等待工具重新运行 |
| 公差上限<下限 | "公差上限不能小于下限" | 交换上限下限值 |

## 九、与其他工具的关系

| 前置工具 | 关联方式 | 说明 |
|----------|----------|------|
| CircleFinder | 按圆拾取链接 | 用户选择圆查找工具的输出作为圆输入 |

| 同层工具 | 区别 |
|----------|------|
| PointToPoint测量 | 测量两点距离，不涉及半径 |
| PointToLine测量 | 测量点到线的垂直距离 |
| PointToCircle测量 | 测量点到圆边缘/中心的距离 |
| LineToLine测量 | 测量两线段/点线距离 |
| LineToCircle测量 | 测量线到圆的距离 |

圆圆测量工具是测量工具组的核心成员，专门处理圆形特征之间的位置关系。

## 十、参数序列化

采用 System.Text.Json + 多态序列化:

```
[JsonDerivedType(typeof(CircleToCircleParameters), "CircleToCircle")]
public class CircleToCircleParameters : ToolParameters
```

序列化内容包括:
- 三个 Tab 的所有参数值
- 圆链接关系 (工具名 + 圆索引)
- 显示样式设置

序列化示例 (JSON 结构):

```json
{
  "$type": "CircleToCircle",
  "InputSource": { "SourceToolName": "CircleFinder1", "SourceOutputKey": "OutputImage" },
  "Circle1InputMode": "Link",
  "Circle1LinkTool": "CircleFinder1",
  "Circle1LinkIndex": 1,
  "Circle2InputMode": "Manual",
  "Circle2X": { "Value": 250.0 },
  "Circle2Y": { "Value": 300.0 },
  "Circle2R": { "Value": 80.0 },
  "MeasureMode": "CenterDistance",
  "MeasureUnit": "mm",
  "PixelCalibration": { "Value": 0.05 },
  "DecimalPlaces": 2,
  "IsToleranceEnabled": true,
  "ToleranceUpper": { "Value": 10.0 },
  "ToleranceLower": { "Value": 8.0 }
}
```
