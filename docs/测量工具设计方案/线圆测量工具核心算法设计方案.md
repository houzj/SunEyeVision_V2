# Line-Circle Measurement Tool Core Algorithm Design

## 1. Overview

The Line-Circle measurement tool computes the distance between a line and
a circle. It supports two measurement modes: Center-to-Line distance and
Shortest distance. The tool also supports inside/outside sign conventions
to produce signed distance values.

The core mathematics involves computing the perpendicular distance from
the circle center to the line, optionally subtracting the circle radius,
and applying a sign based on the selected inside/outside mode.

## 2. Input Data Structures

### 2.1 Line Parameters

A line is represented in the standard form:

    A * x + B * y + C = 0

Where:
- A, B, C are the line coefficients (floating point)
- (A, B) is the normal vector of the line
- The direction vector of the line is (B, -A)

A line can also be defined by two points (X1, Y1) and (X2, Y2).
The conversion to standard form:

    A = Y2 - Y1
    B = X1 - X2
    C = X2 * Y1 - X1 * Y2

After conversion, the coefficients are normalized so that sqrt(A^2+B^2)
equals 1. This normalization simplifies distance calculations and avoids
floating-point precision issues.

### 2.2 Circle Parameters

A circle is represented by:

    CenterX     The X coordinate of the circle center (pixels)
    CenterY     The Y coordinate of the circle center (pixels)
    Radius      The radius of the circle (pixels, must be >= 0)

If a negative radius is provided, the tool takes its absolute value
before proceeding.

## 3. Measurement Modes

### 3.1 Mode 1: Center to Line Distance (centerDist)

This mode calculates the perpendicular distance from the circle center
point to the line.

    signedCenterDist = (A * Cx + B * Cy + C) / sqrt(A^2 + B^2)
    absCenterDist    = |signedCenterDist|

where (Cx, Cy) is the circle center point.

The signed distance indicates which side of the line the center lies on.
A positive signed value means the center is on the same side as the
normal vector (A, B). A negative value means the opposite side.

Use case: Checking whether a circle center is properly aligned with
a reference line in an assembly inspection task.

### 3.2 Mode 2: Shortest Distance (shortestDist)

This mode calculates the minimum distance from the circle boundary (edge)
to the line.

    centerDist    = |A * Cx + B * Cy + C| / sqrt(A^2 + B^2)
    shortestDist  = max(0, centerDist - Radius)

When the circle does NOT intersect the line:

    centerDist > Radius
    shortestDist = centerDist - Radius

This is the positive gap between the circle edge and the line.

When the circle DOES intersect the line:

    centerDist <= Radius
    shortestDist = 0

The circle and line have at least one overlapping point.

Use case: Detecting clearance or interference between a circular object
and a straight reference edge.

## 4. Inside/Outside Sign Convention

The sign of the final distance value is determined by the signed
center-to-line distance combined with the Inside/Outside mode.

### 4.1 Sign Convention Definition

The signed center-to-line distance is:

    signedDist = (A * Cx + B * Cy + C) / sqrt(A^2 + B^2)

This value ranges from -inf to +inf. Zero means the center lies exactly
on the line.

### 4.2 Inside Mode

Result = +signedDist (no change)

The distance is positive when the center is on the inside side of the
line, negative when on the outside side.

### 4.3 Outside Mode

Result = -signedDist (inverted sign)

The distance is positive when the center is on the outside side of the
line, negative when on the inside side.

This is equivalent to swapping the definition of "inside" and "outside".

### 4.4 Nearest Mode

Result = +|signedDist| (absolute value, always positive)

The distance is always reported as a positive value regardless of which
side the center lies on.

This is useful when the user only cares about the magnitude of the
distance, not the direction.

## 5. Complete Algorithm

The end-to-end algorithm proceeds as follows:

    Input values:
        Line coefficients:  A, B, C
        Circle parameters:  Cx, Cy, Radius
        Mode:               CenterToLine | Shortest
        Side:               Inside | Outside | Nearest
        Calibration:        pixel calibration (mm/px)
        Unit:               px | mm
        DecimalPlaces:      0 to 6
        ToleranceEnabled:   true | false
        UpperLimit:         upper tolerance bound
        LowerLimit:         lower tolerance bound

    Step 1 -- Normalize line coefficients

        denom = sqrt(A * A + B * B)
        if denom == 0:
            return error "invalid line: A and B cannot both be zero"
        A_norm = A / denom
        B_norm = B / denom
        C_norm = C / denom

    Step 2 -- Compute signed and absolute center-to-line distance

        signedCenterDist = A_norm * Cx + B_norm * Cy + C_norm
        absCenterDist    = abs(signedCenterDist)

    Step 3 -- Compute raw distance based on mode

        if Mode == CenterToLine:
            rawDist = absCenterDist
            signedRawDist = signedCenterDist
        else: // Shortest
            rawDist = max(0, absCenterDist - Radius)
            signedRawDist = rawDist * sign(signedCenterDist)

    Step 4 -- Apply inside/outside sign

        if Side == Inside:
            signedResult = signedRawDist
        else if Side == Outside:
            signedResult = -signedRawDist
        else: // Nearest
            signedResult = rawDist

    Step 5 -- Convert units

        if Unit == mm:
            finalDist = signedResult * Calibration
        else:
            finalDist = signedResult

        pixelDist = rawDist

    Step 6 -- Apply tolerance

        if ToleranceEnabled:
            absDist = abs(finalDist)
            if absDist >= LowerLimit AND absDist <= UpperLimit:
                isPass = true
                msg = "OK"
            else:
                isPass = false
                msg = "Out of tolerance"
        else:
            isPass = true
            msg = "OK"

    Step 7 -- Round

        finalDist = round(finalDist, DecimalPlaces)

    Step 8 -- Assemble output

        Output.Distance       = finalDist
        Output.DistancePixels = pixelDist
        Output.Mode           = Mode
        Output.Side           = Side
        Output.CenterCoord    = (Cx, Cy)
        Output.IsPass         = isPass
        Output.Message        = msg

## 6. Output Data Structure

The tool produces the following output fields:

    Field            Type        Description
    -----            ----        -----------
    Distance         double      Final measurement value in the selected
                                 unit (px or mm). May be signed depending
                                 on the Inside/Outside mode. Rounded to
                                 the configured decimal places.

    DistancePixels   double      Raw absolute distance in pixels before
                                 unit conversion. Not affected by the
                                 DecimalPlaces setting. Always positive
                                 (absolute value of the center-to-line or
                                 shortest distance before sign application).

    Mode             enum        The measurement mode used:
                                 0 = CenterToLine
                                 1 = Shortest

    Side             enum        The inside/outside mode used:
                                 0 = Inside
                                 1 = Outside
                                 2 = Nearest

    CenterCoord      PointF      The original circle center coordinates
                                 (Cx, Cy) in pixel units. Stored as a
                                 2D floating-point point structure.

    IsPass           bool        True when the measured value is within
                                 the tolerance range or tolerance is
                                 disabled. False when out of tolerance.

    Message          string      Status description. "OK" for valid
                                 measurements. "Out of tolerance" for
                                 tolerance failures. Error descriptions
                                 for invalid inputs.

## 7. Edge Cases and Error Handling

### 7.1 Degenerate Line (A and B both zero)

When both A and B are zero, the line equation becomes C = 0, which is
not a valid line representation. The tool returns:

    IsPass  = false
    Message = "Invalid line: coefficients A and B cannot both be zero"

The Distance value is set to double.NaN.

### 7.2 Zero-Radius Circle

When Radius is 0, the circle degenerates to a point. In this case:

- CenterToLine mode: Result equals the center-to-line distance.
- Shortest mode: Result equals the center-to-line distance (since
  subtract 0 has no effect).

This is treated as a valid input case.

### 7.3 Circle Intersects Line

In Shortest mode, when absCenterDist <= Radius, the circle and line
intersect. The shortest distance is 0. This is a mathematically correct
result and is always valid.

### 7.4 Negative Radius

If the input circle has a negative radius, the tool takes the absolute
value: Radius = abs(Radius). This prevents invalid negative radius
calculations.

### 7.5 Zero or Negative Pixel Calibration

When the unit is set to "mm" and the pixel calibration value is <= 0,
the tool returns:

    IsPass  = false
    Message = "Invalid pixel calibration: must be greater than zero"

Distance is set to double.NaN.

### 7.6 Numeric Overflow

For very large coordinate values (e.g. > 1e9 pixels), the intermediate
multiplications A*Cx, B*Cy may overflow. The tool uses double-precision
floating point (64-bit IEEE 754) which provides approximately 15-16
decimal digits of precision. Coordinate values up to 1e6 are safe.

## 8. Coordinate System

All coordinates use the standard image coordinate system:

- X axis: horizontal, increasing to the right
- Y axis: vertical, increasing downward
- Origin: (0, 0) at the top-left corner of the image
- Unit: pixels

The line equation Ax + By + C = 0 uses the same coordinate system.
The circle center coordinates (Cx, Cy) also use this system.

## 9. Precision Considerations

1. Line normalization is performed before any distance calculation to
   ensure that the denominator sqrt(A^2 + B^2) is computed only once
   and is exactly the unit normal. This improves both speed and accuracy.

2. When the line is nearly horizontal or vertical, the normalization
   step prevents catastrophic cancellation in signed distance computation.

3. The sign function sign(x) returns:
   - 1 if x > 0
   - -1 if x < 0
   - 0 if x == 0

4. Rounding uses midpoint rounding away from zero (System.MidpointRounding.
   AwayFromZero) to match typical measurement expectations.

### 10.2 Basic Shortest Distance

Input:  Line y=0  (A=0, B=1, C=0), Circle (0, 5, r=2)
Mode:   Shortest, Inside
Output: Distance=3.0, DistancePixels=3.0, IsPass=true

Input:  Line y=0  (A=0, B=1, C=0), Circle (0, 1, r=3)
Mode:   Shortest
Output: Distance=0.0 (circle overlaps line)

Output: Distance=5.0
